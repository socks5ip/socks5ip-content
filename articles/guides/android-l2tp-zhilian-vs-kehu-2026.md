# 安卓直连 L2TP 还是装客户端：一条线还是一批线

系统设置里拨号直连，还是装个客户端管一批线路，分界不在速度，在你要换的是一个 App 的出口，还是整台手机的出口。

**安卓系统自带 L2TP 直连零安装、全机流量一起走，但同一时间只能挂一条线路，换 IP 要重填 6–7 个输入项；第三方客户端把线路存成列表，可多条并存，并能只让勾选的应用走代理。**

| 维度 | 系统自带 L2TP 直连 | 第三方客户端 |
|---|---|---|
| 接管谁 | 整台手机的流量 | 你勾选的应用，其余直连 |
| 同时几条线 | 一次只能一条 | 可存多条，随时切 |
| 换一次 IP | 断开、改参数或新建，重填表单 | 列表里点另一条 |
| 要装东西吗 | 不用，系统自带 | 要装，且客户端质量参差 |
| Android 12 以后 | 部分机型已无该类型 | 不受系统版本影响 |

数据来源：Android 系统隧道设置项与站内实测口径（2026-11-24 复核）｜机型差异以系统设置为准

## 系统那条做的是全隧道，客户端做的是规则路由

**拨通系统 L2TP 之后，所有愿意走默认网络的程序都从这条隧道出去，包括你不希望它换出口的银行客户端；客户端的流量由软件自己挑，没命中规则的原地不动。**

这一层差别在日常使用里非常具体：同一台手机上，一个要换地区的工作 App 和一个要正常收验证码的工具，系统直连一开，两个一起换地区。客户端可以只让前者走代理，后者继续用本地网络。

代价也不同。系统那条零权限申请，稳定性接近系统本身；客户端要装 APK、要给网络权限、要常驻一个前台服务，部分机型还会因省电策略把它的后台掐掉，表现是用着用着变回本地出口。

## 同一时间只能有一条隧道在线，这是系统层面的限制

**Android 同一时刻只允许一条系统隧道处于连接状态，所以系统直连没法两条线并存；换 IP 只能断开再改，或者新建一条。**

这条限制不是厂商偷懒。它带来两个连带后果：一是线路交替使用时每次切换都会断一次；二是配置会堆积——换过几次之后，隧道列表里留下三四条名字相近的配置，谁也记不清哪条对应哪个地区，只能逐条连上去看出口。

客户端的处理方式是把线路存成一条条可命名的记录，切换只是列表里点一下，不用重建。这一点在一天要换三五个 IP 的场景里，省下的不是几秒钟，是「重复填表」这件事本身。

## 换一次 IP 要重填六到七个空，成本在这里

**系统里换一次出口，要么修改现有配置（服务器地址、预共享密钥、账号、密码），要么新建一条（还要加名称、类型，部分机型多一个 DNS 栏），六到七个字段一个都不能错。**

填错的表现不是立刻报错，而是转圈半分钟后失败，排查又得从头来。这条成本在低频场景里可以忽略：一周只换一次、换完长期挂着的人，感觉不到它。

高频场景就不一样了。一天换三五次，时间全花在填表上；这时候该比较的已经不是哪条路更快，而是哪条路能少做重复动作。

| 换 IP 的动作 | 系统直连 | 客户端 |
|---|---|---|
| 切到另一条已有线路 | 断开 → 列表选另一条 → 重连 | 列表点一下，自动重连 |
| 换一条全新线路 | 新建配置，重填六到七个空 | 粘贴一行或手填四项，保存 |
| 两条线交替用 | 来回切，切一次断一次 | 两条都在列表里，互不干扰 |
| 清理旧线路 | 逐条长按删除 | 批量删，或整组导入导出 |

## 只让一个 App 换出口，系统给不了这个开关

**原生 Android 的系统拨号面板没有「只让某几个应用走代理」的开关，少数定制系统自带分应用代理，多数机型没有；这是两条路最难互相替代的一处。**

客户端通常还带三样东西：按应用勾选的名单、按域名或 IP 段匹配的规则表、以及一个能看见当前连接状态的悬浮窗。悬浮窗经常被忽略，但它解决的问题很实在——随时知道现在走的是哪条线，不用切回主界面确认。

选客户端时要看一个指标：最近一次更新时间。这类工具多为个人或小团队维护，版本更新不规律，个别版本在新系统上会出现前台服务被回收，表现为突然变回本地 IP。功能列表好看，不如更新日期新。

## 什么时候系统直连就够了

**只换整机出口、一周动不了几次、装的又是系统还保留 L2TP 的机型——这三种情况叠加，系统直连最省事。**

反过来，需要按应用分流、需要几条线并存、或者机型升级后已经找不到 L2TP 这一项，就只能走客户端。判断顺序建议是：先定要换的是一个 App 还是整机，再定换线频率，最后才看协议与价格。

线路本身是同一个东西：SK5 单条和 L2TP 一份是两种交付形态，客户端吃前者，系统拨号吃后者。买之前先确认手上这条线能不能填进你选的那条路，比价比到最后发现协议不匹配，是最常见的白花钱方式。

## 常见问题

**问：安卓 12 以后还能用系统自带 L2TP 吗？**
答：部分机型已经把这一项去掉了，设置里找不到「L2TP/IPSec PSK」就只能走客户端或换协议。

**问：系统直连能不能同时挂两条线？**
答：不能。同一时间只允许一条隧道连接，两条线只能切换，不能并存。

**问：客户端会不会更慢？**
答：多一层转发理论上多一点开销，但实际体感差别主要来自线路本身，不是客户端。

**问：只让一个 App 走代理，系统能做到吗？**
答：原生系统做不到，少数定制系统有分应用代理；通用做法是装客户端按应用勾选。

**问：换 IP 后 App 里还是显示旧地址怎么办？**
答：先确认隧道是否真的重连成功，再看 App 是否走了代理通道；缓存类应用建议强停后重开。

**问：SK5 线路能填进系统自带的拨号面板吗？**
答：不能。系统拨号只认 L2TP/PPTP 这类协议，SK5 要走客户端。

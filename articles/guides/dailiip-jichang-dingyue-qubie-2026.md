# 买出口和买通路，是两门不同的账

2.24 元买到一条可以指定城市、可以独占的出口，同一笔钱投进机场订阅，换回来的是几百兆流量和一批共享节点——出口落在哪个城市由服务商调度。两件商品的计价单位不是一回事，谁更便宜没法直接横着比。

## 一句话结论

代理IP 卖的是**可指定、可独占的出口身份**，机场卖的是**能连出去的通路**。前者按条（或按窗口）计价，后者按流量或时长计价——除了「都涉及网络出口」，两件商品之间没有替代关系。

| 口径 | 代理IP | 机场订阅 |
|---|---|---|
| 计价单位 | 元/条·月，或元/窗口 | 元/GB，或元/月含流量 |
| 出口归属 | 档位表里直接标覆盖城市，可按地区挑 | 由服务商集中调度，不承诺对应哪个城市 |
| 是否独占 | 可独享（独享线路 / 静态住宅 / 个人定制档） | 共享节点，同一出口可能还有别的用户 |
| 能接什么 | SK5 / HTTP / L2TP / PPTP，模拟器、指纹浏览器、软路由直填 | 订阅链接导入客户端，客户端里点一下就切 |
| 起步价参照 | 站内 23 家里最低 2.24 元/条·月（光梭IP） | 视流量包大小，与出口身份无关 |

（数据取自站内跨平台比价页，月卡最低档口径，核实于 2026-09-13；价格如调整以平台后台实时显示为准。）

## 交付物的差别：一条线路，还是一份订阅

代理IP 交付的是一条条具体线路，每条对应一个出口地址，你能知道它落在哪个城市、是不是住宅段、独不独占、能撑多大带宽。站内比价页上 23 家平台就是从这几个维度切档位的：光梭IP 走「四协议全能 + 全国 700+ 地区」，奔富IP 走「独享 SOCKS5 线路 + 大 IP 池」，沧海IP 走「百兆 + 八大区 + 静态住宅」，鲸云IP 走「机房 / 家庭 AB / 定制 AB + 350+ 城市」。这些平台卖的都是**出口本身的属性**。

机场交付的不是出口，是通路。它把一批节点挂在订阅文件里，客户端拉一次订阅就拿到一串节点，用户在客户端点一下切换。节点出口地址通常不对外承诺，也不承诺独占——同一台节点机器上往往还有别的订阅者，只是互相看不见。

一句区分方式：**要的是「让这个账号从这个地方出去」，选代理IP；要的是「能出去」，订阅更省事。**

## 两个分母，不能横着比

价格对比最容易出错的一步，是拿两种计价单位直接比大小。代理IP 按条（或按窗口）卖，机场按流量或时长卖，分母不是一回事。

| 计费口径 | 单位 | 成本怎么长 | 典型吃力点 |
|---|---|---|---|
| 代理IP · 月卡 | 元/条·月 | 跟着条数线性长：按 2.24 元档算，10 条约 22.4 元、20 条约 44.8 元 | 条数多、切换少 |
| 代理IP · 天卡 / 周卡 | 元/条·天 | 单价约为月卡折算的 3–4 倍，短期项目划算 | 长期跑 |
| 代理IP · 切换额度 | 次/条 或 次/月 | 摊到每次的成本差异很大：**2000 次/月约 0.002 元/次**，**30 次/条约 0.113 元/次** | 高频换 IP 的业务 |
| 机场 · 流量包 | 元/GB | 跟着流量长：下载、看视频、传文件都会吃额度 | 大流量下载 |
| 机场 · 时长 | 元/月 或 元/年 | 跟时间走，与你要几条出口无关 | 需要出口身份时用不上 |

这里有个反直觉的地方：**按流量买不一定更省，前提是你真的用得少**。如果业务是「10 个模拟器挂着不动」，流量很小但需要 10 个不同出口，按流量买到的那点便宜换不来 10 个出口；反过来，只是偶尔下载，买 20 条代理IP 是纯浪费。

切换额度的差价同样值得先算一遍：站内比价页给出的数字从「30 次/条·月」（JiuIP 月卡）到「2000 次/月」（光子IP、天机IP、优众IP）都有，按 4 元档折下来，前者的单次成本是后者的 **50 倍以上**。所以比价不能只看起步价，切割换次数、协议、免费测试额度一起看才有意义。

## 只有代理IP 办得到的四件事

「先用机场顶一下」是这类问题里问得最多的一句。下面四件事是机场结构上做不到的，跟它好不好用无关：

| 你要的能力 | 机场为什么给不了 | 代理IP 怎么给 |
|---|---|---|
| 指定城市 / 地区 | 节点出入口由服务商集中调度，用户手上只有节点名 | 档位表直接标覆盖范围（全国 700+ / 350+ / 300+ 城），可按地区挑 |
| 独占出口 | 节点共享，同一出口可能同时有别的用户 | 独享 SOCKS5 线路、静态住宅档、个人独享定制档 |
| 被模拟器 / 软路由直连 | 客户端装的是订阅，协议与模拟器、路由器原生不兼容 | SK5 / HTTP / L2TP / PPTP 四协议，指纹浏览器、ROS / 爱快 / OpenWrt 都能直接填 |
| 按窗口分配 | 没有「窗口」概念，只有「一个客户端连一个节点」 | 一条线路对一个窗口，可做成单窗口单 IP |

这四条叠起来就是多账号类业务的刚需：这类账号要的不是一条能连出去的通路，而是一个稳定的、跟别的账号不重合的出口身份。

## 反过来：这两件活别指望代理IP

边界另一头也要说清楚，不然同样会买错：

| 场景 | 为什么代理IP 不合适 |
|---|---|
| 只是人手动浏览境外站点 | 单条代理IP 通常绑定一个出口，换站点要手动切，体验不如订阅拉一串节点 |
| 大流量下载、看高清视频 | 低价档带宽多在 1–10M，按条买的成本会随流量撑不住；这类需求要看大带宽档（站内 20 元档、海外独享档） |

另外提醒一句：机场用的协议（SS / VMess / Trojan 这一类）和代理IP 用的协议（SK5 / HTTP / L2TP / PPTP）**不是同一套东西，客户端也不通用**。买之前对着代理协议对照表看一眼「能不能给路由器用 / 能不能给模拟器用」，能省一轮试错。

## 下单前先答三个问题

不用记协议名，按下面三个问题依次答，落点自然出来：

| 问题 | 答「是」的落点 |
|---|---|
| 需要 1 个以上、且要互不重合的出口同时在线？ | 代理IP，按条买 |
| 出口要能指定城市、或长期固定不变？ | 代理IP，静态住宅档或长效静态档 |
| 用出口的是模拟器 / 指纹浏览器 / 软路由 / 采集脚本？ | 代理IP，SK5 或 L2TP 直填 |

三个问题全部答「否」、只是人手动浏览，那就没必要为出口属性多付钱。两种一起用也不冲突——本机日常浏览走订阅客户端，业务程序单独配代理IP，互不干扰。

真要从代理IP 里挑，下单前做两件事：把全平台价格中心的档位价横向拉一遍，再把免费测试额度用掉。免费测试各家给法不同：光梭IP 5 条/天、蛟龙IP 2 条/天、沧海IP / 光子IP / 天机IP / 天行IP / 优众IP 各 10 条、JiuIP 一次性 30 次、长城IP 2 小时、无忧IP 5 小时。**先测再买，能避掉大半「买完发现带宽不够」的情况。**

## 常见问题

**Q：机场订阅能不能拿来做游戏多开？**
A：结构上不行。订阅给的是节点，一个客户端连一个节点，没有「哪个窗口走哪条线路」的分配方式；多开要的是每条线路对一个窗口，那需要能按窗口配的 SK5 / L2TP 出口。另外节点出口不承诺独占，多个账号走同一个共享出口，隔离意义有限。

**Q：代理IP 能不能像机场那样用订阅链接一键导入？**
A：少数平台支持 API 提取和订阅式分发，但主流做法还是「后台取线路 → 填进工具」。原因是代理IP 每条线路都是独立资源，界面必须让你看见条数、带宽、地区这些属性，一键导入反而会把这些信息藏起来。要走自动化，优先挑带 API 提取的平台。

**Q：只是让浏览器访问境外站点，需要买代理IP 吗？**
A：通常不用。这类需求看重「通不通、快不快」，出口身份无所谓，订阅制更省事也更便宜。只有当站点会校验出口地区一致性、或者你需要固定某个地区的出口时，才轮到代理IP 上场。

**Q：代理IP 月卡 2.24 元起，是不是比机场便宜？**
A：这两个数字不同量纲，不能直接比。2.24 元买的是一条月卡线路；机场套餐买的是含一定流量的通路。要比就得把自己的用量折算成「每月要几条出口 + 每月大概切几次」，再跟机场的流量单价对齐。折算完的规律是：**出口条数越多、流量越小，代理IP 越划算。**

**Q：同一个出口 IP 被平台标记了，换节点有用吗？**
A：看标记是怎么落下来的。按出口地址记的，换一个不重合的出口就有用；按设备指纹、行为特征记的，换出口只是把下一次触发推迟。先用 IP 综合检测中心看一次出口的归属地与纯净度，比盲目换线路省额度。

**Q：代理IP 和机场能同时用吗？**
A：能，而且很常见：本机日常浏览走订阅客户端，业务程序（模拟器、采集脚本、指纹浏览器）单独配代理IP。注意别让两者互相接管流量——客户端一旦开了全局模式，业务程序里填的代理会被绕过去，表现为「填了代理、检测出来还是本地 IP」。排查方法就是关掉客户端全局模式，或按进程分流。

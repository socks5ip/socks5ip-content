# 公网IP和私网IP有什么区别？

## 一句话结论

**公网 IP = 全球唯一的"互联网门牌号"（可直接被访问）；私网 IP = 局域网内部的"工位号"（10.x / 172.16-31.x / 192.168.x，只能内网通信，靠路由器 NAT 上网）。** 家用设备拿私网 IP 很正常，只有"要从外面访问家里服务"才需要公网 IP。

## 核心区别

| 对比项 | 公网 IP | 私网 IP |
|---|---|---|
| 唯一性 | 全球唯一 | 仅局域网内唯一 |
| 能否被互联网访问 | 能，直接可达 | 不能，需 NAT 转换 |
| 典型地址 | 运营商分配（如 111.32.x.x） | 192.168.x.x / 10.x.x.x |
| 成本 | 通常需申请/付费 | 路由器自动分配，免费 |
| 适用 | 建站、服务器、远程访问 | 家庭/公司设备上网 |

私网保留地址段（公网不会用）：`10.0.0.0/8`（大型内网）、`172.16.0.0/12`（中型）、`192.168.0.0/16`（家庭最常见）——看到 192.168 开头基本就是私网。

## 怎么自查自己是公网还是私网

1. **看本机地址**：Windows「网络设置-查看属性」/ 手机「Wi-Fi 详情」——是 192.168.x.x / 10.x.x.x 说明在路由器内网；
2. **看出口地址**：用检测工具看"互联网看到的你的 IP"，那才是真正的公网出口。本机私网 + 出口公网是标准家庭架构，不是问题。

## 什么时候才需要公网 IP

- **自建网站/服务**：要让别人访问，必须有公网 IP（或云服务器）
- **远程访问 NAS/监控**：人在外面看家里设备，需公网 IP 或内网穿透
- **游戏联机**：部分游戏对 NAT 类型敏感，公网 IP 联机更顺畅

只是上网/看视频/办公/打游戏（不建服），私网 IP + 运营商出口完全够用，不用刻意申请。

## 拿不到公网 IP 怎么办

| 需求 | 替代方案 |
|---|---|
| 外网访问家里服务 | 端口映射 + DDNS；或 frp/ZeroTier 内网穿透 |
| 直接可用公网出口 | 租云服务器（自带公网 IP） |
| 业务要多地区/纯净出口 | 代理 IP 方案（多城市出口，见价格中心） |

## 常见问题

**Q：我的 IP 是 192.168 开头，被运营商限制了吗？**
不是。192.168.x.x 是标准私网地址，你在路由器内网，公网出口在 WAN 侧，用检测工具看出口即可。

**Q：公网 IP 安全吗？**
公网 IP 会把设备暴露在互联网，需要防火墙与补丁；私网天然更"低调"，但正常使用都安全，关键在设备自身防护。

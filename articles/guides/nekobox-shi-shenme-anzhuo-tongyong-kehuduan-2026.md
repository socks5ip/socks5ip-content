# NekoBox 是什么：一个名字，三个平台三种东西

打开应用商店搜 NekoBox，先别急着点安装——三端搜到的结果，很可能不是同一款软件，只有安卓那一端才是官方在维护的正主。它是基于 **sing-box** 内核的安卓通用代理客户端，英文名 NekoBox for Android、简称 **NB4A**，以 **GPL-3.0** 开源，**自己一个节点都不带**。

## 名字一样，东西不一样

同一个词在三端指向三个不同对象，这是新手最容易踩的坑。

| 平台 | 搜到的结果 | 是不是它 |
|---|---|---|
| 安卓 | NekoBox for Android（NB4A） | 是，官方在维护的那一款 |
| iPhone / iPad | 同名或近名的 App | 不是，iOS 端没有官方版 |
| Windows | 同名的桌面程序 | 不是，那是另一个已停更的项目 |

判断方法：认内核。官方版的内核是 sing-box，关于页里能看到版本串；看不到内核信息的，基本可以放下。

## 内核决定了它能做与不能做

客户端的能力上限来自内核，不来自界面。

| 能力 | 由谁提供 | 边界在哪 |
|---|---|---|
| 多协议出站 | sing-box 内核 | 内核支持的它才支持 |
| 分流规则 | 内核路由 | 规则优先级的写法决定最终走向 |
| 整机接管 | 系统级隧道服务 | 安卓端可行，其他端不适用 |
| 节点来源 | 用户自备 | 软件本身不产出任何节点 |

所以「装上就能上网」这件事不成立：先有订阅或代理账号，才有可配的东西。

## 订阅里能带进来什么

订阅不是万能的，能不能用取决于格式是否被内核识别。

| 订阅里有什么 | 能不能导进来 | 说明 |
|---|---|---|
| 标准节点列表 | 能 | 导入后出现在节点页 |
| 代理组与规则集 | 多数能 | 取决于格式 |
| 需要额外插件的协议 | 不一定 | 得先装对应插件 |
| 非订阅的业务信息 | 不能 | 例如账号余额、套餐余量 |

## 三端各自的安装现状

安卓端能装官方版；iOS 端没有官方包，需要换用系统内可用的客户端方案；Windows 上流传的那个同名项目早已停更。这一点决定了 NekoBox 的定位：**它是安卓方案，不是跨平台方案**。要跨平台统一，得先在产品选型那一步把设备矩阵想清楚。

## 流量接管发生在哪一步

装上就「全机生效」并不神秘：客户端通过系统的隧道服务建一条本地通道，把流量引到自己的出站。这也是为什么它不能细化到「某个窗口」——接管发生在系统层，粒度自然停在应用或全局这一档。需要更细粒度时，要换到按窗口或按环境分配出口的方案。

## 两类人不必急着装

- 主要设备是 **iPhone**：没有官方版，装了也是另一个东西。
- 需要 **窗口级或环境级隔离**：接管粒度对不上，装完仍要另想办法。

反过来，主要在**安卓机上按应用分流**、手上已有标准代理凭据的人，装它是最顺的一条路。

## 常见问题

**Q：NekoBox 是免费的吗？**
客户端免费，GPL-3.0 开源。要花钱的只有线路，站内价格中心里最低月卡档位 2.24 元/月起。

**Q：iPhone 上有 NekoBox 吗？**
没有官方版本。iOS 上搜到的同名应用并不是它，需要换用 iOS 端可用的客户端方案。

**Q：装上以后一个节点都没有，正常吗？**
正常。它不带节点，必须自己准备订阅或代理凭据，导入之后才能在节点页看到条目。

**Q：它能不能让某一款应用单独走代理？**
可以在路由里按应用维度设规则；但接管粒度停在应用这一层，做不到按窗口隔离。

**Q：和 Windows 上那个同名软件是一个东西吗？**
不是。Windows 上流传的同名项目已经停更，不是同一个作者维护的同一款客户端。

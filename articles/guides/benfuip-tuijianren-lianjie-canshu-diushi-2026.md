# 奔富IP 注册页没有推荐人栏：参数丢了也不报错

在奔富的注册表单里找不到「推荐人」这三个字，不是页面没加载完，是**它根本没有这个字段**。表单上只有用户名和密码两格。

邀请码不在页面上，在链接里。打开带参数的链接，服务器返回的是一段跳转代码，把你送到 `benfuip.com/user/login?p=` 那一页，参数名从 `aff` 换成了 `p`，值原样带过去。整个过程不需要你填任何码。

**所以「推荐人填什么」在奔富这里的答案是「没地方填」。** 归属由你打开的那条链接决定，不由你的手决定。参数丢了不会报错、不会提示，注册照样成功——只是这一单挂到了默认上级那里。

| 环节 | 实际形态 | 用户需要做什么 |
|---|---|---|
| 注册入口 | 与登录共用一页，切 tab | 点「还没有账户？点击注册」 |
| 表单字段 | 用户名、密码 | 两格填完即可提交 |
| 邀请码位置 | URL 参数 `?p=adminA1` | 打开链接时别把后半段弄丢 |
| 手机号 | 不在注册表单里，注册后单独绑 | 注册完顺手绑，别拖到付款 |
| 独立注册路由 | 不存在（`/user/register` 返回 404） | 不要自己拼地址 |

## 三种漏参，症状完全一样

**从官网首页自己找注册、链接被聊天工具截断、把参数换成别人的码——三种做法的结果都是一个：注册成功，归属不是你以为的那个。**

第一种最常见。搜到官网，点进首页，再从首页点注册。这条路径上没有任何参数，注册出来的账号挂平台默认归属。识别方法只有一条：看地址栏里还有没有 `?p=` 这一段。

第二种藏在复制粘贴里。群公告、笔记软件、聊天窗口会自动截断长链接，把 `?p=adminA1` 吃掉。手机端更明显，从聊天软件内置浏览器打开时，长链接常被改写成只剩主域。

第三种最隐蔽，因为用户以为自己在做对的事：看到某处写「填 bf168」，于是把手上链接的 `adminA1` 改成 `bf168`。这不是「填码」，这是主动改归属。

还有一种不算丢但常被误会：先注册、后补码。归属在注册那一刻就定了，注册完再想补是补不进去的——页面上没有字段，后台只有一个上级，改不了就是改不了。

## 边界：跳转链路只有一次核对的窗口

**整条链路上只有落地那一瞬间需要人眼确认，其余全是填表。** 这一步三秒钟，能省掉后面全部麻烦。

打开带参数的链接后，先别急着填。看地址栏：还是 `?p=adminA1` 就继续；如果变成光秃秃的 `/user/login`，说明参数在跳转中被吃掉，退回重开，不要在这个页面上继续填。

这个窗口是不可逆的。一旦提交，账号就生了，页面上没有任何入口能改上级。已经充值、已经提过 IP 的账号，多数平台不给改绑——因为涉及结算。所以核对只能发生在注册前，事后补救的成本高得多。

如果用户名被占用，页面会提示换一个。这时候就在当前页改，参数还在；回头从搜索结果重新进官网，参数就没了。

## 自测口径：三个位置，从前往后查

**地址栏是事前唯一的检查点，会员中心的上级一栏是事后最权威的一处，客服查询是兜底。** 三个位置任意一个能看到 `adminA1`，归属就是对的。

地址栏最简单，注册前就能看。会员中心的个人信息或账户信息里会显示上级账号，那是数据库里的真实归属，不是页面渲染出来的。两处都看不懂时，把账号发给客服问一句「我的上级是谁」即可。

一个常见误判要单独说：**会员中心上级一栏空白，不等于挂错了。** 后台返回慢、页面没渲染完、手机端把字段折叠，都会表现为空白。刷新一次、换电脑端复看，两次都空白才按漏参处理。反过来，显示了一个你不认识的账号名，那才是真挂到别人名下。

## 常见问题

**问：奔富IP 推荐人到底填什么？**
答：没有可填的地方。注册表单只有用户名和密码，归属由链接里的 `?p=` 参数决定，打开带 `adminA1` 的链接即自动关联。

**问：网上都说填 bf168，那是官方通用码吗？**
答：不是。平台没有对所有人生效的公共码，`bf168` 是某个推广者的渠道参数。链接尾巴写谁，这一单就归谁；优惠价按渠道配，不按码配。

**问：参数丢了会有什么提示吗？**
答：没有。注册照常成功，页面不报错，只有会员中心的上级一栏能看出来。

**问：已经注册错了能改吗？**
答：账号刚注册、无订单、无余额时，联系客服说明「链接参数丢失、需改绑上级」通常可以。已充值或已提过 IP 的账号多数不给改，这时改用「按优惠价改价」的路子更快——把订单截图发给客服补差。

**问：注册页只有两个框，是不是没加载全？**
答：是设计如此。手机号是注册之后的单独一步，所以注册页上看不到；没绑手机之前账号通常是半成品，能登录但可能不能付款。

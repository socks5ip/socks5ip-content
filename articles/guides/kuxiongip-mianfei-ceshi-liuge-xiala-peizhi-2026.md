# 打开「产品购买」页，六个下拉在测试期就得定死

打开酷熊的「产品购买」页，六个下拉一格格填完，周期那栏改选「免费测试」——这一步做完，测试档和付费档用的是同一张表单。**同一张表单意味着同一组选项，也意味着测试期定错的下拉，付费后会原样错下去。**

所以免费测试的产出不是「通不通」，而是一份可以直接抄进客户端的参数。

## 一句话结论

**酷熊IP 的免费测试是配置演练：用 0 元把六个下拉定死、把 SK5 与 L2TP 两套凭证各抄一遍、把出口归属核到一个具体城市。** 它的额度按订单计、条数以注册后后台实际发放为准，站内公开页面没有写死数字——**别按某个数字做计划**。测试线路可以验协议、验地区、验出口，但**不能用来判断付费档的带宽带得动几个窗口**。

| 测试期要定下来的 | 填什么 | 定错的后果 |
|---|---|---|
| 代理类型 | SK5 或 L2TP，二选一 | 付费后想换要重新下单 |
| 出口地区 | 业务对口的省份或城市 | 属地与账号定位不一致 |
| 带宽档 | 5M／7M／10M 三档里的一个 | 挂满窗口才发现不够 |
| IP 数量 | 同时要独立的出口数 | 一个出口挂多个账号 |
| 接入方式 | 提取到客户端，或隧道整机接入 | 客户端里填不进凭证 |
| 周期 | 免费测试 | 误付成日卡或周卡 |

## 六个下拉分别对应后面哪一步

**代理类型决定后面所有表单长什么样。** 选 SK5，最终拿到的是一行 host:port:user:pass；选 L2TP，拿到的是服务器地址加上账号密码，填进系统网络设置。两者不是同一套凭证格式，测试期就要把两种都看一遍，才知道自己团队会用哪一种。

**地区与带宽决定价格档。** 酷熊的价表按「协议·带宽」分行，同样是 5M，SK5 稳定档月卡 20 元，L2TP 稳定档 21 元；同样是 10M 隧道档，SK5 59 元、L2TP 80 元。测试期把带宽选到你要买的那一档，比选最低档更能暴露问题。

**IP 数量决定出口数。** 这一格最容易被当成「先填 1 试试」。填 1 只能验证一条线的行为，团队实际要 6 个出口时，测试期就该填 6，看看后台一次给几条、切换额度怎么算。

## SK5 和 L2TP 的凭证不是一个形状

**同一份订单，两种协议在客户端里的填法完全不同。** SK5 是四段式参数，L2TP 是系统层拨号。

| 项目 | SK5 提取 | L2TP 隧道 |
|---|---|---|
| 拿到的内容 | IP、端口、账号、密码四段 | 服务器地址、账号、密码 |
| 填在哪 | 客户端或指纹浏览器的代理栏 | 系统网络设置里新建连接 |
| 生效范围 | 单个程序或单个浏览器窗口 | 整台设备，或整条内网 |
| 一机多出口 | 支持，按窗口配不同参数 | 不支持，一台设备一个出口 |
| 测试期要看 | 四段是否齐全、协议是否握手成功 | 拨号是否成功、内网设备是否能通 |

酷熊的价表里 SK5 四行、L2TP 五行，同一带宽下 L2TP 通常贵 1 到 2 元。**贵的那 1 到 2 元买的是「整机生效」，不是更快的速度。**

## 测试期该产出三样东西

**第一样是一段能粘的 SK5 参数。** 不是截图，是能直接粘进客户端的四段值。粘进去之后要能看到出口变成订单里那个城市，这一步过不了，后面的测试都没有意义。

**第二样是一份 L2TP 凭证。** 哪怕你最终不用隧道，也要抄一遍——它能证明你的账号在这台设备上能建隧道，以后换软路由、换整机方案时不用重新摸索。

**第三样是出口归属的核对结果。** 用 IP 综合检测中心看出口地址、归属地与线路类型三项，和订单里选的城市对上，才算这条线可用。归属地对不上，通常是地区下拉选错或者该地区暂无资源。

## 三种最容易误判的现象

**第一种，速度分数很高就以为够用。** 测速反映的是那一刻这条管道的空闲程度，不代表它能持续承载多路窗口。**带宽够不够，只能用你打算买的档位、按实际窗口数跑一遍才知道。**

**第二种，一条线通就以为全部通。** 免费测试通常只给一两条，验证的是「协议与地区组合」这一种配置。你买了 6 个不同城市的线，测试只覆盖了其中一个城市。

**第三种，把免费测试当成免实名的通道。** 酷熊把实名前置写在明处，注册、提 IP 的环节都需要它，测试档不例外。

## 测试线路别拿去跑正式业务

**测试线路的用途是验证配置，不是提前开工。** 拿它去跑正式账号，等于把还没确认过的出口交给真实业务，一旦归属地或线路类型不对，账号侧留下的记录是撤不回的。

测试期结束前，把六个下拉的最终值抄进一张表，连同两套凭证和出口核对结果一起存档。付费后按这张表下单，就不会出现「测试时好好的，买完不通」这种情况。

## 常见问题

### 酷熊的免费测试能测几条？

注册后在后台按实际发放为准，站内公开页面没有写死条数。做计划时按「能验证一种配置」来估，不要按数字排产。

### 免费测试的线路和付费后拿到的是一样的吗？

不是同一批。测试走测试节点，付费后按你下单的地区、带宽、时长组合分配正式节点，所以测试只能证明协议通、地区有，证明不了付费档的带宽表现。

### 测试期选最低带宽档行不行？

不建议。带宽这一格是你要买的那一档才最有参考价值。选最低档测通，再买高档，等于跳过了一次验证。

### 为什么客户端里填进去显示连上了，网页还是打不开？

先看协议：SK5 走了但目标站是加密访问，要看客户端是否支持 CONNECT。再看出口：检测中心显示的地址是不是订单里的城市。最后看 DNS：客户端的远程解析有没有开。

### 企业版和个人版账号能不能通用？

不能。两套账号分开注册、互不通用，企业版在 user.kuxiongip.com，个人版在 www.kuxiongip.com。打算管线路、提 IP 的，注册企业版那一套。

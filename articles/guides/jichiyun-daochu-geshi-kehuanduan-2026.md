# 导出格式选错，客户端白配半天

点开导出、勾中「软路由格式」、按下复制，屏幕上弹出一句「系统不支持，请手动复制！」。极驰云的格式下拉里能读到八项名字，选错一项，后面填客户端的功夫就白费。

## 一句话结论

极驰云的节点导出不是只有「通用」一种，下拉里能读到 **八项格式名**；其中 **「软路由格式」与「软路由格式-地区」两项只对 L2TP 节点生效**，SK5 节点点它们不会有反应——页面原文写的是「软路由格式仅支持 L2TP 协议类型的节点」。SK5 走通用或斜杠格式，L2TP 走软路由格式，配 L2TP 时多出来的那个「共享密钥」栏位不能空着。

| 项目 | 具体口径 |
|---|---|
| 导出入口 | 后台「我的节点」→ 导出 / 复制 |
| 格式项数量 | 八项（含两种软路由格式） |
| 唯一硬限制 | 软路由格式仅支持 L2TP 节点，SK5 不生效 |
| 易漏字段 | L2TP 连接需要「共享密钥」 |
| 复制失败的判读 | 页面原文「系统不支持，请手动复制！」＝浏览器未给剪贴板权限 |
| 测速与核对 | IP 综合检测中心，免费 |

## 八项格式名各自去哪

把下拉里的选项按「导出的字段排布方式」归类，比按名字背更省事。下面这张表是读到什么、拿去填什么。

| 格式名 | 导出后长什么样 | 适合填进 |
|---|---|---|
| 通用 / 通用-地区 | 地址、端口、账号、密码分开成列 | 老鱼加速器、SSTap、Proxifier 等手动逐格填的客户端 |
| 斜杠格式 | 地址/端口/账号/密码串成一行 | 批量粘贴、脚本读取、一次贴一整批 |
| 域名 IP | 偏结构化的两段式，便于二次处理 | 自己写脚本抓取解析 |
| 软路由格式 / 软路由格式-地区 | 按软路由录入字段排好顺序 | 爱快、OpenWrt —— 仅 L2TP 节点可用 |
| 万安格式 | 按对应工具的字段顺序 | 万安系工具 |
| 地区格式 / 地区日期格式 | 按地区或按到期日分组 | 多设备分地区投放、按到期日排续费 |

名字里带「-地区」的两项，本质是在原格式上多带一个地区字段；需要按城市分机投放的场景用得上，单机日常使用一般用不带地区的那项就够。

## 软路由格式是唯一有协议限制的一项

八项里七项对协议没有要求，只有两项卡协议。**SK5 节点勾「软路由格式」，页面不会给你数据，也不会报错提示，看起来像「点了没反应」。** 这是导出环节最常见的一次误判——多数人第一反应是线路出问题，回头重开节点，其实只是格式选错。

| 你手上是 | 该选 | 不该选 |
|---|---|---|
| SK5 节点 | 通用 / 通用-地区 / 斜杠格式 / 域名 IP | 软路由格式（两项） |
| L2TP 节点 | 软路由格式（两项）／也可用通用格式手填 | —— |
| 只想批量粘贴 | 斜杠格式 | 各类结构化格式 |

分不清手上节点是哪种协议时，回「我的节点」页看节点那一行标注的协议类型再导出，比反复试格式快。

## L2TP 比 SK5 多一个必填字段

导出拿到 L2TP 的四段凭据之后，填进客户端或系统网络设置时会发现比 SK5 多一格：**共享密钥**。服务器地址、账号、密码之外，这一栏也要填，漏掉它通常会连不上，而报错文案往往只说「连接失败」。

| 字段 | SK5 要填吗 | L2TP 要填吗 | 说明 |
|---|---|---|---|
| 服务器地址 | 要 | 要 | 导出格式里给的是同一个地址 |
| 端口 | 要 | 一般用默认 | SK5 端口随节点，L2TP 通常不用改 |
| 账号 / 密码 | 要 | 要 | 从导出结果原样复制，别手敲 |
| 共享密钥 | 不需要 | **要** | 漏填是 L2TP 连不上的高发原因 |

复制的另一个坑是空格：从网页复制账号密码时，很容易把末尾的空格一并带进去，客户端报「认证失败」但看起来凭据完全正确。粘贴后手动检查一次首尾，比反复重开节点省时间。

## 复制没反应时，先读页面原文

点了复制没反应，页面会给出三句原文之一，三句话对应三种完全不同的处理方向。

| 页面原文 | 含义 | 该做什么 |
|---|---|---|
| 复制成功 | 数据已进剪贴板 | 直接粘贴，注意前后空格 |
| 无法复制到剪贴板 | 这一次没成功 | 再点一次，或改用导出文件 |
| 系统不支持，请手动复制！ | 浏览器没给剪贴板权限 | 改成导出文件下载，不要反复点 |

第三句最容易让人误判成「平台功能坏了」。实际是浏览器权限策略在拦——换一个允许剪贴板的浏览器，或直接走导出文件，两条路都能拿到数据，不必去问客服。

## 导出之后先核对四段，再连客户端

凭据拿到手，先做一次静态核对再连，能省掉一轮「连不上—重配—再连不上」的来回。

核对顺序是：**地址段是否完整**（有没有被复制截断）、**端口是否和节点标注一致**、**账号密码有没有多余空格**、**协议类型是否与客户端里的连接类型匹配**。四段都对上，再去 IP 综合检测中心跑一次出口 IP 与连通性，确认这条线本身是通的。

| 核对项 | 怎么核 | 不过关怎么办 |
|---|---|---|
| 地址完整 | 与「我的节点」页显示的地址逐字比对 | 重新导出，别手工补全 |
| 端口一致 | 对照节点详情 | 端口被改过就按后台显示的填 |
| 账号密码无空格 | 粘贴后看首尾 | 手动删掉多余字符 |
| 协议匹配 | 客户端里选的类型与节点协议一致 | SK5 选 Socks5，L2TP 选 L2TP |
| 线路本身通不通 | 检测中心跑出口 IP 与延迟 | 不通就换节点再试，别改客户端配置 |

## 常见问题

**Q：导出时点了「软路由格式」没有任何反应，是节点坏了吗？**
A：先看协议。软路由格式只支持 L2TP 节点，SK5 节点点它不会返回数据，也不会报错。换成通用或斜杠格式再导一次，多数情况下数据立刻出来。

**Q：导出的账号密码复制过去显示认证失败怎么办？**
A：八成是复制时带了空格。从网页复制凭据很容易把首尾空白一起带走，粘贴后先看首尾各删一次再试。仍失败就回后台重新导出，不要手工补字符。

**Q：L2TP 连接一直连不上，字段都填齐了？**
A：检查「共享密钥」那一格。SK5 没有这一项，从 SK5 转过来的人最容易漏它。地址、端口、账号、密码、共享密钥五格都对上，还是连不上就换节点验证一次。

**Q：勾选复制时提示「系统不支持，请手动复制！」是什么意思？**
A：浏览器没有授予剪贴板权限，不是平台故障。改成导出文件下载即可，或者换一个允许剪贴板的浏览器再试，反复点复制不会有第二种结果。

**Q：八种格式到底该选哪一种？**
A：按你用什么客户端倒推：手动逐格填的用通用格式，要批量粘贴的用斜杠格式，软路由用软路由格式（限 L2TP），自己写脚本的用域名 IP 格式。名字里带「-地区」的在需要按城市分投放时才有意义。

**Q：导出之后要不要先测一遍再连？**
A：要。先把四段凭据做静态核对，再用检测中心跑一次出口 IP、归属地与延迟。这一步花两分钟，能区分「凭据填错」和「线路不通」两类问题，省掉一轮盲改客户端。

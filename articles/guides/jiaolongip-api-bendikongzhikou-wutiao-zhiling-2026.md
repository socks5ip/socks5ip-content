# 蛟龙那套 API 到底管什么：一个本机端口，五条控制指令

127.0.0.1:33445 是蛟龙官方 API 文档里唯一出现的请求地址，它把调用方钉死在客户端所在的那台机器上。SOCKS5 1.5M 特惠档 **2.8 元/月起**，注册送 **2 条/天**免费测试，月卡换 IP 不限次——但在写脚本之前，得先分清「控制」与「取号」是两件事。

## 文档给的不是云端地址，而是本机端口

蛟龙的 API 文档是公开的（`api.jiaolongip.com/api/userDevice/apiDoc`），页面标题直接写着「API接口」。把文档从头读到尾会发现：它的请求地址并不是一个云端接口，而是一串本机地址——所有请求都发给 `127.0.0.1:33445`，靠 `?type=` 后面的参数区分要做什么。

这决定了一件事：调用方必须和客户端装在同一台机器上。想在一台服务器上统一指挥 N 台设备的出口，文档里没有这条路径。

## 五条请求清一色是「动作」，没有一条返回数据

| 动作 | 请求写法 | 返回码 | 含义 |
|---|---|---|---|
| 切换IP | `127.0.0.1:33445/?type=switch` | 0 / 1001 / 1101 | 成功 / 当前有操作执行中 / 当前设备无节点，不可切换 |
| 重新链接 | `127.0.0.1:33445/?type=reconnect` | 0 / 1002 | 成功 / 当前代理中，无需重连 |
| 断开链接 | `127.0.0.1:33445/?type=disconnect` | 0 / 1003 | 成功 / 代理已断开，无需重复断开 |
| 获取连接状态 | `127.0.0.1:33445/?type=〈状态查询参数〉` | 0 / 1 | 0 未连接、1 已连接（状态值，不是错误码） |
| 设置设备离线 | `127.0.0.1:33445/?type=offline` | 0 | 成功 |
| 通用错误 | 任意动作 | -2 / -1 | 未处理的任务类型 / 代码异常 |

把范围收一下：它给的是动作与状态，不是数据。程序可以让客户端换一条线路、断开、重连、报告自己有没有连着；但没有任何一条会返回「你有哪几条线路、地址与端口分别是什么」。

## 返回码那一栏里，0 和 1 不是成功与失败

上表最容易读错的是「获取连接状态」那一行。同一份文档里，其它接口用 `0` 表示「成功」，而这一条用 `0` 表示「未连接」——如果脚本统一按「非 0 即失败」判断，查状态这一步会一直判错。

| 常见误读 | 实际含义 | 后果 |
|---|---|---|
| 返回 0 就代表成功 | 只在 switch/reconnect/disconnect/offline 上成立 | 查状态永远判成「失败」 |
| 返回 1001 是权限问题 | 上一次操作还没执行完 | 改成串行调用并留间隔即可 |
| 返回 1101 是频率过高 | 当前设备没有可用节点 | 该去检查实例里有没有节点 |

## 想把一批线路拉下来，入口在会员中心

如果真正想要的是「批量拿号」，蛟龙给的入口在会员中心，不在 API 文档里。官网前台列了一整排以「批量」开头的操作，这也是它替代云端取号接口的做法。

| 后台能力 | 位置 | 一次处理的对象 |
|---|---|---|
| 批量换 IP / 换节点 | IP续费/更换、切换指定地区地址 | 已购实例，可指定地区 |
| 批量换分组 | 分组创建 / 修改 / 删除 | 先建组，再整组操作 |
| 批量续费与升级 | 续费 / 升级产品 / 差价计算 | 整组到期日与档位 |
| 强制下线 / 统一到期时间 | 强制下线、统一到期时间 | 指定实例或整组 |

会员中心的「修改api key」那一项管的是凭据本身，不是取号入口——看到「api key」就以为能把号池拉下来，是这块最常见的误会。真要按接口批量取号，得换到站内标注「可 API 提取」的平台（例如优众IP）。

## 固定域名这一档，比接口本身更影响自动化

登录后进「IP续费/更换」，勾选要用的线路，点「复制/导出」，这时要选地址类型。两种类型决定的是：换完 IP 之后要不要回后台再导一遍。

| 地址类型 | 换 IP 之后 | 生效速度 | 适合什么 |
|---|---|---|---|
| 常规地址 | 需要重新导出 | 切换后立即生效 | 一次配置、不常换 |
| 固定域名 | 无需重新导出 | 生效略有延迟 | 脚本长期挂机、频繁切换 |

打算靠本机端口让脚本自己 `switch` 的话，「固定域名」这一档基本是必选：脚本每换一次出口，配置文件不用改，也就不需要人再回后台导出。这一条对自动化能不能真跑起来的影响，比接口本身更大。

## 这几种做法，本机控制口接不住

| 你的做法 | 蛟龙的答案 | 更合适的路子 |
|---|---|---|
| 用云端接口直接拉一批线路 | 没有 | 站内标注「可 API 提取」的平台 |
| 一台机器统一调度 N 台设备 | 文档未提供 | 每台各自本地调用，或自建一层中间调度 |
| 需要海外出口 | 没有，蛟龙是国内线 | 走海外线路的平台 |
| 需要住宅段出身 | 没有，蛟龙是自建机房 | 换住宅类线路的产品 |

还有一点要摆正：「一机多IP」里的「多」，在这套机制下指的是一个出口按需切换，不是同一时刻有 N 条出口同时在线。要同时在线 N 条，仍然得买 N 条实例、分给 N 个环境。

## 常见问题

**Q：蛟龙到底有没有 API？**
有，但是本机控制接口。请求地址是 `127.0.0.1:33445`，五个动作分别是切换IP、重新链接、断开链接、获取连接状态、设置设备离线，调用方必须和客户端在同一台机器上。

**Q：能用 API 批量取号吗？**
拿不到号池列表。文档里没有任何一条会返回线路清单，批量拿号要在会员中心用分组加批量操作，再点「复制/导出」。

**Q：会员中心能改 api key，说明有云端接口吗？**
是两件事。那一项叫「修改api key」，管的是凭据本身；本机控制口的请求里并没有出现 key 或 token。

**Q：脚本里换 IP 老是被拒，返回 1001 是什么意思？**
上一次操作还没执行完。把切换改成串行、两次之间留一点间隔就行。如果返回 1101，那是当前设备没有可用节点，和调用频率无关。

**Q：换 IP 之后配置文件要重写吗？**
看地址类型。常规地址每次切换后要回后台重新导出；换成固定域名，切换时不用重新导出，只是生效会略有延迟。挂脚本长期跑优先选固定域名。

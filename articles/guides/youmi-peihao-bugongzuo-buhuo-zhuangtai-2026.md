# 有米配好了却不干活？先查进程捕获这一列

打开软件、勾好进程、点了启动，出口检测的结果却仍然指向本机。

**卡住的地方通常不是安装，而是「配好」和「真的在工作」之间那两个动作：开启进程捕获、以及改完配置后的重新捕获进程。** 官方把「流量显示为 0 怎么办」排在图文教程第一条，说明停在这一步的人不在少数。软件本身不收费，配套线路在价格中心 2.24 元/条起。

## 一句话结论

有米是**进程级代理工具**，它只把指定的进程送进代理通道，不代理整机。所以「启动」和「生效」是两个状态：**没有在捕获状态那一列看到目标进程，流量栏就永远是 0。**

| 关键项 | 口径 |
|---|---|
| 安装包体积 | 约 4.8M |
| 默认监视方式 | Snapshot（兼容性最好） |
| 交互端口 | 1357 |
| 配置文件 | 软件目录下的本地文件 YouMiIp.mdb |
| 跑通耗时 | 图形界面操作，十分钟内 |
| 线路来源 | 软件不提供 IP，需从平台提取后导入 |

## 五步里哪一步最容易漏

顺序不能调换，因为后一步依赖前一步的结果。

| 步骤 | 动作 | 没做会怎样 |
|---|---|---|
| 第一步 | 决定「代理谁」：整机、一个软件，还是一个窗口 | 捕获范围说不清，后面全部白配 |
| 第二步 | 导入线路：从平台提取后粘进软件 | 没有出口可走 |
| 第三步 | 按四段字段填代理参数 | 捕获到了也连不出去 |
| 第四步 | **开启进程捕获**，勾上目标进程 | 程序开着，不干活 |
| 第五步 | 点启动，回捕获列表确认状态 | 不知道到底通没通 |

## 流量为 0 时先看列表，不要先看数字

加了进程却没生效，先看这一列，不要先看流量数字。流量为 0 有两种原因：进程没被抓到，或者抓到了但线路不通——这两种情况的处理方式完全不同。

| 捕获状态 | 说明 | 下一步 |
|---|---|---|
| 未捕获 | 进程没进列表 | 重新捕获，或用「添加进程」手动指定 |
| 已捕获、流量为 0 | 进程进了通道但没数据 | 查代理参数四段字段是否填全 |
| 已捕获、流量正常 | 已经在工作 | 无须再动 |

## 换完线路要再捕一次，否则仍走旧规则

这一步最容易被跳过：**改了代理参数或换了线路之后，已经抓到的进程仍会按旧规则走。** 表现为「明明改成新线路了，检测出来的还是老的」。看到这种情况，回捕获列表点一次重新捕获，再复测出口即可。

## 一窗口一出口靠的是通道分配

如果你要的是一窗口一出口，靠单条全局线路做不到——需要在进程级给每个目标单独指定通道。这一点决定了它与整机代理类工具的分工：**整机代理解决「整台机器换一个出口」，有米这类进程级工具解决「同一台机器上不同窗口走不同出口」。**

## 常见问题

**有米的流量栏一直是 0，是不是软件坏了？**
先看捕获状态那一列。进程没被捕获时流量必然是 0，重新捕获或手动添加进程后再看；只有「已捕获但流量为零」才需要怀疑参数或线路。

**开启进程捕获和添加进程有什么区别？**
前者按当前运行中的进程批量抓取，后者手动指定某一个。程序先启动还是先开捕获，会影响抓取结果，抓不到时两种方式可以互换试。

**交互端口 1357 需要改吗？**
默认值正常情况下不用动。只有当本机其它程序占用了同一个端口、或有本地安全软件拦截时，才需要调整。

**设置保存在哪里，换台机器能不能带走？**
全部设置落在软件目录下的本地文件 YouMiIp.mdb 里，连同这个文件一起拷过去即可延续配置。

**有米能自己提供 IP 吗？**
不能。它只负责转发和分配通道，线路必须从代理 IP 平台提取后导入，价格中心可以横向比价后再选。

# 老鱼电脑版常见问题：界面不报错的那一堆怎么查

四个窗口里只有一个反复弹验证码、另外三个照样登录，同一个客户端、同一批线路，结果却不一样——难查的从来不是跳红字的那类，而是界面一切正常、目标站却当你从没换过出口的那类。

老鱼电脑版是进程级 Socks5 客户端，只在「你绑定的那个进程」这一层替换出口，所以它的故障天然分成两堆：**会跳提示的**九成出在四格字段里，**不跳提示的**要往进程边界、出口质量、目标站风控三处找。先分清是哪一堆，比反复重装省事得多。

## 先把故障分成两堆

| 现象 | 属于哪一堆 | 第一处该看 |
|---|---|---|
| 线路列表里那条读不出来 | 有提示 | 分隔符与行内空格 |
| 提示认证失败 | 有提示 | 端口与密码这两格 |
| 显示已连接，目标站打不开 | 无提示 | 换条线路、换个站对照 |
| 只有部分程序走了代理 | 无提示 | 进程边界与权限 |
| 换了 IP 仍被认出来 | 无提示 | 出口之外的四种身份 |

数据来源：站内老鱼加速器免费版／专业版配置教程口径，核对日期 2026-11-27。

有提示和没提示，处理方向相反。有提示说明客户端已经把请求送到了服务器、服务器给了回应，问题在「送的对不对」；没提示说明链路是通的，问题在「送出去之后对方怎么认你」。把这两件事混着改，就会来回折腾。

## 会跳提示的，其实只集中在一格

老鱼对格式问题几乎不报错，能跳出来的提示基本只剩「这条线路读不出来」和「认证失败」两种。

前者是格式层，后者是凭据层。格式层的表现是那行线路干脆不出现，或显示成一串看不懂的字符；凭据层的表现是线路能被识别、能点选、也显示已连接，但一跑流量就认证失败。这时最容易犯的错是回头去平台上换线路——换了三条还是同样的表现，因为问题从来不在线路上。

| 看到的提示 | 它在说什么 | 一处改法 |
|---|---|---|
| 那条线路读不出来 | 格式没被解析 | 照软件示例重录一条，确认能识别再批量加 |
| 认证失败 | 凭据被服务器拒绝 | 核对端口与密码，确认四项同一行同一线 |
| 已连接但没流量 | 客户端通了，绑定没命中 | 去进程栏，别动线路 |

四格里最容易错的是端口和密码，而它们出错时界面往往一声不响。端口由平台下发，每条线可能都不一样，凭印象填 1080 大概率失败；密码区分大小写，从网页复制时带上的尾随空格肉眼看不出来。判断办法很笨但有效：把这一整行粘到记事本，光标支到末尾看有没有空白。

批量录线路时还有一种事故：把 A 线的账号配了 B 线的端口，两行错位之后整批认证不过。稳妥做法是先只录一条，跑通再照这条的格式往里加——一次贴十条，出问题就得一条条比对，时间反而更长。

## 显示已连接却打不开，先别动配置

「已连接」只证明客户端和代理服务器握上了手，跟你要用的那个程序走没走这条线是两件事。

这时候再去改线路那栏，等于在没坏的地方反复拧螺丝。判断往哪查，靠外部证据，不靠界面状态。

| 表现 | 更像哪里出问题 | 一条能自证的证据 |
|---|---|---|
| 所有网站都打不开 | 线路或绑定 | 同一客户端换一条线再试，立刻好转＝线路问题 |
| 只有某几个站打不开 | 目标站风控 | 同一条线打开别的站正常，只有它拦 |
| 页面能开但一直在转 | 出口带宽或目标站限速 | 换线后同样慢＝目标站限速 |
| 直接跳验证码或 403 | 出口被目标站标记 | 换线立刻正常＝这个出口脏了 |

这张表的用法是先做减法。所有网站都打不开，问题一定在客户端这一侧，跟目标站无关，别去猜是不是被风控了；反过来只有某几个站打不开、别的站好好的，配置就是好的，再改只会把好的改坏。

还有一类既不属线路也不属目标站：绑定的程序自己留着一条直连通道。浏览器扩展、下载器多线程、游戏更新器都可能绕过客户端单独发包，表现是主页面走了代理、某个功能模块仍然是本地地址。这类问题不给任何提示，只能靠逐个功能试出来。

## 换了 IP 还被认出来，说明只换了一层

老鱼换的是出口地址，浏览器指纹、账号、Cookie、操作节奏这四样一样没动，所以「换了 IP 还是被关联」通常不是软件没生效，是它本来就只管一层。

| 层面 | 归谁管 | 换代理能不能解决 |
|---|---|---|
| 出口地址 | 代理客户端 | 能 |
| 浏览器指纹（画布、字体、WebGL、时区、语言） | 浏览器环境 | 不能 |
| Cookie 与本地存储 | 浏览器 profile | 不能 |
| 操作节奏 | 使用习惯 | 不能 |

判断落在哪一层，有个省事的对照法：用同一条线路，换一个全新的浏览器 profile 再登一次。一切正常说明出口没问题，卡在指纹或 Cookie 上；换了 profile 照样被拦，那才是出口本身被标记了，该换线路。

## 自测口径：四条判据，做完再动手

| 判据 | 怎么验 | 过了说明什么 |
|---|---|---|
| 线路能被识别且跑出流量 | 录一条，跑一次下载 | 格式与凭据都没问题 |
| 只有目标站异常 | 同线换站、同站换线各一次 | 问题在出口，不在客户端 |
| 绑定命中 | 目标程序里查一次出口 IP | 进程边界是对的 |
| 换 profile 后正常 | 新建无痕窗口再登 | 出口干净，问题在身份层 |

四条里前两条能在五分钟内做完，后两条各需要一次登录。顺序别跳：先证明线路能跑，再证明绑定命中，最后才谈身份——跳步会把两个变量同时改动，改完也判断不出哪一步起了作用。

## 什么情况该换线路，什么情况该换工具

判断线只有一条：**问题是否随线路走**。同一条线换到别的工具里能跑，说明是客户端这一层的问题，重装或换工具；换成任何线路都一样，说明是出口或身份层，换工具没有用。

线路一条几元，换十条也就几十元，而排查常常搭进去一整个晚上——所以先花两块钱换一条线做对照，永远比在配置里猜便宜。

## 常见问题

**Q：线路显示已连接，但浏览器还是本地 IP，怎么办？**
A：先确认浏览器是不是被绑定的那个进程。老鱼按进程名接管，浏览器有多个进程（主进程、渲染进程、扩展后台），绑错一个就等于没绑。判断办法是在浏览器里打开 IP 综合检测中心，看出口是不是线路所属地区。

**Q：四个窗口只有一个弹验证码，另外三个正常，是线路问题吗？**
A：更像这个窗口的环境问题。同一条线三个窗口正常，说明出口没被整体标记；把出问题的那个窗口换新 profile 再登，如果恢复正常就是 Cookie 或指纹，不是线路。

**Q：认证失败但账号密码肯定没错，还查什么？**
A：查端口和空格。端口每条线可能不同，不能按 1080 填；密码尾随空格和全角字符肉眼看不出来，粘到记事本看末尾最直接。两项都对仍然失败，就核对四项是否来自同一条线路。

**Q：换 IP 之后速度明显变慢，是买到差线了吗？**
A：先排除单线问题。同一条线换到另一个工具里跑同样目标，速度快说明是客户端侧开销；都慢才是线路。再固定同一测速点和时段复测，换着地方测出来的数字没有可比性。

**Q：免费版和专业版排查方法一样吗？**
A：故障分类一样，差别在边界。免费版单窗口单 IP，一个窗口一条线，问题范围天然小；专业版支持批量导入，四项错位、绑定错进程这两类事故只出现在专业版，排查时先看导入的那一批格式是否一致。

# IP纯净度是什么？为什么决定账号存活率，怎么提升

## 结论

IP 纯净度就是"平台眼里你的 IP 像不像真实用户"，由四层决定：**出身（住宅/机房）、案底（黑名单）、共享、泄漏**。对社媒、电商、游戏多开这类风控敏感场景，纯净度直接决定账号存活率。

## 四个维度

| 维度 | 看什么 | 影响 |
|---|---|---|
| 出身 | 住宅 IP 还是机房 IP | 机房 IP 更像机器流量 |
| 案底 | 是否在黑名单/有滥用记录 | 发过垃圾邮件等会留下案底 |
| 共享 | 独享还是多人共用 | 共用可能被关联污染 |
| 泄漏 | DNS/WebRTC 是否暴露真实身份 | 泄漏=白搭 |

## 怎么提升

1. **选住宅 IP**：家宽资源在"出身"这一层就赢在起跑线
2. **选独享**：避免共享污染，长期项目尤其重要
3. **先测再用**：用 IP 质量检测确认住宅属性、无黑名单标记再上线
4. **配合工具防泄漏**：代理工具里开启 DNS 代理，避免真实 IP 泄漏

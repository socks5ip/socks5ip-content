# 鲸云IP Windows 配 L2TP：导出里没有隧道是后台没开

导出对话框弹出来，隧道那一栏只有表头，下面空着；产品说明里这个区明明写着支持 L2TP。

问题不在电脑上。鲸云IP 的 L2TP 默认是关着的，要在后台「账户 → 编辑/续费」里手动开启一次，开了导出界面才会出现隧道那一项。没开之前，导出的只有 SK5 那几行。

## 一句话结论

鲸云IP 的四个住宅区都能跑 L2TP，但**必须先在后台开启 L2TP 开关才能导出隧道数据**；Windows 侧只填 **服务器地址** 和 **预共享密钥**（平台默认 **666666**），**端口 1701 是内置固定的、不用填**。导出文本里那列「端口」是给 SK5 客户端看的，抄进系统自带拨号反而连不上。

| 环节 | 关键值 | 错了会怎样 |
|---|---|---|
| 后台 L2TP 开关 | 账户 → 编辑/续费 → 开启 | 导出只有 SK5 行，隧道列全空 |
| 服务器地址 | 导出文本里的 IP | 填成登录入口 IP，握手无响应 |
| 预共享密钥 | 导出文本标注值（默认 666666） | 提示「安全参数不匹配」 |
| 端口 | 1701，系统内置 | 抄了 SK5 那列的端口，连不上 |
| 账号密码 | 与后台登录号不同 | 认证失败，报 691 |

数据来源：站内鲸云IP 使用教程与价格表口径，核对日期 2026-11-27，具体数值以后台导出文本为准。

## 第一步：后台把开关打开，导出才有内容

鲸云的导出页面不是「有什么导什么」，而是按你开通的协议生成。账户没有开 L2TP，导出就只给 Socks5 那一组。

操作路径很短：登录后台 → 账户列表 → 找到要用的那条线路 → 编辑/续费 → 勾上 L2TP → 保存。保存之后再回导出页，隧道那一栏才会从空白变成四格。

这一步容易卡住的地方在于它不报错。界面不会提示「你没开 L2TP」，只是安静地给你一份只有 SK5 的文本，于是很多人以为是浏览器缓存或者账号问题，反复刷新。

| 你看到的 | 说明什么 | 下一步 |
|---|---|---|
| 导出只有一行或两行 SK5 数据 | 该账户未开通 L2TP | 回账户页开开关 |
| 隧道列出现但地址为空 | 该区不支持 L2TP | 换住宅区（四个住宅区支持） |
| 隧道列有地址、无密钥 | 需向客服确认预共享密钥 | 别猜，问一次即可 |

## 第二步：分清两份数据，别混着填

同一份导出文本里同时有 SK5 和隧道两种口径，它们的字段含义不一样。SK5 是「地址｜端口｜账号｜密码」四段，隧道是「服务器地址｜预共享密钥｜账号｜密码」，中间那两格完全不是一回事。

| 字段 | SK5 口径 | L2TP 口径 |
|---|---|---|
| 连接地址 | IP + 端口（如 1080/1081） | 只有 IP，无端口 |
| 凭据 | 账号 + 密码 | 账号 + 密码（可能不同） |
| 密钥 | 无 | 预共享密钥（PSK） |
| 填在哪 | 客户端（老鱼、SSTap、Proxifier） | 系统「添加拨号连接」 |

最容易犯的错是把 SK5 那个端口抄进系统自带拨号的端口框。Windows 的 L2TP 连接界面里根本没有端口输入项，你要是看到有，那是第三方客户端，不是系统自带的那一个。

## 第三步：Windows 建连接，只有四格要填

系统路径是「设置 → 网络和 Internet → 拨号连接 → 添加连接」，提供商选 Windows（内置），类型选「使用预共享密钥的 L2TP/IPsec」。

| 输入框 | 填什么 | 不填会怎样 |
|---|---|---|
| 服务器名称或地址 | 导出文本里的服务器 IP | 无法保存 |
| 连接类型 | 使用预共享密钥的 L2TP/IPsec | 默认 PPTP，握手失败 |
| 预共享密钥 | 导出标注值（默认 666666） | 报「安全参数不匹配」 |
| 用户名 / 密码 | L2TP 那一组，不是后台登录号 | 报 691 认证失败 |

保存后点连接，第一次会等 5–15 秒。这段时间是在做 IPsec 协商，不是卡住；如果 20 秒还没有反应，八成是服务器地址填成了登录入口域名。

## 第四步：三条判据确认真的接通了

「已连接」不等于出口换了。系统拨号连上只说明隧道通了，出口是不是这条线的 IP，要另外验。

| 判据 | 怎么验 | 通过标准 |
|---|---|---|
| 出口归属地 | 打开 IP 综合检测中心 | 显示线路所属城市，不是你所在城市 |
| 协议握手 | 看检测页的协议识别结果 | 识别为 L2TP/IPsec，不是未知 |
| 稳定性 | 连续在线 30 分钟 | 不掉线、延迟波动小于 30ms |

三条都过再谈业务。只过第一条的话，通常是隧道通了但 DNS 还走本地，表现为部分站点解析到错误地区，检测页上看不出异常、实际用起来不对。

## 临界点：什么时候该用 L2TP，什么时候别用

L2TP 的价值在「系统级接管」，不在速度。它适合需要整机流量都走线路的场景——软路由、电视盒子、没有代理设置项的软件。反过来，下面三种情况用 L2TP 是绕远路：

| 场景 | 更适合的形态 | 原因 |
|---|---|---|
| 只要某个程序走代理 | 进程级 Socks5 客户端 | L2TP 是整机接管，粒度太粗 |
| 需要频繁换 IP | Socks5 + 切换额度 | L2TP 断开重连要十几秒 |
| 单窗口挂机 | Socks5 | 一个窗口不需要整机接管 |

判断线是「要不要整机」：要，就用 L2TP；只针对一两个程序，Socks5 更省事，也更容易排查。

## 常见问题

**Q：导出里隧道那一栏是空的，是不是这个区不支持 L2TP？**
A：先看后台开关。账户页的「编辑/续费」里没有勾 L2TP 时，导出不会生成隧道数据，界面也不报错。鲸云四个住宅区都支持，开关打开后隧道列会立刻出现。

**Q：Windows 提示「安全参数不匹配」是什么意思？**
A：预共享密钥填错了。这个值由平台下发，导出文本里会标注（鲸云默认 666666），不能自己设。改的时候要删掉原连接重建，在已有连接上改密钥有时不生效。

**Q：连接建立但打不开网页，是线路问题吗？**
A：先查 DNS。系统拨号连上后解析可能仍走本地，表现是能连上、部分站点打不开或打开的是别的地区版本。把 DNS 改成远端或公共解析，再清一次缓存复测。

**Q：能不能把 SK5 的端口填进系统自带拨号？**
A：不能。Windows 的 L2TP 连接没有端口输入项，端口固定 1701 由系统处理。导出文本里那列「端口」是给 Socks5 客户端用的，两套口径不能互换。

**Q：L2TP 连上后速度只有几兆，正常吗？**
A：看档位。家庭 AB 区标称 10Mbps，理论下行约 1.25MB/s，跑满属于正常；如果远低于这个数，先在同一台机器上用 Socks5 连同一区做对照，快就说明是隧道封装开销，慢才是线路。

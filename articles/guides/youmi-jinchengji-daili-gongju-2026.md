# 有米是做什么的？4.8M 的进程级工具，只做分发不带线路

4.8M 的安装包，永久免费、核心开源——有米这三个标签背后是一个 Windows 上的进程级代理工具，**它自己不带任何线路，只负责把你自己买的 SOCKS5 按进程分给不同窗口**。把它当成「装了就有 IP 的加速器」是理解偏差，也是新手最容易踩的一次坑。

## 一句话结论

有米的定位是**分发层**，不是线路层。官方称永久免费、核心完全开源，支持完整的 IPv4 与 IPv6、TCP 与 UDP，可以按进程（也可以按窗口）把一条 SOCKS5 线路指定给指定程序。**线路从哪来它不管——这一点直接决定了出问题时该找谁。**

| 项目 | 口径 |
|---|---|
| 授权模式 | 永久免费，核心完全开源 |
| 代理层级 | 进程级（可指定到进程 / 窗口） |
| 协议栈 | 完整 IPv4 + IPv6，TCP + UDP |
| IP 来源 | 不自带，需自行准备可免费测试的线路 |
| 操作系统 | 主程序 Windows XP 及以上 |
| 交互端口 | 1357 |
| 设置存放 | 软件目录下的本地文件 YouMiIp.mdb |
| 默认监视方式 | Snapshot（兼容性最好的一档） |

上表来自有米官方帮助文档与官网下载页的登记信息，属公开口径，非本站推断。

## 它拦在哪一层：进程级而不是整机

代理工具大致分三层：系统级、整机级、进程级。**层级决定了「换了出口以后，谁的流量走代理」。**

| 层级 | 影响范围 | 典型用途 |
|---|---|---|
| 系统级 | 全局，所有程序一起走 | 只想让整机换一个出口 |
| 整机 / 网关级 | 本机再加下级设备 | 软路由、共享出口 |
| 进程级 | 只有被指定的进程走 | 多窗口分别走不同出口 |

有米站在第三层。它的价值恰恰在这里：同一台机器上开多个窗口、跑同一款程序，可以让每个窗口走不同出口，互不干扰。**整机接管做不到这件事，所以这两类工具并不是「谁替代谁」的关系。**

## 一个进程是怎么被认出来的

进程级工具的核心难题是「认进程」。三种识别方式各管一段场景，理解它比拼字段更重要。

| 识别方式 | 认的是什么 | 适用情形 |
|---|---|---|
| 按进程 | 可执行文件本身 | 一个程序一个出口，最常见 |
| 按窗口 | 程序窗口的独立实例 | 同一程序多开、要分开走线 |
| 按规则 | 协议号与连接方向 | 需要更细粒度控制时 |

再往下一层是监视手段。默认的 Snapshot 兼容性最好，覆盖大多数场景；遇到特定程序识别不到时，才需要换更强的监视方式。**先按默认值配，配不通再升级监视方式**——反过来做，很容易把兼容性问题误判成线路问题。

## 设置存在哪里，换机器要带走什么

有米的全部设置都落在软件目录里的本地文件 `YouMiIp.mdb`。这个细节有两个实际用途。

| 场景 | 动作 | 注意 |
|---|---|---|
| 换一台机器继续用 | 把 YouMiIp.mdb 一起带走 | 线路信息在文件里，不带就要重建 |
| 备份当前配置 | 定期复制一份该文件 | 程序目录不要放在会被清理的位置 |
| 多台机器同步 | 逐台复制，不要共用同一个文件路径 | 共用同一文件在不同机器上会互相覆盖 |

界面结构也不复杂：主菜单只有四个，分别管代理设置、规则、进程列表与插件/工具。**菜单少不代表功能少，而是把选择集中在了「给哪个进程分哪条线」这一件事上。**

## 版本与形态

官方目前提供的是一套主程序加两套插件、外加一个服务端的组合形态。主程序负责进程级接管，插件负责扩展（比如协议转换、负载均衡这类），服务端形态用于跨设备分发。宿主系统以 Windows 为主。

| 组成 | 作用 |
|---|---|
| 主程序 | 进程级代理接管与规则管理 |
| 插件 | 扩展能力（协议转换、负载均衡等） |
| 服务端形态 | 跨设备 / 跨机器分发代理 |

## 什么情况适合用它

| 情形 | 适不适合 | 理由 |
|---|---|---|
| 一台机器开多个窗口、要分开出口 | 适合 | 进程级正是为这个场景设计的 |
| 已经买了线路，只缺一个分发工具 | 适合 | 免费开源，成本只在线路 |
| 想「装了就直接有 IP」 | 不适合 | 它不带线路，必须另配 |
| 只跑一个程序、不需要分流 | 没必要 | 系统级代理就够了 |
| 期望官方按周响应新需求 | 不适合 | 这是维护状态成熟的免费项目 |

## 常见问题（FAQ）

**Q：有米自带 IP 吗？**
A：不自带。它的官方帮助文档开头就写明不提供任何代理 IP、也不提供订阅链接。线路要自己从平台购买，再导入软件。

**Q：装了有米，为什么点了启动还是本机 IP？**
A：最常见的原因是「开启进程捕获」没有勾选，程序只是开着、并没有接管任何进程。第二个常见原因是改完配置后没做一次「重新捕获进程」，已开启的进程仍在走旧规则。

**Q：进程列表里认不出我要的程序怎么办？**
A：先确认监视方式——默认的 Snapshot 兼容性最好，若仍识别不到，再换成更强的监视方式重试。

**Q：一个窗口一条线，能做到吗？**
A：可以。进程级接管支持按窗口指定，这也正是它和系统级代理最大的区别。默认状态下这个能力是关着的，需要在设置里打开。

**Q：有米和有线路的加速器，选哪个？**
A：看你要的是「线路」还是「分发」。只想要一条出口，直接用带线路的平台；已经有线路但要给多个窗口分开走，才有必要加一层有米。

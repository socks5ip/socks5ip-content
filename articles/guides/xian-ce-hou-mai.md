# 为什么选代理IP一定要"先测后买"？

## 结论

代理 IP 是"体验型"产品，**参数表看不出实际质量**。归属地对不对、延迟高不高、稳不稳定、纯净度够不够，只有连上实测才知道。所以：**先测后买，是所有选 IP 的第一原则**。

## 为什么必须测

- **归属地可能不准**：标称"北京"的节点实际出口可能漂移
- **延迟和带宽是玄学**：宣传 100M，高峰期可能连视频都卡
- **稳定性要时间验证**：挂机场景几分钟就掉线的线路，多便宜都是亏
- **纯净度看不见**：住宅还是机房、有没有上过黑名单，直接决定账号存活

## 免费体检四步

1. **查归属地**：IP 质量检测，看归属地是否与套餐描述一致
2. **测线路**：代理线路可用性检测，看协议握手是否通过、延迟分级
3. **测速度**：网络测速，下载/上传/抖动/丢包一目了然
4. **场景模拟**：业务场景模拟检测，按你的业务（社媒/多开/跨境/AI）跑适配评分

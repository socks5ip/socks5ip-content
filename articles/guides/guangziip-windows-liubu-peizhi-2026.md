# 六个步骤，第三步填错一格就得整套重来

## 一句话结论

## 一、先定客户端，再动参数

客户端决定代理的作用范围，作用范围决定后面所有麻烦。这一步在提取凭证之前就要定，因为不同客户端要的填法不一样。

| 客户端 | 作用范围 | 适合什么 | 代价 |
|---|---|---|---|
| 老鱼加速器（进程级） | 只代理选中的进程 | 模拟器多开、只让指定程序走线 | 没加进列表的程序仍走本机网络 |
| SSTap（虚拟网卡） | 整机全部流量 | 需要整台机器走一条线 | 要装网卡驱动，卸不干净会拖网络 |
| Proxifier（规则分流） | 按进程或域名分别指定 | 不同窗口走不同线 | 规则写错会静默直连 |
| 系统隧道拨号（L2TP） | 整机 | 买了 E 或 F 档 | 要预共享密钥，不能按进程分 |

选择逻辑一句话：**要按窗口分线就选进程级或规则分流，要整机一条线就选虚拟网卡。**

## 二、四行凭证对应客户端哪几个空

后台点提取，返回的是四行字。它们对应客户端里四个不同的格，混填是最常见的失败原因。

| 后台给你的 | 填到哪 | 常见填错 |
|---|---|---|
| IP 地址 | 服务器 / 主机（Server / Host） | 把 `socks5://` 前缀一起粘进去 |
| 端口 | 端口（Port）单独一格 | 和 IP 写进同一格，用冒号连 |
| 账号 | 用户名（Username） | 末尾多带一个空格 |
| 密码 | 密码（Password） | 输入法把字母切成全角 |
| 协议类型 | 选 SOCKS5，不是 HTTP | 默认停在上一次用过的协议上 |

第五行不在凭证里，但它是失败率最高的一项。老鱼、SSTap、Proxifier 都有协议下拉框，新建配置后默认值不一定是你需要的那个。

## 三、进程级与整机：这一步决定后面所有麻烦

两种作用范围的差别，在配完之后才会显形：

| 观察项 | 进程级 | 整机 |
|---|---|---|
| 浏览器没加进列表时 | 走本机网络，出口不变 | 一并走代理 |
| 系统更新、云盘同步 | 不受影响 | 一起走代理，占带宽 |
| 同时跑两条线 | 支持，按进程分配 | 不支持，同一时刻只有一条 |
| 卸载残留 | 无 | 虚拟网卡可能残留 |

要在一个桌面上跑五条不同的线，进程级是唯一可行的那条；只跑一条线又不想逐个程序加白名单，整机更省事。

## 四、填完先验出口，再谈效果

配完不要直接开始干活，先验三件事：

| 顺序 | 验什么 | 合格线 |
|---|---|---|
| 第一步 | 在目标程序里打开 IP 检测页 | 显示的出口地址与后台给的 IP 一致 |
| 第二步 | 看检测页的归属与连接类型 | 与所买档位的预期一致（住宅档应显示宽带运营商） |
| 第三步 | 断线重连后复查 | 出口地址不变 |

第二步是分水岭。连通但归属不对，说明你连上的不是那条线，或者走了中转。

## 五、Windows 上最容易翻的三处

| 现象 | 真实原因 | 处理 |
|---|---|---|
| 浏览器能通、客户端里的程序不通 | 程序没进代理列表 | 把进程加入规则，或改用整机模式 |
| 提示认证失败但密码是对的 | 密码被切成全角，或末尾有空格 | 重输密码，切半角输入法 |
| 配好后网速掉一半 | 虚拟网卡与物理网卡路由冲突 | 卸载网卡驱动重装，或改回进程级 |

三处里有四处跟凭证无关，都是作用范围与系统层的配置问题。**先分清是「连不上」还是「连上了但走错」，能省掉一半排查时间。**

## 常见问题

### 光子IP 填了代理为什么浏览器还是本机 IP？

多数客户端默认只代理加进列表的进程。浏览器不在列表里就走本机网络。把浏览器加进规则，或直接改成整机模式。

### IP 和端口要写在同一格吗？

不要。IP 填服务器那一格，端口填端口那一格。写在一起客户端会解析失败或连到错误端口。

### 一台 Windows 能同时跑几条光子IP 的线？

用进程级或规则分流可以按程序分配，理论上几条都行；用虚拟网卡整机模式同一时刻只能一条。

### 提取出来的密码带特殊字符，能用吗？

能用，但要注意编码。如果客户端提示认证失败，先把密码改成纯字母数字试一次，能通说明是特殊字符输入问题。

### 配好之后网速明显变慢怎么办？

先确认是不是走了中转或虚拟网卡冲突。关掉中转前后各测一次出口，两次一致说明中转没生效；网速仍慢就换回进程级模式再测。

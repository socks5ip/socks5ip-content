# 计价基数不同的时候，比出来的价格一定是错的

打开 JiuIP 的购买页，同一个 2M 档位上并排挂着两个价格：日卡 0.85 金币、月卡 3.4 金币（1 金币≈1 元）。这两个数字的计价单位压根不同，放在一起比大小本身就是道错题。JiuIP（官网 jiuip.com）用金币计价，四条线路共用一套价目：**2M 月卡 3.4 金币、5M 5.58 金币、20M 11.64 金币**，带宽买定后不能升档。真正决定选谁的，是四把尺子：**计价基数、带宽含不含在价内、切换次数另算不另算、有没有免费测试额度**。

## 一、计价基数不同，数字就没法直接比

代理 IP 的报价落到纸面上有三种基数：按「出口条数 × 时长」计（X 元/条、X 元/条/天）、按「账号 × 月」计（出口条数写在套餐里）、按「带宽 × 月」计（限的是单条出口速率）。三种写法混在一起比数字，得到的结论一定是错的。

| 报价写法 | 实际计价单位 | 换算成「单条出口 · 天」 | 容易误判的点 |
|---|---|---|---|
| 0.85 金币/天（JiuIP 2M 日卡） | 条 × 天 | 0.85 金币 | 拿它和月卡比，等于拿一天的租金比一个月的租金 |
| 3.4 金币/月（JiuIP 2M 月卡） | 条 × 带宽档 × 月 | ≈ 0.113 金币 | 只有这一栏才是可比的单价 |
| X 元/条（按条购买） | 条 | 取决于用几天 | 没有包月封顶，条数越多总价线性上涨 |
| X 元/月（账号包月） | 账号 | 月费 ÷ 套餐内出口数 ÷ 30 | 套餐写「含 5 条出口」，单价可能低到看不出来 |

换算完的结论有点反直觉：**代理 IP 的成本不由单价决定，由「你用不用满」决定**。一条 3.4 金币的月卡，如果只跟前三天，实际成本是 1.13 金币/天，比老老实实买日卡还贵 0.28 金币。所以「月卡更便宜」这句话有前提——这条线你整月都在用。

## 二、带宽含在价内，还是另外买并发

这是四把尺子里最容易被漏掉的一条。有些平台基础价只给一个很窄的速率，同时开几个窗口还得再买「加速包」或「并发数」；有些平台把带宽直接做进档位，价格随带宽阶梯走，不再收第二笔钱。

JiuIP 是后者：价目表按 2M / 3M / 5M / 10M / 20M 分五档，**档位即速率上限，档位之外不单独卖并发**。两笔钱合成一笔的好处是账目清楚，代价是选档那一步页面上有明确提示「后期不能升级」，想从 3M 换 10M 只能重新下单。

| 带宽 | 1 天 | 7 天 | 30 天 | 站内价格表给的适用场景 |
|---|---|---|---|---|
| 2M | 0.85 金币 | 1.94 金币 | **3.4 金币** | 轻量挂机、单窗口（全站最低价） |
| 3M | 0.97 金币 | 2.43 金币 | **4.37 金币** | 少窗口多开，平台建议的起步档 |
| 5M | 1.09 金币 | 3.03 金币 | **5.58 金币** | 常规多开、多任务并行 |
| 10M | 1.21 金币 | 3.64 金币 | **6.79 金币** | 视频类、中高占用 |
| 20M | 1.58 金币 | 5.94 金币 | **11.64 金币** | 直播、大流量（仅阿里云/家庭住宅） |

把日卡和月卡横向拉平会看到一条规律：**带宽越小，月卡相对日卡的折扣越狠**——2M 档买月卡比按天买省约 87%，20M 档只省约 75%。小带宽长期跑就该直接上月卡；大带宽如果只是短期压测，日卡的灵活性反而更值。

## 三、切换次数按卡型给额度，还是单独计费

换 IP 的频次直接决定成本，但收费方式各家不同：有的每次换 IP 扣钱或扣次数包，有的把它做成卡型自带的额度。JiuIP 是后者——每条 IP 自带切换额度，**日卡 2 次、周卡 7 次、月卡 30 次**。

这条规则的含义比数字本身更重要：月卡 30 次 ÷ 30 天 = 每天一次，刚好覆盖「一天换一次出口」这个最常见的节奏；而日卡只有 2 次，做高频换 IP 的业务会在半天内把额度用光。

| 你的换 IP 节奏 | 建议卡型 | 理由 |
|---|---|---|
| 几乎不换，一条线跑整月 | 月卡 | 30 次额度完全用不完，单价最低 |
| 一天换一次 | 月卡 | 额度刚好对齐，不多不少 |
| 一天换 3 次以上 | 月卡 + 多买条数 | 单条 30 次撑不住，用条数把频次摊开 |
| 只在某几天集中跑 | 日卡 / 周卡 | 不为整月付费，按天更省 |

## 四、四条线路同价，属性才是分水岭

JiuIP 的线路一栏有四个选项：阿里云、天翼云、移动云、家庭住宅。前三项是大厂机房 IP，出口地址长期固定；家庭住宅是住宅 IP，后台会隔 2–7 天把地址重播一次。**两者标价相同**，所以选线看的不是价格，是你要「固定」还是「像真人」。

| 你的业务 | 优先看哪把尺子 | JiuIP 侧的落点 |
|---|---|---|
| 游戏多开 / 模拟器长挂 | 带宽 + 切换次数 | 3M 或 5M 月卡，4.37 / 5.58 金币 |
| 电商店铺 / 社媒账号矩阵 | 出口属性 | 家庭住宅线（2–7 天自动重播） |
| 数据采集 / 批量任务 | 条数 + 单价 | 多条 2M 月卡，3.4 金币/条 |
| 直播 / 大流量推流 | 带宽上限 | 20M（11.64 金币/月），仅阿里云与家庭住宅提供 |

第三行值得单独说：采集类业务真正的瓶颈是「同时能开多少条出口」，不是单条跑多快。为了「带宽大一点保险」把预算压到一条 20M 线上，结果条数不够，是最常见的配比错误。

## 五、自测口径：30 次测试卡怎么用得不浪费

四把尺子里最该先看的是这一条，因为它能替你避开一次整月误购。JiuIP 新账号注册并完成实名后自带 **30 次免费测试**，位置在「购买代理」页的支付方式里，选「测试卡」提交即可，每次下发 3 条 IP、有效期 5 小时。

体量折算一下：30 次 × 3 条 = 最多摸到 90 个出口，累计 **450 条·小时**，按 2M 月卡口径约值 2.1 金币。金额不大，但足够回答「这条线在我的业务里跑不跑得通」这个必须花钱才能回答的问题。用的时候把带宽档位分开测——测试卡发的线路属性以领取页实时显示为准，拿归属对不上业务的样本去推带宽结论，会得出错误结果。出口归属建议用 [IP 综合检测中心](https://socks5ip.com.cn/ip-check-center/)交叉核对，别只看后台自报参数。

## 六、哪些需求换别家更合适

比价文章只讲「选我」没有参考价值。下面四种需求，直接说不合适，省得事后走退款流程。

| 你的需求 | 为什么不合适 | 该往哪找 |
|---|---|---|
| 单条出口要长期固定不变（绑平台白名单、软路由固定映射） | 家庭住宅线 2–7 天自动重播 IP 地址 | 改走机房线（阿里云/天翼云/移动云），出口长期固定 |
| 一天要换十几次 IP | 月卡每条 30 次额度，撑不住这个频次 | 按条购买，或转向短效代理类产品 |
| 需要 50M 以上的单条带宽 | 最高档位停在 20M | 找专线或独享带宽类方案 |
| 要程序化 API 大批量提取 | 以后台提取与客户端导入为主 | 先确认目标平台的 API 能力与配额再决定 |

反过来也成立：如果你的需求是**出口数量不多、要长期稳定挂着、按带宽买断、下单前能免费验货**，这套计价方式正好对路。四条线同价、不用为线路属性额外付钱，是这张价目表里最实在的一处。

## 常见问题

**Q：JiuIP 和别的平台比，到底算贵还是便宜？**
要看换算口径。按 2M 月卡 3.4 金币折算，单条出口每天约 0.113 金币，放到按条计价的平台里通常有优势；但如果使用周期只有三四天，按天买反而更省。

**Q：同样是月卡，为什么有的平台按条卖、有的按账号卖？**
这是计价基数不同，不是文字游戏。按账号卖的套餐里出口条数固定，用不满就浪费；按条卖的更贴近实际用量。比价时先把两边都换算成「单条出口每天多少钱」再决定。

**Q：JiuIP 的带宽买小了，能加钱升档吗？**
不能，选档那一步会明确提示「后期不能升级」。所以别用「先买最小档试试」的心态选带宽——先用 30 次测试卡跑一轮真实占用，再照峰值往上留一档余量下单。

**Q：1 金币到底等于多少钱？**
站内与官方口径均为 1 金币≈1 元，且充值金额越大赠送比例越高（5%–25%），实际单价比标价再低一档。具体到账比例以充值页面实时显示为准。

**Q：一个月换 IP 三十次，JiuIP 够用吗？**
够。月卡每条 IP 自带 30 次切换额度，折下来正好每天一次。一天要换 3 次以上就得靠多买条数把频次摊开，单条额度撑不住。

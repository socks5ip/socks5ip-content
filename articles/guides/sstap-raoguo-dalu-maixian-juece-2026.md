# SSTap 勾了绕过大陆 IP，5.3 元的国内线还在工作吗（2026）

这个勾到底怎么运作？它改的不是线路，而是一张名单。**SSTap 的「绕过大陆 IP」勾上之后，目标落在国内 IP 段的流量全部从本地宽带出去，TAP 网卡只接海外那一段。** 拿 5.3 元/30 天的国内线去跑国内游戏、国内店铺后台，出口一次都不会变，这条线一个月里不会被调用一次。

| 你以为的 | 实际发生 |
|---|---|
| 勾上「绕过大陆 IP」＝更快 | 国内流量绕开代理，代理只服务海外 |
| 国内线买了就一定生效 | 目标站是国内的，这条线不会被调用 |
| IP 换了＝全站都换了 | 海外站换了，国内站还是本地出口 |
| 按天卡试一天就能判出来 | 只测国内站，试一百次也测不出差别 |

数据来源：站内 SSTap 教程页与常见问题页、无双IP 价格表页（2026-11 核实）。

## 一、这一勾改的是一张名单，不是一条线路

SSTap 干活的方式没变过：装一块 TAP 虚拟网卡，把整机请求先接下来，再按规则决定谁走代理、谁放回本地。接流量是全局的，分不分流取决于模式和那个勾。

它上面有两类模式，差别不在快慢，在名单要不要生效：纯「全局」全部交出去，一条不留；带「内置规则」的那一档，会把私网段和国内 IP 段先列成直连，剩下的才送去代理服务器。「绕过大陆 IP」这个勾，加的就是后面这份名单。不同版本界面文字有出入，按「内置规则」四个字找那一档。

| 模式 | 谁被接走 | 国内站看到的出口 |
|---|---|---|
| 全局（不带规则） | 全部流量，含内网与国内站 | 代理 IP |
| 全局 + 内置规则 | 海外目标 + 未命中名单的流量 | 本地宽带 IP |
| 全局 + 内置规则 + 绕过大陆 IP | 只剩海外目标 | 本地宽带 IP |
| 自定义规则 | 你手写进规则的那几条 | 看你写没写 |

还有一处容易被忽略：勾选之后，代理服务器那头看到的连接数会明显下降。这不是线路变好了，是一半请求根本没到它跟前。

## 二、按目标站的位置买线：三种业务三张账单

先按目标站归属选线，再决定那一勾怎么设，顺序反了就会白花钱。

| 你要跑的业务 | 目标站归属 | 绕过大陆 IP | 买什么线 |
|---|---|---|---|
| 国内游戏多开、国内店铺多号 | 国内 | 取消勾选 | 国内 SK5，一条线对一个出口 |
| 海外店铺、海外社媒、海外游戏 | 海外 | 勾上 | 海外精选 7.5 元起，要家宽出身再往上走 |
| 国内海外都要，一台机器 | 混合 | 勾上但手写例外 | 国内一条 + 海外一条，靠自定义规则分开 |
| 软路由、整机隧道 | 看你接什么 | 不适用 | L2TP 按带宽档，不用 SSTap 这套 |

第二行在国内业务里代价最大。做多店铺最怕的不是 IP 不好用，是「以为用了」：SSTap 勾着这一栏，后台里显示的登录 IP 与家里那条宽带完全一致，而你以为自己在用一条 5.3 元的线——平台侧看到的是同一台机器、同一个出口登了五家店。

## 三、价差从 5.3 元开始分叉

同一个月卡，国内线和海外线是两条独立曲线。拿无双IP 的公开价目做对照：

| 线路档位 | 30 天价 | 折到每天 | 服务的目标 |
|---|---|---|---|
| 国内线路（SK5） | 5.3 元 | 约 0.18 元 | 国内站点、国内游戏 |
| 游戏精选（海外） | 7.5 元 | 0.25 元 | 香港云节点为主，加一条美国原生 |
| 游戏优选（海外） | 10.5 元 | 0.35 元 | 二十多个云节点，按国家选 |
| 游戏住宅推荐（海外） | 19.8 元 | 0.66 元 | 家宽出身，二十多个地区 |
| 游戏住宅（海外） | 24.2 元 | 0.81 元 | 十个家宽节点 |

这张表最容易误读的地方是「都按月卡比」。5.3 元那行折到每天不到两毛，看着最划算，但它只对国内目标生效——勾着「绕过大陆 IP」，这 5.3 元一个月里一次都不会被调用。反过来，只做海外业务的人根本不需要这一行。

价目表上还有一处差别值得记住：SK5 按条卖，一条线一个出口；L2TP 按带宽卖，走的是一条整机隧道。**SSTap 只认 SOCKS5 这类代理协议，填不了 L2TP**，想用 L2TP 得走系统拨号，那时候谈不上「绕过大陆 IP」这一勾——整机流量全在隧道里。

## 四、三步验出口：只测一个站永远判断不出来

判断标准只有一个：同一个浏览器、同一个时刻，国内站和海外站显示的出口 IP 是不是同一个。

| 步骤 | 看什么 | 怎么判读 |
|---|---|---|
| 第一步：国内 IP 查询站看出口 | 归属地、运营商 | 显示你家宽带所在省市＝国内流量没走代理 |
| 第二步：海外站或海外 IP 查询页看出口 | 国家、城市、ASN | 显示你买的那条线的地区＝海外流量走通了 |
| 第三步：把两个结果摆一起 | 是否同一个 IP | 不同＝只换了一半，这正是要查的东西 |

第二步别只测一个海外站。有些站的页面走了 CDN、节点就在国内，你看到的是 CDN 边缘 IP 而不是这条线的出口，容易误判成「没生效」。想稳一点，用站内的 [IP 综合检测中心](https://socks5ip.com.cn/ip-check-center/) 把出口归属、线路可用性、目标场景模拟一次跑完。

还有三个会让读数骗人的地方：浏览器开了 QUIC 或内置 DoH，解析走了一条你没预期的路；机器上同时装了两个客户端，两边都在抢流量；系统代理里还留着旧 PAC 地址。测之前把这些关掉，读数才有意义。

## 五、反过来用：这一勾省的是流量和延迟

对只做海外的人来说，这一勾不是坑，是省钱那一栏。国内流量不进代理，月卡额度就只花在真正需要换出口的请求上。

| 做法 | 省下的 | 代价 |
|---|---|---|
| 勾上，国内站全部直连 | 月卡流量只算海外请求；国内 CDN 不绕路 | 国内站看到真实 IP，敏感业务别这么干 |
| 不勾，全部走代理 | 出口统一，好核对 | 国内流量也吃额度，国内站点绕一圈再回来 |
| 勾上 + 手写几条例外 | 核心站点仍走代理，其余直连 | 要维护规则，写错顺序会不生效 |

无双的 SK5 月卡给 130GB、周卡给 30GB，续费重置。这个额度放在「勾上」的用法里够跑很久，放在「不勾」的用法里会明显吃紧——同样的钱，一勾之差就是两个消耗速度。

## 六、SSTap 接不住的四种场景

| 场景 | 能不能做 | 换线能治吗 |
|---|---|---|
| 单窗口单 IP | 做不到，它不认识进程 | 不能，要换按进程接管的客户端 |
| 填 L2TP | 填不了，只吃 SOCKS5/SS/SSR | 不能，走系统拨号或软路由 |
| UDP 转发 | 看线路，多数按条提取只开 CONNECT | 部分能，要单独测一列 |
| 连接数上限 | 默认 256-512，调到 1024 以上先撑不住路由器 NAT | 不能，改回去就好 |

这四件事里只有第三件和「买哪条线」有关，其余三件换线也治不好。判断顺序是先看这四件有没有踩到，再回头调模式和勾选，别把客户端的问题当成 IP 的问题。

## 七、自测口径

| 测什么 | 怎么测 | 判定标准 |
|---|---|---|
| 国内出口 | 国内 IP 查询站 | 与本地宽带一致＝直连生效 |
| 海外出口 | 海外查询页 + 检测中心 | 落在所购线路的城市与 ASN |
| 额度消耗 | 用一整天的真实业务跑完看后台流量 | 与「只走海外」的预估差多少，决定要不要加量 |

先装客户端再买线。客户端免费，装完什么也测不出来是正常的，因为没有线。再拿平台的免费测试卡把线路导进去，按第四节三步测一遍出口，最后才决定买国内线还是海外线。

## 九、常见问题

**Q：勾了「绕过大陆 IP」，国内游戏里为什么还是本地 IP？**
因为国内 IP 段被写进了直连名单，游戏服务器地址命中了名单，流量根本不进 TAP 的代理通道。要在国内游戏里换出口，得取消这一勾，或者换一条明确走代理的国内线。

**Q：怎么一眼看出只换了一半？**
同一时刻分别看国内站和海外站显示的出口 IP。两个不一样，就是只换了一半；两个一样，才算全部走了代理。

**Q：国内线和海外线能共用同一个客户端吗？**
能填多条，但同一时刻只有一条生效。要一台机器同时跑国内和海外两个出口，靠自定义规则把不同目标分给不同线路，或者开两台机器各跑一条。

**Q：5.3 元的国内线，勾上之后是不是白买了？**
对国内目标是。这条线的价值在于给国内站点一个不同于本地的出口，勾上就等于把它闲置。要么取消勾选让它干活，要么把这条线留给另一台不勾的机器。

**Q：为什么测速显示很快，实际用起来还是原来的网络？**
测速站多半在海外或走 CDN，命中的是代理通道；而真正在用的国内站点走的是直连。速度读数只能证明代理通不通，证明不了「目标站看到的出口变了」。

**Q：先装客户端还是先买线？**
先装客户端，它免费。再拿平台的免费测试卡把线路导进去，按三步测一遍出口，确认国内海外各是什么结果，最后才决定买国内线还是海外线。

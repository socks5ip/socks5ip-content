# 老鱼免费版和专业版：27 行功能表只 4 行卡业务

打开功能对比页，27 行从上往下数，会发现 25 行的勾只打在右栏——但真正让人干不了活的，只有其中四行。

老鱼免费版和专业版的差别，常被说成「功能多少」。按条数比没意义：25 行的差距里，二十来行是效率开关，用不到的人升了也感觉不出差别；剩下四行才是「能不能干」。12 元一年买的不是多开，是这四行。

**老鱼专业版 12 元一年，官方功能表 27 行里 25 行只在专业版一侧，两版都不含线路 IP；真正决定业务能不能跑的是四行——非易语言编译、虚拟硬件、模拟器绑定线路、规则粒度。**

| 差异点 | 免费版 | 专业版（12 元/年） |
|---|---|---|
| 编译语言 | 易语言 | 非易语言 |
| 模拟器绑定线路 | 不支持 | 支持（雷电 / 逍遥 / 夜神） |
| 代理规则粒度 | 仅进程名 | 进程名 / 路径 / MD5 / 文件夹 |
| 虚拟硬件 | 约等于没有 | 多套配置，可绑线路 |
| 线路 IP | 不含，需自备 | 不含，需自备 |

## 25 行差距，其实只有四类

**把 25 行按性质分，只有四类：决定「进程怎么被识别」的、决定「窗口怎么分线」的、决定「线路怎么进来」的、以及纯效率开关；前三类踩到就是干不了，第四类踩不到则升了也白升。**

这个分法比逐条背功能有用，因为它把「功能条数」换成了「业务会不会踩到」。判断要不要花那 12 元，只要回答三个问题：程序会被检测吗、窗口要不要各走一条线、线路是不是短效池。

| 类别 | 具体条目 | 踩到了会怎样 |
|---|---|---|
| 识别类 | 无易语言特征、虚拟硬件、自定义驱动名称、反截屏 | 被目标程序的特征检测挑出来 |
| 分线类 | 模拟器绑定线路、模拟器走本地、进程启动器 | 多个窗口没法各走各的线 |
| 进线类 | API 提取模式、用户 Api、禁用/启用线路、重新分配 IP | 短效 IP 池要手工搬，搬不过来 |
| 效率类 | 随机使用线路、自动切换、暂停代理、启动后最小化、自适应 DPI | 能用，只是省不下手工时间 |

三个问题都说「不用」，免费版就是够的。这是实话，也是很多人不愿意在推广文里写的一句——12 元不是必买项，它是按需项。

## 编译语言：唯一一条直接指向风险的说明

**「无易语言特征」是整张功能表里唯一一条明确写到封号风险的行，官方备注原话是国内很多游戏厂商会检测易语言程序导致误封。**

易语言编译出来的程序，在可执行文件结构、导入表、字符串特征上与 C++、Delphi 那类构建有明显区别。游戏客户端做进程枚举时，除了看进程名和窗口标题，通常会连模块特征一起扫。免费版被扫到，不等于一定出事，但等于你主动交出了一个别人没有的标记。

专业版这一行解决的是「像不像常规程序」，官方另外还给了一条：支持版本定制，自助做随机参数混淆编译，用来减少特征。说白了，12 元买的不是功能，是让这个客户端在进程列表里不显眼——对挂机时间长、账号成本高的场景，这一项的权重比多几个窗口大得多。

## 进程往外读的三样，专业版能换

**虚拟硬件、自定义驱动名称、反窗口截屏三行，解决的是同一件事：被代理的进程往外读信息时，读到的东西与这台物理机对不上。**

虚拟硬件那一格写的是「多套配置、绑线路、支持 32/64 位目标进程」。硬件信息在风控里的用途很直白：多个账号在同一台机器上登录，如果每次都读到同一组机器标识，账号之间的关联是白送的。虚拟硬件把这个层面的信息按线路拆开，一条线一套配置，换来的是「同一台电脑开多个窗口，从目标程序看过去像几台不同的机器」。

边界要说清：虚拟硬件改的是被代理进程读到的信息，不改系统里的真实设备，也不等于换了一台电脑。它能降低关联度，但网络出口、时区、语言、浏览器指纹各管一段——只补一处，另外几处照样能对上。

另外两项容易被忽略。「自定义驱动名称」意味着这个名称可以自己改，不再固定成一个能被特征库记住的字符串；「反窗口截屏」官方描述是可在设置中开启反截屏与壁纸保护模式，窗口在截屏类操作下不直接露出内容。两处都不影响功能，影响的都是「像不像一台普通机器」。

## 一窗一线：免费版做不到的那一步

**免费版的规则粒度只有进程名，专业版给到进程名、路径、MD5、文件夹四种；配合模拟器绑定线路，才能做到「这个窗口走这条线，那个窗口走那条」。**

这一条是多开业务真正的分水岭。进程名是最粗的一层：同一个模拟器开五个窗口，进程名往往一样，规则写下去五个窗口全走同一条线，等于没分。只有按路径、按 MD5、按文件夹区分，才能把不同实例指到不同线路。

模拟器绑定线路是配套的另一半：雷电、逍遥、夜神三个常被点名的模拟器，专业版能把线路绑到具体实例上。免费版没有这一项，多开就等于所有窗口共享一个出口。

| 需求 | 免费版能不能做 | 专业版怎么配 |
|---|---|---|
| 单窗口走代理 | 能 | 同 |
| 五个窗口各走一条线 | 不能（只认进程名） | 按路径/MD5 建规则 + 绑实例 |
| 同一程序挑其中一份走代理 | 不能 | 按文件夹或 MD5 区分 |
| 短效 IP 池批量换线 | 手工搬 | API 提取模式 |

## 12 元买的是客户端，不是线路

**两版都不含线路 IP，专业版 12 元只是客户端授权；线路要另买，一条窗一线意味着线路条数跟窗口数走。**

这一点在预算里最容易被漏算。10 个窗口要各走一条线，就得有 10 条线路，客户端那 12 元在这笔预算里几乎可以忽略。按市面常见价位算，一条线几元到二十几元一个月，10 条一年的线路费是客户端授权费的几十倍。

所以正确的问法不是「专业版值不值 12 元」，而是「我的窗口需不需要各走一条线」。需要，12 元是必付的门票；不需要，12 元省下来买线路更实在。

## 三个问题，决定升不升

**程序会不会被检测、窗口要不要各走一条线、线路是不是短效池——三个都答「不用」，免费版够；有一个答「要」，专业版就是必买。**

| 问题 | 答「要」的后果 | 免费版 |
|---|---|---|
| 目标程序会做进程特征检测 | 需要非易语言构建 | 做不到 |
| 每个窗口要独立出口 | 需要实例级规则 + 绑线 | 做不到 |
| 线路是短效池、要批量换 | 需要 API 提取 | 只能手工 |

三个问题里第一个最容易被低估：很多人只盯着「能不能多开」，忽略了「多开之后被认出来」。挂机时间越长、账号成本越高，这一项的权重越大。

## 自测口径：三项，一小时内

**装完专业版先跑三项：在任务管理器里看进程与模块特征、开两个实例分别配不同线路后从各自窗口查出口、退出客户端确认本地直连恢复。**

第一项看的是「像不像常规程序」，不用工具也能粗看：进程名、公司名、版本信息是否完整。第二项是核心，两个实例分别打开检测页，出口必须不同——相同就说明规则没落到实例级。第三项最容易被忘：全局接管类工具退出后若没还原路由，表现是「没开代理却上不了网」，别误判成线路坏了。

## 常见问题

**问：老鱼免费版和专业版差在哪？**
答：官方功能表 27 行，25 行只在专业版。真正影响业务的是四行：编译语言、虚拟硬件、模拟器绑定线路、规则粒度。

**问：专业版 12 元一年，含线路吗？**
答：不含。两版都是客户端，线路要另外买，一条窗一线意味着线路条数跟窗口数走。

**问：为什么免费版多开时所有窗口都走同一个 IP？**
答：规则粒度只到进程名，同一个模拟器的多个实例进程名相同，规则无法区分。

**问：只做单窗口挂机，需要专业版吗？**
答：不需要。单窗口不涉及实例级分线，免费版够用，12 元可以省下来买线路。

**问：装了专业版还是被检测到，问题在哪？**
答：先看是不是只补了客户端这一处。出口身份、时区、语言、浏览器指纹各管一段，客户端只解决进程特征那一层。

**问：退出客户端后上不了网怎么办？**
答：全局接管类工具会改系统路由或虚拟网卡，退出没还原就是「没开代理却断网」。先在客户端里点一次恢复，或重启网卡，别当成线路故障。

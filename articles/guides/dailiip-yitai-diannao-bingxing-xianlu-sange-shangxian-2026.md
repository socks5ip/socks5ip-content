# 一台电脑挂几条线路，卡住你的不是月费

打开网络设置那一刻会发现，能填代理的地方只有一处——再买几条线路也无处安放。**一台电脑能同时挂几条代理线路，答案不是月费决定的，而是三个上限里最小的那个**：系统代理只有一份配置、工具决定并行单位是进程还是窗口、平台按档位给额度。三者取最小，才是这台机器实际能用的条数。

## 系统里只有一个代理位，这是最容易被跳过的那条上限

Windows 的「设置 → 网络和 Internet → 代理」只有一份手动配置，macOS 按网络服务各配一份。这意味着同一台机器上，所有跟随系统代理的程序共享同一个出口——填了 A 线路，全都走 A；换成 B，全都跟着换。

麻烦在于「跟不跟随」这件事，看名字看不出来：

| 程序类型 | 跟不跟系统代理 | 实际后果 |
|---|---|---|
| 主流浏览器（Chrome、Edge） | 默认跟随 | 系统代理一改，全部浏览器一起改 |
| Firefox | 自带独立代理设置 | 可以单独走一条，与系统代理不一致 |
| 自带网络栈的客户端（游戏、部分工具） | 多数不读系统代理 | 系统里填了照样直连，表现为「换了 IP 没反应」 |
| 下载器 / 网盘 / 办公软件 | 一部分跟随、一部分自带 | 同一套配置下行为不统一 |

所以只动系统代理的话，第一个答案往往就是 1 条。想要多条并存，要换的是**并行单位**，而不是往系统设置里继续塞线路。

## 并行单位不同，能挂的条数能差好几倍

把「并行单位」想清楚，条数问题就解开一半：同样叫多条线路同时在线，按进程分、按窗口分、按设备分是三套完全不同的做法。

| 并行单位 | 怎么做 | 条数由什么决定 |
|---|---|---|
| 整机（系统代理） | 系统设置里填一组地址端口账号密码 | 固定 1 条，改了就全改 |
| 按进程 | 用能按可执行文件指定出口的工具，给每个程序单独配 | 等于你要区分的程序个数 |
| 按窗口 | 用支持单窗口单 IP 的加速器，把线路绑到窗口 | 等于你要隔离的窗口个数 |
| 按下游设备 | 把线路配到软路由，按设备或网段分流 | 等于下游要独立出口的设备数 |

四类做法的上手成本依次上升，收益也依次上升。只跑一两个程序，第一类就够；一个屏幕上十几个窗口各走各的，只有第三类或第四类做得干净。站内的**代理工具中心**把这几条路分别列了教程：按窗口的看[老鱼加速器免费版教程](https://socks5ip.com.cn/dailigongju/laoyujiasuqimianfeib/)，按进程的看 [SSTap 配置教程](https://socks5ip.com.cn/dailigongju/sstapjiaocheng/)，整机分流看 [软路由专题](https://socks5ip.com.cn/ruanluyou-proxy/)。

## 线路与出口是两件事，别当成一个词用

一条线路在后台通常就是一组「地址 + 端口 + 账号 + 密码」，它是一份可以反复填写的凭证，不是一把独占锁。两台机器、两个程序里填同一组凭证，目标网站看到的仍然是同一个出口 IP。

| 单位 | 它是什么 | 什么时候会撞 |
|---|---|---|
| 线路（凭证） | 后台给的一组分发信息 | 多条线路可能来自同一账号，也可能来自不同平台 |
| 出口（目标站看到的 IP） | 线路真正的落地点 | 两个程序共用一组凭证，出口就是同一个 |
| 账号（业务身份） | 你在目标平台运营的那个号 | 两个账号落在同一出口，隔离等于没做 |

这份顺序就是自查表：先数业务账号有几个，再数出口有几个，最后看有没有两个账号落在同一个出口上。**数量对不上，就是隔离没做够，跟买了几条线路无关。**

## 条数一多才会冒头的三处冲突

单独挂一条时下面这三处根本不会出现，一旦并行条数上去就会轮流跳出来，这也是「能挂几条」在工程层面的真实天花板：

| 冲突点 | 多线路下的表现 | 处理方向 |
|---|---|---|
| 端口占用 | 多个客户端抢同一个本地监听端口，后起的连不上 | 每个客户端分配不同本地端口，别都用 1080 |
| DNS 走向 | 两个工具都想接管解析，谁的规则先命中就听谁的 | 固定由一个工具解析，其余只做转发 |
| 默认路由 | 多条隧道抢默认路由，优先级高的把其他的压掉 | 按目标网段分流，不要都挂默认路由 |

这三处和「单条线路连不上」是两码事：单条出问题（填错、被拦、DNS 不通）走另一套排查顺序，而上面三条只在并行时才出现。

## 三个数取最小：你的条数这么算出来

| 要数的数 | 怎么数 | 常见误判 |
|---|---|---|
| 业务需要几个不同出口 | 数「最多同时要互相隔离的账号 / 窗口 / 设备」有几个 | 按账号总数买，其实同时在线的只有一部分 |
| 本机能并行几条 | 看用哪套并行单位：整机 1 条、按进程、按窗口、按设备 | 以为买够了就能并行，没换工具 |
| 平台那一档允许怎么用 | 看后台的切换次数、并发与白名单写法 | 把「不限次数」当成「不限条数」 |

## 常见问题

**Q：一台电脑最多能同时挂几条代理线路？**
没有固定数字，取决于你用哪种并行单位。只改系统代理就是 1 条；按进程或按窗口分流，条数等于要区分的程序数或窗口数；配到软路由上，条数等于下游要独立出口的设备数。真正的瓶颈通常是工具，不是电脑配置。

**Q：系统里已经填了一条，再加一条会怎么样？**
会直接覆盖，不会叠加。系统代理只有一份配置，填第二条等于把第一条换掉，之前走那条线的程序会一起改过去。想两条并存，必须换并行单位。

**Q：同一个 IP 被两个程序同时用，会有问题吗？**
技术上没问题，一组凭证本来就可以被多个程序同时填写，出口还是同一个 IP。风险在业务侧：如果两个本该互相隔离的账号落在同一出口，平台的关联判断看到的是同一台机器。

**Q：多开到底该用 SSTap、老鱼还是软路由？**
看你的并行单位。要按窗口隔离，用支持单窗口单 IP 的加速器；要按程序隔离，用能配规则的客户端；要让整台机器甚至下游设备统一走某条线路，用软路由做分流。三者不是替代关系，是三种不同的切分方式。

**Q：条数加多了，速度会不会一起变慢？**
会，但摊薄的是整条宽带和每条线路各自的带宽，不是平台在限你。多开时每条线路如果都跑满，本地出口带宽会被分掉，所以要用测速工具在同一时间点测一遍多开前后的差别。

**Q：买之前怎么确认条数够不够？**
把三个数取最小：业务同时需要的出口数、本机能并行的条数、平台那一档允许的额度。多数平台都留了免费测试额度，先用测试额度跑一遍真实场景，再按测出来的数字下单最稳。

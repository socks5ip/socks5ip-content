# NekoBox 电脑端怎么配：Windows 上的全局接管有两条路

刚把客户端装好、代理开关一拨，浏览器里页面刷得出来，可游戏一连上就断——卡住的是「谁有权限替程序决定流量去向」，而 Windows 上能做这件事的桌面项目，名字里并没有 Box。

## 三个带「Neko」的名字，只有一个进得了 Windows

搜「电脑端」，翻出来的结果其实混着三种不同的东西。它们同名、同开发者，但只有中间那个能在 Windows 上装。

| 名字 | 是什么 | 现在什么状态 |
|---|---|---|
| NekoBox for Android | 安卓端图形客户端，手机上装的就是它 | 官方在维护，最新稳定版 1.4.2，内核 sing-box 1.12.19-neko-1 |
| NekoRay | 同一位开发者的桌面项目，Windows / Linux 的 Qt 界面 | 仓库 2025-03-17 已归档（只读），最后一版 4.0.1 停在 2024-12-12，内核 sing-box 1.9.7-neko1 |
| 应用商店里的「NekoBox」 | 第三方推送的同名版本 | 冒充版，2024 年 5 月起脱离开发团队、不含开源核心 |

结论很直接：你搜的是「NekoBox 电脑端」，能装的只有 NekoRay，而它已经不更新了。安卓的安装包拷到 Windows 上双击是装不上的，两边不是同一份文件。

## 系统代理与虚拟网卡，覆盖面差着一层

「全局」这两个字在 Windows 上有两种实现，能管到的范围差得很远。把它们分清楚，后面所有配置动作都能对号入座。

| 对比项 | 系统代理 | 虚拟网卡（TUN） |
|---|---|---|
| 接管的范围 | 读取系统代理设置的程序：浏览器、系统级下载器、部分桌面软件 | 所有走系统网络栈的程序：游戏客户端、模拟器、不认代理设置的桌面工具 |
| 配置动作 | 填 host、端口、账号密码，开关一开就生效 | 需要装虚拟网卡驱动并用管理员权限启动，再指定要托管的流量 |
| 典型症状 | 浏览器走了、游戏没走，看起来像「只对一半程序生效」 | 全都走了，但规则写错会整机断网 |
| 排错成本 | 低，改错了关掉就恢复 | 高，先小范围试、确认能回退再用 |
| 适合谁 | 只要网页和外网访问走线路的人 | 要覆盖游戏、桌面客户端、模拟器的人 |

虚拟网卡这个名字听起来玄，实质是客户端在系统里创建一块网卡，把流量在网络层截下来交给线路。安卓上的 NekoBox 走的是同一条思路——它靠系统自带的网络接口拿到全局接管能力，所以手机上一开就全设备生效。Windows 没有这个现成接口，得靠虚拟网卡补。

## 哪些程序认系统代理，哪些不认

判断一个程序会不会跟着走，只看一件事：它读不读系统代理设置。

| 程序类型 | 读系统代理设置吗 | 系统代理下会走线路吗 |
|---|---|---|
| 浏览器（Chrome / Edge 等） | 读 | 会 |
| 系统自带下载器、部分桌面工具 | 读 | 会 |
| 游戏客户端、模拟器 | 不读，直接用系统网络栈发连接 | 不会 |
| 某些自带代理设置的程序 | 不读系统的，只认自己那一栏 | 不会，除非单独填 |

所以「设了系统代理，游戏还是本机 IP」并不是设置错了，而是这类程序压根不看那个设置。要让它走，只有往回退一层——在网络层拦；或者反过来，用能按进程指定出口的工具把它抓进来。

## 归档版桌面项目还能做到哪一步

既然只有它能装，就把边界讲清楚，省得配到一半发现卡在版本上。它走的是和安卓版同一套逻辑：先在配置里建一条独立代理账号（SOCKS5 或 HTTP，填 host、端口、账号密码），再决定用哪种方式把流量接进来。协议支持不吃亏——内核是 sing-box，SOCKS5、HTTP、Shadowsocks、WireGuard、VMess、VLESS、Trojan、Hysteria 这些它都认得。

真正要留神的是内核号，不是版本号。它停在内核 sing-box 1.9.7-neko1，而 sing-box 后来陆续加过一批新字段与新的规则写法，拿最新的官方文档去套它的配置文件，报错是正常现象。

| 你的情况 | 建议 |
|---|---|
| 已经在用 NekoRay，配置跑得顺 | 可以不动，它依赖的虚拟网卡机制本身没变，旧版照样工作 |
| 从零开始搭桌面环境 | 不建议再从它起步，归档仓库只读、非重大缺陷不再修 |
| 手上有独立 SOCKS5 / HTTP 账号，只想要个轻量客户端 | 走虚拟网卡那一类工具，接管范围能对上 |
| 只是先确认行不行 | 先用免费测试额度验一条线路，再决定装哪种工具 |

## 挑接管工具看接管范围，不要看名字

名字里带不带 Box、带不带 Ray，和它能管到哪些程序没有关系。挑之前先回答一个问题：你要接管的，是只有浏览器，还是包括游戏和桌面软件？

- 只有浏览器：直接填系统代理就够，不必装驱动、不必提权。
- 包括游戏和桌面软件：走虚拟网卡那一类，接受「规则写错会断网」的代价。
- 只跑一个模拟器里的进程：用能按进程指定出口的工具更省事，不必全局。
- 想连 L2TP 这类隧道线路：换客户端，客户端本身管不了隧道。

## 配完先做三项回读

配完不等于配好，用三件事各确认一次，比凭感觉判断快得多。

| 回读项 | 怎么读 | 通过标准 |
|---|---|---|
| 出口归属 | 用 IP综合检测中心 读一次 | 归属地与线路类型和买到的对得上 |
| 接管范围 | 分别打开浏览器和游戏客户端，各查一次 | 该走的程序都报线路 IP |
| 回退路径 | 关掉接管开关 | 立刻恢复本机 IP，不需要重启 |

## 这两类需求用不上全局接管

全局接管有代价，不是所有场景都需要。只让浏览器走线路的，填系统代理就够了；只跑一个模拟器里的一个游戏，用按进程指定出口的工具也够。真正需要全局的，是「这台机器上随便开什么程序都要走线路」这一类需求。

## 常见问题

**Q：NekoBox 有电脑版吗？**
官方 NekoBox 只发安卓版，最新稳定版 1.4.2。电脑上能装的是同一位开发者的桌面项目 NekoRay，仓库 2025-03-17 已归档。

**Q：设了系统代理，为什么游戏还是本机 IP？**
游戏客户端不读系统代理设置，直接用系统网络栈发连接。要让这类程序也走线路，得用虚拟网卡在网络层接管，或者换成按进程指定出口的工具。

**Q：虚拟网卡和系统代理能同时开吗？**
可以，但要留意规则冲突。稳妥的做法是先单独验证一种，确认能回退，再叠加第二种。

**Q：应用商店里的 NekoBox 能装吗？**
那是冒充版，2024 年 5 月起脱离开发团队、不含开源核心。装客户端前先核对版本与官方渠道。

**Q：配完怎么确认线路真的生效了？**
用站内 IP综合检测中心 读一次出口归属，再分别打开浏览器和游戏客户端各查一次，两个都报线路 IP 才算接管到位。

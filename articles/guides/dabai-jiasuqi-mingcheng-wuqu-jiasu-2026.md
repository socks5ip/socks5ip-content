# 大白加速器不是游戏加速器：它换的是出口，不是延迟

客户端下载不花钱，真正掏钱的是节点——**2.6 元/月一条起**，这笔账和「加速」两个字无关。大白加速器是一个约 **6.9 MB** 的安卓客户端，跑 Android 7.0 以上，做的是把你手机上的流量送到指定的那条线路上；出口换了，速度反而有可能变慢。把它当成游戏加速器去对标，结论必然是「不好用」，但这是对错了对象。

## 「加速器」这三个字被三类软件共用

| 类别 | 它优化的是什么 | 典型目的 |
|---|---|---|
| 游戏加速器 | 路由路径与延迟 | 降低游戏延迟、减少跳ping |
| 隧道类客户端 | 链路加密与转发 | 建一条受保护的通道 |
| 代理客户端 | 出口落地地址 | 让对外地址变成节点所在地 |

大白加速器属于第三类。三类软件解决的是三件不同的事，名字重合只是因为中文里都用「加速」来称呼。

## 大白加速器换的是出口，不是延迟

| 你期待的 | 它实际给的 |
|---|---|
| 延迟更低 | 不优化路由，延迟由节点线路决定 |
| 下载更快 | 不提升带宽，速度受节点档位限制 |
| 出口 IP 变化 | 会给，这是它的核心作用 |
| 本地状态可见 | 会给，列表、检测、连接状态 |

**要的是「换出口」，它就对；要的是「变快」，它不对。**方向弄错，后面所有判断都会歪。

## 它实际做的三件事

| 动作 | 说明 |
|---|---|
| 导入节点 | 把整段节点文本批量放进本地列表 |
| 建立本地通道 | 由系统授权后接管流量 |
| 显示与切换状态 | 启动、断开、在多条节点间切换 |

三件事都不涉及线路质量的改动，节点好不好是平台的事，客户端只负责把流量送过去。

## 按用途对号：你要的是哪一类

| 你的目的 | 该用哪一类 |
|---|---|
| 降低游戏延迟 | 游戏加速器 |
| 让对外地址换一个城市或线路 | 代理客户端 + 一条节点 |
| 给手机上的应用建一条受保护的通道 | 隧道类客户端 |
| 多账号要互相独立出口 | 代理客户端 + 多条节点 |

## 两个同时开着，谁先谁后有讲究

同一时刻只应该有一个在接管出口。两个同类客户端一起开，容易出现启停互相顶掉，表现是「一会儿通一会儿不通」。如果确实要同时装两个，**用的时候只留一个处于启动状态**，需要切换时先断开再启动另一个。

## 免费的是客户端，收费的是节点

| 项 | 是否收费 |
|---|---|
| 客户端安装包 | 免费 |
| 节点线路 | 按平台与档位收费，常见起步约 2.6 元/月 |
| 免费测试 | 多数平台提供，额度各不同 |

所以「装了但连不上」最常见的两个原因就浮现出来了：一个是**根本没买节点**，另一个是**节点买了但没导进列表**。客户端本身没有任何一条内置线路。

## 常见问题

**Q：为什么连上以后网速反而变慢了？**
因为它做的是换出口，不是提速。流量绕到节点所在线路后再出去，链路更长，速度取决于那条线路的带宽与质量。

**Q：它自带节点吗？**
不带。客户端只负责导入与连接，节点要从代理平台单独购买，站内价格中心可以横向比价。

**Q：游戏能用它吗？**
能连，但别指望提速。游戏场景真正需要的是低延迟的专线型线路，而客户端本身不改变延迟。

**Q：装了客户端却提示列表为空，是坏了吗？**
不是。空列表只说明还没有导入节点。先在平台后台提取一条完整节点（四项信息同源），再整段导进列表。

**Q：怎么确认它确实在做该做的事？**
查一次落地地址。地址变成了节点所在的位置，说明接管生效；地址没变，说明流量还没走到这条线上。

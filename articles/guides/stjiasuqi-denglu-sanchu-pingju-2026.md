# 一个账号，三个容器

密码没错，是入口错了还是栏目选错了？ST加速器（搜他网）把一件「登录」拆给了三个容器：官网管订单、客户端接线路、系统里填直连参数，三处各认一套凭据，互相不通用。分不清自己站在哪一处，「账号或密码错误」这句提示就永远解不开。

## 一、三个容器各认一套凭据

| 入口 | 在哪儿 | 拿什么登 | 登进去管什么 |
|---|---|---|---|
| 官网登录弹窗 | 官网导航栏的弹窗（标题为「账户登录」，可用时切换为「微信登录」） | 手机号 + 密码 | 订单、充值、套餐到期时间、资金记录 |
| 电脑端客户端 | ST加速器.exe 的软件后台，左侧【ST加速器账号】 | 购买时设置的账号密码 | 让这台电脑上的指定程序走代理线路 |
| 安卓端客户端 | ST加速器.apk 打开后的后台，左侧【ST加速器账号】 | 购买时设置的账号密码 | 选地区、手动换 IP |
| iOS 系统直连 | 设置 → 通用里新增一条 L2TP 连接 | L2TP 服务器地址 + 账户 + 密码 + 密钥 1234 | 系统级直连，不装 App 也能跑 |

判断自己处在哪一处，看提示你的那个界面是谁就够了：官网弹窗报错，问题在账号本身；客户端报错，问题多半在套餐状态；系统直连连不上，问题在参数有没有抄错。

## 二、导航栏里那个弹窗

最常见的挫败感，是在官网首页翻不出一个像样的登录地址。官网上确实没有独立的登录页面，登录是导航栏里的一个弹窗，账号输入、微信登录、忘记密码都在同一个框里完成。弹窗里的元素不多：账号框收的是手机号（校验提示写的是「请输入合法的手机号」，不接受邮箱格式），密码框下方有一条「忘记密码?」。

| 官网导航项 | 对应路径 | 它管什么 |
|---|---|---|
| 首页 / 产品总览 | `/home` | 套餐、协议与设备支持范围 |
| ST套餐购买 | `/buyPackage` | 选版本、下单付款 |
| ST软件下载 | `/downUpload` | 电脑端与安卓端客户端 |
| PPTP/L2TP | `/pptp`，含 `/pptp/citylist` 与 `/pptp/purchase` | 直连类服务购买与地区选择 |
| 教程 | `/course`、`/coursepc`、`/courseios` | 分设备的使用教程 |
| 个人中心 | `/personManage` | 登录后可见：个人信息、充值、资金记录 |

顺带说清一件事：不要去第三方域名上找「ST加速器后台」。这个平台只有 `souta.com` 一个官网，注册、购买、查订单都在同一处完成；一个能正常登录的账号，登录后一定能在个人中心里看到自己的套餐与到期时间，看不到就是入口不对。

## 三、客户端那一栏，要的是购买时的账号密码

客户端和官网是两个不同的容器。打开后在软件后台左侧能看到【ST加速器账号】这一栏，站内教程对这一栏的原始表述是「输入购买的账号密码登录」。它不是给你查订单的后台，登进去的目的是让这台设备接上线路。

所以客户端报「账号或密码错误」时，分两步排除：第一步确认填的位置对不对；第二步回官网个人中心看套餐状态——**没开通、已到期、或者买的是另一个版本的线路，客户端一样连不上**。这两步走完再去试密码，比反复改密码有效得多。

## 四、系统直连那一处：五个字段的填法

在手机上配置系统直连时，那一屏根本没有「登录」两个字，但很多人把它当登录在排查。这里的账号密码来自购买 PPTP/L2TP 服务时平台给出的凭据，与官网登录密码是两套东西；密钥是一个固定值，不需要向客服索要。

| 参数项 | 填什么 |
|---|---|
| 类型 | L2TP |
| 描述 | 自定义，写「ST加速器」便于自己辨认 |
| 服务器 | 购买 PPTP/L2TP 服务后平台给出的地址 |
| 账户 / 密码 | 购买该服务时设置的账号与密码 |
| 密钥（预共享密钥） | 固定填写 1234 |

填完勾选这条配置并连接，状态栏出现连接图标即为接通。这一路常见的失败原因只有三个：服务器地址抄错、账号密码用成了官网密码、密钥那一栏空着或填了别的值。

## 五、六种报错表现，按最可能的原因排序

平台返回的报错文案很少，官网这边只有「账号或密码错误」和「请求超时！」两种，剩下的表现都藏在界面行为里。

| 你看到的现象 | 最可能的原因 | 先做什么 |
|---|---|---|
| 官网弹窗提示「账号或密码错误」 | 手机号或密码不匹配，平台在不匹配时返回的就是这句 | 走弹窗里的「忘记密码?」重设，别在原密码上反复试 |
| 提示「请求超时！」 | 网络或接口超时，不是账号问题 | 换一次网络重试，不要顺手去重置密码 |
| 点微信登录提示「请先注册账号，注册成功后，便可直接使用微信登录」 | 这个微信号从未在平台建过账号 | 先用手机号注册，再回微信登录完成绑定 |
| 客户端【ST加速器账号】登不上 | 凭据位置填错，或套餐未开通 / 已到期 | 核对栏位，再回官网个人中心看套餐状态 |
| 系统直连连不上 | 服务器地址、账户或密钥其中一项不对 | 密钥固定 1234；账号密码取 PPTP/L2TP 服务订单里的那一套 |
| 登录成功但看不到自己的套餐 | 登进去的账号与购买时不是同一个 | 在个人中心核对绑定的手机号，确认登录身份 |

三套凭据里，只有官网那一套有自助找回通道，另外两套的来源在订单里，找不回就得回订单页或联系客服。真人客服是最后一步，不是第一步——上面六种表现里有四种能在你自己的账号里查清。

## 常见问题

**Q：ST加速器官网为什么找不到登录页？**
官网上没有独立的登录地址，登录是导航栏里的一个弹窗：账号输入、微信登录、忘记密码都在同一个框里完成，标题会在「账户登录」和「微信登录」之间切换。

**Q：客户端提示「账号或密码错误」，是密码真的错了吗？**
不一定。先确认填的是软件后台左侧的【ST加速器账号】那一栏，再回官网个人中心核对套餐是否已开通、有没有到期；这两步都对，才需要去改密码。

**Q：可以直接用微信登录吗？**
可以，但前提是这个微信号已经在平台上有账号。没有账号时点微信登录会提示「请先注册账号，注册成功后，便可直接使用微信登录」——先用手机号完成注册，再回来做微信绑定。

**Q：忘记密码怎么办？**
官网登录弹窗内就有「忘记密码?」入口，按提示用手机号重设，成功后会提示「修改密码成功」，改完用新密码重新登录客户端即可。

**Q：登录进去之后在哪看套餐和到期时间？**
登录成功后，地址栏会进到官网的个人中心，下面挂着个人信息、充值、资金记录等子页，套餐状态与到期时间在这一区核对。

**Q：系统直连时提示账号密码错误，是官网那个密码吗？**
不是。系统直连填的是购买 PPTP/L2TP 服务时拿到的服务器地址、账号和密码，密钥固定 1234，跟官网登录密码是两套独立的凭据。

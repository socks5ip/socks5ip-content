# 极驰云登录入口在哪？根域名打开就是登录页

填完用户名和密码点提交，跳出来的却是一片空白——这种情况多半是入口地址不对，极驰云的登录页只有一个：根域名 www.jichiy.com。**它不在某个二级目录里，根域名本身就是登录入口。**

## 一句话结论

**极驰云（官网 www.jichiy.com）的首页与登录页是同一个地址。** 页面标题就是「极驰云账号登录」，左侧是品牌介绍、右侧是登录卡片；它有两种登录方式，一个页面同时承载登录、注册、找回密码三个入口。判断「入口对不对」只看三件事：地址栏是不是 www.jichiy.com、页面上有没有图形验证码、登录成功后是不是落到 /views/main.html。

| 项目 | 具体口径 |
|---|---|
| 登录入口 | www.jichiy.com（根域名即登录页，路径 /views/login.html） |
| 登录方式 | 账号密码（用户名 + 密码 + 图形验证码）／ 手机验证码（手机号 + 短信码） |
| 登录后落地 | /views/main.html（后台首页），充值、购买、提取线路都在这里 |
| 主体信息 | 页脚备案 闽ICP备2024049909号-2，页内自带法律法规免责声明 |

## 首页和登录页是同一个地址

不少人以为官网首页会是产品介绍页、要再点一次「登录」按钮才进登录框。极驰云不是这个结构：把域名输进去回车，落地页的标题直接就是登录页，右侧就是登录卡片。**不存在「先找登录按钮」这一步。**

| 登录方式 | 要准备什么 | 什么情况下更顺 |
|---|---|---|
| 账号密码登录 | 登录用户名、登录密码，再加一个图形验证码 | 常用设备、密码记得住 |
| 手机验证码登录 | 注册时用的手机号、一条短信验证码 | 换设备、忘了密码、只记得手机号 |
| 忘记密码 | 手机号、短信验证码，以及新密码和确认密码 | 密码确实想不起来；走的是重置而非找回原密码 |

图形验证码这一项值得单独说：页面加载时会向后端取一组校验标识，**在同一台设备上停留太久再提交，很可能提示验证码失效**。遇到这种情况不用重开浏览器，把验证码那一格清空重新点一次即可。

## 看不到表单的两种情形

「登录入口在哪」之所以被反复问，根源不是入口藏得深，而是有两种情形会让你打开官网却看不到登录表单。

| 你看到的现象 | 为什么 | 怎么回到登录框 |
|---|---|---|
| 打开根域名直接进了后台，没有登录框 | 浏览器还留着上一次的登录状态，脚本检测到后自动跳到 /views/main.html，表单根本没渲染 | 先从后台退出，再用浏览器无痕窗口打开根域名 |
| 打开的是别人发的注册链接，直接弹出注册框 | 链接带了推广码参数，页面读到参数后主动切到注册弹层，这是设计如此 | 在弹层底部点「已有账号？立即登录」，或直接打开不带参数的根域名 |
| 点的是旧链接，打开一片空白 | 大概率停在一个已不存在的旧地址上，页面没内容不等于账号有问题 | 只认准 www.jichiy.com 这一个入口，把旧链接从收藏夹清掉 |

## 注册、登录、找回在同一个页面

三个功能做在同一个页面里，靠弹层切换。所以「登录入口」和「注册入口」其实是同一个地址，区别只在于打开后显示哪一层。注册那一层要填的东西比登录多：

| 字段 | 说明 |
|---|---|
| 用户名 | 页面上写的是「设置登录用户名」，以后每次登录都用它，不是昵称 |
| 登录密码 + 确认密码 | 两格必须一致 |
| 手机号码 | 注册即绑定，后续短信登录与找回密码都靠它 |
| 短信验证码 | 旁边有「获取验证码」按钮，带倒计时，归零后再点第二次 |
| 图形验证码 | 与登录用的是同一套校验 |
| 推广码 | 这一格是灰的、不能手动输入，值由你从哪条链接进来决定 |

## 推广码那一格为什么是灰的

它的值来自链接参数，页面读到参数后自动填好并锁定，避免填错。**如果你是通过站内的官方入口链接进来的，这一格已经替你填上了 D06B99413C764A8B8DB7EBFC901A5C85；直接在地址栏手打域名进来，这一格就是空的，也就拿不到渠道折后价。** 这是「同一个页面、不同入口、结果不同」的地方，值得停下来确认一眼。

| 入口 | 打开方式 | 用到什么 |
|---|---|---|
| 登录 | 根域名默认显示的那一层 | 用户名 + 密码 + 图形验证码，或手机号 + 短信码 |
| 注册 | 登录卡片底部「立即注册」，或带推广码参数的链接 | 用户名、密码、手机号、短信码、图形验证码、推广码、勾选协议 |
| 找回密码 | 登录卡片上「忘记密码？」 | 手机号、短信码、新密码、确认新密码 |

## 进后台之后的四条路径

判断「登录成功没有」最简单：地址变成 /views/main.html，左侧出现后台菜单。真正会用到的只有四条路径。

1. **充值余额**——两套金币相互独立：SK5 约 1元=2.5金币、L2TP 约 1元=2.4金币，充进去不能互转，先确定用哪种协议再充对应的那一套。
2. **购买线路**——SK5 走「socks5购买」、L2TP 走「L2TP购买」，是两个独立入口，别进错。
3. **选路线**——电信路线、腾讯路线，或自定义路线（可自选地区与 IP 数量，买完还能改）。
4. **提取与查看**——订单生效后在「全部节点」或「我的代理」里看，支持 IP 更换、地区切换与节点分组。

这里有个前置条件容易被忽略：**账号要过实名认证之后才进得了购买环节**，不是可选项。没做实名的话，登录是成功的、后台也能进，但走到付款那一步会卡住。

## 登录失败的六种现象对照

| 现象 | 大概率原因 | 处理顺序 |
|---|---|---|
| 提示验证码错误或已失效 | 图形验证码停留太久，或上一次提交失败后没有刷新 | 清空验证码 → 重新获取 → 再提交；连续失败就换手机验证码登录 |
| 提示用户名或密码错误，但自己记得没错 | 用手机号当用户名填了；或密码在找回后已重置 | 确认填的是「设置登录用户名」；不确定就点「忘记密码」重置一次 |
| 收不到短信验证码 | 手机号未在注册时完成绑定，或通道有延迟 | 等 60 秒倒计时归零再点一次；仍收不到就换账号密码登录，进去后核对绑定手机号 |
| 登录进去了，但购买按钮点不动 | 实名认证还没做，购买环节被前置条件拦住 | 到账号设置里完成实名认证，一次认证长期有效 |
| 推广码那一格空着，价格比同行贵 | 不是从官方入口链接进来的，参数没带上 | 退出后重新从带参数的官方入口打开，推广码会自动填好并锁定 |
| 页面加载很慢或样式错乱 | 浏览器缓存了旧版本脚本 | 强制刷新一次，仍异常就换无痕窗口 |

## 常见问题

**Q：极驰云登录入口在哪？**
A：官方登录页就是官网根域名 www.jichiy.com，页面标题直接写着「极驰云账号登录」，不需要再点任何按钮。同一地址同时承载注册弹层与找回密码，靠页面内的切换按钮换层。

**Q：为什么我打开官网没有登录框，直接进了后台？**
A：这是登录状态还在的缘故。页面脚本检测到本机已有登录凭据后会自动跳转到 /views/main.html，登录表单根本没有渲染。想在别处重新登录，就先退出，或换浏览器的无痕窗口打开。

**Q：注册时的推广码一栏为什么是灰的、打不了字？**
A：推广码由链接参数决定，页面读到参数后自动填入并锁定，所以输入框是禁用状态。从官方入口链接进来时这一格会预填；直接手打域名进来则是空的，拿不到渠道折后价。

**Q：账号密码登录要填的图形验证码，为什么总提示失效？**
A：图形验证码在页面加载时就向后端取了一组校验标识，停留时间过长或提交失败后都需要重新获取。不用重开浏览器，把那一格清空再点一次即可；实在反复失败就切到手机验证码登录。

**Q：登录进去以后，SK5 和 L2TP 的金币能通用吗？**
A：不通用。两套余额相互独立，SK5 约 1元=2.5金币、L2TP 约 1元=2.4金币，充进去不能互转。正确顺序是先定协议、再充对应的那一套。

**Q：登录后能换 IP 或换地区吗？**
A：可以，不用重新下单。订单生效后在「全部节点」或「我的代理」里就能做 IP 更换、地区切换与节点分组；购买时选的自定义路线还支持自选地区与 IP 数量。

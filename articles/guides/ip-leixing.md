# 静态/动态、住宅/机房：代理IP四大类型怎么选？

## 结论

两对概念组合出四类主流选择：**住宅静态（最稳）＞ 住宅动态（轮换）＞ 机房静态（性价比）＞ 机房动态（采集）**。按业务对纯净度和稳定性的要求选。

## 两对概念

| 维度 | 选项 | 特点 |
|---|---|---|
| 静态 / 动态 | 静态=地址固定 | 适合长期挂机、固定身份业务 |
| | 动态=可换地址 | 适合轮换、采集、多账号 |
| 住宅 / 机房 | 住宅=家宽资源 | 更"真实"，纯净度高，价格较高 |
| | 机房=数据中心 | 便宜、量大，纯净度一般 |

## 组合与场景

- **住宅静态**：账号安全管理、社媒运营、长期项目 —— 最推荐，价格中等偏上
- **住宅动态**：轮换需求+纯净要求，如批量社媒 —— 成本适中
- **机房静态**：预算有限的常规业务、测试 —— 性价比之选
- **机房动态**：海量采集、对纯净度不敏感的场景 —— 最便宜

## 选购提醒

- 纯净度敏感的行业（社媒、电商账号）优先住宅，别省这个钱
- 采集场景注意并发和轮换频率，静态机房不一定够用
- 用 IP 质量检测工具能直接识别住宅/机房属性，买前测一测

## 常见问题

**住宅IP一定比机房好吗？** 纯净度和稳定性通常更好，但价格高 2-5 倍，按场景取舍。

**能不能先买机房再升级住宅？** 多数平台支持调换，建议先免费测试再定。

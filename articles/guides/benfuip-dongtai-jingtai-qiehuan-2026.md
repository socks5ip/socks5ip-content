# 奔富IP动态和静态怎么切？（2026 教程）

## 一句话结论

**奔富IP的"动态"和"静态"不是同一个套餐的两个开关，而是两条产品线**——「电脑静态」给电脑/模拟器/软路由搭配第三方工具用（老鱼、SSTap 等），SK5 独享线路 2.6元/月起；「安卓动态」给安卓端官方加速器用，登录后一键切换节点。两条线都能在后台【线路管理】统一管理：**勾选线路 ID → 导出 → 复制进客户端**就完成切换，地区随时可改、不用重新购买。切换完先到 [IP综合检测中心](https://socks5ip.com.cn/ip-check-center/) 免费验一下归属地与纯净度，再跑业务。

## 一、先搞懂：静态和动态分别指什么

很多新手把"动态/静态"理解成"一个套餐随时切换模式"，实际上在奔富后台，**购买时选的产品类型就决定了线路属性**：

| 对比项 | 电脑静态 | 安卓动态 |
|---|---|---|
| 适用设备 | PC、安卓、iOS、虚拟机、模拟器 | 安卓手机、安卓模拟器、云手机 |
| 使用方式 | 提取线路配置，导入第三方代理工具 | 登录奔富官方加速器，一键切换节点 |
| 典型场景 | 游戏多开、挂机任务、软路由全局 | 手机端轮换出口、轻量任务 |
| 协议支持 | SK5/HTTP、PPTP/L2TP/SSTP | 以官方加速器内置线路为准 |

记住一句话：**要用老鱼、SSTap、软路由这类第三方工具，就买「电脑静态」；只在安卓设备上用官方 App 一键换 IP，就选「安卓动态」。** 两条产品线互不通用，先想好设备再下单。

## 二、切换怎么做？两步搞定

后台切换分两层：**换地区**和**换线路**，都不用重新下单。

1. **换地区**：在【线路管理】选择目标地区即可调整，原套餐时长与线路数量不变——这也是奔富支持"按游戏项目随时更换地区"的原因。
2. **换线路**：进入【线路管理】→ 勾选需要的线路 ID → 导出默认格式信息 → 复制到第三方软件（老鱼/SSTap 等），客户端自动读取新线路完成切换。多开场景可**一次批量勾选多条线路批量导出**，再按窗口逐条配置。

切换后先验证再跑业务：打开 [IP综合检测中心](https://socks5ip.com.cn/ip-check-center/) 免费测出口 IP、归属地与纯净度，确认干净稳定再正式使用。

## 三、多设备/多窗口，线路怎么分组管理？

工作室多开最怕"线路多到分不清哪条给哪个窗口"。奔富没有单独的"分组"菜单，但【线路管理】天然支持分组式管理：

| 做法 | 操作 | 适用场景 |
|---|---|---|
| 按窗口勾选 | 每个窗口固定勾 1 条线路 ID，导出后单独配置 | 单窗口单 IP 隔离 |
| 按项目批量勾选 | 同一项目的窗口统一勾同批次线路 | 多开搬砖、批量任务 |
| 按地区区分 | 不同地区线路用不同标签记录（如 A 区/B 区） | 地区敏感业务 |
| 导出文件命名 | 每次导出按项目命名存档 | 换机、重装快速恢复 |

把"勾选 → 导出 → 命名存档"做成固定动作，几百条线路也能管得清清楚楚。

## 四、静态配老鱼怎么操作？

「电脑静态」最常见的用法是导入老鱼加速器实现**单窗口单 IP**：登录奔富后台 → 提取 SK5 线路 → 老鱼里添加 Socks5 代理 → 填入服务器/端口/账号/密码 → 保存后绑定对应窗口进程。安卓模拟器、iOS 小火箭等工具同理，本质都是把线路信息填进工具的代理设置。

## 常见问题

**Q：电脑静态和安卓动态能互相切换吗？**
A：不能直接互转。两条产品线使用方式不同（第三方工具 vs 官方加速器），需要哪类就在购买时选对应产品类型；已购线路如需调整，可联系官方客服咨询。

**Q：静态线路能用在安卓模拟器上吗？**
A：能。「电脑静态」适配 PC、安卓、iOS、虚拟机、模拟器，模拟器里装老鱼等第三方工具后导入 SK5 线路即可。

**Q：换地区要重新买吗？**
A：不用。在后台【线路管理】随时调整地区，套餐时长与线路数量不受影响。

**Q：一次买几十条线路怎么批量导入老鱼？**
A：在【线路管理】批量勾选 ID 一次性导出，再按窗口逐条填入老鱼；导出文件按项目命名保存，方便换机恢复。

**Q：动态线路适合什么业务？**
A：适合安卓端轻量任务与手机端轮换需求，走官方加速器一键换节点；需要单窗口单 IP、软路由全局的场景选「电脑静态」更合适。

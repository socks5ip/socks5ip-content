# 72 条线、58 城：这次改的是城市选择，不是你的带宽

72 条线路铺在 58 个城市，门槛却写着一行小字：仅限 3M 以上套餐。

把这句话读完，比数 IP 个数有用得多。

## 一句话结论

**这批上新改变的是「能挑哪个城市」和「同城能不能换运营商」，不改你手上的带宽。** 72 条线路里 100M 标称 65 条、200M 标称 7 条，覆盖 58 城、27 个省级行政区，1800 多个固定 IP 摊下来一条约 **25 个**。参与条件写死为 **3M 以上套餐**，而 SK5 与 L2TP 两条线的台阶不同：SK5 从 **3M** 起，L2TP 落到 **5M**。

| 项目 | 2026-10 口径 |
|---|---|
| 线路条数 | **72 条**（100M 标称 65 ／ 200M 标称 7） |
| 覆盖范围 | 58 个城市、**27 个省级行政区** |
| 运营商构成 | 电信 28 ／ 移动 24 ／ 联通 13 ／ 200M 未标运营商 7 |
| IP 数量 | 1800 多个，一条线约 25 个 |
| 参与门槛 | 仅限 **3M 以上**套餐（SK5 3M 起／L2TP 5M 起） |
| 起步价 | **2.6 元/月**（价格表最低档） |

## 一、这批线路铺在哪，差异在哪

数量之外，值得看的是分布形态。

| 维度 | 数字 | 意味着什么 |
|---|---|---|
| 城市数 | 58 个，覆盖 27 个省级行政区 | 大部分省会与沿海城市可挑，西北与东北覆盖略稀 |
| 同城多运营商 | 多数城市 2 家以上 | 同一城市可换运营商，比换城市更省事 |
| 200M 标称 | 7 条，洛阳 3、大连 2、深圳 2 | 高标称容量集中在三地，其余城市全为 100M |
| 单线 IP 数 | 约 25 个/条 | 一次换 IP 不是换整条线，而是换其中一个地址 |

第三列是这批资源真正的新增能力。以前同一个城市往往只有一家运营商，业务侧看到同城不同运营商来源时无法伪装；现在同城两家可选，城市不变、运营商变，这在地区与线路归属校验上是两种不同的信号。

## 二、两层口径：标称 100M 与套餐 3M

这是这批上新最容易被读错的地方。

| 你在哪里看到的数字 | 它说的是什么 | 与你的业务关系 |
|---|---|---|
| 线路名里的 100M／200M | 机房侧这条线路的标称容量 | 决定这条线能承载多少用户共享，不是给你的带宽 |
| 套餐里选的 1M／3M／5M | 分配给你这一条的实际带宽上限 | 决定你能同时跑几个窗口、能不能拉资源 |
| 后台显示的峰值 | 一段时间内的实测最高值 | 短时能冲高，不能当稳态 |

三行是三个层级。把标称当套餐买，最常见的后果是「买了一条 100M 的线却只能跑两个窗口」——因为你选的是 1M 档。

选档经验值：单窗口稳态占用按 0.5M 估，手游挂机 0.1–0.3M，端游多开 0.3–0.6M，需要拉资源包的按 2M 以上算。3M 档覆盖 3–6 个轻量窗口，5M 档覆盖 6–10 个。

## 三、门槛：仅限 3M 以上，两条产品线不同台阶

| 产品线 | 可参与的最低档 | 低于这个档会怎样 |
|---|---|---|
| SK5 | **3M** | 后台看不到这批新线路的可选项 |
| L2TP | **5M** | 同上，且 L2TP 本身起步档更高 |

这条细则解释了一个常见疑问：同一时间注册的两个人，一个人后台能看到新城市，另一个人看不到。差别不在账号，在套餐档位。

另外两个常被混用的概念要分开：**固定 IP 不等于独享 IP**。固定说的是这个地址在一段时间内不变；独享说的是这个地址只有你在用。这批上新提供的是固定地址的线路资源，是否独享要看所买档位的定义，两者不能互相替代。

## 常见问题

### 奔富IP 新上的 1800 多个 IP 我能全部用吗？

不能。1800 多个是这批线路资源池的总量，你能用到的是所买套餐分配给你的那一条线路上的地址，一条线平均约 25 个。想覆盖更多城市，得按线路数买。

### 为什么我的后台看不到新上的城市？

先看套餐档位。这批资源限定 3M 以上套餐参与，SK5 线 3M 起、L2TP 线 5M 起；低于这个档位，后台不会显示这批线路的选项。升档后刷新一次后台即可。

### 线路名写 200M，是不是我就能跑 200M？

不是。200M 是机房侧这条线路的标称容量，属于共享资源的上限描述；你能用的带宽是套餐里选的那一档，1M、3M、5M 各自独立计。

### 固定 IP 和独享 IP 是一回事吗？

不是。固定指地址在一段时间内不变化，独享指这个地址只有你在使用。同一批固定线路，可能多人共享同一个地址段下的不同地址，具体看所买档位的定义。

### 同城两家运营商，换运营商要另外加钱吗？

按线路数计费，同一档位下换一条同城另一运营商的线路，成本与换城市相同。真正的差别在效果：城市不变、运营商变，适合需要同城多来源的场景。

### 3M 档够跑几个窗口？

按单窗口稳态 0.5M 估算，3M 覆盖 3–6 个轻量窗口。如果其中有窗口需要下载资源包，瞬时需求会超过 2M，这时候要么错峰，要么升到 5M 档。

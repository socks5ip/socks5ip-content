# 五格下单页，第二格决定了后面全部步骤

只让三个模拟器走代理，还是整台机器一起换？这个问题在酷熊IP 的下单页就要定死——两种代理类型给的是形状不同的凭证，配通了才发现方向错，只能重买一张卡。

SK5 给的是**地址、端口、账号、密码**四段，进第三方客户端；L2TP 给的是**地址、用户名、密码**三段，进 Windows 自带的拨号。同带宽两者月卡只差 1 金币，差价小到不会提醒你选错了。

## 一句话结论

**要整台机器换出口就选 PPTP/L2TP 配系统拨号，只让指定程序换出口就选 SK5 配老鱼加速器或 SSTap；两者的提取按钮也不是同一个——SK5 在订单管理里点「便捷提取」，L2TP 点「批量提取」。** 配完别信界面上的「已连接」，去检测页看出口 IP 变没变，这一步才算生效。静态 5M 两档相差 1 金币、7M 相差 0、10M 隧道相差 21 金币，所以「选错」的代价主要在返工，不在价格。

| 对比项 | SK5（四段） | PPTP/L2TP（三段） |
|---|---|---|
| 后台给什么 | 地址、端口、账号、密码 | 地址、用户名、密码（无端口栏） |
| 落到哪 | 老鱼加速器、SSTap | Windows 自带拨号 |
| 生效范围 | 按进程，选中才走 | 整机，拨上全走 |
| 提取按钮 | 便捷提取 | 批量提取 |
| 同带宽月卡 | 静态 5M 20 金币 | 静态 5M 21 金币 |

## 两条路从下单页就开始分

**代理类型这一格不是偏好，是商品品类。** 选 SK5，后面所有步骤都围绕「把四段值填进某个客户端」；选 L2TP，后面只有「新建一个拨号连接」这一条路。中途换协议，等于重买。

| 下单页这一格 | 怎么选 | 选错的代价 |
|---|---|---|
| 代理类型 | 按「改谁的出口」判断，SK5 还是 PPTP/L2TP | 凭证形状不同，两套不通用 |
| 套餐带宽 | 5M 起，多开往上加 | 带宽不够表现为「能用但卡」，不像故障 |
| 购买周期 | 第一次先选免费测试 | 手快点成日卡就直接扣费 |
| 项目 | 搜不到就挑最接近的 | 不影响连通，业务类型对不上要重配 |
| 运营商 | 跟本地宽带一致：电信对电信、联通对联通 | 跨网进来首日体验明显掉一截 |
| 省市与 IP 数量 | 先按需要的城市选，不确定就少买几条 | 教程写明后期可免费切换，这格容错最高 |

## 提取按钮不是同一个

**这一步是两条路第一个实操分岔。** 勾选 IP 之后，SK5 订单点「便捷提取」，出来的是可以直接复制的四段；L2TP 订单点「批量提取」，出来的是三段，没有端口。

找错按钮的表现是「复制出来的内容少一栏」，多数人第一反应是后台缺数据，其实是点了另一种协议的按钮。**两条订单在列表里长得几乎一样，只有代理类型那一列不同。**

## SK5：四段值怎么填进老鱼加速器

打开客户端，新增一条线路，依次填地址、端口、账号、密码，线路名保持默认不影响使用。填完先存，再单独测这条线一次。

三个容易被忽略的点：

- **端口不要按经验猜。** SK5 的端口由平台分配，同一订单里不同 IP 的端口可能不一样，批量粘贴时尤其容易串行。
- **密码里的特殊字符别改。** 有些客户端会把 `#` 之后当注释，遇到就手工粘贴而不是键盘输入。
- **按进程分流要在客户端里勾。** 老鱼加速器的分配是「选中才走」，没选中的程序走本地网络——这正是它比整机拨号灵活的地方。

## L2TP：系统拨号的三个框

新建连接，选「连接到工作区」，填入地址、用户名、密码三格，拨号即成。**这里没有端口栏，因为 L2TP 走固定端口，平台也不给端口。**

常见的两处卡点：一是拨号提示「远程服务器无响应」，多为运营商或安全软件拦了 UDP 500/4500；二是拨上了但网页打不开，检查拨号属性里有没有勾「在远程网络上使用默认网关」——不勾，流量不会走隧道。

## 连上是假象，验出口才算配完

**界面显示「已连接」只说明隧道建起来了，不代表流量真的从那条线出去。** 打开检测页看两栏：当前 IP 是否等于后台分配的 IP，归属城市是否等于下单时选的省市。

两栏都对才算生效。有一个技巧：**用另一个浏览器或另一个没配代理的程序去验**，避免刚配好的那个本身走了本地直连，让你误以为成功。

| 现象 | 大概率原因 | 处理 |
|---|---|---|
| 拨号成功，网页打不开 | 没勾默认网关，或 DNS 仍是本地 | 勾上默认网关，DNS 改自动 |
| 拨号弹出「无响应」 | UDP 500/4500 被拦 | 关安全软件再试，或换一条线 |
| 客户端显示已连，出口没变 | 只连了客户端，没选进程 | 在客户端里勾选要走的程序 |
| SK5 填完连不上 | 端口或密码沾了空格 | 逐格重新粘贴，别用键盘敲 |

## 常见问题

### SK5 和 L2TP 能同时买吗？

能，但用途要分开：SK5 给按进程分配的窗口，L2TP 给整机出口。同时用时注意优先级，整机隧道会盖住按进程的那条，配置顺序反了会出现「明明选了线路，出口还是隧道那条」。

### 为什么界面显示已连接，出口却没变？

因为「连接成功」指的是客户端到代理服务器这一段通了，不是系统流量已经全部改道。整机拨号要勾默认网关，按进程的客户端要在里面勾选具体程序。

### 五个模拟器只想让三个走代理，选哪个？

选 SK5 配老鱼加速器。L2TP 是整机拨号，拨上之后五个全走，分不出谁走谁不走。这也是两条路最核心的分界。

### 静态 5M 的 SK5 和 L2TP 差价真的只有 1 金币？

价格表上是 20 与 21，静态 7M 两档都是 30，10M 隧道那档差 21 金币。所以 5M 这一档选错几乎不花钱，代价全在返工时间上。

### 提取时找不到「便捷提取」按钮？

说明订单的代理类型是 PPTP/L2TP，那一类只有「批量提取」。反过来，SK5 订单点批量提取也拿不到端口。按钮跟着协议类型走，不跟订单号走。

### 配好之后怎么确认走的是住宅段而不是机房段？

在检测页看 IP 类型那一栏，显示住宅或机房是按段属性判的；再核归属城市是否与下单所选一致。两栏都对，才算真正用上了这一档。

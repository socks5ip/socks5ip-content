# 中途升带宽前，先算订单里还剩多少天

把「升级带宽」当成补一次差价来理解，最容易算错。多数平台按订单计价，带宽在下单那一刻就锁进订单里；能不能改，只看平台开没开变更入口。

## 一句话结论

代理IP 行业里，「中途升级带宽」不是通用功能。**站内目前只有全球代理IP 有明文规则：升级费＝（新套餐价 − 原套餐价）× 50%，到期日不重新计算。** 其余多数平台只提供「退旧购新」或「等到期换档」两条路。选哪条，取决于一个变量——你手里还剩多少天。

| 项目 | 具体口径 |
|---|---|
| 有明文升级规则的平台 | 全球代理IP（补两档差价 50%，到期日不变） |
| 其余平台的通行做法 | 后台无变更入口，只能退旧购新或到期换档 |
| 决策变量 | 订单剩余天数 |
| 最划算的一跳 | JiuIP 5M→10M：每 M 仅加 0.242 金币 |
| 最贵的一跳 | 奔富 3M→5M：每 M 要 1.50 元 |
| 先测后买 | 站内 20 多家平台价格中心，多数支持免费测试 |

## 同一句抱怨，背后是四种改不动的参数

把这四个字拆开，每一件的处理方式完全不同。混在一起问客服，往往只得到一句「不支持」，但你真正要解决的那件事另有办法。

| 你嘴上说的 | 典型症状 | 真正要动的参数 | 能靠改单解决吗 |
|---|---|---|---|
| 带宽不够 | 窗口一开多就卡、下载跑不满 | 标称带宽 | 看后台有没有升级入口，多数要退旧购新 |
| 条数不够 | 窗口没加，但一条只能一开 | 并发 / 独享条数 | 多数是加购，不是「升级」 |
| IP 不够纯 | 平台提示环境异常、频繁弹验证 | IP 出身（住宅 / 机房） | 改不了，只能换档型 |
| 线路不稳 | 半夜掉线、延迟忽高忽低 | 线路类型（阿里云 / 天翼云 / 移动云） | 改不了，换线路或换平台 |

只有第一行跟带宽有关。后三行把带宽从 3M 升到 30M，症状也不会消失——这是升级带宽最常花冤枉钱的地方。

## 登进去看订单行尾，四个动作判断能不能改

不用问客服，登进后台看订单列表就能判断。四步走完还找不到入口，就不用再问了。

| 步骤 | 在哪看 | 看到什么算「有入口」 |
|---|---|---|
| ① 看已购节点每一行行尾 | 「我的节点 / 我的套餐」页 | 多出一个「升级 / 变更」按钮 |
| ② 点进「续费」看弹窗 | 订单详情 | 弹窗里出现带宽选项 |
| ③ 翻订单属性 | 订单详情页 | 带宽写成独立字段而不是备注文字 |
| ④ 都没有 | —— | 按「新下单」思路算账，别再找入口 |

三种后台长相对应三种结论：**行尾带「升级 / 变更」的**能补差价升档，全球代理IP 属于这一类；**只有「续费 / 编辑」的**通常只能开关协议和改备注（鲸云IP 的【账户】→【编辑 / 续费】可切换 SK5 与 L2TP），带宽一般不动；**只有「重新购买」的**只能新下单。

## 三条可行路径，差别只在剩余天数

后台没入口不等于没救，实际能落地的是三条路，选哪条只看剩余天数。

| 走法 | 什么时候选 | 会损失什么 | 生效速度 |
|---|---|---|---|
| 补差价升档 | 后台有升级入口 | 补差价（按平台口径，可能按差价比例，也可能要全额） | 即时 |
| 退旧购新 | 后台没入口，但业务等不了 | 剩余天数作废，客户端要重新配置一遍 | 几分钟到一小时 |
| 到期换档 | 剩余天数已经不多（一周以内） | 剩下这几天继续将就 | 1–7 天 |

判断可以写成一句话：**剩余天数 × 每天因短板损失的产出 > 补差价成本 → 退旧购新；反过来就等到期。** 月卡还剩 20 天以上的，退旧购新的沉没成本最高，这时候值得争取补差价这条路；只剩三四天的，等到期换档几乎零成本，没必要为此多付一笔。

## 跳档边际价：最贵的一跳往往不是翻倍那跳

同一张带宽表上，「差一档就升一档」往往不是最划算的买法。把月价折算到每 M，再单独算跳到下一档时每多 1M 要加多少钱，才是决定值不值得升级的依据。

| 平台 / 协议 | 带宽档（低 → 高） | 月价 | 跳档边际价（元 / M） |
|---|---|---|---|
| 奔富 SK5 独享 | 1M / 1.5M / 3M / 5M | 2.6 / 4.0 / 6.0 / 9.0 | 2.80 / 1.33 / 1.50 |
| 烽迅 SK5 | 1M / 5M / 10M / 20M | 2.6 / 4.8 / 6.0 / 8.8 | 0.55 / 0.24 / 0.28 |
| JiuIP（金币计价） | 2M / 3M / 5M / 10M / 20M | 3.4 / 4.37 / 5.58 / 6.79 / 11.64 | 0.970 / 0.605 / 0.242 / 0.485 |
| 光梭 SOCKS5（8 折） | 1.5M / 2M / 4M / 6M / 峰值 25M | 2.24 / 3.6 / 5.6 / 8.0 / 8.0 | — / 1.00 / 1.20 / 0 |
| 光梭 L2TP（8 折） | 1.5M / 3M / 6M / 12M | 4.0 / 6.4 / 8.8 / 14.4 | 1.60 / 0.80 / 0.93 |

表里最有用的是最后一列，它有两个反直觉的落点：

**其一，加钱最多的一跳常常不是带宽翻倍的那一跳。** JiuIP 从 2M 跳到 3M，每 M 要多花 0.970 金币；而从 5M 跳到 10M，每 M 只多花 0.242 金币——同样是多花一笔钱，3M 只多拿到 1M，10M 拿到 5M。凭空升一档是最常见的买法，也是最容易买亏的买法。

**其二，「最便宜的那条」和「每 M 最划算的那档」不是同一个套餐。** 光梭 1.5M 特惠档 2.24 元是单条绝对价最低；但每 M 单价最低的是标称峰值 25M 那一档，折算只要 0.32 元/M。按单条价买会买错，按每 M 单价买才和批量业务的账对得上。

## 先数窗口再反推带宽，才不是拍脑袋

与其纠结「升不升」，不如倒过来算：先数清要同时跑多少个窗口，再反推需要多少带宽。经验公式是 **可用带宽 ≈ 标称带宽 × 0.6 ÷ 单窗口稳态占用**，乘 0.6 是因为标称带宽是峰值，稳态跑不满。

| 业务形态 | 单窗口稳态占用 | 建议档位 |
|---|---|---|
| 手游挂机、轻量多开 | 0.1–0.3M | 1.5M–3M |
| 端游多开、模拟器群控 | 0.3–0.6M | 5M–10M |
| 需要拉资源、频繁更新 | ≥ 2M | 10M 起 |
| 视频 / 直播 / 大流量持续传输 | 持续高占用 | 视频专线档，别在通用档里加带宽 |

用法是反向的：算出来落在 1.5M–3M 的人，本来就不该去升 10M；算出来超过 10M 的人，纠结 6M 和 8M 之间的差价没有意义，应该直接跨两档——跨两档的每 M 边际价通常比跨一档低一半以上。

## 换档也不会好转的五种症状

下面五种症状在后台看起来都像带宽不够，但换档之后不会好转。

| 症状 | 真实瓶颈 | 该动的参数 |
|---|---|---|
| 窗口一开多就卡 | 并发条数不够，单条带宽还有富余 | 加条数，或换支持多开的档 |
| 提示切换次数用完 | 换线额度，与带宽完全无关 | 换长周期卡（JiuIP 月卡 30 次/条，日卡只有 2 次/条） |
| 平台提示环境异常 | 出口被识别为机房 IP | 换住宅档，不是提速 |
| 白天正常、深夜掉线 | 线路出口拥塞 | 换线路类型（JiuIP 官方写明不推荐天翼云 / 移动云跑大带宽） |
| 只有下载和视频慢 | 峰值口径与稳态吞吐的差距 | 直接买视频专线档 |

升级前建议先用 IP 综合检测中心把出口归属、延迟与连通性测一遍，确认瓶颈是否真在带宽上，再决定加不加钱。

## 常见问题

**Q：带宽档买小了，能直接找客服改吗？**
A：先看后台有没有「升级 / 变更」入口。有入口的多数能补差价升档，没入口的客服通常也改不了。全球代理IP 是目前站内有明文规则的例子：升级费按两档差价的一半补，到期日不重算。

**Q：升级带宽一般要补多少钱？**
A：取决于平台口径。有明文规则的按差价比例折算（如 50%），按订单计价的平台通常要求按新档全价重买、剩余天数作废。下单前先把目标档的每 M 单价算出来，再决定是补差价还是重新下单。

**Q：哪一档的升级最划算？**
A：看每 M 边际价。JiuIP 的 5M→10M 每 M 只加 0.242 金币，是站内这一列里最低的；光梭 6M 跳到峰值 25M 是同价（8 元到 8 元），等于免费跨档。反面例子是奔富 3M→5M，每 M 要 1.50 元。

**Q：加了钱升带宽，为什么速度没变快？**
A：大概率瓶颈不在带宽。并发条数不够、切换次数用完、出口被识别成机房 IP、线路出口拥塞——这四种症状都不会因为带宽变大而好转，要动的是条数、换线额度、IP 出身和线路类型。

**Q：中途升级和重新买一条，哪个更省钱？**
A：算剩余天数。月卡还剩 20 天以上，走补差价升档最省；只剩 3 到 5 天，等到期换档几乎零成本；后台没有升级入口又急着提速的，只能接受剩余天数作废，这时候优先用周期短的卡过渡。

**Q：升带宽之前应该先测什么？**
A：先测出口 IP 的归属与连通性，再测延迟抖动，最后按业务真实负载跑一次。检测中心这几项都免费，测完再对照窗口数表反推档位，比凭感觉加钱靠谱得多。

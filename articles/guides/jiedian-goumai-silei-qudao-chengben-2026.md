# 自建、订阅、共享账号、商业代理：四类来源的成本与边界

自建 VPS 要花时间维护，还是直接买一条线路？这个问题用标价回答不了——四类来源的月成本摊平后差距不大，真正的分水岭是买到的东西不一样：一台机器的控制权、一个共享节点池的位置、别人账号里的一个席位，还是一条可指定出身、可随时切换的出口。选错类型以后，你会发现钱花了、事情没办成，而且症状往往业务跑到第三天才有。

## 一、四类来源买到的不是同一样东西

| 渠道 | 你实际拿到 | 能指定出口归属地吗 | 能指定 IP 出身吗 | 主要风险 |
|---|---|---|---|---|
| 自建 VPS | 一台服务器的控制权 | 只能选机房所在地区 | 不能，几乎都是机房段 | 时间成本高，IP 段被大量标注 |
| 机场订阅（按季付） | 一个共享节点池的使用权 | 部分节点可选 | 不能 | 池子被多人共用，IP 被反复标记 |
| 共享账号 | 别人账号里的一个席位 | 看账号里有什么 | 不能 | 账号主随时改密、异地登录触发限制 |
| 商业代理IP | 一条可管理、可切换的出口 | 可按城市指定 | 机房 / 住宅可选 | 有最低购买周期，档位买错要重下单 |

一句话概括差别：**前三类买的是「能不能连上」，第四类买的是「这条出口是谁的」。** 目标平台不查归属、只要求通道可用时，前三类够用；一旦平台看 IP 出身、看 C 段复用度，前三类基本都会被筛掉。

## 二、把 30 天的账摊平算一遍

| 渠道 | 标价区间 | 摊到 30 天 | 标价外的成本 |
|---|---|---|---|
| 自建 VPS | 25–60 元/月 | 25–60 元 | 装机、配、排障时间，按时薪折算通常超过带宽费本身 |
| 机场订阅 | 10–30 元/月（多按季付） | 10–30 元 | 节点波动要自己换线，服务方停运没有补偿 |
| 共享账号 | 5–15 元/人 | 5–15 元 | 账号主改密即全组停摆，多人异地登录互相牵连 |
| 商业代理IP | 2.24–12 元/月 起 | 按周期买，月卡最省 | 首期促销价与续费价常不同，比价要按实付价 |

把标价放一起看，共享账号最便宜、自建最贵，但加上第三列之后排序会变：**自建省的是月费、花的是时间；共享账号省的是钱、赌的是账号主的稳定性。** 如果一件事的产出取决于通道稳定，那么「便宜但随时可能断」的方案实际单价最高。

一个具体的临界点：单条业务线的月产出如果不到 100 元，先把时间成本算进来往往就不划算；当你要同时维持 5 条以上独立出口，自建的总成本会迅速超过直接购买——因为自建要按机器数扩容，而商业代理是按条数加购，边际成本低得多。

## 三、三类不写进标价的隐藏成本

| 隐藏成本 | 出现在哪类 | 具体表现 | 怎么规避 |
|---|---|---|---|
| 运维时间 | 自建 VPS | 系统更新、证书、线路排查都要人盯 | 按自己的时薪折算，超过月费就说明不该自建 |
| 池子污染 | 机场订阅、共享账号 | 同池 IP 被多人使用，目标平台识别为共用出口 | 先查 C 段复用情况，再决定是否长期使用 |
| 服务方中断 | 机场订阅、共享账号 | 服务方停运或账号主改密，直接归零且无补偿 | 不做唯一通道，关键业务至少留一条可追溯来源 |

第三类里还有一层常被忽略：**共享账号和订阅池都没有售后主体**。出问题时你能找的只有对方一个人，而商业代理平台至少有后台、有工单、有可核对的订单记录。

## 四、按需求对号入座

| 你的需求 | 建议方向 | 为什么 |
|---|---|---|
| 只是本机临时查资料、看页面 | 订阅或低价共享即可 | 只要通道可用，不需要出口归属可控 |
| 要按城市/运营商固定出口 | 商业代理IP 的静态档 | 出口可按城市指定，这是自建和共享给不了的 |
| 多开、单窗口单 IP | 商业代理IP 按条购买 | 出口条数可扩，且每条独立 |
| 需要住宅出身通过风控 | 商业代理IP 的住宅档 | 归属类型可核对，订阅池基本拿不到 |
| 有技术能力且要完全自主 | 自建 VPS + 自管线路 | 前提是你能接受运维时间成本 |

选择顺序建议固定成：**先确认目标平台查什么 → 再看哪一类能提供 → 最后才比价格。** 反过来先比价，买到的多半是最便宜但不对路的那一类。

## 常见问题

**Q：自建 VPS 比买代理贵，为什么还有人用？**
因为它给的是控制权——你能自己决定协议、端口和分流规则。但这份控制权要用运维时间换，且机房 IP 段被标注的比例通常很高，需要住宅出身的业务自建解决不了。

**Q：共享账号那么便宜，能用吗？**
做一次性、无账号属性的任务可以。一旦涉及账号登录态、需要出口长期固定，共享席位就不合适——账号主改密或别人异地登录，都会把你带下水。

**Q：机场订阅和商业代理IP 的核心区别是什么？**
一个是共享池的使用权，一个是可管理的独立出口。前者比的是节点多不多，后者比的是每条线路的归属、带宽与切换额度。用哪种，取决于目标平台查不查 IP 出身。

**Q：怎么判断买到的 IP 是不是被很多人共用？**
查出口 IP 的归属类型和同 C 段记录：如果整段都被标注为代理，说明是被反复转卖过的池子。用 [IP 综合检测中心](https://socks5ip.com.cn/ip-check-center/) 先跑一次再决定是否长期使用。

**Q：预算只有 30 元，怎么分配最合理？**
优先买 2–3 条你能验证出结果的线路，而不是把钱摊给多个低价来源。分散买的结果通常是每一条都没测清楚，业务上线后一起出问题。

**Q：促销价和续费价不一样，怎么比？**
按实付价比，不要按宣传价比。把首期价和续费价都记下来，换算成 90 天的总支出，差距往往比单看月费明显。

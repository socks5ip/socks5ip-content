# 蛟龙IP 两种地址类型：固定域名换 IP 不用重配，常规地址要（2026）

选定节点、点下导出，再把拿到的串粘进软路由或客户端——这一步选的是格式，定的是后面每次换 IP 的工作量。两种格式都不加钱，选错的代价落在流程上。

**一句话结论：**蛟龙IP 导出时可选**常规地址（IP 形态）**与**固定域名（域名形态）**，**两者不额外收费**。区别只在一处：**常规地址换 IP 后，本地存的那串数字作废，必须重新导出并覆盖**；**固定域名换 IP 是后台动作，工具里不用动，等解析生效即可**。按换 IP 频率选——**一天换几次选域名，一周几次选 IP**。

## 一、提取页那一步，改的是后面整条流程

后台左侧【IP续费/更换】里勾选线路，点【复制/导出】，然后选导出格式。教程给的建议是「默认设置」，但对经常换 IP 的人，默认值未必是最省事的那个。

| 导出内容 | 形态 | 换 IP 后要做什么 |
|---|---|---|
| `IP:端口:账号:密码` | 常规地址 | 重新导出、重新覆盖每一个用到的位置 |
| `域名:端口:账号:密码` | 固定域名 | 什么都不用做，等指向刷新 |

两种格式在导出那一刻是等价的，差别只在第一次换 IP 时出现。

## 二、常规地址：换完 IP，本地存的数字就作废了

常规地址导出的就是那一串数字。换 IP 之后，旧值指向的地址已经不属于你，所有填过它的地方都要改。

- **软路由**：拨号或代理规则里的目标地址。
- **指纹浏览器**：每个环境的代理设置，逐条改。
- **采集脚本**：配置文件、环境变量、数据库里的记录，三处都可能存了旧值。

所以常规地址的隐性成本不是钱，是**覆盖的次数**。换十次就是十次导出加十次覆盖，漏一处就会出现「明明换了 IP，出口还是旧的」。

## 三、固定域名：换 IP 变成后台动作

固定域名导出的是一段域名。换 IP 时后台把域名指向新地址，工具侧不用动。

| 环节 | 常规地址 | 固定域名 |
|---|---|---|
| 导出内容 | IP 字面值 | 域名 |
| 换 IP 后工具侧 | 必须重新导出覆盖 | 不用动 |
| 生效速度 | 切换后立即生效 | 略有延迟，等解析刷新 |
| 中间环节 | 无 | 多一层域名解析 |
| 排错怀疑面 | 窄，IP 就是那个 IP | 宽一位，还要排除解析 |
| 换 10 次的人工量 | 10 次导出 + 10 次覆盖 | 10 次后台点击，工具侧 0 次 |

两个代价要认：**生效有延迟**（解析没刷新前还指旧地址），**多一层依赖**（本地 DNS 异常时会表现成「代理连不上」）。换 IP 不频繁的话，这两条比省下的覆盖动作更值钱。

## 四、重配成本按换 IP 次数算，不按条数算

算这笔账时，条数是分母里最不重要的那个。

| 卡种 | 典型换 IP 节奏 | 一年重配次数（常规地址） | 建议 |
|---|---|---|---|
| 月卡 | 一周几次 | 几十次 | 按 IP 形态即可 |
| 天卡／短周期 | 一天几次 | 数百次 | 固定域名 |
| 独享类 | 长期不动 | 个位数 | 两种都行 |

短周期卡的用户如果选了 IP 形态，一年会多出几百次导出与覆盖。这类人工量不会出现在账单上，但会出现在「为什么昨天还好今天全断了」的排查时间里。

## 五、最常见的假故障：换了 IP，客户端还显示旧地址

这是常规地址最典型的误判：后台已经换了，工具里还填着旧值，于是现象是「换来换去还是同一个出口」。

排查顺序只有三步：

1. **看后台显示的当前地址。** 与工具里填的对比，不一致就是没覆盖。
2. **看生效状态。** 固定域名形态下，解析没刷新前仍指旧地址，等几分钟。
3. **看客户端缓存。** 部分客户端会缓存连接，改完要重启进程。

三步都过还不对，才去怀疑线路。

## 常见问题（FAQ）

### Q：固定域名要不要另外加钱？

不用。两种地址类型在导出时选择，价格一致。决定支出的是档位，不是地址形态。

### Q：选了固定域名，为什么刚换完 IP 还是旧地址？

解析刷新有延迟。后台已经指向新地址，但本地或上游 DNS 还缓存着旧记录，等几分钟再测；期间不要反复重连，重连不会加速解析。

### Q：用固定域名会不会更容易被识别？

域名只是多一层解析，对外看到的仍然是出口 IP。目标站看到的是地址本身，不是你的域名。

### Q：软路由上适合用哪种？

看换 IP 频率。软路由配置改动成本高，一天换几次的建议固定域名；一周换几次、追求立即生效的，用常规地址更直接。

### Q：两种形态能随时切换吗？

重新导出一次就切换了，不需要换套餐。切换后记得把旧格式的配置清掉，两种格式混用会出现「一部分流量走旧地址」。

### Q：换 IP 之后多久能确认生效？

后台显示切换成功即已生效，剩下的是本地覆盖或解析刷新。用检测页看出口地址，与后台显示的当前地址一致就算完成。

# 检测页三栏全绿，进站还是被拦，脏的未必是出口

检测页三栏全绿，站点却照拦——多数人第一件事是换线，其实脏的不一定是这个出口。

## 一句话结论

**「纯净度」不是一个分数，是三个独立问题：这条线挂在谁名下、这个出口的历史干不干净、你从本机到出口这一段有没有把真实身份漏出去。三项里任意一项不合格，整条线的表现都会像「IP 脏」。** 55游（55u.net）不公开纯净度评分，只按出身分为三类：原生住宅双 ISP **1.2 元/天、月卡 30 元**；原生 IP 与云 IP **0.6 元/天、月卡 15 元**。

| 项目 | 2026-10 口径 |
|---|---|
| 品类 | 境外固定出口 Socks5 线路，按时长售（1／7／30 天） |
| 起价 | 原生/云 0.6 元/天、月卡 15 元；住宅双 ISP 1.2 元/天、月卡 30 元 |
| 纯净度口径 | 官方无评分字段，只有出身分类，干不干净须自测 |
| 三个测点 | 出口归属（ASN、rDNS）、历史记录（黑名单、代理库）、链路泄漏（DNS、时区、UDP） |
| 最容易被骗的地方 | 开着中转测，或按「服务器」形式买的线，测到的不是你以为的那个 IP |

## 一、官方页面没有「纯净度」这一栏，这不是遗漏

把「纯净度」做成一个百分制分数，是检测站的做法，不是代理平台的做法。平台能承诺的是「这条线是什么出身」，不能承诺「它进任何一个站点都不会被拦」。

| 平台能定义的 | 平台定义不了的 |
|---|---|
| 这条出口的 IP 类型（住宅/原生/机房） | 目标站点用哪套风控规则 |
| 带宽与卡期 | 这个 IP 在别人手里的使用历史 |
| 出口国家与地区 | 你本机的时区、语言、字体是否对得上 |

第二列这三项，恰好是「检测页全绿但进站被拦」的常见来源。**所以纯净度只能自测，且必须分项测。**

## 二、三项各查什么，一次检测页只能答一项

| 测点 | 查什么 | 用什么数据 | 检测页一栏够不够 |
|---|---|---|---|
| 出口归属 | 这个 IP 属于谁 | ASN、rDNS、whois、上游 AS 数量 | 够，但要看完三栏 |
| 历史记录 | 前任留下过什么 | 黑名单库、公开代理库、风险标记 | 部分够，需要交叉查 |
| 链路泄漏 | 真实身份有没有漏 | DNS 解析地、时区、UDP 可用性 | 不够，要看本机设置 |

## 三、第一项：出口挂在谁名下

这一项判断的是「你买到的是不是你以为的那种出身」：

| 字段 | 怎么看 | 民用段长什么样 | 机房段长什么样 |
|---|---|---|---|
| ASN | 检测页运营商信息，或查 AS 归属 | 当地电信、宽带运营商 | 云厂商、IDC、托管商 |
| rDNS | 反查这个 IP | 形如 `x.dsl`、`ppp`、`broadband` | 形如 `cloud`、`hosting`、`vps` |
| whois | 看 netname 与 orgname | 运营商名称，段规模偏小 | 数据中心名称，整段整齐 |
| 上游数量 | 看这个段被几个 AS 宣告 | 两个及以上才是双 ISP | 通常只有一个 |

表格第四行解释了「住宅双 ISP」这个词：双 ISP 指的是这段地址由两个上游共同宣告，属于多归属（multi-homing），不是「两条线路叠加提速」。

## 四、第二项：这个地址的前任留下过什么

固定出口是共享的历史容器：上一个用这条线的人做过什么，会留在公开库里。

| 查什么 | 合格的样子 | 不合格的样子 |
|---|---|---|
| 黑名单命中 | 主流反垃圾库零命中 | 任意一条命中就该换 |
| 代理标记 | 未检测到，或标为低风险 | 被公开列为代理或匿名网络 |
| 同段邻居 | 同 C 段多数干净 | 同段大量带风险标记，整段受牵连 |

第三行是最容易忽视的：**单条再干净，同段邻居一片红，平台也会整段处理。**

## 五、第三项：漏身份的不是 IP，是链路

前两项都过了还被拦，多数问题出在这一层：

| 泄漏点 | 为什么会漏 | 怎么补 |
|---|---|---|
| DNS | 域名解析仍走本地运营商 | 把 DNS 也走代理，或改用远端解析 |
| 时区与语言 | 出口在境外，系统还是东八区中文 | 跟着出口国调整 |
| UDP 直连 | 部分应用走 UDP，不经过代理 | 确认代理支不支持 UDP 转发 |
| 浏览器指纹 | Canvas、字体、分辨率 | 属浏览器环境，代理管不到 |

前两项是最常见的组合：**出口换到境外，时区和语言还留在本地，环境自相矛盾。**

## 六、测之前最容易搞错的两件事

| 情形 | 会发生什么 | 正确做法 |
|---|---|---|
| 开着中转去测 | 测到的可能是中转节点的地址 | 关掉中转测一次，开中转再测一次，两次应一致 |
| 按「服务器」形式买的线 | 换线后仍测到旧地址 | 断开会话重连，或换端口生效后再测 |

第二种情形里，很多人误判成「平台给了个假 IP」。实际是旧连接还在，检测请求走了老会话。

## 七、判定线：能过、勉强、别用

三项查完，按这张表落结论：

| 结论 | 三项状态 | 建议用途 |
|---|---|---|
| 能过 | 归属符合预期、黑名单零命中、无泄漏 | 账号类、支付类业务 |
| 勉强 | 归属对但同段有风险标记，或时区未对齐 | 浏览、采集、非敏感操作 |
| 别用 | 归属是机房段而你要住宅，或黑名单命中 | 换线，别测第二次 |

第二档不是「凑合用」，是「限用途用」。**同段有风险标记的线跑账号业务，等于开局就带风险。**

## 八、0.6 元档与 1.2 元档，15 元差在哪

| 对照项 | 原生 IP / 云 IP（0.6 元/天、15 元/月） | 住宅双 ISP（1.2 元/天、30 元/月） |
|---|---|---|
| 出口属性 | 运营商名下（原生）或机房段（云） | 家庭宽带段，双上游宣告 |
| 带宽 | 20M（云 30M） | 20M |
| 过账号类风控 | 视平台而定，机房段常被单列 | 通过率更高 |
| 适合 | 浏览、采集、短期验证、游戏 | 店铺后台、长会话、付费业务 |

差的 15 元买的不是速度，是「这段地址在对方眼里像不像家庭用户」。原生的价值在归属，云的价值在带宽，双 ISP 的价值在归属与冗余同时具备。

## 常见问题

### 55游 的 IP 纯净度有官方评分吗？

没有。平台不给分数，只按出身分类（住宅双 ISP、原生、云）。干不干净要自己按三项测，分数类结论在检测站之间也不通用。

### 检测页显示是代理，是不是这条线就废了？

不一定。被公开库标记会影响部分平台，但不等于所有站点都拦。先看归属是否符合预期，再看具体业务场景。

### 同一个 IP 前几天干净，现在被标了怎么办？

固定出口的历史会累积。被标之后换一条同档位的线即可，不必换平台。

### 出口显示住宅，为什么还是被要求验证？

住宅属性只解决第一项。时区、语言、DNS 泄漏属于链路层，检测页不会替你判断，需要自己对齐。

### 0.6 元的和 1.2 元的，跑账号业务选哪个？

账号类选住宅双 ISP。原生 IP 在部分平台能被识别为运营商段而非家宽段，机房段更容易被单列。

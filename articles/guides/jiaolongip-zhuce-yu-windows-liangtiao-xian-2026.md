# 蛟龙IP 装完连不上：两条协议线的凭据别混填

填完推广码、付完款，客户端的连接按钮点下去，进度条在最后一格停住了——账号能登进后台，节点却一个都连不上。蛟龙IP（蛟龙加速器）把产品拆成 SOCKS5 与 L2TP 两条独立的协议线，起步带宽都是 **1.5M**，起步价一个是 **2.8 元/月**、一个是 **5 元/月**，但节点地址、端口形态与认证字段完全不通用，**填错地方就只表现为「连不上」**。

## 一个账号里其实装着两条产品线

把蛟龙加速器当成「买一个能用的 IP」会在后面反复踩坑。它按协议拆线：**SOCKS5 线给客户端与应用层用，L2TP 线给系统网络连接用**。同一个账号下，两条线的节点地址、端口形态、认证字段都不一样，这也是官网把价格表拆成两张的原因。

| 协议线 | 档位数 | 独有档位 | 交接对象 |
|---|---|---|---|
| SOCKS5 | 八档 | 2M / 4M / 25M | 客户端、浏览器、脚本 |
| L2TP | 五档 | 3M / 12M | 系统网络连接、软路由 |

站内价格表页对两条线的定位写得很直白：L2TP 适合需要全局接管的场景，SOCKS5 更适合游戏与专业应用。**档位网格不重合**这一点很关键——想买 12M 只能走 L2TP，想买 25M 只能走 SOCKS5。

## 注册流程只多一栏，但这一栏影响结算价

注册本身和同类平台没有区别：手机号或邮箱注册 → 实名 → 选购 → 后台提取。真正要留意的是推广码那一栏。

| 步骤 | 要做什么 | 容易漏掉的地方 |
|---|---|---|
| ① 进入注册页 | 从带推广码的链接进入，页面自动带入 adminA1 | 直接访问官网首页注册，推广码栏是空的 |
| ② 注册账号 | 手机号 / 邮箱 + 密码 | 密码和节点凭据分开记，别用同一个 |
| ③ 领免费测试 | 注册即享 2 条/天 | 别急着买月卡，先用这 2 条验证本地网络能不能通 |
| ④ 购买套餐 | 在 SOCKS5 八档与 L2TP 五档里选一档 | **先定协议线，再挑带宽**；顺序反了会买到用不上的档 |
| ⑤ 提取并配置 | 后台「提取」拿 IP:端口与账号密码，或 L2TP 的服务器地址与密钥 | 两套凭据形态不同，见下一节 |

推广码不影响功能，只影响结算价。注册页那一栏为空时手动填 **adminA1** 即可；**填完再付款**，比先付款后找客服补要省事。

## Windows 上只有三种接法，各自只吃一类凭据

新手最常卡住的就是这一步：手上有节点，却不知道该往哪填。

| 接法 | 填什么 | 适合 | 局限 |
|---|---|---|---|
| 系统代理（设置 → 网络和 Internet → 代理） | SOCKS5 的 IP + 端口 | 只想让浏览器走代理的最省事方案 | 只接管认系统代理的程序，多数游戏客户端不认 |
| SOCKS5 客户端（老鱼加速器 / SSTap / Proxifier 一类） | SOCKS5 的 IP + 端口 + 账号密码 | 多开、单窗口单 IP、按进程分流 | 多一层软件，要按客户端分别配规则 |
| L2TP 拨号（网络和共享中心 → 设置新连接 → 连接到工作区） | L2TP 的服务器地址 + 预共享密钥 + 用户名密码 | 需要全局接管，游戏与模拟器一起走 | 全局生效，同一台机器上没法给两个程序分不同出口 |

把 L2TP 的服务器地址填进 SOCKS5 客户端，或者反过来把「IP:端口」当拨号地址填，表现都是**连不上、或连上但没有流量**，而账号本身完全正常。这就是开头那个问题的标准答案。

两条视频专用档要单独说：SOCKS5 视频档 30 元、L2TP 视频档 40 元，价格表没标具体带宽，只写「大带宽」。**长时间推流或高清播放落在这两档**；拿 1.5M 的低价档跑视频，问题不在平台，在档位选错了。

## 这几种情况，蛟龙IP 不是最优解

- **需要海外出口**：蛟龙加速器是国内线路产品，价格表里的档位都在国内场景下讨论；跨境访问、海外平台运营要看海外线的平台。
- **需要一条 IP 带多个店铺**：同一出口被多个账号共用，本身会增加关联判定风险，要隔离就得一条线一个出口。
- **需要无限次自动轮换**：切换额度按购买时长给（月卡才不限次数），要的是「每隔几分钟自动换一次」的短效轮换，逻辑不一样。
- **只是临时用一次**：先用每天的 2 条免费测试验通，比买日卡更省钱。

## 常见问题

**Q：蛟龙IP 的免费测试有几条，怎么领？**
A：按站内口径是注册即享 **2 条/天**，在后台「提取」里直接取，不需要先充值。建议把这 2 条花在「验证本地网络能不能通」和「验证目标程序走不走代理」上，比用来看速度有价值。

**Q：推广码 adminA1 在哪里填？**
A：在注册页的推广码一栏。从带推广码的链接进入时该栏会自动带上 adminA1；显示为空时手动填入即可。顺序是**先填码再付款**，付款后再补通常要走客服。

**Q：SOCKS5 和 L2TP 到底选哪一条？**
A：看你要不要全局。要让整台机器的流量都走代理（游戏、模拟器一起），选 L2TP；要按程序分流、做单窗口单 IP，选 SOCKS5。两条线起步带宽同为 1.5M，起步价一个 2.8 元、一个 5 元。

**Q：节点填进客户端却连不上，可能是什么原因？**
A：先核对凭据类型。SOCKS5 用「IP + 端口 + 账号密码」，L2TP 用「服务器地址 + 预共享密钥 + 用户名密码」，两者不通用。类型对了再检查端口是否被本地安全软件拦截。

**Q：月卡真的不限切换次数吗？**
A：价格表页写的是「日卡 5 次、周卡 30 次、月卡不限次数」。要注意这是切换次数不限，**不等于可以无限条数并发**——能同时跑多少条，仍受你买的档位数量限制。

**Q：只买 2.8 元那档够用吗？**
A：取决于你要同时跑几个窗口。1.5M 适合单线程的轻量任务；要多开，10 元档里的 25M 特惠档每 M 只要 0.40 元，比在低带宽档上加量更划算。

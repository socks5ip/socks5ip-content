# 酷熊的邀请码藏在哪里

邀请码并不是表单里的一个格子——酷熊的注册页压根没有可以填它的地方，推荐关系全靠地址栏尾部 `?promoteCode=` 那一段带进去。更要紧的是：**不带参数直接打开注册页，绑定照样会发生**，只是绑到了另一个默认码上（本次实测为 GRb4x1bB）。

## 没有输入框，只有地址栏尾部那一段参数

把「酷熊IP邀请码」当成一个要动手输入的字段，是大多数人卡住的第一步。实际打开注册页会发现：页面上压根没有这一栏，也找不到「推荐人」「上级」之类的文本框。邀请关系是通过链接传进去的——形如 `user.kuxiongip.com/register?promoteCode=l9avX8dG`，把问号后面那一段带到页面里，系统自己识别。

这条设计带来的直接后果是：**你用什么链接进来，就绑到那条链接对应的上级**。链接少一段、被聊天软件截断、或者嫌麻烦直接手打域名进官网，结果都不是「没填邀请码」，而是「绑到了另一个码」。

## 实测注册页五个字段，逐项对一遍

把注册页渲染出来逐项读了一遍，表单就是下面这五项。页面提示文案照抄，方便核对：

| 字段 | 是否必填 | 页面原文提示 |
|---|---|---|
| 用户名 | 必填 | 6–16 位字母数字组合，首位为字母 |
| 登录密码 | 必填 | 至少 6 位，包含字母和数字 |
| 确认密码 | 必填 | 请再次确认登录密码（必填） |
| 手机号 | 选填 | 请输入手机号（选填，用于上级联系您） |
| 验证码 | 必填 | 请输入验证码（图形码，看不清可点图片换一张） |
| 邀请码 | —— | 表单中没有这一栏 |

页面副标题写的是「填写账号信息，即可提交注册。邀请关系将随注册自动绑定」，页头三条卖点里也有一条「邀请关系自动识别，无需重复填写」。旁边还有一句「创建账号，预计用时不到 1 分钟」，以及平台自述「本平台仅提供合规国内 IP 服务，请勿用于任何违法用途」。

手机号标着选填，但提示写得很直白——「用于上级联系您」。如果打算走售后，这一格别空着；页面本身不强制。

## 带码与不带码，页面提示的差别

这是最容易吃亏的一处。带 `?promoteCode=l9avX8dG` 打开，注册页顶部会浮出一条绿色信息条：「邀请信息已确认 · 邀请码 l9avX8dG 将在注册后自动绑定」。而把参数去掉、直接打开 /register，这条提示**照样在**，只是里面的码换成了另一个——本次实测显示为 GRb4x1bB。

| 对比项 | 带 ?promoteCode=l9avX8dG 打开 | 直接打开 /register |
|---|---|---|
| 页头信息条 | 邀请信息已确认 · 邀请码 l9avX8dG | 邀请信息已确认 · 默认邀请码（实测 GRb4x1bB） |
| 新账号归属 | 绑到该码对应的上级 | 照样绑定，但绑到默认上级 |
| 表单字段 | 五项，无邀请码输入框 | 五项，无邀请码输入框 |
| 「返回登录」链接 | 带 promoteCode 参数 | 不带参数 |

换句话说，酷熊这边不存在「忘了填邀请码」这种情况，只存在「带错了码」。注册前把地址栏看一遍，比注册后再找客服轻松得多——注册页上并没有自助改绑的入口。

## 参数跟着 URL 走，说明绑定发生在提交之前

顺着链接点下去还有个细节：注册页底部「已有账号？返回登录」指向的是 `/login?promoteCode=…`，参数被原样带到了登录页。这条链路说明邀请关系是跟着 URL 走的，页面在做任何提交动作之前就已经把码读进去了。

由此可以推出一个实用的核对动作：**打开链接后先别急着填表**，看一眼地址栏和页头信息条——码对不上就换个干净链接重开，不要在一个已经读进旧参数的页面上硬填。

## 注册前顺手核掉的三项

邀请码只是入口，真正影响花钱的是下面三项。它们与邀请码无关——**码不会改价，档位才是价格变量**：

| 要确认的事 | 为什么 | 到哪看 |
|---|---|---|
| 起步档与协议类型 | 同带宽下 SK5 与 PPTP/L2TP 是两套互不重叠的价目 | 站内酷熊IP 价格表页 |
| 切换额度 | 普通月档按 20 次/天计，隧道版才是无限切换 | 价格表页「核心特性」列 |
| 邀请码是否随链接带入 | 表单没有这一栏，只能靠链接 | 注册页顶部绿色信息条 |

## 五种现象说明上级绑错了

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 注册页顶部没有「邀请信息已确认」 | 链接被截断，参数丢在半路 | 用完整链接重新打开一次 |
| 信息条里的码不是你要的那个 | 用的浏览器历史链接，或手动敲域名进来 | 清掉地址栏，重开带码链接 |
| 注册完上级一直联系不上 | 手机号留空（该栏选填） | 后续在平台内补上联系方式 |
| 注册页显示的是默认邀请码 | 直接访问 /register，未带参数 | 注册页没有自助改绑入口，重开带码链接最省事 |
| 码对了但档位买贵了 | 把邀请关系当成了折扣 | 价格表页没有码与折扣的对应关系，档位才是价格变量 |

一条通用做法：**把带码链接存成书签或收藏**，别在群里转发后再点——多数聊天工具会把长链接折叠，还原时容易丢参数。

## 常见问题

**Q：酷熊IP邀请码在哪里填？**
没有可填的位置。注册表单只有用户名、登录密码、确认密码、手机号（选填）和图形验证码五项，邀请码只存在于注册链接尾部的 `?promoteCode=` 参数里。

**Q：不带邀请码直接注册会怎么样？**
注册页照样会显示「邀请信息已确认」，只是绑定的码换成了默认邀请码（本次实测为 GRb4x1bB），新账号不会挂到你要的上级名下。

**Q：邀请码能让价格变便宜吗？**
价格表页没有标注邀请码与折扣的对应关系，档位价按公开价目执行；邀请码确定的是推荐关系。实付金额以提交订单页显示为准。

**Q：注册需要准备哪些信息？**
用户名（6–16 位字母数字、首位是字母）、登录密码（至少 6 位且含字母和数字）、确认密码、图形验证码；手机号是选填项，页面说明用于上级联系。

**Q：怎么确认这次注册绑对了上级？**
注册页顶部绿色信息条会直接写出邀请码；参数还会被带到 `/login?promoteCode=…`，说明绑定在提交表单之前就已完成，注册前看一眼最稳妥。

**Q：酷熊IP 起步价是多少？**
公开价目里最低一档是稳定 5M 静态住宅 SK5，4 元/天、7 元/周、20 元/月，另可按周和按天计费；价格表页标注更新于 2026-04-15，以下单页实时显示为准。

# 代理IP 用着用着出口变了：先分清是回收、超时还是抖动

线路用着用着出口变了，是平台按周期回收了 IP，还是本机这条连接自己断了？**家庭住宅款**通常 **2 到 7 天**自动重播一次、短效款按购买时长回收，而长效静态款只要不手动切换就一直不变——但更多时候，动手的其实是客户端。把 IP 有效期、连接时长、线路质量混成一件事，就会一直在错的那一层排查。

## 三种现象长得很像，动手的却是三个主体

这三种情况的共同点是「用着用着就不能用了」，区别在于背后是谁在动手。平台回收 IP 是产品设计，客户端超时是参数设置，链路抖动才是真出了问题。

| 你看到的现象 | 背后是谁触发 | 要不要处理 |
|---|---|---|
| 出口变了，个别账号要重新登录 | 平台侧回收或自动重播 | 属正常，按新出口重新绑定即可 |
| 提示连接超时或无响应，点重连就恢复 | 客户端空闲超时或保活被回收 | 属正常，调长超时或加定时心跳 |
| 卡顿、时断时续，出口却没变 | 链路抖动、丢包 | 需要排查，必要时换线路 |

判定顺序建议从「出口有没有变」开始，这一步能直接排掉一半的误判。

## 谁会让出口自己换掉

同样是买代理 IP，线路类型决定了出口会不会自己变。长效静态是买断一条出口，家庭住宅是租一段时间后自动重播，后者的重播周期由平台定，不是故障。

| 线路类型 | 会不会自己换 | 典型口径 |
|---|---|---|
| 长效静态（独享） | 不会，不手动切换就一直不变 | 天行IP 长效静态 6 元/月（原价 15 元） |
| 家庭住宅 | 会，2–7 天自动重播 | JiuIP 家庭住宅档，通常 2–7 天重播一次 |
| 短效 / 按天 | 会，按购买时长到期回收 | 天行IP 日卡 1–3 元、周卡 3–5 元 |
| 动态轮换 | 会，由你的切换动作或接口触发 | 视平台的切换额度而定 |

这里有个容易被忽略的细节：「静态」讲的是性质（IP 不主动变），「长效」讲的是时长（这段时间里它归你）。两个词常被当成同义词，但买之前最好在价格表页把这两栏分开看。

## 挂机掉线，多数是客户端先松手

代理协议的连接形态不同，断开的「体感」也不一样。SOCKS5 是按需建连的：每发起一次请求就握手一条 TCP 连接，用完即关（RFC 1928）；隧道协议则是一条隧道把整台机器的流量都装进去。挂机场景下，前者断的只是某一条连接，后者一断就是整条线。

| 协议 | 连接形态 | 长时间挂机时的表现 |
|---|---|---|
| SOCKS5（RFC 1928） | 每次请求各自建连 | 单条连接断了客户端通常自动重连，表现为时好时坏 |
| HTTP / HTTPS（CONNECT） | 逐请求或逐会话 | 与 SOCKS5 接近，长轮询业务更容易被空闲回收 |
| 隧道协议 | 一条隧道承载全部流量 | 平时最稳，断一次影响面最大 |

系统级的 TCP keepalive 默认是 2 小时才探测一次空闲连接，而很多程序自己的空闲超时比这个短得多。所以「挂机几小时后掉线」大多不是平台掐的，而是客户端先把连接判成了闲置。

## 额度单位不同，能换的次数差几十倍

如果自动重播满足不了需求，就得靠主动切换来换出口。这里的坑是各家的计量单位不一样：有的按次、有的按条、有的干脆写「不限次数」。同一句话换个单位，实际可用次数能差出几十倍。

| 平台 / 档位 | 自带切换额度 | 折算口径 |
|---|---|---|
| JiuIP 月卡 | 30 次 / 条 | 单次成本 ≈ 月卡价 ÷ 30 |
| JiuIP 日卡 | 2 次 / 条 | ≈ 日卡价 ÷ 2，同档日卡比周卡贵的情况真实存在 |
| 天行IP | 自带 1000 次 | 额度内切换不额外计费 |
| 光梭、奔富、烽讯等 | 官方标「不限次数 / 自助切换」 | 分母不封顶，列不出单次成本 |

中间两栏要特别注意：「30 次/条」里的「条」指的是一条线路，不是整个账号。买 5 条线路，月卡额度就是 150 次，别按账号总数去算。

## 一个观察点就能分流

判定只需要一个观察点：重连之后，出口地址是不是变成了新的。变了，说明原 IP 被回收或重播，属于正常换血；没变却仍然连不上，才需要往线路和配置上查。

| 观察点 | 正常到期 / 回收 | 需要排查 |
|---|---|---|
| 重连之后 | 出口变成新的，立刻可用 | 出口没变，依旧连不上 |
| 发生频率 | 与购买时长或重播周期吻合（2–7 天） | 几分钟一次 |
| 同一账号其他线路 | 照常可用 | 全部同时断开 |

出口、归属地与线路类型在 IP 综合检测中心可以直接读到，比反复开关软件凭感觉判断可靠得多。

## 几条常见的误判

| 你的判断 | 实际情况 |
|---|---|
| 出口变了就是线路坏了 | 多半是自动重播或到期回收，属产品设计 |
| 静态 IP 就一定永不变化 | 「静态」指不主动轮换，线路维护仍可能导致出口变更 |
| 掉线就得找客服 | 先看出口有没有变，没变且能连上就不必报障 |
| 「不限次数」就是随便换 | 平台侧不计数，但池子余量和目标站点风控仍是约束 |

把这几条排掉之后，剩下的才是真需要找客服的那一类。

## 常见问题

**Q：代理IP 买来之后，大概多久会自己换一次？**
看线路类型。长效静态不手动切换就一直不变；家庭住宅通常 2–7 天自动重播；按天或按周买的短效款，从购买那一刻开始倒计时。下单前看清「线路类型」那一栏，比记周期更可靠。

**Q：挂机一整晚，早上起来发现出口变了，要联系客服吗？**
先别急着报障。如果重连后能正常使用、新出口也有效，大概率就是自动重播或到期回收。只有重连之后仍连不上、或者几十分钟断一次，才需要走客服排查。

**Q：为什么 SOCKS5 用起来断断续续，换成隧道协议反而稳？**
因为连接形态不同。SOCKS5 每次请求都要重新握手一条 TCP 连接，短时抖动会体现在某几条连接上；隧道协议是一条隧道承载全部流量，平时最稳，但一断就是整条线。两者不是谁更好，是取舍不同。

**Q：切换次数用完了会怎么样？**
通常表现为切换按钮不可用或切换不生效，已提取的线路在有效期内一般仍可继续用。月卡档位最好在购买前算一遍：30 次/条摊到 30 天就是每天一次，多开的账号要按「条数 × 30」估算总次数。

**Q：静态住宅 IP 是不是就一定不会变？**
静态说明的是「不会主动轮换」，不等于「物理上永不变化」。线路维护、节点调整都可能让出口发生变更，只是频率远低于短效款。

**Q：怎么确认是 IP 被回收，还是线路出故障？**
只看一个信号——重连之后的出口地址有没有变。变了就是回收或重播；没变却仍连不上，再从端口、账密、协议这些配置项往下查。

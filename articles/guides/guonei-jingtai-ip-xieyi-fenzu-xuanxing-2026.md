# 挑国内静态 IP 的第一步：按协议把平台分成两组

国内静态 IP 该怎么挑？先看你的接法需要哪一层的协议。**23 家国内静态 IP 平台里只有 4 家给不了 L2TP 隧道**——先按协议把平台分成两组，再在组内比带宽和月费，比一上来就问「哪家好」能省掉一半无效比价。国内起步价从 **2.24 元/月** 到 **20 元/月**，多出来的钱都落在带宽与独享度上。

## 判据只有三个问题，答完就锁定协议

「国内静态 IP 哪家好」这个问题本身少了半句。静态说的是地址属性——这个出口在档位期内不变；协议说的是流量怎么发出去——应用层代理还是网络层隧道。两件事各说一层，混在一起问，得到的答案一定是「都行，看你需求」。

| 判据 | 怎么问自己 | 结论 |
|---|---|---|
| 谁去用这条线 | 是某个应用、某个浏览器，还是整台设备 | 单个应用 → 应用层；整机 → 网络层 |
| 有没有中间设备 | 要不要经过路由器或软路由转发 | 要 → 必须支持 L2TP 或 PPTP |
| 地址要不要长期不变 | 对方认不认「同一个出口」这件事 | 认 → 静态档；不认 → 动态池更省 |

这三个问题答完，你需要哪个协议就定死了。往下的比价才有意义——协议不通的平台，价格再低也和你无关。

## 19 家与 4 家的分界线划在哪里

站内跨平台比价表把 23 家的协议支持列在一起，分界线非常清楚。

| 组别 | 支持协议 | 能接什么 | 接不了什么 |
|---|---|---|---|
| 四协议组（19 家） | SK5 + HTTP + L2TP + PPTP | 应用层与网络层都行，可接软路由与整机隧道 | 没有明显短板 |
| SK5 + HTTP 组（4 家） | SK5 + HTTP | 单应用或系统里填代理 | 路由器层接隧道、整机隧道 |

只提供 SK5 + HTTP 的是无忧IP（4.5 元/月起）、百兆王IP（5 元/月起）、优享云IP（6 元/月起）、皇冠IP（12 元/月起）。这一刀切下去，最大的作用是排除：如果你的方案是「上游路由器接隧道」，这 4 家直接从候选里划掉，不用再纠结它们的价格——在你的方案里根本不成立。

## 组内比价要绕开两个陷阱

确定了组别再看价格，比价的维度会突然清爽。同一组里，价格差主要来自三件事：带宽形态、地址独享度、是否住宅属性。

| 档位 | 代表平台 | 月卡起步价 | 贵出来的钱换成什么 |
|---|---|---|---|
| 最低价档 | 光梭IP | 2.24 元/月 | 无限切换，适合按量取用的轻需求 |
| 主力便宜档 | 奔富IP / 烽讯IP | 2.6 元/月 | 四协议齐全，静态与住宅分档 |
| 住宅中位档 | 沧海IP / 光子IP / 天机IP | 4 元/月 | 住宅属性，按区域与带宽再分档 |
| 带 L2TP 的常用档 | 天行IP / 鲸云IP / 极驰云IP | 6 元/月起 | 静态 L2TP 与住宅 L2TP 分带宽卖 |
| 高带宽档 | 酷熊IP | 20 元/月 | 更高带宽与更强独享 |

比价时有两个陷阱要绕开。一是拿「上一条出口的总带宽」去比「这一条出口的可用带宽」，两者不是一回事，会把便宜档看成不够用、把贵档看成浪费。二是拿动态池的单价去比静态档的单价，动态池按量取用、静态档包月，计价方式不同，直接比数字没有意义。

## 从用途倒推该在哪一组里挑

把常见需求倒推回「该在哪个组里挑」，比从平台出发效率高得多。

| 你的用途 | 需要什么协议 | 在哪个组里挑 | 典型月费 |
|---|---|---|---|
| 浏览器、单应用、系统里填代理 | SK5 或 HTTP | 两组都可以，重点比住宅属性与带宽 | 国内 2.24–7.2 元/月 |
| 整机走隧道，或接到软路由 | 必须 L2TP（或 PPTP） | 只在四协议组里挑 | 带 L2TP 的档多在 6–10 元/月 |
| 要覆盖全屋多台设备 | 必须 L2TP | 只在四协议组里挑 | 线路费同上，另加一台路由 |

落到具体平台，这份反查表可以直接用：要接软路由和整机隧道，看四协议组的光子IP 与天行IP；只做单个应用、又想压低月费，看沧海IP 与糖果IP 的住宅档；要海外出口，就在海外 4 家里按同样逻辑分。

## 免费额度先花在出口属性这一项

国内平台普遍给免费测试额度，但额度怎么花，直接决定测出来的结论有没有用。建议只测三件事：

| 判据 | 怎么测 | 合格线 |
|---|---|---|
| 出口对不对 | 把出口填进检测中心，看地址与 ISP 一栏 | ISP 能写出运营商名字，而不是机房标识 |
| 带宽够不够 | 在真实业务时段跑一次，看稳态可用带宽 | 能撑住你当前的活，不频繁掉速 |
| 峰值稳不稳 | 在业务最忙的时段再测一次 | 延迟 30–60ms 良好，丢包接近 0% |

站内检测中心的测速口径是延迟 25 分、抖动 15 分、丢包 15 分、下载 20 分、上传 15 分，满分 100，全程大约 8 秒。同一个平台测两次分数差得多，先看是不是测的时段不同，而不是马上判定平台不行。

## 比价前先排掉的四个误解

| 误区 | 实际情况 |
|---|---|
| 把 SOCKS5 当成静态住宅 IP | 协议和地址属性是两回事，同一条住宅线可用 SK5 也可用 HTTP |
| 只看最低价，忽略协议 | 协议不通，价格再低也接不上你的方案 |
| 以为贵的一定支持更多协议 | 协议支持看平台设计，不看价格高低 |
| 一次就买最大档试 | 先用最低档带试用的线路跑通，再按实际用量升档 |

把这几条记住，再回到最开始那个问题：「国内静态 IP 哪家好」的正确答案不是某一家，而是「先按协议分组，再在组内按带宽和月费挑」。同一档价位的平台，适合你的那家，取决于你的接法而不是它的排名。

## 常见问题

**Q：国内静态 IP 到底哪家好？**
没有单一答案，要看你需要哪种协议。先在四协议组（19 家）和仅 SK5 + HTTP 组（4 家）里选出能对上你接法的那一组，再在组内比带宽与月费，这才是有效的挑法。

**Q：价格高的平台是不是支持协议更多？**
不一定。协议支持看平台自身的产品设计，跟月费高低没有必然关系。站内比价表里，2.6 元档的奔富IP、烽讯IP 就是四协议齐全的，不能拿价格当协议支持的代理指标。

**Q：只做单个应用，还要买支持 L2TP 的平台吗？**
不需要。只在应用或系统里填代理，用 SK5 或 HTTP 就够，四协议平台的 SK5 与 HTTP 同样可用。只有要接软路由或走整机隧道时，才必须挑支持 L2TP 的那一组。

**Q：静态住宅和机房静态，挑的时候怎么区分？**
把出口填进检测中心，看 ISP 一栏。能写出运营商名字的是住宅属性；只显示机房或 IDC 标识的是机房线路。这一步比看平台宣传更可靠，而且是买之前用试用额度就能做的。

**Q：动态池和静态档能不能放一起比价？**
不能直接比数字。动态池多按量或按条计费，静态档是包月，计价方式不同。要先把业务需求落到「要不要长期同一个出口」这一条上，选定形态，再在同一形态内比价。

**Q：免费测试额度有限，先测哪一项最划算？**
先测出口对不对——填进检测中心看地址和 ISP，这一步最省额度也最能筛掉不合适的档位。出口这关过了，再花额度测带宽和峰值时段的稳定性。

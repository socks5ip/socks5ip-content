# 换了城市出口价格没变：IP 决定看到什么，不决定价格

换了城市出口，商品价格为什么一分没变？因为在这类平台上「你在哪」是两个分开的问题，出口只管其中一个。

**平台判断位置只有一个依据：这条连接的公网源地址，请求头怎么改都不算；但价格、库存、配送范围多数记在账号的收货地址上。** 出口决定的是城市频道、门店列表、广告位与推荐流，不决定商品标价。本机实测五个请求只改请求头、不改出口，返回的城市一次没变，三个伪造头里有一个直接被 403。

| 你想看到的东西 | 由什么决定 | 要不要买城市线 |
|---|---|---|
| 城市频道、本地门店列表 | 出口 IP | 要 |
| 商品价格、库存、配送范围 | 账号收货地址 | 不要 |
| 区域广告位与活动入口 | 出口 IP + 账号地区 | 要 |
| 搜索结果与推荐流 | 出口 IP + 语言 + 历史 | 要，语言要固定 |
| AI 工具、流媒体的可用性 | 出口国家 | 要，按国家不按城市 |

数据来源：全网低价IP 本站五次对照请求实测（只改请求头不改出口）｜ 最后更新：2026-11-25

## 位置判定只有一个入口，就是这条连接的公网源地址

同一台机器（天津，出口 111.32.67.174，中国移动 AS38019）向同一个接口连发五次请求，只改请求头、不改出口，返回的城市一次没变。这条结论决定了后面所有判断：想让平台认为你在另一个城市，唯一办法是换出口，不是改参数。

所以「改个请求头就能看外地价」这类说法，从机制上就不成立。能改的只是「你以为的浏览器身份」，改不了对端看到的源地址。

反过来说，出口一换，平台看到的就是另一个城市的人——但它只把这当成「你在哪」，不把它当成「你买给谁」。

## 请求头伪造为什么不算

请求头里的 X-Forwarded-For、Client-IP 这类字段，是给反向代理链路用的，用来在内部传递「原始来源」。平台在最外层拿到的已经是真实源地址，它没有理由去相信一个可以被任意填写的头。

本机实测的三个伪造头全部无效，其中一个还触发了 403——不是「伪造成功但被忽略」，而是直接被当成异常请求挡掉。所以伪造不只是没用，还可能给自己加一层风控标记。

要验这一点很简单：同一个接口，改头不改出口，看返回的城市有没有变。变了说明平台信任头部，不变说明只认源地址。多数电商类接口属于后者。

## 不归 IP 管的四类数据：价格、库存、配送、会员权益

价格是最容易被误判的一项。多数平台的商品价按「站点 + 账号收货地址」算，出口只影响你进的是哪个站点、看到哪个城市频道，不改变结算价。

库存与配送范围同理。库存按仓算，配送范围按收货地址算，两者都跟出口无关。把出口换到广州，看到的仍是「配送到你的收货地址要几天」，而不是「广州仓有货」。

会员权益、优惠券可用范围、活动资格，这类又加了一层账号维度。出口换了，账号还是那个账号，权益不会跟着搬。

这四类数据加起来，几乎覆盖了「比价」这件事的全部。所以想比价，改的是收货地址，不是出口。

## 真正按 IP 变的四类内容：频道、门店、广告位、推荐流

城市频道是第一个。很多平台把首页做成「城市站」，出口在哪个城市，进去就是哪个城市的首页，栏目与活动都不一样。

本地门店列表是第二个。到店类、生鲜类、本地服务类平台，门店清单直接由出口城市决定，这也是城市线最实用的场景。

广告位与活动入口是第三个。区域投放的广告位按城市卖，出口换了，看到的投放素材也换。

搜索结果与推荐流是第四个，但它不只由 IP 决定，还叠了语言和浏览历史。所以做这类采集时，除了固定出口，还要固定语言与账号状态，否则每次结果都不一样。

## 条数怎么算：城市数 × 账号数 × 平台数

城市线按条卖，一条线一个出口。要同时看五个城市，就得五条线；每个城市还要两个账号各自独立，就是十条。

按常见报价，城市线 4 元/月起，十城就是 40 元/月。这个数不是重点，重点是先算清「真正需要几个城市」——多数业务只需要两三个城市，一次买十城是把预算摊在了用不上的地方。

如果只是「偶尔看一眼外地频道」，更省的做法是用免费测试额度临时验，而不是长期持有十条线。城市线适合「每天都要看」的场景。

## 三个常见误判，每个都会多花钱

第一个：以为换了出口就能看到外地价。结论是不会，价格挂在收货地址上。第二个：以为改了请求头就能换城市。结论是无效，还可能被 403。第三个：以为出口国家对了，城市就无所谓。结论是分场景——流媒体与 AI 工具按国家就够，本地生活类必须精确到城市。

三个误判的共同点，是把「位置」当成一个整体。拆成「源地址」与「账号资料」两层之后，该买什么就清楚了。

## 自测口径：五次对照请求，两次换变量

第一次，固定出口、固定头，连发三次，确认返回稳定。第二次，只改请求头，看城市有没有变——不变就说明只认源地址。第三次，换出口、头不变，看城市有没有变——变了就说明出口是唯一变量。

三步做完，再拿同一个商品在两种出口下各查一次价格。价格相同，说明价格与出口无关；价格不同，才说明这个平台按 IP 定价，值得买城市线。

采样时固定三样东西：语言、账号、时间。三样里有一项在变，结论就不可信。

## 常见问题

**Q：换了城市出口，为什么价格还是本地的？**
A：价格挂在账号收货地址上，出口只决定城市频道与门店列表。要比价就改地址，不是换线。

**Q：改请求头能骗过平台吗？**
A：不能。平台读的是连接的公网源地址，本机实测三个伪造头全部无效，其中一个直接 403。

**Q：城市线要买几条？**
A：城市数 × 账号数。五个城市、每城两个账号就是十条；多数业务只要两三个城市，别一次买十城。

**Q：流媒体和 AI 工具也按城市算吗？**
A：按国家就够。这类服务看的是出口国家，不细分到城市，买国家节点比买城市线省。

**Q：只偶尔看一次外地频道，值得长期买吗？**
A：不值得。用免费测试额度临时验，比长期持有一条线便宜得多。

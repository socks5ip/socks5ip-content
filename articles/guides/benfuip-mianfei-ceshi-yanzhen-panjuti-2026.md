# 奔富IP 免费测试验什么：三项属性的合格线（2026）

免费测试的额度，怎么花才不算白花？先分清这次是验货，不是压测。验货问的是「它承诺的属性兑现了没有」，压测问的是「它性能优不优秀」——两套标准，一套有明确合格线，一套基本给不出结论。

## 一句话结论

**短测能给出确定答案的只有三类属性：线路通不通、出口落在哪个地区、IP 属于机房还是住宅。**这三项各有一条可以当场读出来的合格线，达不到就是没兑现承诺，跟「快不快」无关。带宽跑不跑得住、晚高峰会不会掉、目标平台认不认这个 IP，一次短测的样本量撑不起结论，得靠分时段重测。

## 验货与压测，评价标准是两套

供应商开放免费测试，目的是让你确认这条线能不能接进业务，不是让你免费做一次性能评估。这两件事的评价方式完全不同：验货是二元判断，通或不通、对或不对；压测是连续读数，得跑够样本才能下结论。

把额度花在压测上，最常见的结局是测了半小时，得到一个「今天这个时段还行」的读数，既不能证明长期稳定，也不能否掉这条线。花在验货上，十分钟能拿到三个确定的「是」或「否」。

## 三项属性的合格线，各看哪一个读数

每项属性配一条合格线，读数取不到就是不合格，不用再测第二遍。

| 属性 | 在哪读 | 合格线 | 不合格怎么办 |
|---|---|---|---|
| 线路通不通 | 客户端握手结果 + 检测页是否出结果 | SOCKS5 或 L2TP 一次握手成功，检测页能读出出口 | 换协议试一次，仍不通即报障，不要反复改配置 |
| 出口落在哪个地区 | 检测页的出口归属地一栏 | 与下单时选的地区一致 | 不一致就换线，别用「大概在附近」将就 |
| IP 属于机房还是住宅 | 检测页的 IP 类型 / ISP 一栏 | ISP 写出运营商名字才算住宅，否则是机房 | 买的是住宅档却不符，直接找客服核档 |

第三条最值得花时间。**「显示是代理」不代表这条线不干净**，反过来「没显示是代理」也不代表它是住宅——真正的判据是 ISP 那一栏写不写得出运营商名字，写不出来的基本是机房线路贴了张住宅标签。

## 10.2 元差价落在 IP 类型上，这一项当场能验

2.6 元的 SK5 1M 和 12.8 元的住宅独享 20M，差的 10.2 元不是带宽的钱，是 IP 类型的钱。带宽差多少要跑业务才知道，IP 类型差多少打开检测页就能看出来——所以这项是免费额度里回报最高的一次验证。

| 你买的是 | 该看到的类型 | 看不到时的含义 |
|---|---|---|
| 2.6 元特价独享 1M | 机房 / IDC 段 | 看到住宅反而不对，说明档位标错了 |
| 12.8 元优质住宅独享 20M | 住宅段，ISP 有运营商名 | 看到 IDC 段即未兑现，按档位找客服 |
| 8.8 元特价独享（峰值 20M） | 机房段，峰值不是保底 | 别拿它跟 9.0 元的 5M 比带宽 |

## 「换地区生效」这一步，最容易验成假的

换地区不是重新连一次就算换成功。控制台显示的地区是「这条线应该落在哪」，实际出口要以检测页为准。常见的假成功有三种：客户端缓存了旧连接、会话没断开就切了、切完连的是另一条线。

验法只有一条：**换地区之后，先把旧连接彻底断掉，再重新握手，然后打开检测页读出口归属地**。三步顺序错了，读到的还是上一个地区的出口。地区敏感的业务（比如按注册国养号）每条线都要走一遍这个流程，别拿控制台的显示当结论。

## 验不出的三项，靠分时段重测而不是拉长时长

「稳不稳」不是加时长能测出来的。连着挂八小时，得到的仍然是一个时段的样本；分三个时段各挂二十分钟，才勉强构成一天的横截面。

| 想确认的 | 单次短测 | 正确做法 |
|---|---|---|
| 连续连接成功率 | 样本量不足 | 分时段各跑一轮，记录断线次数 |
| 晚高峰表现 | 测不到，除非正好在高峰 | 20:00–23:00 单独补一轮 |
| 目标平台的风控判定 | 完全测不出 | 先拿小号跑一个业务周期，再决定上不上主号 |

## 十二分钟四步核对单

按这四步走，额度基本不会浪费：

1. **握手**：把提取到的地址、端口、账密填进客户端，确认一次连通，记下协议与端口。
2. **读三项**：打开 IP 综合检测中心，抄下出口归属地、IP 类型、ISP 名称，与下单档位逐项核对。
3. **换地区**：断开 → 切地区 → 重新握手 → 再读一次归属地，确认真的变了。
4. **留底**：把三次读数截图存档，后续正式使用出问题时，这是最省事的对照材料。

四步之外的动作（跑速、连挂、反复调配置）都不产生判断依据，只会吃掉额度。

## 常见问题

**问：免费测试能测出带宽够不够吗？**

不能给出稳定结论。短测读到的是当前时段的速率，反映的是那一刻的网络状况，跟晚高峰、跟长期表现都不是一回事。带宽要靠「窗口数压测 + 分时段复测」两件事凑出来。

**问：2.6 元的档和 12.8 元的住宅档，差 10.2 元差在哪？**

差在 IP 类型。2.6 元是机房段特价独享，12.8 元是住宅段独享 20M。带宽差多少要跑业务才知道，类型差多少打开检测页就能看出来，所以这一项最值得用免费额度先验。

**问：检测页显示「是代理」，这条线就不能用了吗？**

不必然。「显示是代理」只是检测库里的一个标记，判干净的真正依据是 IP 类型与 ISP 一栏：ISP 写不出运营商名字的，才基本可以判定是机房线路贴了住宅标签。

**问：换了地区，检测页还是原来那个城市？**

大概率是旧连接没断干净。正确顺序是断开旧连接、切地区、重新握手、再读归属地。跳过「断开」这一步，客户端会继续用缓存的会话，读到的还是上一次的出口。

**问：免费额度里最该先验哪一项？**

先验 IP 类型。它决定你买的是不是自己以为的那款产品，而且当场能读出结论；连通性和地区排在它后面，因为这两项不通会立刻暴露，不用专门安排验证。

**问：验完满意，直接就上年付吗？**

不建议。年付最高省 30%，但省下的绝对金额跟档位挂钩，入门档一年只省 5 元上下。线路还没跑满一个业务周期，先月付。

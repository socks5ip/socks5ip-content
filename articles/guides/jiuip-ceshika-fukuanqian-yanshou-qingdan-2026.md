# 30 次测试卡，只够回答四个问题

打开「购买代理」页，先把支付方式那一栏拉到底——金币支付下面还压着一项「**测试卡**」。选它提交，系统照样发 IP，不扣余额。JiuIP（官网 `jiuip.com`）给新账号的额度是 **30 次，每次 3 条 IP、有效期 5 小时**，而**测试卡发出来的 IP 与付费 IP 走的是同一套线路资源**，不是降级版本。这意味着这 30 次能验的东西，和真金白银买到的完全一致；反过来，乱领一通也会在同一天里把额度烧完，结论却还是模糊的。

## 一、测试卡的位置：它在支付方式里，不是一个独立页面

这一步不确认，后面所有动作都无从谈起。后台看不到「免费测试」菜单不代表没有额度，页面默认高亮的是金币支付，不往下翻就看不到测试卡。

| 步骤 | 点哪里 | 应该看到什么 |
|---|---|---|
| 1 | 登录后进左侧「静态代理」 | 展开「我的代理」与「购买代理」两个入口 |
| 2 | 进「购买代理」 | 线路列表：阿里云 / 天翼云 / 移动云 / 家庭住宅 |
| 3 | 拉到支付方式一栏 | 金币支付之外还有「测试卡」 |
| 4 | 选中测试卡并提交 | 测试 IP 进「我的代理」，余额不变 |
| 5 | 在「我的代理」里导出 | 拿到 IP / 端口 / 账号 / 密码，可导入老鱼、SSTap |

另外提醒一处最常见的误报：**后台登录密码与代理工具的连接凭证是两套东西**。前者管进后台，后者管连线路。把登录密码填进代理工具，客户端会一直提示认证失败，看上去像线路坏了。

## 二、一轮 3 条 / 5 小时，先问完这四个问题

测试卡按「次」计，一次给 3 条、活 5 小时。把 30 次当成 30 轮问答来用，比当成 30 次「随便连一下」划算得多。

| 要回答的问题 | 怎么测 | 判定口径 |
|---|---|---|
| ① 哪条线路适合我的业务 | 四条线路各领一轮，固定同一档带宽 | 记延迟与出口归属，挑最低的那条作为主用 |
| ② 几 M 够我用 | 选定线路后，2M / 5M / 10M 各领一轮跑真实任务 | 实测吞吐达到档位标称的**七成以上**才算够 |
| ③ 连续跑会不会掉 | 一轮里只连 1 条，跑满 5 小时 | 5 小时内不掉线、不重连，才叫稳定 |
| ④ 换 IP 之后质量变不变 | 一轮里换 2 次 IP，对比延迟 | 峰值延迟超过谷值 **3 倍**，说明这条线路波动大 |

四个问题里，①和②决定「买哪一档」，③和④决定「值不值得长期买」。只做①的话，你只是知道了能不能连上——那是免费测试最不值钱的用法。

测完每轮，用 [IP 综合检测中心](https://socks5ip.com.cn/ip-check-center/) 复核一次出口 IP 的归属地与类型。**第三方检测出来的才是你实际拿到的那个 IP**，平台后台显示的参数是发放记录，不是外部看到的身份。

## 三、这三个指标别用测试卡去验

额度有限，有些结论本身就不该由 5 小时的测试卡来回答，硬测只会浪费轮次。

| 想验的指标 | 为什么测不出 | 换什么办法 |
|---|---|---|
| 一个月会不会涨到更高带宽 | 档位不支持升级，测再多也改变不了 | 直接按峰值需求选档，别按平均值买 |
| 目标站点会不会判定账号异常 | 5 小时里跑不出长期账号行为曲线 | 用小周期正式套餐跑，或在业务侧观察二次验证频率 |
| 高峰期（晚八点后）的真实表现 | 单轮 5 小时通常跨不过完整的晚高峰 | 把 2–3 轮错开到晚高峰时段，专门测延迟波动 |

这三条的共同点是：**结论取决于时间跨度，不取决于测几次**。30 次额度全砸进去也得不出答案，唯一的解法是把测试轮次分布到不同时段。

## 四、三个「可以付款」的信号，和两个「先别买」的信号

验收该有个收口判据，否则会一直测下去。

可以付款的信号：① 选定线路上连续 5 小时不掉线、不重连；② 实测吞吐稳定在标称的七成以上；③ 换 IP 后延迟波动在 3 倍以内。

先别买的信号：① 同一轮里 3 条 IP 有 2 条连不上——这不是运气问题，是线路池整体质量的问题；② 连续两轮都在高峰期掉线——说明这条线在你最需要它的时段最不稳定。

判断顺序上有一条经验：**先用完 2–3 轮把「哪条线路 + 哪一档带宽」定下来，再拿剩下的轮次做高峰时段复测**，而不是把 30 次平摊成 30 次随机连接。

## 常见问题

**Q：登录进去只看到付费套餐，免费测试是不是取消了？**
没有取消。测试卡在「购买代理」页的支付方式一栏里，页面默认高亮金币支付，往下拉才能看到「测试卡」选项，选中提交不扣余额。

**Q：测试卡领来的 IP 质量比付费的差吗？**
不差。测试卡走的是与付费 IP 同一套线路资源，不是降级版，所以测出来的延迟、归属地和稳定性可以直接作为选档依据。

**Q：30 次额度用完了还没想好，怎么办？**
按第二节的四个问题倒推：如果①和②都有答案，直接买最小周期的月卡；如果两轮都是高峰期掉线、多条 IP 连不上，就不必再试，换一条线路或换一家平台更省时间。

**Q：20M 档为什么只有两条线路可选？**
天翼云与移动云这两条线路上限是 10M，20M 只在阿里云和家庭住宅提供。所以选档顺序是先定带宽、再看线路，反过来会挑一轮才发现选不出组合。

**Q：能同时开很多条 IP 吗？**
可以，后台按线路、带宽、时长组合。实操建议按窗口数配 5M 或 10M 档，先用测试卡跑一遍真实占用再定量，不要一上来就买大带宽。

**Q：换 IP 有次数限制吗？**
每条 IP 自带配额：日卡 2 次、周卡 7 次、月卡 30 次。频繁换 IP 的业务直接上月卡，短周期买多了会发现次数不够用。

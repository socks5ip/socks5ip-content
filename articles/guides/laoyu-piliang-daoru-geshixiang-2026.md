# 老鱼专业版批量导入总在第 4 个窗口失败：五个格式项要核

把 200 行线路粘进导入框，前三个窗口通了，从第四个开始报错——错的不是这条线，是表格第三行的端口列。

**一句话结论：老鱼加速器只吃 Socks5 的四项参数（地址、端口、账号、密码），批量导入失败九成落在表格格式而不是线路本身；专业版 12 元/年 提供批量导入与单窗口单 IP 多开，导入前必须核五个格式项——列序、端口数据类型、空行与合并单元格、分隔符与编码、导入后逐窗口验出口。**

## 前三个能通、第四个不通，说明什么

这说明软件本身没问题，前三条线也没问题。导入是「一行对一条线」的机械映射，一旦某一行解析失败，后面的行要么整体错位、要么被跳过，表现出来就是「前面几个好、后面全红」。

所以排查顺序应该反过来：**先看表格，再看线路**。线路坏一条是偶然，从某一行的位置开始集体失败是必然，差别就在那一行。

## 第一个格式项：列序别自己重排

后台的导入模板有五列甚至更多，顺序是固定的：地址在前、端口在后，接着是账号与密码，其余列是备注或分组。把 Excel 里调过顺序的表直接粘进去，软件仍然按它的列序读，结果就是地址列被当成端口、端口列被当成账号。

核对方法很笨但有效：把模板的第一行抄到一张空表里，再把数据一行行贴到对应列下面，不要「看起来差不多就粘」。

## 第二个格式项：端口被 Excel 改成数字

端口是数字，但它是标识符，不是数值。Excel 对数字列会做三件事：去掉前导零、把长数字转成科学计数法、对超范围的数字自动四舍五入。

导入前把端口列整列设成「文本」，再重新粘一次。判断有没有中招很简单：**看这一列有没有哪个值显示成 `1.08E+04` 这类形式，或者数字变短了**。有就是被转换过。

同理，账号列如果纯数字，也会被吃掉前导零——那种账号在后台是存在的，只是你导入的这一份变了形。

## 第三个格式项：空行与合并单元格会让行号整体错位

两种常见的表格习惯会直接毁掉映射：

| 表格里的写法 | 导入后发生什么 | 正确做法 |
|---|---|---|
| 中间插一个空行做分隔 | 空行之后的线路全部错位或丢弃 | 删掉空行，用备注列分组 |
| 用合并单元格给一组线路打标签 | 只有第一行带标签，其余行为空 | 每行都写全，标签重复写 |
| 表头有两行（大标题 + 字段名） | 第二行被当成一条线路导入 | 只留一行字段名 |
| 末尾留着几百行空白格式 | 生成大量空记录，导入变慢或报错 | 删掉数据区之外的所有行 |

最后一条最容易被忽略：Excel 里看着只有 200 行，实际文件里可能带着上万个空行，导入工具会逐行读。

## 第四个格式项：分隔符与编码

粘贴和导入是两种不同的路径。从 Excel 直接粘贴，走的是制表符；存成 CSV 再导入，走的是逗号。同一份数据用错路径，整行会被当成一列。

编码的问题更隐蔽：带 BOM 的 UTF-8 文件，第一个字段前面会多出一个看不见的字符，导致第一行永远失败。判断方法是**把第一行挪到中间再导一次**——如果失败的位置跟着走，就是首行带了脏字符。

## 第五个格式项：导入成功不等于生效

导入框不报错，只说明行被读进去了，不代表线路可用。逐窗口验出口这一步不能省：

1. 每个窗口单独打开一次目标程序，确认它走的是代理而不是本地网络。
2. 用 IP 综合检测中心看出口归属地与线路类型，与导入表里那一行对照。
3. 抽查最后一个窗口——错位类问题总是从尾部先暴露。

只验第一个窗口是无效验证：第一条线几乎永远是对的。

## 自测口径：先用三行样本试导

正式导 200 行之前，抽三行做样本：**第一行、中间一行、最后一行**。

三行都通了再全量导。这个动作花两分钟，能省掉一次「导完发现全错、重来一遍」的返工。三行里只要有一行失败，就回到上面五个格式项逐个核，别急着换线路。

还有一个前提要确认：老鱼只接 Socks5。L2TP、PPTP 和仅 APP 可用的分区，无论表格写得多规整都导不进去——这类线路得走系统隧道，不是导入框能解决的事。

## 常见问题

**问：导入成功了，为什么打开程序还是本地 IP？**

导入只把线路存进软件，没决定哪个程序走它。要回到「代理模式」那一栏，把目标程序勾进接管列表，或者切到全局。窗口能连上但程序不走代理，通常是这一栏没选。

**问：老鱼能导入 L2TP 线路吗？**

不能。老鱼只认 Socks5 的四项参数，L2TP、PPTP 这类整机隧道要在系统网络里建连接，或者用软路由接。分区页面明确标注仅支持 L2TP 的，就别往导入框里放。

**问：端口那一列明明是对的，为什么报错？**

先看它是不是被 Excel 当成数字处理了。整列设成文本再粘一次，特别注意有没有值变成科学计数法。端口是标识符，不是数值，任何自动格式化都会破坏它。

**问：只导入几十条，也要先试三行吗？**

要。试三行的成本是两分钟，失败的成本是重导一遍加逐个复查。行数少的时候更容易漏掉尾部错位，因为前面几条通常都对。

**问：免费版和专业版在导入这件事上差在哪？**

免费版面向单窗口单 IP 的配置，专业版（12 元/年）提供批量导入与多开管理。表格格式的要求是一样的，差别在于一次处理多少行、以及能不能按窗口分组管理。

**问：导入后怎么确认每条线都对上了窗口？**

不要只看第一条。打开最后一个窗口验一次，再用 IP 综合检测中心核对出口归属；首尾都对上，中间错位的概率就很低。

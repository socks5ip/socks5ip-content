# 优众IP 电脑配置：L2TP 零安装，SK5 要客户端

在优众IP 上买 L2TP 还是买 SK5，落到 Windows 这台机器上，争的不是带宽，而是"要不要装东西"：L2TP 用系统自带的拨号功能就能连，SK5 没有原生支持，必须配一个第三方客户端。

**优众IP 的 L2TP 三档（3M 13.2 元、5M 18 元、10M 27.6 元，30 天折后价）走 Windows 自带拨号，零安装；SK5 两档（30 天 7.2 元）必须装支持 socks5 的第三方客户端。** 两条路之前还有两个前置动作——实名认证和金币账户，SK5 与 L2TP 的金币分开记，充错那一笔买不了另一条产品。

## 一、两条路的差别不止"装不装软件"

系统自带拨号只认几种协议，L2TP 在里面，SOCKS5 不在。这一条决定了动手前要准备什么，也决定了买完之后的分流方式。

| 协议 | Windows 原生支持 | 要装客户端吗 | 表内带宽 | 适合 |
|---|---|---|---|---|
| L2TP（三档） | 支持，系统拨号直接连 | 不用 | 3M／5M／10M 固定 | 单机全局出口、软路由思路的项目 |
| SK5（两档） | 不支持 | 要，装支持 socks5 的第三方软件 | 峰值 100M／固定 3M | 按窗口或按进程分流的多开 |

差别还落在分流上：L2TP 拨上之后是整机走这条线，同一台电脑要让不同窗口走不同出口，得靠虚拟机或额外的分流工具；SK5 配的第三方客户端通常支持按进程指定代理，多开场景更顺手。**先想清楚"整机走一条"还是"每个窗口走一条"，再选协议，比先看价格有用。**

## 二、配置之前的两件前置动作

教程页把顺序写得很直白：注册、实名认证、充值或领试用、买节点、提取。前三步里有两步是"没做就白折腾"的硬门槛。

| 动作 | 在哪做 | 不做的后果 |
|---|---|---|
| 实名认证 | 个人中心 | 教程页标"使用前必需"，不认证提取不了 |
| 充值或领试用 | 账户金币 | 买节点时余额不足，卡在下单页 |
| 买节点 | 选代理项目 + 选地区 | 没有节点，节点管理里是空的 |
| 提取 | 节点管理，勾选 IP 序号 | 拿不到服务器地址与账号密码 |

地区那一栏教程页写的是"性能相近可随意选"，意思是同一档位内换地区不影响基础性能。所以配置阶段不用纠结地区，该纠结的是档位——带宽在买的时候定死，填客户端的时候补不回来。

## 三、L2TP 那条：系统拨号六步

从节点管理复制出来的信息里，要用的是服务器地址、账号、密码，可能还有预共享密钥。填的位置在系统设置里，不在任何安装包里。

| 步 | 动作 | 填什么／选什么 |
|---|---|---|
| 1 | 设置 → 网络和 Internet → 添加连接 | 选"连接"里的对应类型 |
| 2 | 提供商 | 选 Windows（内置） |
| 3 | 连接名称 | 自己起，建议带档位，如"优众-L2TP-10M" |
| 4 | 服务器名称或地址 | 粘节点信息里的服务器地址 |
| 5 | 类型 | 使用预共享密钥的 L2TP/IPSec |
| 6 | 账号密码 | 粘节点信息里的账号与密码，保存后连接 |

预共享密钥那一栏：节点信息里单独给了就照抄，没给就先留空连一次。失败的报错码指向不同地方——789 一般是安全层协商失败（密钥或加密设置不对），691 是账号密码被拒。两个码别混着改，一个是安全参数，一个是凭证。

## 四、SK5 那条：客户端里四个字段

SK5 要靠第三方客户端，站内常用搭配是老鱼这一类支持 socks5 的工具。填的东西比 L2TP 少，但字段名各家叫法不同。

| 节点信息里的字段 | 客户端里对应 | 常见填错 |
|---|---|---|
| 服务器地址 | 服务器／主机／IP | 把端口一起粘进地址栏 |
| 端口 | 端口／Port | 漏填，客户端默认走 1080 |
| 账号 | 用户名 | 把整行"账号:密码"一起粘进去 |
| 密码 | 密码 | 复制时带了空格 |

填完先做一件事：点连接，然后打开浏览器查一次出口 IP。查到的是节点所在地，这条线才算通；查出来还是本地 IP，问题在客户端的代理模式，不在节点——多数客户端默认"仅浏览器"或"规则模式"，得切到全局。

## 五、金币账户独立，充错不通用

教程页专门用一行加粗提醒：SK5 和 L2TP 的金币账户独立、单价不同。这不是排版上的强调，是实打实的坑。

| 你买的产品 | 扣哪个账户 | 充错之后 |
|---|---|---|
| SK5 两档 | SK5 金币账户 | L2TP 账户里余额看得见，下单时用不上 |
| L2TP 三档 | L2TP 金币账户 | 反过来一样，SK5 那侧的钱动不了 |

稳妥的做法是先定协议再充钱：确定要 SK5 就只充 SK5 那一侧，别为了"反正都是金币"一次充两边。真要两边都用，按先跑通一条、再补另一条的顺序来，充错了至少还有一边能用。

## 六、自测口径：四种现象对应四处

| 现象 | 先查 | 多半是这个原因 |
|---|---|---|
| 拨号报 789 | 预共享密钥、加密设置 | 密钥没填或填错，安全层协商不过 |
| 拨号报 691 | 账号密码 | 复制带了空格，或用了另一个账户的密码 |
| 客户端显示已连，网页还是本地 IP | 客户端的代理模式 | 停在规则模式，只有部分程序走代理 |
| 连上几十秒就断 | 当前档位带宽与用途 | 3M 跑视频或多窗口并发，被限速或掐断 |

最后一个现象最容易误判成"线路不稳"。价格表页在那几行旁边写明了限制：3M 档"适合游戏类低带宽需求，不支持大流量项目"，10M 档才写"支持视频挂机，禁止 24 小时大流量"。带宽不够时，换客户端、换地区都救不回来，只能换档。

## 八、常见问题

**Q：优众IP 在 Windows 上一定要装软件吗？**
A：看你买哪条。L2TP 三档用系统自带拨号，不用装；SK5 两档没有原生支持，必须装支持 socks5 的第三方客户端。

**Q：节点信息里哪些字段是必填的？**
A：服务器地址、端口、账号、密码四个。L2TP 另外可能给预共享密钥，SK5 不需要密钥但必须填端口。

**Q：为什么买完节点，节点管理里是空的？**
A：先确认实名认证做完了，再看买节点时选的是不是当前登录账号。实名那一步漏掉，后面全卡住。

**Q：金币能两边通用吗？**
A：不能。SK5 与 L2TP 金币账户独立、单价不同，充错账户的钱只能用在对应产品上。

**Q：一台电脑能同时用 L2TP 和 SK5 吗？**
A：能，但会互相抢默认路由。建议 L2TP 只给指定环境用，SK5 那边按进程分流，别让两条线都当全局出口。

**Q：连上但网页很慢，是节点问题吗？**
A：先看档位带宽。3M 是固定带宽，多窗口并发立刻见底；10M 档才写明支持视频挂机。速度不够优先换档，不是换节点。

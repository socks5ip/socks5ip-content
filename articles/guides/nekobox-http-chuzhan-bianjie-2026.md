# 安卓客户端的 HTTP 出站：能填不等于能干

同一个端口，类型栏选 HTTP 能连上，选 SOCKS5 也能连上——那到底该选哪个？答案取决于你要传什么：**安卓客户端里的 HTTP 类型只走 TCP**，开网页、跑采集、喂给只认 HTTP 入口的软件都够用；游戏、语音这类含 UDP 的流量，以及 TUN 全局模式，必须切回 SOCKS5 类型。两种类型能填同一个端口，前提是平台给的是 HTTP / SOCKS5 混合入口——JiuIP 就是全协议入口，**2M 月卡 3.4 金币/月（1 金币 ≈ 1 元）**，注册实名后送 30 次免费测试，每次 3 条、时长 5 小时。

## 一、能力边界：HTTP 出站只承载 TCP

NekoBox for Android 的内核来自 sing-box，出站类型里同时包含 HTTP 与 SOCKS5，所以"支不支持 HTTP"这个问题可以直接回答：支持。真正需要说清的是支持的范围——**HTTP 出站走的是 HTTP CONNECT 隧道，这条通道只承载 TCP，UDP 不从里面走**。

| NekoBox 里的类型 | 走哪一层 | UDP 支持 | 认证方式 | 典型用途 |
|---|---|---|---|---|
| HTTP | 仅 TCP（HTTP CONNECT 隧道） | 不支持 | 用户名 + 密码（Basic） | 网页访问、只认 HTTP 入口的软件 |
| SOCKS5 | TCP + UDP | 支持 | 用户名 + 密码 | 游戏多开、模拟器、UDP 业务、TUN 全局 |
| Shadowsocks | TCP + UDP | 支持 | 密码 + 加密方式 | 订阅型节点、安卓端常用 |
| WireGuard | 系统级隧道 | 支持 | 密钥 | 整机代理、跨设备统一出口 |

顺带排除一个常见误会：**L2TP 不在 NekoBox 的类型列表里**。L2TP 是操作系统级的隧道协议，手机端走系统自带的连接配置，电脑端和软路由（OpenWrt / 爱快 / ROS）才用它。所以"NekoBox 能不能连 L2TP 线路"这个问题，答案是不能——需要在平台后台单独提取 L2TP 账号密码，用系统连接或软路由接。

## 二、四个判断点：端口、UDP、解析位置、TUN

两种类型都能填的时候，选哪个不靠"哪个更新"这类感觉：

| 判断点 | 填 HTTP 时 | 填 SOCKS5 时 |
|---|---|---|
| 端口能不能通用 | 平台给混合口才通；只开 SOCKS5 的端口填 HTTP 会连不上 | 通用性最好，混合口和纯 SOCKS5 口都能填 |
| UDP 业务 | 完全不支持，游戏、语音、部分推流会掉 | 支持，前提是线路本身开了 UDP |
| 域名解析在哪端 | 只能由代理端解析（请求里带完整地址） | 可以交给代理端，也可以本地解析，控 DNS 更灵活 |
| TUN / 全局模式 | 不能单独接管整机流量，UDP 会穿出去 | 配合 TUN 可以接管 TCP + UDP，适合整机走代理 |

其中"端口能不能通用"最容易卡住。不少平台把 HTTP 和 SOCKS5 做成同一个混合端口，同一组地址、端口、账号密码，类型栏填哪个都连得上，于是很多人以为两者没区别；也有平台只开单协议端口，这时候类型填错就是一直转圈。判断方法很简单：**后台只给你四项参数（地址、端口、用户名、密码）、没有额外说明端口类型时，先用 SOCKS5 试，通了再试 HTTP。**

认证那栏也有细节。HTTP 出站用 Basic 认证，本质是"用户名:密码"拼起来发过去，所以四项参数必须原样复制——多一个空格、大小写抄错一位，表现都是反复弹出认证框。**地址栏只填 IP 或域名，不要带 `http://` 前缀**，端口单独写在端口栏；把协议头一起粘进地址栏是新手最常见的一个错。

## 三、临界点：什么时候必须换回 SOCKS5

抛开"哪个更强"，按业务直接对照更省事：

| 你的用法 | 建议类型 | 原因 |
|---|---|---|
| 只开网页、刷信息流、查资料 | HTTP 或 SOCKS5 都行 | 纯 TCP 场景，两者体验没有差别 |
| 剪贴板导入的链接是 `http://` 开头 | HTTP | 分享链接的协议头决定导入后的类型，不用手改 |
| 安卓端带游戏、模拟器叠跑 | **SOCKS5** | 游戏流量含 UDP，HTTP 类型会直接漏掉这部分 |
| 做采集、批量请求，走单窗口单 IP | **SOCKS5** | 并发连接更多，且能配合分应用代理精确控制出口 |
| 要开 TUN 接管整机流量 | **SOCKS5** | TUN 下 TCP 和 UDP 都要接管，HTTP 类型做不到 |

有一个位置需要单独点一下：**NekoBox 的 HTTP 是"出站类型"，管的是节点本身怎么走**；而 SSTap 那类驱动层工具的 HTTP 是"本地代理模式"，管的是本机软件怎么接进来。名字一样、位置不同，网上把它们混着讲的内容不少，照着配容易越配越乱。如果需要的是电脑端按窗口分配出口，走的是老鱼加速器或 SSTap 那条线，和 NekoBox 的手机端方案不是一套，客户端汇总见 [代理工具中心](https://socks5ip.com.cn/dailigongjuzhongxin/)。

## 四、在 NekoBox 里加一条 HTTP 代理

加 HTTP 节点和加 SOCKS5 节点是同一套操作路径，区别只在类型栏那一步：

1. **拿到四项参数。** 在平台后台的"我的代理"里查看节点链接信息，拿到服务器地址、端口、用户名、密码。JiuIP 这类平台会直接把二维码和四项参数一并给出，HTTP 与 SOCKS5 共用同一套账号信息，不需要额外开通。
2. **新建配置并选类型。** 打开 NekoBox，点右上角「+」新建配置；类型栏选 HTTP，把四项参数按后台原样填进去保存。拿到 `http://` 开头的分享链接时，用剪贴板导入或扫二维码会自动识别成 HTTP，不用手填。
3. **选中并启动。** 回到服务器列表，点选刚建好的节点，按下底部图标启动；打开浏览器访问一次查询 IP 的页面，确认出口已经换成线路 IP。这一步别跳过——**HTTP 类型填错的典型表现就是"看着连上了、出口还是本地"**。

手填的建议先把参数粘到备忘录核对一遍再复制进 APP：NekoBox 的配置项没有"撤销上一步"，改错一处往往要删掉整个配置重建。

## 五、连不通时按现象排查

| 现象 | 多半是什么 | 怎么改 |
|---|---|---|
| 类型填 HTTP 连不上，换 SOCKS5 立刻通 | 平台的这个端口只开了 SOCKS5 | 保持端口不动，把类型改成 SOCKS5 |
| 网页能开，游戏 / 语音连不上 | HTTP 类型不走 UDP | 换 SOCKS5 类型，并确认所选线路支持 UDP |
| 反复提示要账号密码、认证失败 | 账号密码手抄出错，或协议与端口不匹配 | 从后台重新复制四项参数，不要手动输入 |
| 导入后类型不是 HTTP | 分享链接的协议头是 `socks://` | 用 `http://` 开头的链接导入，或手动新建 HTTP 类型 |
| 开了代理访问国内站点变慢 | 路由规则开关没启用 | 左滑菜单进「路由」，把开关打开后重启代理 |

还有一种情况不属于故障：HTTP 类型连上之后，某些应用依然显示本地 IP。这不是 NekoBox 没生效，是那个应用自己走了直连或自带网络通道，HTTP 出站管不到它。判断方法还是同一个——用浏览器查一次出口 IP，浏览器走了线路、应用没走，问题就在应用侧。

## 八、常见问题

**Q：NekoBox 里选 HTTP 还是 SOCKS5，能连上不就一样吗？**
不一样。能连上只说明这个端口两种协议都放行了，能力上 HTTP 只走 TCP、不支持 UDP；涉及游戏、语音、TUN 全局的场景必须用 SOCKS5。只是开网页的话两者确实没差别。

**Q：填了 HTTP 类型，网页能开但游戏连不上，是什么原因？**
HTTP CONNECT 隧道只承载 TCP，游戏的 UDP 流量不会走这条通道。把类型改成 SOCKS5，并确认所选的线路档位支持 UDP 即可。

**Q：开了代理还是本地 IP 怎么办？**
先确认节点真的启动（浏览器查一次出口 IP），再看应用是不是自带网络通道绕过了代理。浏览器走了线路、单个应用没走，问题就在那个应用侧，不在 NekoBox。

**Q：NekoBox 的 HTTP 能配合 TUN 全局模式吗？**
不建议。TUN 要接管 TCP 和 UDP 全部流量，HTTP 出站带不了 UDP，会出现"部分应用走代理、部分还是本地 IP"的情况。要整机走代理就把类型换成 SOCKS5。

**Q：NekoBox 能连 L2TP 线路吗？**
不能，L2TP 是系统级隧道协议，不在 NekoBox 的类型列表里。需要 L2TP 就在平台后台单独提取账号密码，用手机系统自带的连接配置或软路由（OpenWrt / 爱快 / ROS）来配。

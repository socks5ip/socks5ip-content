# 手机 IP 和 WiFi IP 是同一个吗：先分清三个地址谁在最外面

手机没连 WiFi 也在用运营商网络这件事，很多人是第一次听说——以为「关掉无线才会走流量卡」，其实蜂窝那一层从没断开，连着 WiFi 时它只是退到内层待命。**手机上同时存在三个地址，切换 WiFi 只决定哪一层在往外发数据，不是把另外两层关掉。**

## 三张网卡同时对着一台手机

| 地址 | 由谁分配 | 什么时候在承载流量 | 关掉它会发生什么 |
|---|---|---|---|
| 蜂窝数据 IP | 运营商基站 | WiFi 断开时 | 断网，收不到短信与来电 |
| WiFi 公网 IP | 宽带路由器（NAT 后） | WiFi 连上且未走代理时 | 退回蜂窝数据 |
| 代理出口 IP | 代理服务器 | 代理生效且规则放行时 | 退回上一层地址 |

**三者的关系是叠加，不是替换。** 连上 WiFi 之后，蜂窝那一层退到内层待命；挂上代理之后，代理出口成为最外面那层，WiFi 公网地址也跟着退到内层。

## 哪个地址在最外层，由谁说了算

| 你的状态 | 检测页会显示 | 说明 |
|---|---|---|
| 只用 WiFi、没开代理 | WiFi 公网 IP | 宽带路由器拿到的地址 |
| 只用蜂窝、没开代理 | 蜂窝数据 IP | 运营商基站分配的地址 |
| WiFi + 代理已生效 | 代理出口 IP | 最外层被替换 |
| WiFi + 代理没生效 | WiFi 公网 IP | 看起来「属地在本地」，其实是没连上 |

最后一行是绝大多数「换了代理属地没变」的真实原因：**不是代理不起作用，是它根本没接管这条流量。**

## 「换了属地没变」的四条路，按顺序排查

| 顺序 | 排查项 | 怎么确认 | 修法 |
|---|---|---|---|
| 1 | 代理有没有连上 | 检测页是否显示代理出口地址 | 重连、检查凭据与协议匹配 |
| 2 | 分流规则是否放行 | 规则里这条应用是走代理还是直连 | 把目标应用加进规则 |
| 3 | 是否只代理了部分应用 | 换一个应用再查一次出口 | 改成全局接管或补齐规则 |
| 4 | 对方读的是不是 IP | 页面显示的属地是否来自其他依据 | 换判定项，见下节 |

**按这个顺序查，成本最低**：前三条都是配置问题，改完立刻能看到检测页变化；只有第四条牵涉到判定依据本身。

## 属地是怎么被读出来的：IP 只是其中一条

换了出口只解决「出口 IP 归属地」这一条依据，其他依据要各自处理。

| 判定依据 | 换代理出口能改吗 | 需要另外处理什么 |
|---|---|---|
| IP 归属地 | 能 | 选对地区池即可 |
| 手机号归属地 | 不能 | 与 SIM 卡绑定，换线路无效 |
| 定位 / GPS | 不能 | 由设备定位权限决定 |
| 时区与语言 | 不能 | 由系统设置决定 |
| 登录历史地 | 部分 | 需长期保持一致的出口 |

**看到「属地没变」，先确认页面上显示的属地来自哪一项**——如果是手机号归属地或 GPS，换多少条线路都不会变。

## 自测口径：三步确认出口真的换了

| 步骤 | 做什么 | 合格的样子 |
|---|---|---|
| 1 | 断开 WiFi，只用蜂窝数据查一次 | 记下运营商分配的地址 |
| 2 | 连上 WiFi、挂代理，再查一次 | 显示代理出口地址与目标归属地 |
| 3 | 打开一个未走代理的应用查出口 | SOCKS5 下显示本地地址，属正常 |

第 3 步是判断规则是否精确接管的最好办法：**SOCKS5 只接管规则里放行的程序，未放行的照旧走本地。** 用 [IP 综合检测中心](https://socks5ip.com.cn/ip-check-center/) 逐个核对，能省掉大部分「明明开了代理却没用」的返工。

## 常见问题

**Q：手机 IP 和 WiFi 的 IP 是同一个吗？**
A：不是。蜂窝数据 IP 由运营商基站分配，WiFi 公网 IP 由宽带路由器分配，两者是不同网络分配的不同地址。检测页显示哪一个，取决于当前哪一层在承载流量。

**Q：关掉 WiFi 后，原来的 WiFi IP 还在吗？**
A：不在对外显示，但那一层并没有消失——设备还连着路由器（如果没关 WiFi 开关），只是数据不再从那条路径出去。真正决定对外地址的是当前承载数据的那一层。

**Q：开了代理，为什么属地还是本地？**
A：按四条路排查：代理是否连上、分流规则是否放行、是否只代理了部分应用、页面读的是不是 IP。前三条改配置即可，第四条要看判定依据是不是手机号归属地或 GPS。

**Q：代理只对部分应用生效，正常吗？**
A：SOCKS5 的设计就是只接管规则里放行的程序，未放行的走本地，这是正常的。要让全部流量都走线路，需要改用整机接管的协议或在工具里设置全局规则。

**Q：手机端做多账号，每条线要多少钱？**
A：国内独立代理 IP 起步价 2.24 元/月一档，按条计价、多开按条数叠加。先用最低档跑通业务，再按账号数决定条数。

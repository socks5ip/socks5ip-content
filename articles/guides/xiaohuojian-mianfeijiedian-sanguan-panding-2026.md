# 延迟数字好看，不代表能用

免费节点连得上，就说明它能用吗？小火箭里点一下延迟测试，验证的只是握手成功；出口 IP 归谁、业务会不会被拦，这两关都没过。免费源被共享的从来不是带宽，而是**出口地址**——同一个出口今天登录过多少个不同账号，目标平台那边看得一清二楚。

## 一、三关的判定顺序，顺序不能颠倒

| 关卡 | 用哪个工具 | 看什么 | 通过判据 |
|---|---|---|---|
| 第一关：握手 | [代理线路可用性检测](https://socks5ip.com.cn/proxy-check/) | SOCKS5 / HTTP 真实握手结果与延迟分级 | 握手成功，延迟分级不来回跳档 |
| 第二关：出口 | [IP 综合检测中心](https://socks5ip.com.cn/ip-check-center/) | 出口 IP 归属、线路类型、IP 质量 | 出口 ≠ 本机 IP，归属与平台描述一致 |
| 第三关：业务 | IP 综合检测中心的业务模拟 | 目标业务能不能真的跑通 | 不弹验证码、不出现风控拦截 |

握手不过，后面两步都是白测；握手过了但出口归属对不上，说明导入的不是平台承诺的那种线路；只有前两关都过，业务模拟才有意义——它验证的是这个出口能不能被目标平台接受。

## 二、三类免费源的失效节奏完全不同

| 免费源 | 出口 IP 归谁 | 典型失效节奏 | 适合的用法 |
|---|---|---|---|
| 公开订阅 / 节点分享站 | 几十到上百人共用一个出口 | 数小时到数天就可能整批失效 | 临时查资料 |
| 平台官方免费测试 | 平台自有池，按条分配给你 | 额度用完即止（2 条/天 到 30 次） | 验证配置、先测后买 |
| 自建节点 | 自己的服务器，独享 | 不失效，但出口是机房段 | 需要固定出口的轻量用途 |

三类的取舍逻辑其实很清楚：公开订阅源拼的是作者还在不在更新，官方免费测试拼的是你测完会不会买，自建拼的是你愿不愿意每月再付一份服务器钱。想长期用，第二类和第三类才有讨论价值；第一类只适合当临时通道。

## 三、官方免费测试的额度区间

这是被低估的一类免费源：出口是平台自己的池子，按条分配，还带客服，比公开订阅干净得多。缺点只有一个——额度用完就得做决定。各家给的量差得很远：

## 四、四个维度决定免费源能不能长期用

| 维度 | 公开订阅源 | 付费线路 |
|---|---|---|
| 出口 IP 归属 | 几十人到上百人共用一个 | 按条分配，可选独享 |
| 能不能换 IP | 取决于作者下次更新，自己换不了 | 自带切换额度（天行 1000 次/月、优众 2000 次/月） |
| 协议形态 | 一般只给客户端能直接吃的格式 | SOCKS5 + L2TP 双协议齐全，可接软路由 |
| 出问题找谁 | 只能等下一次更新 | 有客服，部分平台支持免费调换 |

第二行最容易被忽略。免费源的 IP 是死的，**一旦被目标平台标记，你没有任何办法换掉它**——只能删掉这条订阅，等作者放新的。付费线路自带切换额度，撞上脏 IP 直接换一条就行。

## 五、这几种用法别把免费节点挂上去

| 你的用法 | 建议 | 理由 |
|---|---|---|
| 单人查资料 | 免费源够用 | 出口被共用，对只看网页的人影响有限 |
| 多开 / 搬砖 / 电商店铺 | 走付费线路 | 出口共用会被关联，账号风险不可控 |
| 需要固定出口的数据采集 | 选静态独享 | 免费源的出口地址随时会变 |
| 只想先验证配置能不能跑通 | 用官方免费测试 | 有额度、有客服，测完再决定买不买 |

把这几条倒过来看就是选型思路：凡是「多个账号 + 同一个出口」的组合，免费源都是错的那一档；凡是「只是想确认小火箭的配置写对了没有」，公开订阅源反而更省事。

## 常见问题

**Q：小火箭里导入的免费订阅，为什么刚能用一会儿就失效了？**
这类订阅的出口是多人共用的，作者一旦停止更新或出口被目标平台封掉，整批节点会同时失效。它能连上说明握手没问题，失效说明出口被回收了，两者并不矛盾。

**Q：2026 年还有真正稳定的免费节点吗？**
稳定的免费节点基本只剩自建这一条路——出口是自己的服务器，但每月仍要付一份服务器费用，而且出口是机房段，对风控敏感的业务照样不合适。

**Q：免费节点能不能拿来挂游戏多开或者电商店铺？**
不建议。多账号最怕的就是出口重合，几十人共用的出口等于把账号关联风险交给别人决定，出了问题你连换 IP 的权限都没有。

**Q：官方免费测试和公开免费节点，测出来的结果能通用吗？**
不能。官方免费测试测的是你将要购买的那条线路，结果直接代表正式使用效果；公开订阅测的是别人的免费出口，跟付费线路没有任何对应关系。

**Q：怎么判断一个免费节点的出口 IP 干不干净？**
把节点导入小火箭后打开 IP 综合检测中心，看出口 IP 的归属与线路类型是否和描述一致，再跑一次业务模拟看会不会弹验证码。只看延迟数字判断不了这件事。

**Q：先测后买的免费测试一般给多少量？**
多数平台给 5-10 条/天或 2 小时左右，JiuIP 给 30 次，蛟龙IP 是 2 条/天。额度够验证配置和跑一次业务模拟，够不够用要看你的测试项目数。

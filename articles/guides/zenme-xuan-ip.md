# 怎么选代理IP？6个维度一次讲清（附决策路径）

## 结论

选 IP 别先看价格，先看**场景**。把场景定下来，6 个维度逐个过滤，答案自己就出来了。

## 六个维度

| 维度 | 要问的问题 | 判断标准 |
|---|---|---|
| ① 场景 | 多开？跨境？采集？社媒？ | 决定 IP 类型和预算区间 |
| ② IP 类型 | 静态还是动态？住宅还是机房？ | 长期项目静态、纯净要求住宅 |
| ③ 协议 | 客户端/工具支持什么？ | 工具类 SOCKS5 为主，软路由 L2TP |
| ④ 地区 | 出口要在哪？ | 国内业务选国内，跨境选海外 |
| ⑤ 带宽与调换 | 大流量？需要频繁换 IP？ | 视频/直播要大带宽，轮换场景看调换次数 |
| ⑥ 价格与服务 | 单条成本、免费测试、售后 | 先测后买是底线 |

## 按场景的快速答案

- **游戏多开 / 工作室**：国内静态住宅 IP，低预算起步（2.6-6 元/月档），重点看稳定性和调换规则
- **跨境电商 / TikTok**：海外住宅 IP，优先原生、纯净度高，价格 5-20 元/月
- **社媒矩阵运营**：国内或海外住宅 IP，一账号一 IP，看重纯净度
- **数据采集**：看并发与轮换能力，动态住宅或大带宽静态均可
- **软路由 / 多设备**：L2TP 套餐，一台路由器全屋接入

## 决策路径

```
先测后买 → 免费测试验证归属地/延迟/稳定性 → 满意再按月/按季购买
```

## 常见问题

**是不是越贵越好？** 不是。贵在带宽、纯净度、独享属性；场景不需要时不必多花。

**一个平台够吗？** 可以多平台互补（比如国内+海外各备一个），价格中心支持一站式比价。

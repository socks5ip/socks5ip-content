## 住宅出口和机房转发，差在四个地方

这是选型时最先要分清的一层。「住宅」不等于「不会被识别」，它只是让出口的出身更接近普通用户。真正能被读到的差别在下面四处。

| 对比项 | 静态长效住宅 | 机房 / 数据中心 IP |
|---|---|---|
| ASN 归属 | 当地运营商的宽网段 | 云厂商或 IDC 运营商自有 ASN |
| 反向解析 | 通常是 ISP 宽带域名，常带地区 | 常为空，或直接写着机房标识 |
| 段内邻居 | 多为真实家庭用户，行为分散 | 服务器、采集脚本、批量任务集中 |
| 稳定性 | 一条线路用一段时间，出口不跳 | 取决于机房，通常也稳 |
| 价格 | 通常更高 | 通常更低 |

**第一步不是比较参数，而是查一次 ASN。** 把拿到的出口 IP 填进检测工具，归属写运营商宽带业务的多半是住宅，写云厂商或 IDC 的多半是机房。这一步免费，也不用听描述。

## 2000+ 节点这个数字，比 160+ 国家更有用

两个数字要分开读：前者说「能在哪些国家拿到出口」，后者说「同一时间可用的线路条数」。真正影响日常体验的是后者——节点池越大，换到一条落点不理想的线路时，可替换的余地越大。

| 指标 | 平台口径 | 对你的实际意义 |
|---|---|---|
| 国家地区数 | 160+ | 小语种市场的目标地区也有覆盖可能 |
| 在线节点数 | 2000+ | 同一地区可选线路多，替换余地大 |
| 骨干网延迟 | < 50ms | 属可接受区间，具体看你的真实线路 |
| 连接可用率 | 99.9% | 月度口径，日常波动仍要实测 |

平台自己也建议先拿测试卡跑一遍：测试卡约 2 小时 / 1GB 流量，够把目标国家节点连一轮、量一遍延迟和可用率，再决定买不买。

## API 是它和多数海外平台拉开差距的地方

纵游IP 的接口基址在官方文档里给出（形如 `zunoip.com/api`），共 52 个接口，鉴权走请求头里的 `X-Api-Key`。这个规模在同类型海外平台里不算常见——不少平台只有后台手动提取，要么没有接口，要么数量很有限。

| 能力项 | 情况 |
|---|---|
| 接口基址 | 以官方接口文档为准（形如 zunoip.com/api） |
| 接口数量 | 52 个，覆盖账号、节点与业务常用动作 |
| 鉴权方式 | 请求头 X-Api-Key |
| 适合 | 脚本批量取节点、与自有系统对接、自动化调度 |
| 不适合 | 把 key 写进前端页面或公开仓库 |

接口多不等于「一定覆盖你的场景」——具体某个动作有没有对应接口，仍要对着官方接口文档核。但它至少把「程序化取用」这条路留了出来，对要管几十上百个环境的业务来说这是硬需求。

## 什么业务适合，什么业务用不上

| 业务形态 | 适不适合 | 理由 |
|---|---|---|
| 跨境电商多店铺 | 适合 | 一店一出口，住宅归属更接近真实买家环境 |
| 海外社媒 / 短视频运营 | 适合 | 出口长期不跳，账号环境更稳定 |
| 程序化取数 / 自动化调度 | 适合 | 52 个接口可批量取用 |
| 需要指定城市级别的出口 | 要先核 | 海外平台以国家 / 地区粒度为主，城市粒度看后台实际清单 |
| 偶尔换个出口看网页 | 用不上 | 静态长效住宅按周期买，零星使用不划算 |
| 只追单条最低价 | 用不上 | 它卖的是住宅属性与 API 能力，不是最低单价 |

落在「适合」那栏再往下看价格和档位；落进「用不上」，直接去价格中心找更对路的平台，不必勉强。

## 常见问题（FAQ）

**Q：160+ 国家是真的能选到这么多地方吗？**
A：160+ 是平台口径的覆盖国家与地区数，实际可选清单以后台节点列表为准。购买前建议用测试卡把目标国家逐个连一次，比对着宣传数字推测可靠。

**Q：静态长效住宅和普通动态住宅，主要差别在哪？**
A：在「跳不跳」。静态长效住宅是一条线路用一段时间，出口不自动变；动态住宅会按规则或按次切换。要维持同一张脸选前者，要按任务换脸选后者。

**Q：52 个接口是全部开放的吗？**
A：接口基址与鉴权方式（请求头 X-Api-Key）是公开的，具体每个接口的路径与参数以官方接口文档为准。本站不做转述，避免版本对不上。

**Q：5Mbps 带宽够用吗？**
A：看业务。月卡 100GB 配 5Mbps，全速跑满约 44 小时——折到 30 天就是每天 1.5 小时左右。它不是为大流量场景设计的，够不够取决于你要跑多久。

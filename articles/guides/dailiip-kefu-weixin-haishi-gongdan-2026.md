# 一句「这个档还有吗」，该发消息了事还是提一张工单

一句「这个档还有吗」，该发条消息了事，还是提一张工单留档？

分界线不在谁回得快，而在这件事**以后还要不要翻回来看**。三条常被忽略的事实先摆出来：工单**免注册、免登录**，打开表单就填；提交完立刻给单号，凭**单号加联系方式后 4 位**在任何设备上都能调回同一条；回复按「你提交的 / 检测结果 / 处理建议 / 留言」**分块**排，隔两三天回来接着看不用在聊天记录里往上翻。

| 对比项 | 即时消息 | 客户服务台工单 |
|---|---|---|
| 要不要注册 | 不需要 | 不需要 |
| 留痕方式 | 靠聊天记录往上翻 | 单号 + 状态 + 分块回复 |
| 截图与图片 | 能发，混在对话里 | 跟对应分块一起显示 |
| 换设备继续 | 要重新说明一遍 | 凭单号 + 后 4 位调回 |
| 补充线索 | 重新描述 | 原单追加，状态回待处理 |

数据来源：站内联系方式页与客户服务台服务边界说明，核对日期 2026-11-28。

## 入口只有三处，别在站内绕圈

首页右卡那张服务台入口点进去直接是表单，页脚列着微信、QQ、邮箱，服务中心页把售后与联系渠道集中放了一页。三处之外没有第二个工单入口——**任何要求你先填账号密码才能提问的页面，都不是本站服务台**。

另外要分清的是：站内聚合了二十多家平台，各家有自己的客服，本站服务台接的是选型、报障分流、结果复核、价格口径这几类；账号、订单、续费、开通这些平台侧的事，仍要找对应服务商。把两边弄混，是最常见的白跑一趟。

## 四条情形直接发消息

影响面大、或者答案本来就是一句话的，走即时通道最省时间。

| 情形 | 为什么走即时 | 带上什么 |
|---|---|---|
| 整批业务中断、已付款完全不可用 | 先把影响面压住，再谈排查 | 起始时间、影响几个窗口 |
| 只要一句确认（档位、口径、有没有货） | 答案不需要结构化记录 | 问具体那一句 |
| 实付与站内价不符、已在别处注册过 | 属商务口径，可以免费改价 | 不用自己先算差额 |
| 开票、退款、退费、量采合作 | 走商务流程 | 按客服说明提供材料 |

价格那一格要单独说清：站内展示的是优惠价，只通过专属链接注册才生效。实付和站内价对不上，先问改价口径，不用在几张价目表之间反复核。

## 四类情形提单更省轮次

需要看你的具体环境、或者以后还要翻回来看的，结构化表单比对话高效。

| 情形 | 工单替你省下什么 | 要填的 |
|---|---|---|
| 连不上，要贴报错和截图 | 图文按分块归档，不混在对话里 | 六项信息 + 图片 |
| 要分几轮排查、隔天补线索 | 原单追加，不用重述环境 | 追加说明 |
| 换电脑、清过浏览器还要看 | 凭单号调回同一条记录 | 单号 + 后 4 位 |
| 选型结果和实测对不上 | 结合实测结果复核条件填错没 | 直连基准 + 挂代理结果 |

表单按问题分类、涉及平台、协议、业务场景、现象与已试动作分栏，还有一栏自查清单可以勾。它的意义不是让你多填点字，而是免掉第一轮「请问用的哪家、什么协议」的往返。平台栏不知道填什么就选「未购买／不确定」，这是有效答案；协议栏拿不准就把客户端里那一栏叫什么写进现象。

凭据只走「线路信息」这一栏，其余栏位出现完整代理地址、密码或密钥会被拦下要求删掉；客服回复之后，本单该栏自动清除、不长期保留。

## 单号与后 4 位，是两条不通用的路

本机上「我的工单」会记住你提交过的单，点开就能看；换了电脑、清过浏览器数据，就走「凭单号查」，两者读到的是同一条记录。

状态只有三种要分清：未回复／待处理表示还在队列里，已回复表示给了检测结果与处理建议，已处理表示这一轮闭环。在原单里追加说明，状态会回到待处理并触发提醒，后台看到的是同一单的延续，不会新建。

「提交完就找不到单了」几乎是同一个原因：联系方式填了一个自己不看的值，或者后 4 位和查询时对不上。它既用来接收回复提醒，也是换设备校验的另一半。

## 有三类事其实不用找人

| 你的诉求 | 更快的地方 | 什么时候才该找人 |
|---|---|---|
| 查价格、档位、优惠 | 价格中心、各平台价格表 | 实付与站内价不符、要改价开票 |
| 该买哪家、买哪一档 | 帮你选IP 智能推荐（免登录） | 结果与实测差距大、条件定不了 |
| IP 质量、延迟、出口地区 | IP 综合检测中心 | 测出异常但不知怎么改 |
| 配置步骤、客户端下载 | 代理工具中心与教程中心 | 照做仍报错，需要看你的环境 |

工具回答「一般情况该怎么办」，客服回答「我这个具体情况哪里不对」，两者不互相替代。把通用信息先用工具补齐，真需要人工时只写差异，整条链路最短。

## 承诺什么，不承诺什么

| 会做 | 不承诺 |
|---|---|
| 提交后给工单号，回复里给检测结果与处理建议 | 具体响应时长、一次就能解决 |
| 补充后状态回待处理并触发提醒 | 替平台查订单、账号与购买数据 |
| 线路信息在回复后自动清除 | 最低价一类的价格保证 |
| 改价、开票、退款按流程接住 | 代做业务侧效果保证 |

工单按普通与加急分流；加急请留给批量中断、已付款完全不可用这类影响面大的情况，那个按钮才有意义。只承诺行为、不承诺结果与时长，是这套服务台从一开始定下的口径。

## 自测口径：提交前先备三样

| 备什么 | 为什么 | 判据 |
|---|---|---|
| 直连基准与挂代理后的两组结果 | 没有对照就无法判断是线路还是本机 | 两组出口 IP 是否不同 |
| 已试动作清单 | 避免客服重复让你做一遍 | 每步都有「做了什么、结果如何」 |
| 联系方式与后 4 位 | 决定你能不能查回这张单 | 查询时能对上 |

三样备齐，一张单基本一轮就能定性；缺其中任何一样，通常要多跑一到两轮。

## 常见问题

**Q：找客服要先注册或登录吗？**
A：都不需要。微信、QQ、邮箱直接联系；工单也是免注册免登录，填完就提交，立刻给单号。

**Q：微信和工单到底该选哪个？**
A：只问一句、整批中断、问改价开票，走即时消息；要贴图、分几轮排查、换设备查进度、隔天补线索，走工单。急事可以两条一起用，先压住影响面再补一单留痕。

**Q：换台电脑，「我的工单」是空的，单丢了吗？**
A：没丢，列表只认当前浏览器。走「凭单号查」，填单号加联系方式后 4 位就能调回来。

**Q：想补一句会不会变成新单？**
A：不会。在原工单里点追加说明即可，补充后状态回到待处理并触发提醒，后台看到的是同一单的延续。

**Q：客服回复能带图片吗？我贴的凭据会一直留着吗？**
A：检测结果与处理建议都支持文字加图片，图片跟对应分块一起显示。凭据只走线路信息栏，回复后该栏自动清除。

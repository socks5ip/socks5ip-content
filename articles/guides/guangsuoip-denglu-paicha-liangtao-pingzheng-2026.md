## 二、两套凭证分别管什么

这一节是整篇文章的重点。光梭IP 后台里跟「密码」有关的凭证不止一个，混用之后的报错方向刚好相反：

| 凭证 | 从哪来 | 用在哪 | 混用后的表现 |
|---|---|---|---|
| 登录密码 | 注册时自己设置（建议 8 位以上、含大小写与数字） | 登录官网后台 | 拿提取密码去登 → 后台提示「账号或密码错误」 |
| 提取账号 / 密码 | 后台勾选已购 IP 后「复制/导出」得到的串，形如 `IP:端口｜账号｜密码` | 填进老鱼加速器等代理工具、或软路由的拨号配置 | 拿登录密码去填 → 工具报认证失败，看着像账号坏了 |

判断顺序很简单：**进不去后台 → 查登录密码；后台能进、工具连不上 → 查提取信息**。这两条线索不会同时成立，所以症状本身就把答案给出来了一半。

导出的串不要手打。端口、竖线、大小写任意一个字符错了，报错通常只写「认证失败」，看不出是哪一位出的问题；回后台重新导一次、整体覆盖粘贴，比逐字核对快得多。

## 三、进后台之后先认三个位置

光梭IP 后台是左侧菜单式布局，第一次登录不必逐项点开，跟登录这条线关系最紧的只有三处：

| 菜单位置 | 用来干什么 | 什么时候动它 |
|---|---|---|
| IP 续费 / 更换 | 勾选已购 IP 后「复制/导出」；更换地区、分组管理、续费也都在这里 | 买完 IP 第一次导出时 |
| 导出格式选项 | 常规地址（切换后立即生效，需重新导出）／ 固定域名（切换无需重导，生效略有延迟） | IP 切换频繁时改选固定域名 |
| 实名认证入口 | 平台对接实名系统、不保存用户信息；认证后按 F5 刷新页面 | 下单之前必须完成 |

这里有一个容易卡住的顺序问题：**先实名、再购买**。实名刚做完但页面没刷新就点购买，按钮可能没有反馈——这不是账号异常，按 F5 重载一次就恢复。导出格式的选择也常被忽略：选「常规地址」每次切换 IP 都要回后台重新导出覆盖，选「固定域名」则不用，切换后 2–5 分钟自动生效，切换频繁的场景后者省事得多。

## 四、按顺序往下试：七种现象对应七处

把现象归成几类之后，排查是有固定顺序的——先确认域名，再确认账号状态，然后是实名与本地环境：

| 现象 | 先查这里 | 怎么处置 |
|---|---|---|
| 打开官网只看到登录框，进不去后台 | 账号状态 | 当前是未登录或登录态过期，输入登录密码即可，不是入口出错 |
| 提示账号或密码错误 | 密码类型 | 确认输的是官网登录密码，不是导出信息里的提取密码；换无痕窗口手敲一遍，避开浏览器自动填充的旧记录 |
| 能登录，但点购买没反应 | 实名状态 | 完成实名认证后按 F5 刷新页面，再走正常下单流程 |
| 页面一直转圈、加载不出来 | 本地环境 | 换无痕窗口或换浏览器；再不行换网络（手机热点）试，排除本机缓存与插件拦截 |
| 短信验证码收不到 | 手机号与频次 | 确认是不是注册时那个号；查短信拦截箱；仍收不到就隔一段时间再试，具体限制以后台提示为准 |
| 后台正常，代理工具连不上 | 提取信息 | 回后台重新导出 TXT，整体复制粘贴覆盖工具里的旧线路 |
| 提示账号异常被限制 | 登录环境 | 先重设密码，再单独使用；多地共用同一账号是这类判定的主要来源 |

把这张表倒过来读，能看出一条规律：**登录环节的卡点几乎都落在密码类型、实名、本地缓存这三处，很少真出在平台侧**。所以不用一上来就找客服，先把这三处确认掉。

## 八、常见问题

**Q：光梭IP 的登录入口到底是哪个网址？直接搜官网能进吗？**
入口就是官网 `www.guangsuoip.com`，登录和注册都在这个域名下，搜官网打开也能正常登录。但要拿 8 折渠道价，新用户得走带邀请码 adminA8 的专属注册链接，从官网直接注册是原价。

**Q：后台能登进去，代理工具却提示认证失败，是账号被限制了吗？**
多数不是。后台登录用的是自己设的登录密码，工具里要填的是导出串里的「IP:端口｜账号｜密码」，两套凭证不通用。回后台重新导出一次，整体复制粘贴覆盖工具里的旧线路即可。

**Q：登录进去点购买没反应，是账号出问题了吗？**
先看实名认证是否完成。光梭IP 接入实名系统，认证完成后需要按 F5 刷新页面才能正常下单，页面没刷新时购买按钮可能没有反馈，这不属于账号异常。

**Q：切换 IP 之后需要重新登录吗？**
不需要，账号登录态不受切换影响，切换本身在后台「IP 续费/更换」里操作。区别在导出格式：选「常规地址」切换后要重新导出覆盖；选「固定域名」不用重导，切换后 2–5 分钟自动生效。

**Q：每天 5 条免费测试怎么用，要先充值吗？**
不用先充值。注册并完成实名后在平台内领取，验证 IP 类型、延迟与稳定性之后再决定买哪档。测试资格每天 5 条、次日重置，适合用来对 1.5M 与 6M 两档做一次实测对比。

**Q：一个手机号能在官方渠道注册两次拿两次 8 折吗？**
不行，一个手机号只能注册一个账号，渠道价会跟着账号走。如果之前已经在官网按原价买过，最省事的做法是联系客服说明情况，而不是另开账号——多账号反而会让后续的实名与售后对不上。

# 大白加速器连不上怎么查：五段链路挨个对号

打开客户端，导入列表里那条节点还在，一次检测却只回一行超时。这不是节点坏了——大白加速器的链路是**导入、节点、授权、本机网络、出口**五段串起来的，**任何一段断掉，表现都不一样**，按顺序往下查，多数情况停在前两段就能定位。这条线路的国内起步价在 **2.6 元/月**上下，真出问题时单据还在，不必急着删节点重装。

## 表现先归到五段里去

「连不上」是五种故障共用的一个说法，先看手机上出现的是哪一种，再决定查哪一段，比反复点「检测所有」有效得多。

| 手机上看到的 | 断在哪一段 | 先去动哪里 |
|---|---|---|
| 列表里根本没有这条节点 | 导入段 | 重新整段粘贴，核对导入条数 |
| 节点在，检测一行红或超时 | 节点段 | 拿这条线单独做一次线路检测 |
| 点启动没有任何系统提示 | 授权段 | 找回被拒绝的那次授权弹窗 |
| 提示已连接，但所有 App 都打不开 | 本机网络段 | 查手机自身这条链路 |
| 显示已连接，出口 IP 没变 | 出口段 | 用检测页核对落地地址 |

## 第一段：这条节点有没有真的进列表

粘贴进来的是一整段文本，只要换行或分隔符被改动，客户端就可能只吃进去一部分。**导入完成后要对着客户端给出的条数核一次**，条数对不上，后面所有检测都是白测。这一步常见的是「列表里只躺了两三条」，而不是一条也没有。

## 第二段：检测那一栏在说什么

| 检测结果 | 含义 | 处理 |
|---|---|---|
| 有延迟数值 | 这条线可以连通 | 保留，继续用 |
| 显示超时 | 本次没连上 | 复测一次，仍超时再剔除 |
| 显示 0ms | 这次没真正测到往返 | 不要当「最快」，直接复测 |

检测的作用是筛掉不可用的条目，不是给线路排名。0ms 尤其容易误读——它往往代表探测本身没走通。

## 第三段：被点掉的那个授权框

安卓客户端建本地通道时，系统会要一次授权。这个提示如果被顺手拒绝，客户端界面照样显示正常，但流量根本没被接管。**去系统的应用权限里看这条授权还在不在**，比在 App 里反复点启动有用。多个同类客户端同时开着，也容易出现互相顶掉的情况，同一时刻只留一个。

## 第四段：手机自己这条链路通不通

把客户端先断开，用同一台手机的浏览器打开任意页面。如果断开后也打不开，问题不在客户端，在手机当前的网络：数据流量与无线是否切换过、是否连了一个需要额外认证的热点、是否开了省电模式把后台限制掉了。这一段是唯一与节点无关的排查。

## 第五段：显示已连接，出口却没换

这是最容易误判成「连上了」的一种。状态变化只说明通道在建立，不代表流量走了对的路。**验收动作只有一条：查一次出口地址**，用 [IP 综合检测中心](https://socks5ip.com.cn/ip-check-center/) 看落地地址有没有变成节点所在的那个。查出来还是本地地址，就说明接管没生效，回第三段复查授权，或者换一条节点复测。

## 一分钟速查

| 顺序 | 一句话判断 |
|---|---|
| 1 | 列表里有这条节点吗（条数对不对） |
| 2 | 这条线单独测，能不能出延迟 |
| 3 | 系统授权在不在，有没有第二个客户端在抢 |
| 4 | 断开客户端，手机自己能上网吗 |
| 5 | 检测页里的出口地址换了没有 |

## 常见问题

**Q：检测全是超时，是不是节点被封了？**
先复测。单次超时可能只是探测没走通，连续两三次都超时才值得换线。换之前看一眼这条线在别的客户端里能不能通，能通就说明问题不在节点。

**Q：为什么断开客户端以后，手机反而上不了网？**
多半是开了网络锁这类开关。它的设计是「代理不可用就断流量」，属于宁可断也不漏的选择，挂机类用途一般不开。

**Q：两个同类客户端一起开会有影响吗？**
会。同一时刻只应该有一个在接管出口，两个同时开着容易出现启停互相顶掉，表现就是「一会儿通一会儿不通」。

**Q：显示已连接但网页打不开，最该先看哪里？**
先看出口地址变没变。地址没变说明接管没生效，属于第三段的问题；地址变了但网页仍打不开，回到第四段查手机自身网络。

**Q：节点一个月 2.6 元起，便宜的线路是不是更容易断？**
价格高低主要对应带宽与线路类型，不直接等于稳定性。真要比较，用同一条测试节点连跑十分钟以上看会不会掉，比看标价靠谱。

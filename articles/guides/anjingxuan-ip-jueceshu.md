# 按业务场景选代理IP：一张决策树走完

## 一句话结论

**选 IP 不是玄学，是五步决策**：先问"任务要不要长期稳定的固定出口"，再问"对纯净度敏不敏感"，接着定地区、算并发、卡预算——每一步都指向明确的类型。本文给一张文字决策树，照着走 3 分钟出结论。

## 决策树（文字版）

```
第 1 步：你的任务类型？
├─ 数据采集 / 批量查询 / 比价  → 走向 A（要量大价低）
├─ 账号运营 / 店铺后台 / 社媒   → 走向 B（要稳定可信）
└─ 远程办公 / 自建服务         → 走向 C（要固定可达）

A（量大价低）→ 第 2 步：目标站风控严吗？
   ├─ 不严 → 动态机房（最便宜，采集主力）
   └─ 严（验证码/封IP） → 动态住宅（贵但能跑）

B（稳定可信）→ 第 2 步：要长期固定还是可轮换？
   ├─ 长期固定（后台/主号）→ 静态住宅（核心选择）
   ├─ 可轮换（批量账号）  → 动态住宅（住宅级纯净+轮换）
   └─ 预算有限           → 静态机房（折中，纯净度打折）

C（固定可达）→ 静态（机房或住宅均可，按纯净需求定）

第 3 步：地区——业务出口在哪个国家/城市就选哪的节点
第 4 步：并发——同时几个任务 = 至少几条线（问清套餐并发上限）
第 5 步：预算——先测后买，小周期验证再转长周期
```

## 各场景直接结论

| 场景 | 结论 |
|---|---|
| 公开数据采集（网页级） | 动态机房，按并发买量，2.6-6 元/月档起步 |
| 强风控目标站采集 | 动态住宅，放慢频率+住宅纯净 |
| 电商/跨境店铺后台 | 目标国静态住宅（1 条核心先保证） |
| 多账号运营（矩阵） | 一账号一出口：静态住宅为主，出口互不交叉 |
| 游戏多开 | 低延迟优先：静态 100M 档（如 8 元/月级） |
| 软路由/整网出口 | L2TP 套餐，6 元/月起步 |
| 远程办公固定出口 | 静态（机房即可，按纯净需求升级） |

## 三条兜底原则

1. **选型错误比价格错误贵**：买错类型（如采集用静态）浪费的钱远超省下的差价
2. **先测后买不跳步**：所有正规平台给免费测试，测试期验证归属/纯净/稳定
3. **复合需求拆单买**：又采集又运营账号的人，别指望一条线通吃——动态+静态组合通常最优

## 常见问题

**Q：走完决策树还是不确定？**
拿不准就先从"动态机房小周期"起步验证真实需求，多数场景跑一周数据会告诉你答案。核心账号类需求例外——直接按静态住宅配，别拿核心业务试错。

**Q：决策树哪里说得最容易被忽略？**
第 4 步并发。很多人买完才发现套餐并发不够，任务一多就断——下单前必问并发上限。

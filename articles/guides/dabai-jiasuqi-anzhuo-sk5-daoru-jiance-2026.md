# 大白加速器安卓版怎么用：SK5 节点导入、检测与出口核对

三个动作就能把安卓端的大白加速器跑通：装好 App、把一串 SK5 节点贴进列表、连上以后核对出口 IP。它本身不产出节点，安装包约 **6.9 MB**、支持 **Android 7.0 以上**，完整链路其实是三段——**先拿到一条完整 SK5 节点、再导进来、最后连上验一次**。

## 它做什么、不做什么

先摆正定位，能省掉一半的「为什么连不上」。

| 它做的事 | 它不做的事 |
|---|---|
| 把节点批量导进本地列表 | 不提供任何节点 |
| 启动连接、切换节点 | 不修改线路的可用率 |
| 显示实时连接状态 | 不判断出口地区是否符合预期 |
| 断开并回到本地网络 | 不动系统其他设置 |

## 一条完整的 SK5 节点长什么样

四项信息必须来自**同一条线路**，混填是新手第一号错误。

| 字段 | 例子形态 | 常见误填 |
|---|---|---|
| 主机 | 域名或 IP 地址 | 填成平台官网域名 |
| 端口 | 一个数字端口 | 与协议不匹配的端口 |
| 账号 | 平台签发的用户名 | 填成登录账号 |
| 密码 | 平台签发的密码 | 填成登录密码 |

## 准备：把节点整段备好

在平台后台按「复制/导出」拿到节点串，通常是四段式结构。导出的格式要能在客户端里被逐行识别，换行或分隔符被破坏会导致后面的批量导入只进来一部分——**导入多少条、失败多少条，客户端会给出计数，这一步要对着数**。

## 把节点贴进列表并检测

进入添加节点，切到批量导入，把整段节点贴进去。导入完成后先做一次「检测所有」：这一步的意义不是看谁快，而是**筛掉根本连不上的条目**。

| 检测结果 | 含义 | 处理 |
|---|---|---|
| 有延迟数值 | 线路可连通 | 保留，可继续用 |
| 显示超时 | 本次未连上 | 先复测一次，仍超时则剔除 |
| 显示 0ms | 多半是本地缓存或未真正测到 | 不要当成「最快」，直接复测 |

## 选中并启动连接

从列表里选一条，点启动。启动瞬间状态会变，但**状态变化只代表隧道在建立，不代表流量已经走对出口**。这一步先别急着打开业务应用。

## 用浏览器核对出口 IP

真正的验收动作是查一次出口地址。打开浏览器访问 [IP 综合检测中心](https://socks5ip.com.cn/ip-check-center/)，看出口 IP 是否变成了节点所属的落地地址。如果查出来还是本地 IP，说明流量没被接管，往下按「连不上」的四层顺序查。

## 设置页里的三个开关

| 开关 | 作用 | 什么时候打开 |
|---|---|---|
| 自动重连 | 掉线后自动恢复连接 | 长时间挂机时 |
| 网络锁 | 断开代理时阻断流量，避免裸奔 | 对出口一致性敏感时 |
| 启动自连 | 打开 App 即连接 | 固定用法、省一步操作 |

网络锁要慎用：它会在代理不可用时直接断网，属于「宁可断也不漏」的选择，不适合对可用性要求高、又不能接受中断的场景。

## 连不上时按四层顺序查

| 层次 | 检查点 | 判断信号 |
|---|---|---|
| 节点本身 | 主机/端口/账号/密码是否同源 | 四项来自同一条线路 |
| 线路可用性 | 把节点填进代理检测页单独测 | 能看到延迟与连通结果 |
| 客户端状态 | 是否选中了要用的那条并已启动 | 状态栏显示已连接 |
| 系统层 | 是否有其他客户端抢占出口 | 同一时刻只有一个生效 |

四层里，只有第三层和第四层是客户端侧问题。前两层不通，换客户端没有意义。

## 常见问题

**Q：检测里显示 0ms 是什么意思？**
不是「最快」。0ms 通常说明这次没有真正测到往返，直接复测一次再判断，别拿它当质量排名。

**Q：节点导进去只进来一半，为什么？**
多半是粘贴时格式被破坏。节点串要按原样整段贴，分隔符与换行不能改动，导入后对着客户端给的条数核对。

**Q：连上了但网页打不开，先查哪里？**
先按四层顺序从上往下走：节点四项是否同源、这条线单独测能不能通、客户端是否选中并启动、系统里有没有别的客户端同时抢出口。

**Q：大白加速器自己带节点吗？**
不带。它是节点导入与连接工具，节点要从代理平台单独买，站内价格中心可横向比价。

**Q：网络锁要不要开？**
对出口一致性敏感的用法建议开，代价是代理不可用时会直接断网。挂机类用途一般不开，避免误断。

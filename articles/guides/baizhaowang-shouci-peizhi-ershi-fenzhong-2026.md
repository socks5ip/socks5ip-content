# 百兆王装完客户端那 20 分钟：五个动作的顺序与三个卡点

客户端点开，进度条走到 90% 停住不动，多数人会去点第二次刷新——而这一步恰恰是错的：**重复刷新会让节点列表和服务端会话对不上，后面绑定窗口时全部失效**。装完客户端只是第 0 步，真正的活在后头。

**一句话结论：装完客户端只是第 0 步，真正决定能不能干活的是随后 20 分钟的五个动作，顺序错了就要重来。**

## 20 分钟的排程表

| 时间 | 动作 | 通过标准 |
|---|---|---|
| 0–3 分钟 | 用带邀请码的链接登录，确认套餐与到期日 | 后台能看到剩余天数与产品线 |
| 3–6 分钟 | 刷新节点列表，等它自然走完 | 列表出现编号、延迟有数值 |
| 6–10 分钟 | 按用途建分组（一组一个用途） | 分组里有节点，命名能看懂 |
| 10–16 分钟 | 绑定窗口：一个窗口填一个节点编号 | 每个窗口的编号互不重复 |
| 16–20 分钟 | 验出口：逐个窗口查一次 IP | 出口与所填编号一致 |

五步里第 2 步和第 4 步最容易返工，原因都在「等不及」。

## 进度条卡在 90%：先看这三处

1. **后台套餐还没生效**：付款后有一小段同步时间，此时刷新会一直转；
2. **本机网络本身不稳**：节点列表要访问服务端，本地断一下就会卡住；
3. **重复点击刷新**：第一次请求还没回，第二次又发出去，列表状态被打乱。

处理方式统一：**关掉客户端、等 30 秒、重开一次**。三次之后仍卡，再去后台看套餐状态，不要在客户端里反复点。

## 绑定窗口靠填编号，不靠点选

百兆王的窗口绑定是「填编号」这一种形态：每个窗口填一个节点编号，编号互不重复。**页面上的按钮只负责提交，选哪个由你填的数字决定。**

这一步的常见错误是「两个窗口填了同一个编号」——现象是两个窗口出口一样，很容易被误判成「代理没生效」。真要确认，把窗口的出口 IP 与编号对应的节点 IP 逐个比对一次。

## 分组在第一天就建好

分组不是装饰。它决定你后面换 IP 时是「一个个改」还是「一次换一组」。

- **按用途分组**：一个用途一组，组内节点可以随时换；
- **按窗口分组**：窗口多的时候更好管，换组即换一整批出口；
- **按剩余天数分组**：快过期的节点放一组，到期前集中处理。

三种都可以，关键是**第一天就定下来**。等窗口涨到二十个再回头整理，成本要高好几倍。

## 已连接不等于能用

客户端显示「已连接」，只证明本地进程起来了。**真正的判据是出口 IP**：打开检测页，看 IP 与归属地是不是你填的那个编号对应的节点。

三个动作验完才算通过：

| 验收项 | 动作 | 通过标准 |
|---|---|---|
| 出口正确 | 每个窗口各查一次 IP | 与所填编号一致 |
| 分流正确 | 开一个不该走代理的程序 | 出口保持本机地址 |
| 可干活 | 访问一次真实目标站 | 正常返回，不是拦截页 |

第二格里出问题，说明接管范围设错了，而不是线路坏了。

## 首日最容易白做的四件事

1. **裸域名注册**：不带邀请码的入口会落到登录页，走一遍发现开不了号；
2. **先装客户端再注册**：客户端要登录态，顺序反了只能重装一次；
3. **产品线选错**：电脑代理、手机代理、SK5 导出是三条线，买错要重新下单；
4. **不建分组直接开工**：窗口一多，换 IP 就成了体力活。

这四件事的共同点是**都能在十分钟内避免，却要花一小时返工**。

## 常见问题

**问：刷新节点列表一直转圈，是不是账号有问题？**
先排除本机网络：换一个网页能不能打开。能打开却刷不出节点，就去后台看套餐是否已生效；付费后短时间内刷新失败属于正常同步延迟。

**问：两个窗口能填同一个节点编号吗？**
技术上能，但没有任何意义——两个窗口会共用同一个出口，等于没做一机一 IP。要分开就填不同编号。

**问：稳定模式和高速模式怎么选？**
看你要不要换 IP 后重新导入。稳定模式换 IP 后配置不变，高速模式换完要重导一次。要长时间挂着不动选稳定，要频繁换出口选高速。

**问：客户端显示已连接，为什么目标站还是打不开？**
先查出口 IP 是否正确。出口对了还打不开，再看目标站是否对该地区有限制——这类问题不在客户端里。

**问：档位买低了会有什么表现？**
不是报错，而是「能用但不够用」：窗口一多就排队，速度掉下去。站内价格页把 5 元、7 元、10 元三档的差别列得很清楚，按窗口数和并发选，别按单价选。

**问：分组建错了要重来吗？**
不用。分组可以改名和重新指派，节点不用重新买。只有窗口绑定写错编号才需要逐个改。

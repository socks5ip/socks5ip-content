# IP 体检报告怎么读？

要么信那个 7 分直接开干，要么因为「适用场景推荐」写着「谨慎」就把线退掉——这两种读法都会错，因为 7 分和「谨慎」说的根本不是同一件事。

站内 IP 质量检测中心出的一页报告，由**六项数据和一条结论**组成。免费、不注册、不限次数，跑一次几秒钟。麻烦的地方在于六项里只有一项是结论，其余五项都是原料。

## 判读起点：先找结论那一行

大多数人从分数往下读，正确的顺序是从结论往回读。下表是本文建议的五步顺序，与报告页面的排列顺序相反。

| 顺序 | 看哪一行 | 它回答的问题 | 不合格时 |
|---|---|---|---|
| 第 1 步 | 适用场景推荐 | 这一栏有没有你要做的事 | 直接换线，后面不用看 |
| 第 2 步 | IP 类型（住宅/机房/移动） | 这段地址分给了谁 | 机房段跑账号类业务要降级使用 |
| 第 3 步 | 原生 / 广播 | 注册国与所在地是否一致 | 不一致时跨境业务的风控分会被拉低 |
| 第 4 步 | ASN 所有者 | 谁持有这段地址 | 用来判断同段邻居的整体水平 |
| 第 5 步 | 风控值 | 公开渠道有没有这条 IP 的问题记录 | 只在这一步失败，通常换个段就能解决 |

第一行是硬门槛：**国内 IP 去跑海外平台，会被直接标成「不推荐」，不给中间档。** 不是分数不够，是位置不对——IP 在天津、业务要落在洛杉矶，风控值再低也没有意义。

## 7 分说的是「没案底」，不是「能用」

风控值不是某家风控公司卖的付费评分，而是把 ipapi.is、ip-api、ipwhois 三家的公开信号（滥用记录、代理与匿名网络标记、机房标识、企业专线、移动网络、广播段特征等）汇总后给出的一个数。分数低，只说明**公开渠道查不到这条 IP 的问题记录**。

| 风控值区间 | 档位 | 你该做什么 |
|---|---|---|
| 0-15 | 极度纯净 | 可上账号类业务，仍建议小量跑一轮 |
| 15-25 | 纯净 | 常规业务可用 |
| 25-40 | 中性 | 可用于浏览、比价，敏感操作前先测行为 |
| 40-50 | 轻微风险 | 只做一次性、低风险动作 |
| 50-70 | 稍高风险 | 换段优先于调设置 |
| 70 以上 | 极度风险 | 别用，换线比修它划算 |

这里有个常被忽略的机制：**风控值低有时是「没信号」而不是「很干净」**。新分配、少人使用的段，公开库里本来就没有记录，分数自然低；这恰恰是它最不可靠的时候——真正的风险要等你用它跑业务才会暴露。

## 四种互相打架的组合怎么裁决

| 组合 | 报告长什么样 | 怎么判 |
|---|---|---|
| 低分 + 场景「不推荐」 | 风控值 7，场景栏写不推荐 | 信场景栏。位置或类型不对，分数再低也没用 |
| 低分 + 机房类型 | 风控值 10，IP 类型标机房 | 浏览类业务可用，账号类业务降级使用 |
| 高分 + 住宅 + 原生 | 风控值 55，出身看着很好 | 大概率是同段邻居的历史拖累，换段而不是换平台 |
| 低分 + 广播 | 风控值 12，原生/广播标广播 | 跨境业务要谨慎：注册国与所在地不一致会被单独核 |

裁决原则只有一条：**场景推荐 > 出身 > 分数**。场景栏是综合判断，分数是单一维度的观察值，两者冲突时永远信前者。

## 7 分和「谨慎」同时出现，先信「谨慎」

这是本文开头那个两难的正面回答。场景栏写「谨慎」，意味着它已经把 IP 所在地、原生/广播、住宅/机房、风控值、运营商类型放在一起对过一遍，判定这条线只适合一次性、低风险的动作。**7 分只是它参考的其中一项，且是最容易被「没信号」骗的那一项。**

具体怎么动，取决于你要做的事：

| 你要做的事 | 场景栏「谨慎」时的处置 |
|---|---|
| 一次性查数据、比价 | 可以用，别登录账号 |
| 养号、长期登录 | 换线，别在这条线上花时间 |
| 支付、绑卡 | 直接换，成本和风险不成比例 |
| 只是测速、看出口 | 无所谓，测完就走 |

## 必须重测的三个触发条件

报告是有时效的。同一个 IP，隔一段时间读数会变，触发重测的条件有三个。

| 触发条件 | 为什么 |
|---|---|
| 换了使用地或换了宽带 | 归属地与 ASN 判定会跟着变 |
| 目标平台换了 | 场景推荐是按平台类型给的，换平台等于换考题 |
| 距离上次检测超过两周 | 公开库的信号在持续更新，滥用记录会新增 |

**同一批线要横向比，必须在同一天、用同一个入口测完**，否则比出来的是时间差，不是质量差。

## 自测口径：三步

| 动作 | 怎么做 | 合格线 |
|---|---|---|
| 跑一次体检 | 打开 IP 质量检测，看场景推荐那一栏 | 场景栏包含你要做的事 |
| 查同段邻居 | 同一条线换 3 个出口各测一次 | 三条线的分数不要一条极低、两条偏高 |
| 业务侧复测 | 用这条线登录目标平台，看是否弹验证 | 连续 3 次不弹验证才算过 |

第三步才是真正的验收。体检报告能给的是「段干净」，给不了「你不会被认出来」——后者取决于 TLS 指纹、时区语言、登录节奏，这些与 IP 无关。

## 常见问题

**问：风控值 7 分，是不是可以直接上号？**
不一定。7 分只说明公开库查不到问题记录，还要看场景推荐那一栏有没有你要做的事。场景栏写「谨慎」时，7 分不能翻案。

**问：为什么同一条线，上午测 7 分下午测 20 分？**
公开库的信号在实时更新，同段邻居的行为也会影响判定。差几个点在正常波动内，跨档（比如从 15 以内跳到 25 以上）才值得重测一次。

**问：IP 类型写「住宅」就安全吗？**
住宅只说明这段地址分给了家庭宽带，不说明这条线干净、也不说明目标平台认它。宿主机房的段也可能被标成住宅，要看原生/广播那一行。

**问：国内 IP 检测出来场景是「不推荐」，能强行用吗？**
技术上能连，业务上不建议。场景栏对国内 IP 跑海外平台是直接判不可用的，因为它核的是属地匹配，不是线路质量。

**问：分享体检报告截图要注意什么？**
报告会带出口地址。分享前把 IP 的后两段打掉；固定 IP 的长效业务，建议连 ASN 一起模糊——同一 ASN 加前两段加城市，已经足够定位到一条具体线路。

**问：测出来分数很高，是该换线还是换平台？**
先看同段其他地址。如果整个 ASN 下大批地址都高，是段的问题，找平台换段；只有你这一条高，那是被前一个用户用烂了，换一条即可。

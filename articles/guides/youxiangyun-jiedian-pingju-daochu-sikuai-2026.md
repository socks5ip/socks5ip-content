# 两套东西都叫账号密码

最容易踩的坑不是忘密码，而是把节点那一串账号当成了后台登录名——优享云的「账号密码」有两个版本，一套给人和后台，一套给代理工具，填错一件就是认证失败。月卡 6 元、周卡 3.5 元、天卡 2 元，这三档价格标的都是**一条节点**，而每条节点在后台导出的文本里都会带出**四段独立信息**：节点地址、端口、账号、密码。这四段和你的登录账号毫无关系。

## 一、两套凭据的分工，一张表说清

| 对比项 | 后台账号（给人和后台） | 节点凭据（给代理工具） |
|---|---|---|
| 谁发给你 | 注册时自己设置，绑定手机号或邮箱 | 下单后由后台生成，一个节点一组 |
| 长什么样 | 手机号 / 邮箱 + 自设密码 | 四段：节点地址、端口、账号、密码 |
| 什么时候用 | 登录后台做实名、充值、下单、续费 | 填进老鱼加速器、SSTap 等支持 SOCKS5 的工具 |
| 填在哪里 | 官网首页的登录入口 | 代理工具的连接信息栏，不碰官网登录框 |
| 弄混的后果 | 拿节点信息去登官网，永远登不上 | 拿后台账号密码填工具，直接认证失败 |

记一句就够：**要在浏览器里打开官网、点按钮的，用后台账号；要填进软件让它连网的，用节点四段信息。** 前者出错通常是「密码记不住」，后者出错通常是「照抄少了字符」。

## 二、四位凭据的出处：从节点管理到导出文本

后台左侧的节点管理里勾选已购节点，点批量导出并选择 SK5 协议，下载下来的文本就是那四列。优享云的产品说明把这件事叫「四位一体验证」——四段必须同时对上，缺一个字符就是连不上。

| 四段信息 | 导出文本里的位置 | 最容易出的岔子 |
|---|---|---|
| 节点地址 | 第一列 | 把它当成官网域名，或手动补了个 `http://` |
| 端口 | 第二列 | 复制时带进空格，工具不报错但连不上 |
| 账号 | 第三列，节点级 | 误填成后台登录名（最常见的错） |
| 密码 | 第四列，节点级 | 大小写被输入法自动改了首字母 |

导出之后不要手打。文本里的字符看起来都眼熟，但节点密码里常混大小写与数字，手抄四个字段等于给自己加了一道随机错误。

## 三、后台五个菜单，各自管什么

| 后台菜单 | 作用 | 什么时候点它 |
|---|---|---|
| 费用中心 | 充值与余额、订单金额 | 第一次购买前，或余额不足时 |
| 购买节点 | 选项目、地区、数量、时长 | 新增节点；没有完全对应的项目就选类型相近的 |
| 节点管理 | 列出已有节点，勾选后批量导出 SK5 | 拿节点信息、准备配置工具时 |
| 导入续费 / 更换 | 粘贴原节点做匹配，批量续费或换 IP | 节点到期前，或某条线路表现变差时 |
| 节点更换记录 | 记录每次更换的结果 | 换完后回头导出新的一批 |

## 四、两处会直接影响连接结果的细节

**线路要跟着本地宽带走。** 电信宽带选电信线路、联通选联通、移动选移动。跨网不是连不上，是延迟会明显变高。选错地区或线路不用重新买，在「导入续费 / 更换」里粘贴原节点信息、点账号匹配，再选全局过滤或指定资源过滤，就能免费换一批。

**后台账号那一关还有一道硬门槛。** 完成支付宝人脸实名之后，购买按钮才会解锁；而同一个证件只能实名一个账号。所以团队作业的正确姿势是「账号一个、节点多条」，按项目数买节点，而不是每人注册一个小号。

## 五、报错的定位路径：先看现象，再动密码

| 现象 | 更可能的原因 | 先做什么 |
|---|---|---|
| 后台登录提示密码错误 | 用注册手机号登的，但密码记成了别处那一套 | 走官网登录页的找回流程，拿不到重置信息就找客服 |
| 登录进去按钮是灰的 | 人脸实名没过或被驳回 | 回实名入口重做，通常一两分钟出结果 |
| 工具里填完连不上 | 把后台账号当节点账号填了 | 回节点管理重新导出 SK5，四段一起复制 |
| 昨天能用今天连不上 | 套餐到期，或节点被同项目流量挤占 | 先在费用中心看有效期，再考虑批量更换 |
| 换了一批 IP 仍然慢 | 线路与本地宽带不是同一家运营商 | 按本地宽带的运营商重选线路 |

## 六、自测口径：拿到节点先过三关

不要只看客户端那个延迟数字。**握手成功只证明端口通了**，要算「这条节点能用」，还得再看出口归属是否与选购时说的地区一致，最后跑一次业务模拟看会不会弹验证码。三关顺序不能颠倒：握手不过，后两步都是白测；出口对不上，说明导入的不是平台承诺的那种线路。

后台下单弹窗里还有「申请测试 2 小时」的选项，走的是与正式节点同一条链路，适合用来排除「路径错、填错、线路选错」这三类低级问题，但它验不了跨天波动和晚高峰表现。

## 常见问题

**Q：优享云后台用什么账号登录？**
注册时填的手机号或邮箱，加你自己设置的密码。这个账号只用于登录官网后台，跟节点的四段信息完全无关。

**Q：登录后为什么点不动「购买节点」？**
绝大多数情况是实名没过。平台要求先完成人脸实名认证才能购买和使用节点服务，认证走支付宝人脸核身，结果以官方接口返回为准。

**Q：导出文本里的「账号」是我的登录账号吗？**
不是。那是节点级的独立账号，一个节点一组，只填进代理工具用。把它和后台登录名混着填，是最常见的认证失败原因。

**Q：工具里填了四段信息还是连不上，先查什么？**
按「地址 → 端口 → 账号 → 密码」的顺序逐个核对有没有多余空格或漏字符，再确认线路与本地宽带是不是同一家运营商。四段里任何一段抄错，表现都是同一种连接失败。

**Q：换电脑或换手机之后要重新登录吗？**
后台登录状态跟着浏览器走，换设备需要重新登录；节点凭据不受影响，工具里填的还是那四段信息，重新粘贴即可。

**Q：可以多注册几个账号分别买节点吗？**
不行。平台执行一人一账号，同一个人不能实名多个账号。要多条节点就在一个账号里按项目数量购买。

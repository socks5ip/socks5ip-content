# 老鱼安卓版五类问题排开：只有不到一半出在软件上

5 类反馈排开，真正出在软件上的不到一半——剩下的来自线路本身、系统权限和后台省电策略。

**老鱼安卓版只是一个把代理线路导入手机的客户端，它负责转发流量，不负责生成线路。** 所以遇到「看着连上了其实没生效」，先按现象分类，比反复重装有效得多。它本身不收费，配套线路在价格中心 2.24 元/条起。

## 一句话结论

| 现象 | 先查什么 | 大概率的责任方 |
|---|---|---|
| 开关转圈后失败 | 线路是否可用、账号是否填错 | 线路 / 配置 |
| 装不上或一开就闪退 | 系统版本与安装包来源 | 软件 / 系统 |
| 连上几分钟就掉 | 后台省电策略与网络切换 | 系统 |
| 网页能开、个别应用连不上 | 该应用是否被分流规则排除 | 配置 |
| 速度忽快忽慢 | 同时段换一条线路复测 | 线路 |

## 转圈之后报失败，先分离线路与配置

先分离「线路问题」和「配置问题」。在别的客户端上导入同一条线路，能通就是配置写错，不通就是线路本身。

| 检查点 | 怎么看 | 结论 |
|---|---|---|
| 服务器地址 | 与后台给的地址逐字符对比 | 不一致 ⇒ 配置问题 |
| 端口与账号 | 是否用了官网登录账号 | 用了登录账号 ⇒ 认证必失败 |
| 线路是否到期 | 后台看剩余时长与流量 | 已耗尽 ⇒ 换线或续费 |

## 装不上或一打开就闪退，多半不在软件本身

安装环节的问题通常与软件无关，而是系统版本或安装包来源。

| 检查点 | 常见情况 |
|---|---|
| 系统版本 | 过低版本缺少需要的运行组件 |
| 安装包来源 | 非官方渠道的包可能被改动 |
| 已有版本冲突 | 旧版本未卸载干净导致覆盖失败 |

## 用一会儿就断，先怀疑后台回收

这类反馈里，系统侧的原因比软件侧更多。安卓的省电与后台限制会在息屏后回收连接，**表现是「用着好好的，锁屏再打开就断了」，与线路质量无关。**

| 检查点 | 动作 |
|---|---|
| 后台省电策略 | 把客户端加入不限制列表 |
| 网络切换 | 关闭自动切换移动数据 / 无线，避免切换时断连 |
| 息屏回收 | 确认是否只在锁屏后出现 |

## 个别应用不通与速度起伏，怎么分开看

| 现象 | 先做的一件事 | 判断 |
|---|---|---|
| 网页能开、个别应用连不上 | 换成整机转发再试该应用 | 整机能通 ⇒ 分流规则漏了它 |
| 速度忽快忽慢 | 同一时段换一条线路复测 | 换线即好 ⇒ 线路负载差异 |

## 不管落在哪一类，都先做这一步

不管落在哪一类，都建议先做同一件事：**连上之后打开 IP 综合检测中心看归属地。** 归属地变了说明出口已切换，可以继续查应用；归属地没变，说明流量根本没走这条线，前面的现象都只是表象。

## 常见问题

**老鱼安卓版装了、状态栏也亮了，为什么查出来还是本机 IP？**
状态栏图标只表示客户端在运行，不代表流量已经走进代理通道。打开 IP 综合检测中心看归属地，没变就说明转发没生效，回到配置里逐项核对。

**连不上一定是软件的问题吗？**
不是。连不上、装不上、频繁掉线这三类里，真正出在软件上的不到一半，其余多来自线路到期、账号填错、系统权限或省电回收。

**为什么只有某几个应用连不上？**
多半是分流规则没把它们包进去。把转发方式切成整机再试同一个应用，能通就说明问题在规则范围，不在线路。

**频繁掉线要不要重装？**
先查省电策略。把客户端加入系统的不限制后台列表，并关闭网络的自动切换，多数「用一会儿就断」会直接消失，重装解决不了策略层面的回收。

**老鱼安卓版自己提供 IP 吗？**
不提供。它只负责把线路导入手机并转发流量，线路需要从代理 IP 平台获取，价格中心可以先比价再选。

# 天行IP 在 Windows 填完不通：四种症状各卡在哪一步（2026）

打开「长效静态IP购买」，页面正常加载、节点也列得出来，唯独购买按钮是灰的——账号里还有余额，密码也没填错，可就是点不下去。这种「看着都正常、就是动不了」的状态，比报错更难查，因为它不在网络层，而在账号状态那一层。

**一句话结论：**天行IP 在 Windows 上的失败分四类，各自卡在完全不同的位置：**灰按钮卡实名**、**下拉没有你的项目卡人工补录**、**连上但网页打不开卡在导出格式与四段字段**、**目标站不放行卡在出口归属地**。六步流程里只有「填客户端」这一步跟网络有关，其余五步都在账号与订单里。最短验证路径是用自带的 **10 次测试卡**先跑一遍，别急着充月卡。

## 一、四种症状，四个位置

先照症状对号，别从头重装一遍。重装客户端能解决的只有最后一类。

| 症状 | 你在屏幕上看到什么 | 卡在哪一层 | 处理方向 |
|---|---|---|---|
| 买不了 | 能进购买页，按钮灰或点了没反应 | 账号状态 | 实名认证未完成 |
| 买不到想要的 | 下拉里没有我的游戏/项目 | 订单字段 | 找客服补一条 |
| 连不上 | 客户端显示已连接，网页打不开 | 凭据与格式 | 四段字段顺序、导出格式 |
| 连上也打不开目标站 | 出口对了，目标站给验证页 | 出口归属 | 换池子或换地区 |

四类里前三类与线路质量无关。把这三类排掉之后再谈「这条线好不好」，否则会一直以为买到了坏线。

## 二、灰按钮：不是没货，是实名没过

注册表单六项：用户名、密码、邮箱、QQ、手机号、短信验证码，推广号一栏填 **tianxingA0**。提交后进用户后台，接下来还有一步实名：用户后台 → 用户信息 → 我的信息 → 实名认证，填姓名与身份证号，点开始验证，扫脸。

不实名买不了节点，这不是可选项，是前置条件。判断方法很直接：**能进购买页但点下去没有购买入口，就是实名还没完成**，跟余额、跟库存都无关。

## 三、充值时那个二选一，充错了钱不会少但买不了

充值有两条路：找客服后台划转，或自助充值（金币信息 → 在线充值 → 自定义金额 → 选类型 → 确定）。类型那个二选一是关键——**长效静态与住宅家庭两类金币不互通**。

| 你想要的 | 该充哪一类 | 折后月价 | 原价 | 出身 |

## 四、下拉里没有你要的项目，不是页面没加载完

购买路径是：长效静态IP购买 → 购买节点 → 弹窗确定 → 选游戏 → 选地区 → 选数量 → 订单确认。中途那个「选游戏」的环节没有「其他」选项让你自己填，下拉里没有就是要人工补一条，找客服加。这一步在流程中间，最容易被当成页面卡了，于是反复刷新。

## 五、导出格式对不上，粘进去就是不通

后台按格式导出，常用三种：老鱼、万安、有米。导出的不是统一的一串，而是按各软件习惯整理好的结构。

| 你装的软件 | 导出选什么 | 填到哪里 |
|---|---|---|
| 老鱼 | 老鱼 | 导入列表，不用手工拆 |
| 万安 / 有米 | 万安 / 有米 | 对应软件的导入项 |
| Proxifier / SSTap 等通用 | 通用格式 | IP、端口、账号、密码四个框分开填 |

通用格式是四段用竖线隔开，形如 IP｜端口｜账号｜密码。四个框少填一个，或账号密码填反，表现都是「连不上」，但原因跟线路一点关系都没有。这一步做完再做生效验证：出口 IP 是不是节点那一串、城市对不对、目标站放不放行。

## 常见问题（FAQ）

### Q：天行IP 的 Windows 客户端在哪下载？

它不自带 Windows 客户端。Socks5 那一组必须配第三方软件——老鱼、万安、有米、SSTap、Proxifier 都行；L2TP 那两条线用 Windows 自带拨号，不需要任何软件。买的是线路凭据，不是一个能双击安装的程序。

### Q：充了钱为什么买不了节点？

两种可能。一是实名没过，购买入口不出现；二是充错了金币类型——长效静态和住宅家庭两类不互通，充进 A 类的钱买不了 B 类的节点。钱还在账户里，只是当下这一档用不上。

### Q：下拉里找不到我玩的游戏怎么办？

天行IP 的下拉没有「其他」自填项，找不到就找客服加一条。这一步卡在流程中间，很容易被误认为页面没加载完，刷新没用。

### Q：客户端显示已连接，网页还是打不开？

先看后台导出的格式和你装的软件是否一致，再核对四段字段（IP、端口、账号、密码）的顺序。四段里任何一个填错，表现都是「连不上」。这一步排除完再看出口归属地。

### Q：想先试再买，用什么方式最省？

用自带的 10 次测试卡，日卡 1–3 元也适合短期验证。测试额度别用来验「能不能连上」，那个 ping 就能测；要验的是登录一次账号、跑一次实际操作过不过风控。

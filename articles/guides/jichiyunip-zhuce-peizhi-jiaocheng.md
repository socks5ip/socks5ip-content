## 四、充值、购买与提取线路

**充值**：后台左侧「充值余额」。两套金币独立——SK5 约 1 元=2.5 金币、L2TP 约 1 元=2.4 金币，按所需协议充对应余额。

**购买**：选「socks5购买」或「L2TP购买」，右侧搜索框输入项目名（搜不到可用近似类型，如「贪玩蓝月」搜「传奇手游」）。

**选路线**：电信路线（本地电信网络推荐）／腾讯路线（多网络通用）／自定义路线（自选地区与 IP 数量，支持后期切换）。

**提取 IP**：订单生效后到「全部节点」或「我的代理」查看，数量少直接复制到工具，数量多导出文本文件批量管理；支持节点分组、IP 更换与地区切换。

## 五、多工具配置

**SK5 → 老鱼/SSTap**：打开工具 → 添加代理/线路 → 协议选 Socks5 → 填提取到的地址、端口、账号、密码 → 连接后全局走该 IP。SSTap 步骤一致。

**L2TP → 软路由/设备**：L2TP 无需代理软件，直接在爱快/OpenWrt 软路由或 Windows/手机网络设置里新建 L2TP 连接，填入服务器地址与账号密码即全局生效，配一次全设备可用。

A：是的。购买线路前需完成实名认证，仅对接验证系统用于安全识别，不存储个人信息，一次认证长期有效。

**Q：SK5 和 L2TP 怎么选？**
A：要配合老鱼/SSTap 等工具按线路提取的选 SK5（折后 6 元/月起）；想在软路由或设备上直接全局代理、一拖多的选 L2TP（8 元/月起）。注意两套金币独立，别充错。

**Q：IP 用腻了能换吗？**
A：后台「我的代理」支持 IP 更换与地区切换，自定义路线可自选地区与 IP 数量。

**Q：最低多少钱能跑起来？**

# 同一个号换了 IP 还弹滑块：四个信号里出口只占一个（2026）

该先动浏览器环境，还是先换一条出口？顺序反了，换多少条都照样弹，账号还会多记一笔异常记录。

**一句话结论：**验证码不是"检测到你用了代理"，而是一次会话的**风险分越过阈值**之后的动作。风险分由**出口信誉、会话一致性、操作节奏、账号自身记录**四类信号合成，出口只占其中一类——**换 IP 能改动的只有四分之一**。所以"换完还是弹"很正常；真正能稳住的是**同一个账号长期走同一条固定出口**，这件事 6 到 8 元的独享静态档就能做到，不必上到 35 元的定制独享。

## 一、滑块弹出来，说明这次会话的风险分过了线

风控系统处理一次请求，通常不做"是或否"的判断，而是先算一个分数，再按区间选动作。同一个账号在不同时刻遇到不同动作，原因就在这里——分变了。

| 平台的动作 | 通常对应什么分数段 | 换出口能改善多少 |
|---|---|---|
| 静默放行 | 低风险，信号之间不矛盾 | 无意义，本来就通 |
| 弹一次滑块 | 中风险，某一类信号异常 | 有效，但只在出口是主因时 |
| 短信或邮箱二次验证 | 偏高，通常是会话与出口同时异常 | 部分有效，还得改会话 |
| 直接拒绝或提示环境异常 | 高风险，多为账号自身已有记录 | 基本无效 |

这张表能解释一个常见疑惑：同一个号今天弹滑块、明天直接放行，线路一点没变。分是浮动的，动作跟着分走。

## 二、四个信号里，出口只改得动一个

| 信号 | 具体看什么 | 你能不能动手 |
|---|---|---|
| 出口信誉 | IP 类型（机房／住宅）、段位是否集中、有没有被别人用过 | 能，这是唯一能花钱改的一项 |
| 会话一致性 | 浏览器 profile、时区与语言、Cookie 是否跟着换 | 能，但不花钱，改配置就行 |
| 操作节奏 | 请求间隔、点击密度、是否机械重复 | 能，降速与打散即可 |
| 账号自身记录 | 历史失败次数、绑定信息、注册时长 | 基本不能，只能靠养号 |

四组里前三组你能动，但只有第一组要花钱。把预算全部压在出口上，等于只修了四分之一——这也是很多人换了五条线还在弹的原因。

## 三、出口的三层信誉：钱买的是后两层

同一个标价能买到完全不同的东西，这是这行最容易买反的一处。

| 层级 | 看什么 | 便宜的档能满足吗 |
|---|---|---|
| 是否干净 | 这个 IP 近期有没有被大量账号用过 | 部分能，新池通常较干净 |
| 类型对不对 | ASN 归属是机房还是住宅（isp／hosting） | 不能，机房档便宜也补不上出身 |
| 是否独享 | 有没有别人跟你共用这个出口 | 不能，共享池就是共享 |

判断顺序上，**先看类型，再看分散，最后才谈纯净**。类型不对（拿机房档去跑需要住宅出身的业务），后面两项做得多好都是白费。

## 四、换完 IP 立刻还弹，多半卡在这三处

**第一处：没离开那个浏览器窗口。** 同一个 profile、同一套字体与时区，出口换来换去，在平台眼里还是同一台机器在说话。这是出现频率最高的一条。

**第二处：请求节奏没变。** 换线之后照旧按同样的间隔猛点，风险分里的节奏项一路满格。换出口只降了一类，另外三类没动。

**第三处：新 IP 落在同一个 /24 段。** 切换额度说的是"能换几次"，不是"能换出多少个不同段"。同一个池子里换 20 次，可能只经过 4 个 /24。

## 五、/24 分散度：先量，再决定要不要加额度

| 平台 | 切换额度（公开口径） | 该额度管的是 |
|---|---|---|
| 天行IP | 1000 次 | 提取后换地址的次数 |
| 光子IP | 2000 次/月（约 66 次/天） | 账号级切换次数 |
| 鲸云IP 定制区 | 500 次/月 | 定制区内的切换 |
| ST加速器月卡 | 30 次 | 月卡内的换线次数 |

量分散度的办法不需要工具：连取 10 条，看前三段有几个不同的组合。**少于 3 个就是池子集中**，这时候加额度没用，加钱买更大额度换出来的还是同一片段。

## 六、自测口径：三步判断换出口有没有用

1. **看类型。** 把当前出口丢进检测中心，读 asn.type：hosting 是机房、isp 是住宅、cellular 是移动。类型和目标业务不匹配，先换类型，别换条数。
2. **看会话。** 换 IP 的同时换一个干净的浏览器 profile，时区与语言跟出口属地一致。这一步不花钱。
3. **看节奏。** 同一批动作的间隔拉开、打散，连续失败两次就停手换个时段。

三步都做完还弹，基本可以判定是账号自身记录在起作用，这时候继续买 IP 是无效花费。

## 常见问题（FAQ）

### Q：换了住宅 IP 还是弹滑块，是不是买到了假住宅？

先上检测中心看 asn.type 是不是 isp。是 isp 还弹，就往下查会话和节奏两项，别急着换第二家。把住宅当成"不弹验证"的保险，本身就是误读。

### Q：同一个号一天最多换几次出口合适？

没有统一数字，方向是越少越好。要长期登录的号，一天换一次都算多；采集类任务按窗口摊，换之前先把正在跑的任务停干净。

### Q：独享 IP 就一定比共享池干净吗？

独享解决的是"没有别人跟你共用这个出口"，不解决这个 IP 自身的历史。新开的独享段通常更干净，用久了同样会有记录，定期换段仍然必要。

### Q：住宅 IP 和机房 IP，平台真的分得出来吗？

分得出。ASN 归属是公开信息，谁家的段、属于运营商还是机房，第三方库一查就有，平台拿到的也是同一份数据。拿机房档做需要住宅出身的业务，第一步就露了。

### Q：滑块过了就没事了吗？

过滑块只是这一次放行，风险分不会因此清零。背后的信号没改，下一次同样会弹，而且门槛可能更高。

### Q：预算有限，先补出口还是先改环境？

先改环境。独立 profile、时区语言对齐、节奏降下来，这三件不花钱；做完再看出口够不够，能省掉一半换线路的钱。

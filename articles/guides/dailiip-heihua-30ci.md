# 代理IP圈的30个术语，一次讲清

## 一句话结论

**代理 IP 圈的黑话集中在"类型/质量/交易/用法"四类**——看懂这 30 个词，再看套餐页、跟客服聊选型基本无障碍。每条一句话，按使用频率排。

## 类型类（8 个）

| 术语 | 一句话解释 |
|---|---|
| 静态 IP | 出口地址长期固定不变 |
| 动态 IP | 出口地址周期性轮换 |
| 住宅 IP | 家庭宽带资源，看起来像真实用户，纯净度高 |
| 机房 IP | 数据中心资源，便宜量大，纯净度一般 |
| 原生 IP | 与注册地一致的"本地出生"IP，比广播 IP 更可信 |
| ISP 住宅 | 运营商直接分配的家宽线路，住宅里的高纯净档 |
| 移动 IP | 手机运营商网络出口，纯度接近住宅 |
| 独享 / 共享 | 独享=只有你用；共享=多人共用同一出口 |

## 质量类（9 个）

| 术语 | 一句话解释 |
|---|---|
| 纯净度 | 出口"像不像干净真实用户"，与黑名单命中负相关 |
| 黑名单 | 记录被滥用 IP 的信誉库，命中越多越脏 |
| ASN / 归属 | IP 的网络所有者，查归属能区分住宅/机房 |
| 可用率 | 一定时间内可成功连接的比例（注意问清口径） |
| 存活率 | IP 提取后仍能用的比例 |
| 延迟 | 数据往返耗时，采集/游戏的关键指标 |
| 丢包率 | 连接中丢失的数据比例，高丢包=线路废 |
| 带宽 | 吞吐上限，视频/大文件任务才吃这个 |
| 超卖 | 一个资源卖给超过其承载能力的用户 |

## 交易类（8 个）

| 术语 | 一句话解释 |
|---|---|
| 套餐档 | 按带宽/并发/IP 数划分的购买单元 |
| 并发 | 同时进行的连接/任务数（按需买的关键） |
| 轮换 | 动态 IP 更换出口的机制（按请求/定时/手动） |
| 提取 | 从后台拉取 IP 列表的动作（API 提取=程序化拉取） |
| 测试额度 | 平台给的免费试用，先测后买的依据 |
| 促销价 / 续费价 | 首期折扣价与之后的正式价，两个价 |
| 免费代理 | 来路不明的公共节点（≠免费测试） |
| 邀请码 / 推荐码 | 注册时填的推广码，通常关联优惠/测试入口 |

## 用法类（5 个）

| 术语 | 一句话解释 |
|---|---|
| SOCKS5 | 通用代理协议，软件里填 IP:端口+账号 |
| HTTP 代理 | 应用层代理，浏览器/爬虫适用 |
| L2TP | 隧道协议，系统拨号整机生效 |
| 白名单 | 只允许指定出口访问的机制，需固定 IP |
| 指纹浏览器 | 管理浏览器指纹的软件，与独立出口搭配做隔离 |

## 一句话送新手

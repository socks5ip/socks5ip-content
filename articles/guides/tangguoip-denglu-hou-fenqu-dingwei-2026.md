# 糖果IP 后台分区切错了，列表自然是空的

打开糖果IP 后台，左侧菜单点进 SOCKS5 代理，已购列表一片空白——多数情况不是 IP 丢了，而是套餐买在 L2TP 软路由那个独立分区里。糖果IP 把两类协议拆成两套互不相通的分区：各自计价、各自提取、各自显示，登错区域看到空列表是正常现象，而不是账号出问题。先把这套结构记住，后面大半「东西不见了」的疑问都能自己回答。

## 一、登进去之后，六个位置就够用

糖果IP 后台的功能收在左侧菜单里，第一次登录不用逐项点开：

| 位置 | 叫什么 | 用来干什么 | 第一次登录要不要动 |
|---|---|---|---|
| 左侧菜单 | 钱包 | 充值，**1 元 = 2 金币**，套餐按金币计费 | 要动，先充最小额试线路 |
| 左侧菜单 | SOCKS5 代理 | 提取「IP:端口\|账号\|密码」，可导出 TXT、切换 IP | 电脑端、代理工具用户看这里 |
| 左侧菜单 | L2TP 软路由 | 提取「服务器地址\|用户名\|密码」 | 软路由、设备直连用户看这里 |
| 分区内 | 「!」图标 | 看该分区的带宽与线路说明 | 买之前点一眼，别买错带宽档 |
| 左侧菜单 | 分组管理 | 把大量 IP 分类维护 | IP 上到几十条以后再用 |
| 左上角 | 个人中心 | 账号信息，页面底部有注销入口 | 平常不用动 |

关键结构只有一条：**SOCKS5 代理和 L2TP 软路由是两个互相独立的分区**。只在其中一个分区买了套餐，另一个分区里自然是空的。之后凡遇到「登录都正常，就是找不到我的 IP」，先看左侧是不是切到了另一个分区。

## 二、三个带「密码」的东西，各自管一段

后台里跟密码有关的凭证不止一个，混用就会出现「明明能登录、工具却报认证失败」这种看着矛盾的现象：

| 凭证 | 从哪来 | 用在哪 | 混用的后果 |
|---|---|---|---|
| 登录密码 | 注册时自己设置（建议 8 位以上、含大小写与数字） | 登录官网后台 | 输成提取密码 → 后台登不进去 |
| 提取密码 | 分区页面勾选 IP 后「导出 TXT」，里面的「账号\|密码」 | 填进老鱼加速器等代理工具的线路设置 | 输成登录密码 → 工具认证失败，看着像账号坏了 |
| 支付相关密码 | 充值、购买环节按提示设置 | 后台内的资金操作 | 与上面两个都不通用 |

还有一条习惯值得养成：导出 TXT 之后不要手打，直接复制粘贴。提取信息里大小写、竖线、端口号一个字符都不能错，手敲一串 `IP:端口|账号|密码` 出错概率极高，而报错信息往往只写「认证失败」，容易让人误以为是账号被限制。

## 三、换 IP 与分组：额度是 40 次/条/天

在对应分区页面勾选已购 IP，再用「切换 IP」这类按钮操作，**切换额度是 40 次/条/天**。这个额度比多数同价位平台宽，日常换 IP 基本碰不到上限；真正会卡住的是「买了套餐却在另一个分区里找 IP」这类操作问题。

IP 数量上来之后用「分组管理」分类，比在同一页里翻找快得多。按窗口分组的常见做法是：一条 IP 绑定一个固定窗口，组名直接写窗口编号，换线时只动需要动的那个组，不会再出现「换了一条结果另一个窗口的线路跟着变了」的连带问题。

## 四、页面转圈或按钮没反应时怎么查

| 现象 | 最常见的原因 | 怎么处置 |
|---|---|---|
| 提示账号或密码错误 | 把导出 TXT 里的提取密码当成官网登录密码在输 | 确认输入的是登录密码；用无痕窗口重新手敲一遍，避开浏览器自动填充的旧记录 |
| 界面一直转圈、进不去 | 本机缓存、浏览器插件拦截、当前网络异常 | 换无痕窗口或换浏览器打开官网；再不行换网络（手机热点）试 |
| 登录成功，但看不到已买的 IP | 左侧分区没切对，或套餐已过期 | 切到 SOCKS5 代理 / L2TP 软路由 对应分区；再到「钱包」看套餐有效期 |
| 后台能登，代理工具连不上 | 提取信息抄错，或用了登录密码当提取密码 | 回后台重新导出 TXT，整体复制粘贴覆盖工具里的旧线路 |
| 提示账号异常被限制 | 异地登录、账号被多人共用 | 先重设密码，再单独使用；账号共享是这类问题最主要的来源 |

把这张表倒过来读，能看出一条规律：**登录与后台环节的卡点几乎都落在密码和分区这两处，而不是平台本身**。所以不用一上来就怀疑线路或找客服。

## 八、常见问题

**Q：登录进去看不到之前买的 IP，是账号出问题了吗？**
多数不是。SOCKS5 代理和 L2TP 软路由是两个独立分区，先看左侧菜单是不是切到了另一个分区；两侧都空，就去「钱包」确认套餐是否已到期。

**Q：一个账号多个人一起用会有问题吗？**
会。异地登录、账号共享是触发「账号异常」限制的主要来源，风控识别到之后登录环节就会拦。建议一人一号；确需多人协作就按「分组管理」分配 IP，不要直接共用登录凭证。

**Q：登录后想换 IP 或者换地区在哪里操作？**
在对应分区页面勾选已购 IP，再用「切换 IP」这类按钮操作，切换额度是 40 次/条/天。IP 数量多的时候用「分组管理」分类，比在同一页里翻找快得多。

**Q：手机上能登录糖果IP 后台吗？**
官网是网页端，手机浏览器可以正常打开登录、充值、提取信息。移动端主要受屏幕限制，导出 TXT、复制长串配置信息时不如电脑顺手；配置环节建议还是用电脑。

**Q：为什么钱包里是金币而不是直接显示套餐价格？**
糖果IP 的套餐按金币计费，充值汇率是 1 元 = 2 金币，所以 5 折后的价格和金币余额不是一比一对应。比价时统一换算成人民币再看，不要拿金币余额直接跟别家的人民币价格比。

**Q：换了 IP 之后工具里要不要跟着改？**
要。工具里填的是「IP:端口\|账号\|密码」这一串，换了 IP 就得回后台重新导出一次，整体覆盖粘贴，不要只改其中的 IP 段——端口和账号在多数情况下也会一起变。

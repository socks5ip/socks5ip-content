# 三套账号不通用，「登不上」当场能定位

为什么免费版老鱼加速器里没有登录按钮？因为它压根不需要账号——要登的后台一共三处，而**这三套账号分属不同系统，互不通用**。老鱼加速器是解压即用的绿色客户端，免费版与安卓版没有服务器端账号体系，**卸载就等于停用，不需要注销，也不存在「忘记密码」这件事**。真正需要账号的只有：**12 元/年的专业版付费账号**、你购买 IP 线路的那家代理平台后台、以及渠道站（`socks5ip.com.cn`）的站内账号。把这三者的归属分清，「登不上」这类问题当场就能定位。

## 一、三套账号，归属、入口、找回路径都不一样

| 你以为在登的 | 实际是什么 | 账号从哪来 | 入口在哪 | 忘了怎么办 |
|---|---|---|---|---|
| 老鱼账号 | 专业版付费账号 | 购买专业版时由对接渠道发放 | 专业版软件内的登录框 | 找购买时对接的客服 |
| IP 提货后台 | 代理 IP 平台的用户后台 | 在哪家平台买线路就在哪家注册 | 该平台官网用户中心 | 用平台自带的找回密码 |
| 渠道站账号 | 全网低价IP 站内账号 | 站内自助注册 | 站内登录入口 | 站内找回，客服协助 |

最容易卡住人的是第三种与第二种的混用：**拿代理平台的账号去登老鱼客户端，一定提示账号不存在；反过来拿老鱼账号去平台后台提货，也一定会失败**。先想清楚自己要办的是「解锁软件功能」还是「提取 IP 线路」，再决定去哪个入口。

## 二、三个版本共用同一个下载渠道，装哪一个都叫「老鱼」

| 产品线 | 要不要账号 | 有没有登录入口 | 线路从哪来 |
|---|---|---|---|
| 老鱼通用免费版 | 不要 | 无 | 自己导入 SOCKS5 / SS / SSR 线路 |
| 老鱼加速器专业版 | 要，12 元/年 | 有，就在软件界面内 | 同样需要自备线路 |
| 老鱼加速器安卓版 | 不要 | 无 | 手机端导入线路 |

如果你打开软件发现功能比宣传的少一大截，**先确认自己装的是免费版还是专业版，比在界面里翻找登录框有用得多**。同一件事还有两种常见误会：装完发现线路列表是空的，以为「没登录所以拉不到节点」；搜到专业版介绍，看到界面里确实有登录框，回头在自己的免费版里怎么找都没有。两个误会指向同一件事——**账号和线路是两回事，免费版既不需要账号，也不提供线路**。

## 三、12 元/年买的到底是软件能力，还是线路

老鱼加速器的收费项目只有一个：**专业版年费 12 元**。这 12 元买的是账号本身的功能解锁，**不包含 IP 线路**——节点资源要自备或另行购买。付费后拿到的账号还有一个额外好处：可以登录所有收费版加速器，一次付费全平台通用，换设备不用重复买。

| 能力项 | 免费版 | 专业版（12 元/年） |
|---|---|---|
| 单窗口单 IP | 支持 | 支持 |
| 虚拟硬件（MAC / 机器码） | 不支持 | 支持 |
| 模拟器绑定线路 | 不支持 | 支持（雷电 / 逍遥 / 夜神） |
| 64 位程序 | 不支持 | 支持 |
| API 提取与自动切换线路 | 不支持 | 支持 |

判断标准很直接：**只需要偶尔换 IP、窗口在 3 个以内，免费版够用，也就意味着你不会有登录这一步**；一旦要跑模拟器矩阵或者需要虚拟硬件，才需要那 12 元的账号，登录这件事才真正出现。

## 四、下载到能跑，三步顺序别乱

官方合作渠道入口是 `socks5ip.com.cn`（全网低价IP），免费版、专业版、安卓版三端下载与配套教程都在站内，不需要另外找下载站。下载环节有一条判别标准：**全过程不会要求你输入老鱼账号密码**——免费版免注册，任何「先登录才能下载」的页面都值得警惕。

安装后的三步是固定的：完整解压到文件夹、把整个文件夹加进杀毒软件信任区、右键以管理员身份运行。跳掉任何一步都可能表现为「打不开」或「被杀毒删了」。

## 五、五类现象对号入座

| 现象 | 大概率原因 | 怎么处理 |
|---|---|---|
| 软件里找不到登录框 | 装的是免费版 | 免费版本来就没有登录，需要登录功能请换专业版程序 |
| 提示账号不存在或密码错误 | 拿代理平台账号去登老鱼 | 换成专业版付费账号再试 |
| 双击没反应或闪退 | 在压缩包里直接双击运行 | 完整解压到文件夹后再从文件夹里运行 |
| 被杀毒软件拦截或删除 | 误报 | 整个文件夹加进信任区，再以管理员身份运行 |
| 登录成功了但没有 IP 可用 | 账号不含线路 | 去代理平台买线路，再导入客户端 |

最后一行出现的频率最高。**专业版账号解决的是软件能力问题，线路问题只能靠代理平台解决**，两件事互不替代——这一点在付款前想明白，能省掉一次退款沟通。

## 常见问题

**Q：老鱼加速器到底要不要注册账号？**
免费版和安卓版不需要，装完直接用，也没有注册入口。只有 12 元/年的专业版有一个收费账号，用来解锁高级功能。

**Q：老鱼登录入口在软件的哪个位置？**
只有专业版程序里有，一般在主界面右上角或设置栏内。免费版界面里没有这个位置，找不到属正常。

**Q：忘了老鱼专业版账号密码怎么办？**
联系购买时对接的客服处理。12 元/年的订单通常有购买记录可查，比自助找回快。

**Q：12 元/年的专业版包含 IP 线路吗？**
不包含。这 12 元买的是软件功能解锁，线路要另外在代理 IP 平台购买，2.6 元/月起，可先免费测试。

**Q：能用代理平台的账号登老鱼吗？**
不能。两套账号属于不同系统：代理平台账号只在它自己的后台提货用，老鱼客户端只认收费版账号。

**Q：装了老鱼还是打不开某些程序，是登录问题吗？**
大概率不是。免费版不支持 64 位程序与模拟器绑定，这类需求要专业版；如果专业版登录正常但仍失败，再检查是不是没把整个文件夹加进杀毒软件信任区。

# 家里想要一个固定出口：运营商与代理是两条路

以为找宽带师傅开个固定公网就完事，其实那根网线的地址带不出门。**家庭宽带多数只给动态公网、有的连公网都没有**；想长期稳定同一个出口，代理侧按月 **6 元起**就能拿到静态住宅，还能同时喂给家里好几台设备。两条路的成本、上限和能办成的事差得很远，先分清你要的是哪一种「固定」。

## 公网与固定是两件事，家宽多数只满足前一件

很多人对「固定 IP」的第一印象来自宽带师傅那句话：可以给你开公网。这里有两个词经常被混在一起——公网 IP 说的是这个地址能不能被外网直接访问；固定 IP 说的是它会不会变。家庭宽带常见的状态是「有公网、但会变」，重启光猫或运营商侧调整一次，地址就换了。

| 对比项 | 运营商侧的固定公网 IP | 代理侧的固定住宅出口 |
|---|---|---|
| 地址会不会变 | 办成后长期不变 | 档位期内不变，可自选更换节奏 |
| 谁能申请 | 多要求企业资质或专线产品 | 个人即可注册，先试用再付 |
| 成本形态 | 按年计，通常数百元起 | 按月计，国内起步 2.24 元/月 |
| 只能从哪用 | 绑在这条入户线路上 | 任何能联网、能填代理的设备 |
| 能不能只给一台设备用 | 不行，整条线路共用一个地址 | 能，按设备分别取不同出口 |

这张表里最容易被忽略的是最后两行。入户线路的公网地址是「一根网线的地址」，家里所有设备出去都顶着它；代理的出口是「按设备、按应用挑的地址」，同一屋檐下可以让电脑走一条、手机走另一条。这两件事从根上就不是一类需求。

## 三个问题答完，路子基本就定了

要不要为这件事花钱，先回答三个问题，别急着下单。

第一个问题：这个出口会不会被对方当作身份记下来。如果只是自己在家浏览、看视频，出口是什么没人关心；如果对方要按出口判定账号、判定来源，那出口就是身份的一部分。第二个问题：这个出口要不要长期不变。要长期同一个，就得买静态；允许一定范围内轮换，动态池更便宜。第三个问题：有几台设备要一起走。一台设备可以逐台配，三四台以上就该考虑路由器层统一解决。

| 你的情况 | 该走哪条路 | 大概花多少 |
|---|---|---|
| 出口会被记录、要求长期不变，只有一台设备 | 代理侧买一条静态，逐台填代理 | 国内静态档多在 4–10 元/月 |
| 同样要求，但要覆盖全屋多台设备 | 代理侧买一条带 L2TP 的，接到上游路由器 | 多一台路由设备，线路费同上 |
| 出口会被记录，但允许按天或按批轮换 | 代理侧买动态池，按提取频率取用 | 按条数或按流量计 |
| 只是想上网更稳、下载更快 | 都不要买，去查宽带套餐和路由器 | 0 元 |

把这三个问题答完，路就定了。真正花时间的不是选平台，而是先承认「我要的到底是哪一种固定」。

## 代理侧的带宽口径与入户带宽不是同一回事

站内跨平台比价表把 23 家的月卡起步价列在一起，国内 19 家从光梭IP 的 2.24 元/月一直排到酷熊IP 的 20 元/月；海外 4 家从全球代理IP 的 5 元/月到 55游 的 15 元/月。价格差主要来自三件事：带宽形态、地址独享度、以及是不是住宅属性。

| 档位 | 代表平台 | 月卡起步价 | 带宽与形态 |
|---|---|---|---|
| 最低价档 | 光梭IP | 2.24 元/月 | 无限切换，适合按量取用的轻需求 |
| 主力便宜档 | 奔富IP / 烽讯IP | 2.6 元/月 | 四协议齐全，静态与住宅分档 |
| 住宅中位档 | 沧海IP / 光子IP / 天机IP | 4 元/月 | 住宅属性，按区与带宽再分档 |
| 带 L2TP 的常用档 | 天行IP / 鲸云IP / 极驰云IP | 6 元/月起 | 静态 L2TP、住宅 L2TP 分带宽卖 |
| 高带宽档 | 酷熊IP | 20 元/月 | 更高带宽与更强独享 |

这里要说清一件事：家宽的带宽是「一条线能跑多快」，代理的带宽是「这条出口给你分到多宽」。同样标 10M，家宽是入户上限，代理档位是你这条出口的可用带宽。所以拿家宽的测速去套代理档位，会得出完全错误的结论——代理侧看的不是总带宽，而是每条出口的稳态可用带宽够不够你当前的活。

## 三种固定形态的按月排序

同样是「固定出口」，代理侧其实有三种供给，很多人第一次买会在这三种之间挑错。它们的差别不在价格高低，而在出口长什么样、能挂在哪。

| 供给形态 | 出口长什么样 | 典型接法 | 更适合谁 |
|---|---|---|---|
| 静态住宅 | 住宅属性地址，档位期内不变 | 单台设备的应用或系统里填 SK5 / HTTP | 要「看起来像普通家庭宽带」的业务 |
| 静态 L2TP | 固定出口，整机隧道 | 系统或路由器配 L2TP 客户端 | 要让整机、整屋走同一条线的场景 |
| 动态池 | 一批地址，按规则提取 | 按条数或按频率取用，自动轮换 | 不要求长期同一个出口的批量任务 |

选的时候有一个硬约束要先记住：想让整机或整屋走隧道，就只能挑支持 L2TP 的平台。站内比价表把这件事列得很清楚——23 家里有 19 家同时支持 SK5 + HTTP + L2TP + PPTP 四种协议；只给 SK5 + HTTP 的是无忧IP、百兆王IP、优享云IP、皇冠IP 这 4 家。方案是「上游路由器接隧道」，下单前先把这 4 家排掉。

## 落到路由器层的两条延伸路

如果一台设备一台设备地配太累，或者有些设备根本进不去设置，就要往上游走。

| 你手上的情况 | 照着哪条路做 | 关键一步 |
|---|---|---|
| 有爱快 / ROS / OpenWrt，要让整屋走同一条线 | 软路由接入 L2TP | 把服务端地址、账号、预共享密钥填进 L2TP 客户端 |
| 要多台设备各走一条独立出口 | 路由器层分流 | 按设备或按用途做分流规则 |

这两条路真正决定成败的都是最后一步——分流。整屋走同一条出口很方便，但家里那些只看本地内容、跑局域网打印的设备没必要跟着一起走，把它们留在直连里，出口压力会小很多。反过来，如果要的是「一台设备一个独立出口」，就得在路由器层按设备分配，而不是图省事让全屋共用一个。

| 协议 | 归属层 | 挑平台时的含义 |
|---|---|---|
| SK5 / HTTP | 应用层代理 | 23 家全支持，选择面最宽 |
| L2TP / PPTP | 网络层隧道 | 只有 19 家支持，先排除那 4 家 |

## 四类场景各自的路线

| 场景 | 建议路线 | 为什么 |
|---|---|---|
| 家里几台设备要长期用同一个身份出口 | 代理侧静态住宅 + 逐台配置 | 出口稳定，成本按设备叠加但单条很低 |
| 全屋设备都要走同一条线 | 代理侧静态 L2TP + 软路由 | 一次配好全屋生效，含不认代理的应用 |
| 家里挂着一批自动化任务，允许按批换出口 | 代理侧动态池 | 按量取用，费用随用量走 |
| 只是想让家里网络更稳、更快 | 不买代理，查宽带与路由器 | 这两件事和出口身份无关 |

还有一类容易被忽略：设备本身没有管理员权限，装不了任何东西，也改不了网络设置。这种情况下只能走上游路由器那条路，别在设备上反复折腾。

## 常见问题

**Q：家庭宽带能直接申请固定公网 IP 吗？**
多数地区的个人家宽只给动态公网，固定公网 IP 要按企业宽带或专线办，有些地方甚至不开放给个人。办之前先打运营商客服问清两件事：给的是不是固定、是不是公网，两个条件缺一都不算你想要的。

**Q：既然家宽已经有公网 IP，为什么还要买代理？**
因为家宽那个地址绑在入户线路上，你在外面用手机、用笔记本走的是别的网络，用不上它；而且它随时可能变。代理的出口是按设备挑的，出门在外照样能用。

**Q：家里设备多，是不是买一条就够了？**
看你要几台设备各走不同出口。如果只是全屋共用一条线，一条带 L2TP 的接路由器就够；如果要求「一台设备一个独立出口」，就得按设备分开买，或用支持分流的路由器按设备分配。

**Q：一定要买带 L2TP 的平台吗？**
只有走整机隧道或路由器层时才必须。23 家里 19 家支持 SK5 + HTTP + L2TP + PPTP，挑货时把只给 SK5 + HTTP 的无忧IP、百兆王IP、优享云IP、皇冠IP 先排掉，剩下的选择面依然很宽。

**Q：动态池和静态档，怎么判断该选哪个？**
看你的业务认不认「同一个出口」这件事。要长期同一个，选静态；允许换、甚至换得越勤越好，选动态池更省。拿不准就先各买最低档，用同一台设备跑一遍真实业务再决定。

**Q：还没决定买哪家，怎么先判断值不值得？**
先用最低档带试用的线路，在同一台设备上跑一次「系统填代理」和「路由器接隧道」两种接法，看出口、延迟、丢包三项能不能达到你的要求。各家的试用额度在站内比价表里可以直接对照。

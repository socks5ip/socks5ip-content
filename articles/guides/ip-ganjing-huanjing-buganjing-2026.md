# IP 质量六项全绿却打不开站：干净不等于能出去

六项全绿，四个境外站一个都打不开——多数人这时候的第一反应是换节点，但问题其实未必在节点上。

**一句话结论：质量检测的六项指标回答的是「这段地址在公开库里有没有污点」，没有一项去连目标站；所以全绿只说明档案干净，不说明门开着。同一台机器上，风控值 6、滥用率 0.06% 的地址照样可以一个境外站都连不上。**

## 一、六项各回答什么，不回答什么

| 检测项 | 它回答的问题 | 它不回答的问题 |
|---|---|---|
| IP 类型（家庭宽带 / 机房） | 这段号码登记在什么性质的网络里 | 你现在的流量是不是真从这条线出去 |
| 原生 IP | 登记国与实际归属是否自洽 | 从这儿能不能到达某个境外站 |
| 风控值 | 这段网段上有多少滥用投诉记录 | 你今天的行为会不会触发平台风控 |
| 滥用率 | 网段在公开库里被标记的比例 | 目标平台认不认这份公开标记 |
| 代理识别 | 公开库里有没有把它标成代理 | 平台自己不公开的名单怎么判 |
| 黑名单 | 有没有进公开黑名单 | 平台私有黑名单与信誉分 |

看第二列和第三列的对照就清楚了：**六项全部在查「档案」，没有一项在查「连通」。** 这也是为什么会出现「六项全绿、站点全灭」这种看起来矛盾的画面。

## 二、同样打不开，成因分三层

| 现象 | 更可能是哪一层 | 怎么验证 |
|---|---|---|
| 域名解析不出来，报 DNS 错误 | 解析层 | 换一组 DNS；看 DNS 泄漏状态是否还停在「未开始」 |
| 能解析，转圈很久后超时 | 路由与出海层 | 看连通性卡里境外站是不是整片不可访问 |
| 能打开，但提示地区不支持、验证码、403 | 对方判定层 | 看场景检测里该项是「失败」还是「警告」 |

实测那一屏是这样的：百度可访问、抖音可访问，Google、YouTube、TikTok、ChatGPT 四项不可访问；DNS 泄漏状态显示「未开始」，WebRTC 需要手动点一次才会通过 STUN 取到公网映射并与出口比对。**这是标准的大陆出口画面——国内站可达、境外站整片不可达，而质量卡依然全绿。** 两者不矛盾，它从头到尾没连过那些站。

## 三、一次只动一个变量，四轮就能定位

同时换协议、换节点、换目标站，测完还是不知道是谁的问题。把变量固定住：

| 第几轮 | 动的变量 | 固定住什么 | 看什么结果 |
|---|---|---|---|
| 第一轮 | 直连 → 走代理 | 同一台机器、同一分钟、同一批站点 | 哪些站从不通变通，才算代理真的生效 |
| 第二轮 | 换协议（SOCKS5 → HTTP） | 同一出口、同一目标站 | 是不是协议层被挡，而不是出口不通 |
| 第三轮 | 换一条同档线路 | 同一协议、同一目标站 | 换线就好说明是那条出口的问题 |
| 第四轮 | 换目标站 | 同一出口、同一协议 | 只有个别站不通，问题在对方判定层 |

顺序不能乱：**先确认线路通不通，再谈 IP 好不好。** 反过来做，会在一条根本不通的线上反复研究纯净度，这也是「测三遍还是不知道问题在哪」的来源。

## 四、什么时候换节点，什么时候该换供应商

| 你看到的情况 | 判断 | 下一步 |
|---|---|---|
| 国内站也不通 | 本机网络或整条线路 | 换节点通常立刻缓解，与 IP 质量无关 |
| 国内通、境外整片不通 | 出口在哪一侧 | 买的是境外出口就是异常；用本地宽带直连就是常态 |
| 只有个别境外站不通 | 对方判定层 | 换节点、换协议各试一次，两次都不行再考虑换供应商 |
| 都通但场景分上不去 | 买错了类型 | 看场景关键项，不是线路坏了 |

第四行是最容易被误读的一种：同样的网络，通用体检 86 分、跨境电商场景 67 分（TikTok 不可达），差的是判据换了，不是线路变了。**分数低先看哪一项失败，再看总分。**

## 五、一句必须说清的口径

供应商能承诺的是**动作**——换一个能通的节点、换一段没被标记的地址；不能承诺**结果**——某个平台一定放行。任何声称「保证通过某平台风控」的说法，都超出了 IP 这一层能决定的范围。这条线画清楚了，选型时就不会把希望押在错误的层级上。

## 七、常见问题

**Q：质量检测全绿，为什么还是打不开网站？**
因为这六项查的是档案，不是连通。能不能到达某个站取决于路由、协议、出口和对方是否放行，质量卡一项都不管。

**Q：风控值 6、滥用率 0.06% 算干净吗？**
在这套指标里属于干净区间，说明这段地址没有明显投诉记录。但它不代表目标平台一定放行。

**Q：DNS 泄漏显示「未开始」是什么意思？**
表示这一项还没跑过。需要手动点一次检测，否则它不构成结论。

**Q：换节点就能解决吗？**
看是哪一层。解析层的问题换节点一定不解决；出口层的问题换节点可能解决；对方判定层换节点只是碰运气。

**Q：为什么同一分钟两个场景分数差这么多？**
因为两个场景的白名单和关键项门槛不同。分数是相对判据，不是绝对质量。

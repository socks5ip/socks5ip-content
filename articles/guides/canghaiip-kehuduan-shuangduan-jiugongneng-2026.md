# 沧海IP 客户端上线：三端入口与九项能力拆解

客户端上线之后，原来的网页后台还留着吗？沧海IP 这次在电脑与安卓两端各放了一套入口，八区价格表没动；鸿蒙手机也被单独列进下载项，不用再借道安卓版。

🔗 快速入口：一站式注册入口（聚合 20+ 家平台） ｜ 沧海IP 八区价格表（折后 4 元起） ｜ 沧海IP Socks5 / L2TP 提取教程

## 下载入口按端分，装错版本连不上

三端各有自己的安装包，混装会直接连不上——这不是线路问题，是版本不匹配。

| 端 | 形态 | 备注 |
|---|---|---|
| Windows | 电脑客户端 | 桌面端独立安装包 |
| 安卓 | APK | 覆盖主流安卓版本 |
| 鸿蒙 | 华为版（卓易通） | 单独列出，不沿用安卓包 |

## 九项能力逐条拆

官方卡片列了九项，按「能不能替代后台」分成三类更清楚。

| 能力 | 作用 | 能否替代后台 |
|---|---|---|
| 购买 | 客户端内下单 | 能 |
| 续费 | 到期前续期 | 能 |
| 更换 | 换 IP / 换线路 | 能 |
| 检测 | 一键检查线路状态 | 能，但见下节 |
| 连接 | 拨号 / 接管流量 | 能 |
| 报障 | 提交故障 | 能提交，仍由客服处理 |
| 全局代理 | 整机流量走代理 | 能 |
| 账号信息 | 查看余量与到期 | 能 |
| 提取导出 | 取线路凭据给第三方客户端 | 部分，复杂导出仍建议回后台 |

## 能省事的四项与必须回后台的三项

| 类别 | 项目 | 原因 |
|---|---|---|
| 真省事 | 购买、续费、更换、连接 | 都不用再切浏览器 |
| 仍需后台 | 八区套餐切换、发票与凭证、推荐关系维护 | 涉及资金与归属，官方保留网页端 |
| 看情况 | 批量导出 | 少量能导，批量仍建议后台 |

判断标准很实用：**客户端覆盖的是「日常动作」，网页后台保留的是「资金与归属动作」。**

## 价格仍是那张八区表

本轮上线的不是新线路，价格结构没有变化。折后区间仍是 **4 元到 35 元/月**，最低是二区特价住宅（**4 元/月**），最高是八区定制独享住宅（**35 元/月**）。

| 区 | 线路性质 | 折后月卡 |
|---|---|---|
| 二区 | 特价住宅 IP | 4 元 |
| 一区 / 四区 | 静态住宅 / 住宅 IP | 8 元 |
| 五区 | 安卓手机 IP | 8 元 |
| 三区 | 家庭宽带 IP | 10 元 |
| 六区 / 七区 | 软路由静态 / 住宅 L2TP | 10 元 |
| 八区 | 定制独享住宅 | 35 元 |

二区、五区、八区只提供月卡，没有天卡与周卡——排预算时最容易漏这一点。

## 链接尾部参数决定推荐归属

注册链接的尾部带着两段参数，它们不影响价格，只锁定推荐关系。所以在客户端里点「注册」和从网页点进注册，落到的是同一套账号体系；如果注册后看到的价与优惠价不符，按站内口径联系客服改价即可。

## 自检能力止于哪一步

客户端自带的检测能回答「这条线通不通」，但回答不了「出口是不是我要的落地、是不是住宅出身」。这两件事要交给站内工具：[代理线路可用性检测](https://socks5ip.com.cn/proxy-check/) 看连通与延迟，[IP 综合检测中心](https://socks5ip.com.cn/ip-check-center/) 看出口归属与线路性质。**客户端管连通，站内工具管归属。**

## 安装前的三项确认

1. 确认系统版本符合该端要求，尤其鸿蒙要选华为版而非安卓包。
2. 确认已有账号与套餐，客户端本身不带免费线路。
3. 确认同一时刻只有一个客户端在接管出口，避免两个程序互相抢。

## 常见问题

**Q：客户端上线后，网页后台还能用吗？**
能。客户端覆盖的是购买、续费、换线、连接这类日常动作，涉及资金与归属的操作仍在网页端保留。

**Q：鸿蒙手机装安卓版可以吗？**
不建议。官方把鸿蒙单独列为华为版（卓易通）入口，混装安卓包会出现连不上或功能缺失的情况。

**Q：客户端涨价了吗？**
没有。本轮上线的是入口与功能，线路池与八区价格未变，折后区间仍是 4 元到 35 元/月。

**Q：客户端里的检测和站内检测中心有什么区别？**
客户端只能判断通不通；出口归属、住宅或机房性质要在站内 [IP 综合检测中心](https://socks5ip.com.cn/ip-check-center/) 看，两边各管一段。

**Q：注册链接尾部的参数要保留吗？**
要。它锁定的是推荐归属，不影响价格。注册后发现实付价与优惠价不符，按站内口径联系客服改价即可。

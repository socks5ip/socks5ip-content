# 覆盖 700 个地区，不等于能选到那座城

下单前怎么确认这家平台到底能不能指定城市？先把两个数字分开看：宣传页上的地区数说的是 IP 池里这些地方**有货**，可指定说的是后台**给不给你选择权**。前者是资源池宽度，后者是一栏下拉框，混在一起就会得出「买完才发现选不到」的结论。

**能不能指定，取决于后台有没有「地区 / 节点选择」入口，以及你选的档位区域范围够不够宽。** 覆盖数字本身不能当可选清单用。

## 先看一组站内标注的地区覆盖

各家宣传页上的地区数字，粒度并不一致。把这张表和「指定能力」并排读，误差就出来了：

| 平台 | 站内标注的覆盖 | 粒度大致落在 |
|---|---|---|
| 光梭IP | 全国 700+ 地区 | 城市级 |
| 奔富IP | 全国 700+ 地区（IP 池 3W+） | 城市级 |
| 鲸云IP | 350+ 城市 | 城市级 |
| 烽讯IP | 全国 300 城+ | 城市级 |
| 天行IP | 130+ 地区（住宅 J/N 节点） | 城市 / 区域级 |
| 全球代理IP | 200+ 国家 | 国家 / 地区级 |
| 皇冠IP | 180+ 国家 | 国家 / 地区级 |

一个平台标 700+ 地区，只说明它的 IP 池里这些地方都有货；至于下单时能不能点到某一个具体城市，要看后台有没有可交互的地区入口、以及那个城市**当下有没有余量**。有入口且有余量，才叫能指定。

## 先把需求定在哪一层，再谈能不能指定

「指定地区」其实是四种不同难度的需求。越往下颗粒度越细，能满足的平台越少，能用的场景也越窄：

| 粒度 | 典型问法 | 谁提供 | 解决什么 |
|---|---|---|---|
| 国家 / 地区 | 要一条美国的 IP | 海外类平台（全球代理IP、无双、皇冠、55游） | 跨境店铺、海外社媒、外服游戏 |
| 省份 | 要广东的 IP | 国内平台普遍支持 | 区域化运营、同省多店 |
| 城市 | 要杭州的 IP | 光梭、奔富、鲸云、烽讯等 | 电商比价、本地生活、同城服务 |
| 号段 / 运营商 | 要电信的某个 IP 段 | 少数平台的部分线路（天行支持选号段） | 白名单绑定、细分风控场景 |

口径提醒一句：国内住宅 IP 的「城市」是真实家宽的接入地，运营商数据本身就按省市登记；国内机房 IP 的城市是机房所在地；海外机房 IP 的地区多数只是 GeoIP 归属库里的登记值，不是服务器物理位置。这也解释了「买的时候选了某地区，查出来归属地却不一致」——它不是故障，是两套口径的差别。

## 换一次地区，账户里少的是什么

「换地区」在多数平台不是免费动作，它和你换 IP 共用同一个额度池。额度差异直接决定你能不能靠「反复换城市」跑业务：

| 平台 | 切换次数 | 换地区的成本感知 |
|---|---|---|
| 光梭IP / 奔富IP / 烽讯IP | 不限次数 | 不吃额度，适合频繁换城 |
| 光子IP / 优众IP / 天机IP | 2000 次/月 | 额度宽裕，分钟级换也够用 |
| 沧海IP / 天行IP / 极驰云IP | 1000 次/月 | 常规业务够，高频换城要记账 |
| 鲸云IP | 机房与家庭款 30 次/条/月，定制款 500 次/月 | 两款差一个数量级，选错就会卡住 |
| 糖果IP | 40 次/条/天 | 按「每条每天」计，不是整号通用 |
| JiuIP | 月卡 30 次/条 | 额度最紧，换地区要提前规划 |

用法很直白：业务需要「同一个账号在不同城市之间来回切」，就优先挑不限次数的三家；只是偶尔换个地区，1000 次的档位绰绰有余。各家档位与切换次数可以在[跨平台比价页](https://socks5ip.com.cn/dailiip-jiage-duibi/)一次横向看完。

## 这几种业务，其实不用指定到城市

不是所有业务都需要城市级，盲目追求细颗粒度只会多花钱：

| 业务 | 需要指定到哪一层 | 原因 |
|---|---|---|
| 电商价格监控 / 竞品比价 | 城市（杭州、深圳、广州等） | 不同城市看到的售价、促销和库存不一样 |
| 本地生活 / 同城服务 | 城市 | 平台按 IP 城市推送本地内容与商家 |
| 区域化广告投放 | 省或城市 | 落地页与投放地域要对得上，否则数据失真 |
| 跨境店铺 / 海外社媒 | 国家 / 地区 | 只要是对的国家，具体城市意义不大 |
| 外服游戏 | 国家 / 地区 | 匹配区服、压低延迟才是重点 |
| 多账号隔离 / 防关联 | 不看城市 | 账号是否被关联，看的是出口身份与纯净度 |

最后一行要单独提醒：很多人把「换城市」当成防关联手段，其实同一台设备用同一种住宅线路、换不同城市，并不能解决账号关联的根因。真要做环境隔离，得从设备指纹和出口绑定一起下手。

## 四步验证：宣传语问不出答案，实测能

平台页面上的表述普遍含糊，实测口径反而是最省事的办法。十分钟就能问出结果：

| 步骤 | 怎么做 | 判据 |
|---|---|---|
| 先找入口 | 到后台看有没有「地区 / 节点选择」的下拉框或地图 | 有可交互入口，才有可能指定 |
| 用小额验证 | 用免费测试额度取一条目标城市的线路 | 取得到，才算真能指定 |
| 查归属地 | 用 IP 检测工具查这条 IP 的出口归属 | 与所选城市一致＝通过；不一致要问清口径 |
| 记成本 | 看这次选择有没有扣切换次数 | 扣了就把「换城」计入成本核算 |

第二步的免费测试额度各家给法不一样，站内[免费测试汇总页](https://socks5ip.com.cn/mianfeiceshi/)整理了各家的形式与额度；查归属地直接用 [IP 综合检测中心](https://socks5ip.com.cn/ip-check-center/)，归属地、线路类型、连通性一次测完。

付款之前，把三句话问给客服最省事：能不能指定到城市、还是只能选大区？指定城市要不要额外付费或吃切换额度？指定的城市没货时怎么处理——退款还是给同省替代？三个答案拿到手，后面基本不会有意外。

## 常见问题

**Q：代理IP 到底能不能指定到具体城市？**
A：能，但有前提。国内平台多以城市级可选，海外平台多以国家 / 地区级为主。关键看两点：后台有没有「地区 / 节点选择」入口，以及你选的档位区域范围够不够宽。宣传页上的覆盖数字不等于可选清单。

**Q：为什么买了某地 IP，查出来归属地却是别的地方？**
A：机房类 IP 的「地区」来自 GeoIP 归属库的登记信息，不是服务器物理位置；住宅类 IP 的归属地更贴近真实家宽所在地。拿到 IP 后直接用检测工具查一遍出口归属，比看订单页更准。

**Q：换地区会额外收费吗？**
A：多数平台不加价，但会占用切换次数额度。不限次数的平台（光梭、奔富、烽讯）随便换；按次计的平台（如 JiuIP 月卡 30 次/条）就要把换地区算进规划。个别平台可能对指定区域单独定价，付款前问一句最稳。

**Q：指定城市需要买更贵的档位吗？**
A：通常是的。起步档的区域可选范围往往最窄，城市级精确指定多见于中高档位或定制区。只做账号隔离的话，用不着为城市付溢价。

**Q：海外平台只能选国家，做跨境电商够用吗？**
A：多数跨境场景够用。跨境店铺和海外社媒关心的是「是不是目标国家的干净住宅 IP」，具体城市影响不大；只有做本地化广告或同城业务才需要细到城市。

**Q：怎么确认平台说的城市是真能选？**
A：三步验证——后台先看有没有地区入口，再用免费测试额度取一条目标城市的线路，最后用检测工具核对出口归属地。三步都过，才算真能指定。

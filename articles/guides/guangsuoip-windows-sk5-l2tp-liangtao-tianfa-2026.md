# 光梭加速器 Windows 两套填法：SK5 填客户端，L2TP 填系统拨号

打开光梭后台的线路列表，SK5 和 L2TP 是两行不同的东西：一行给四段凭据，另一行只给地址和账号密码。填错行的表现是拨号报 691、客户端一直转圈，两种症状的修法完全相反。

光梭加速器的两条线在 Windows 上不是同一份配置单：SK5 填客户端，L2TP 填系统拨号，同带宽 L2TP 还更贵。同样 1.5M 一档，SK5 折后 2.24 元、L2TP 4 元，差 1.76 元；买到 6M 时两边只差 0.8 元。先定协议再动手，比装完再换省一半时间。

**一句话结论：要改的是某个软件的出口，走 SK5；要改的是整机的出口，走 L2TP。两者互斥，不能同一台机器上同时生效。**

| 对比项 | SOCKS5 线 | L2TP 线 |
|---|---|---|
| Windows 上填在哪 | 客户端／浏览器扩展／系统代理 | 设置 → 网络 → 拨号连接 |
| 需要装软件吗 | 需要（老鱼、SSTap 一类） | 不需要，系统自带 |
| 入门价（八折后） | 1.5M 2.24 元 | 1.5M 4 元 |
| 6M 档价差 | — | 比 SK5 只贵 0.8 元 |
| 能不能按程序分 | 能，指定进程 | 不能，整机一起换 |
| 凭据字段 | IP／端口／账号／密码 | 地址／账号／密码（无端口） |

## 同一份带宽，两条线的价差在收窄

价差不是固定比例：1.5M 那一档 L2TP 贵 79%，到 6M 只贵 10% 出头。这条曲线决定了「先买哪条试」的答案——低带宽档上 L2TP 明显不划算，高带宽档上两者接近，选哪条都可以。

| 带宽档 | SK5 折后 | L2TP 折后 | 差额 | 差额占比 |
|---|---|---|---|---|
| 1.5M | 2.24 元 | 4 元 | 1.76 元 | 约 79% |
| 6M | 略低 | 略高 | 0.8 元 | 约 10% |

差额收窄的原因是 L2TP 有 4 元的起步价：它按整机一条隧道计费，不按条数叠加，所以低带宽档的成本下不来，高带宽档才摊平。

## L2TP 的四个字段，从哪一行抄

L2TP 线不需要装任何客户端，走 Windows 设置里的「添加拨号连接」，填服务器地址、类型选 L2TP、再填账号密码。路径是：设置 → 网络和 Internet → 拨号 → 添加连接。

| Windows 上的字段 | 从导出里抄哪个 | 常见错法 |
|---|---|---|
| 服务器名称或地址 | L2TP 行的 IP | 抄成 SK5 那行的地址 |
| 连接类型 | L2TP/IPsec | 选成 PPTP，拨号直接失败 |
| 用户名／密码 | L2TP 行的账号密码 | 用 SK5 的账号密码 |
| 预共享密钥 | 导出里没有就留空 | 随手填一个，认证必失败 |

第二步有个容易忽略的选项：「记住凭据」。不勾的话每次拨号都要重输密码；勾了以后平台侧改密码就得回来改一次，忘了改的表现是反复提示认证失败。多台机器共用一条线时建议不勾，避免某台机器用旧密码死磕。

L2TP 有一个绕不开的限制：它只承载 IP 层流量，拨通后这台机器上所有程序一起换，做不到「只有这个软件走」。要按程序分，只能回到 SK5 那条路。

## 提取时三个字段最容易对不上

提取出来的是一份「IP／端口／账号／密码」清单，三处不一致都会表现为「连不上但不报错」：

1. **协议标签**。同一批 IP 在 SK5 和 L2TP 下是两套连接参数，导出时先看标题那一行写的是哪个协议。把 SK5 的行填进系统拨号，或者反过来，都是静默失败。
2. **端口**。SK5 用端口区分实例，是必填项，抄错一位就连不上；L2TP 行里根本没有这一栏，看到端口就说明拿错了表。
3. **账号格式**。有的导出给「用户名:密码」连写的一串，有的给两列分开。填客户端时按字段拆开，别把冒号一起粘进用户名——这是排查时最不容易想到的一处低级错误。

| 现象 | 多半是哪个字段 | 怎么改 |
|---|---|---|
| 客户端提示连接超时 | 端口或地址抄错 | 回控制台重新导出一次 |
| 提示认证失败 | 账号里带了冒号或空格 | 拆成两栏分别填 |
| 拨号报 691 | 用了错协议那行的账号密码 | 换 L2TP 行重填 |
| 导出里找不到端口 | 拿到的是 L2TP 表 | 切到 SK5 标签重新导出 |

导出之后先存一份文本。以后换机器、换客户端、加第二台设备，直接照抄，不用再登一次控制台。

## 三处验收，结果不一定一样

配置完不要只看客户端显示「已连接」，要在三个地方各查一次出口：

| 验收位置 | SK5 的预期 | L2TP 的预期 |
|---|---|---|
| 浏览器查 IP | 显示线路 IP | 显示线路 IP |
| 命令行查 IP | 仍是本机 IP（正常） | 也是线路 IP |
| 目标软件内查 IP | 看它读不读代理 | 也是线路 IP |

SK5 只在你填了它的那个软件里生效，所以「浏览器查到新 IP、命令行还是本机」是完全正常的，不要当成配置失败。L2TP 拨通后三处应该一起变，命令行没变说明连接没拨上，或者被例外规则绕过了。

顺手看一眼 DNS 和时区：出口换了、DNS 还是本地运营商、系统时区还是北京时间，这三项凑在一起本身就是一组可识别的特征。纯浏览用途可以不管，做账号环境的建议对齐。

## 出问题按三层拆

光梭在 Windows 上的故障可以按「能不能连上、连上有没有流量、谁在用这条线」三层切开，只有第一层是平台侧的事。

- **第一层，连不上**：SK5 报超时，先核对端口和账号；L2TP 报 691 或 789，先确认是不是拿错了协议那行的账号密码，再确认连接类型选的是 L2TP/IPsec。
- **第二层，连上了没流量**：SK5 的典型表现是客户端显示已连接、程序还是本机 IP，原因是那个程序压根没读这份配置。
- **第三层，只有一部分生效**：指定了进程却没生效，回去看客户端的规则是不是被别的规则覆盖。

## 常见问题

**问：装了客户端还要再配系统拨号吗？**
答：不用。SK5 走客户端、L2TP 走系统拨号，是两条互斥的路，同一台机器同时开会抢默认路由。

**问：为什么 1.5M 档 L2TP 贵这么多，6M 却差不多？**
答：L2TP 有 4 元起步价，按整机一条隧道收费；带宽越高，两部分成本的差距被摊薄。

**问：SK5 连上了，游戏还是本机 IP 怎么办？**
答：游戏进程没进规则。在客户端里指定游戏进程，或者换一个按进程接管的客户端。

**问：拨号报 789 是什么问题？**
答：多数是连接类型选错（选成了 PPTP），或者本地安全策略拦了 IPsec。先改类型，再查系统日志里那一行。

**问：光梭有免费测试吗？**
答：有，系统默认每天给 5 条免费测试资格，次日重置。先用免费额度把地区、协议、客户端三件事验一遍，确认能跑通再充值。

**问：一条线能不能两台机器同时用？**
答：技术上能拨上，但会互相抢出口，表现是两边都时断时续。按账号数买，别按机器数凑。

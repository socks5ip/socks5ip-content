# 大白加速器支持哪些设备：装不上的机器各有对位客户端

大白加速器支持哪些设备？门槛只有一行：**Android 7.0 及以上，并且允许侧载安装包**。系统版本是唯一的判断依据，说在最前面可以省掉一轮徒劳的寻找。它本身是个约 **6.9 MB** 的安卓客户端，不吃 iOS、不吃桌面系统，也不吃 7.0 以下的老机器。装不上不等于用不了——三类机器各有一条对位的路。

## 门槛只有一行：系统版本

| 项 | 要求 |
|---|---|
| 系统 | Android 7.0 及以上 |
| 安装方式 | 需要允许侧载安装包 |
| 客户端费用 | 免费 |
| 节点 | 需另行购买，站内常见起步价约 2.6 元/月 |

低于 7.0 的机器不是「版本旧一点」，而是装都装不上——安装包在解析阶段就会被拒绝，后面配置得再好也没用。

## iOS 走哪条路

| 项 | 说明 |
|---|---|
| 对位客户端 | Shadowrocket 这类 iOS 端代理客户端 |
| 节点能不能共用 | 能，同一批 SK5 节点换个客户端填即可 |
| 需要多准备什么 | 一个非大陆区的 App Store 账号 |
| 注意 | 系统不提供侧载，只能走应用商店 |

iOS 上不存在「装个安卓包」这条路，所以真正的准备动作是提前解决商店账号，而不是在节点上折腾。

## 桌面系统走哪条路

| 系统 | 对位客户端 | 典型用途 |
|---|---|---|
| Windows | SSTap、NekoBox | 按进程或全局接管出口 |
| macOS | NekoBox | 本地代理与规则分流 |

桌面端的选择比手机端多，也更需要想清楚一件事：你要的是**全局接管**，还是**按应用分流**。两者配置方式不一样，选错了会在「为什么某个软件没走代理」上耗很久。

## 老安卓走哪条路

| 项 | 说明 |
|---|---|
| 对位客户端 | Postern |
| 特点 | 规则在前，节点在后，对手动配置更友好 |
| 适合 | 版本低、但只要求特定应用走代理的机器 |

老机器上别追求「一步到位」，能按应用把流量分出去就已经够用。这类机型跑不了复杂的本地接管，规则越简单越稳。

## 三条替代路都要先备好的东西

| 准备项 | 为什么 |
|---|---|
| 一条完整节点（四项信息同源） | 换客户端不换节点，节点不完整换哪个都白搭 |
| 出口核对方式 | 换完客户端必须查一次落地地址，确认接管生效 |
| 一条回退路线 | 新客户端配不通时，能回到原机器继续用 |

**换客户端是换「谁接管流量」，不换节点本身**。所以旧机器上那份节点资料要完整拿出来，别在新设备上重新抄一遍——抄错一项就是一次无效排查。

## 换设备前先确认两件事

| 确认项 | 判断方式 |
|---|---|
| 节点是否支持目标客户端 | 看平台给的节点形态（整段文本 / 订阅 / 字段） |
| 目标客户端能否吃这种形态 | 形态对不上，换了客户端也导不进去 |

两件事确认完再动手，比装完再找原因省时间。

## 常见问题

**Q：iPad 能装吗？**
不能。它走的是 iOS 那条线，需要 Shadowrocket 这类 iOS 端客户端，系统不允许侧载安卓安装包。

**Q：节点是所有客户端通用的吗？**
节点本身是通用的，差异在于**形态**：整段文本、订阅链接、还是逐项字段。客户端吃不下这种形态，节点再完整也导不进去。

**Q：换了客户端以后，原来的节点要重新买吗？**
不用。节点在平台后台，客户端只是接管流量的那一层，换客户端不影响已购线路。

**Q：老安卓手机装了替代客户端，为什么还是很卡？**
老机型的瓶颈常在硬件与系统本身，不一定是线路。可以用检测页单独测这条线的延迟，把线路与机器的因素分开看。

**Q：怎么确认流量真的走了新客户端？**
查一次落地地址。装好、连上、地址变了，这三步都过才算接管成功。

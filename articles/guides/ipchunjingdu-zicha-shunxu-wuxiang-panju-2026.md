# 三步查完，五项对完，再决定换不换线

打开检测页把线路粘进去，黑名单一栏零命中、ASN 归属写着家庭宽带，看着已经是干净的住宅 IP——但真正决定它能不能跑你的业务，是后面三项还过不过。IP 纯净度行业里没有统一的及格线，实务口径是**五项指标交叉判断**，前三项是硬门槛，后两项决定这条线能用多久。三个步骤全部走公开数据源，**十分钟内能跑完，不需要付费**。

## 一、三步有固定顺序，跳着看会白跑一轮

顺序不是讲究，是省时间：前一步不过，后面的不用查。

| 步骤 | 查什么 | 在哪查 | 出现什么就该停 |
|---|---|---|---|
| 第一步 | 黑名单与滥用记录 | 检测页的黑名单项 | 主流反垃圾库任意一条命中，直接换线，不用往下查 |
| 第二步 | ASN 归属与 IP 类型 | 同一页的 ASN 运营商名称与类型标记 | 归属显示数据中心 / 云服务商，而你要跑的是账号类业务 |
| 第三步 | 同 C 段邻居与历史行为 | 批量检测同段 IP，看风控值与滥用标记 | 同段大量 IP 带风险标记，整段被牵连，单条再干净也没用 |

被跳过的通常是第二步和第三步。查完「没进黑名单」就下单的人最多，最后卡在 ASN 归属上——机房段本身就会被平台按代理流量处理，和有没有黑名单记录无关。

## 二、五项判据：达标长什么样，不达标会怎样

把三步的结果填进这张表，能直接得出「能不能用」的结论。这也是站内 [IP 纯净度在线检测](https://socks5ip.com.cn/ip-tools/ip-quality/ipchunjingdu-zaixianjiance/) 与 [纯净度判据说明](https://socks5ip.com.cn/ip-tools/ip-quality/ruhezhakanipchunjingdu/) 用的同一套口径。

| 指标 | 合格表现 | 不合格时会怎样 | 怎么看 |
|---|---|---|---|
| 黑名单记录 | 主流反垃圾库零命中 | 注册被要求额外验证，短信与邮件收不到 | 检测页的黑名单项 |
| ASN 归属 | 家庭宽带运营商（住宅段） | 被判定为代理或机房流量，风控分被压低 | ASN 运营商名称 |
| 代理标记 | 未被标注，或标注为低风险 | 目标站点弹验证码、频繁限流 | 两家以上 IP 类型库交叉验证 |
| 历史行为 | 近 30 天无异常记录 | 承接前人的黑历史，新号一起被牵连 | 风控值与滥用标记 |
| 同段邻居 | 同 C 段无大量被封记录 | 整段被牵连限流 | 批量检测同段 IP |

前三项任何一项不过，说明这条线路从一开始就不适合跑账号业务；后两项更像「保质期」，决定你多久之后要换一次线。

## 三、同一个地址，两家网站给出相反结论，问题不在工具

各家自建的 IP 情报库不一样、更新频率不一样（有按天的、有按周的）、权重规则也不一样——电商看交易历史、社媒看行为频率，所以同一个 IP 在不同业务里的生死本就不同。

实用做法是**以目标平台自己的表现作为最终判据**（能不能正常登录、会不会频繁弹验证），第三方查询只作参考，且至少交叉两家数据源。出现分歧时按这个优先级判读，比反复换查询站有用。

## 四、两个比检测本身更容易踩的误区

**把「能连上」当成干净。** 连通性只是技术层的事，风控层看的是信誉——一条线路可以稳定连通、延迟很低，同时在所有反垃圾库里都是命中状态。这两件事没有因果关系。

**追求 100% 干净。** 公网 IP 是反复迭代复用的资源，绝对无瑕疵的地址几乎不存在，今天干净也不代表下个月还干净。真正有意义的指标是**相对干净 + 长期稳定不变**：出口固定、不被别人共用、连续几天查询结果一致，比单次拿到满分可靠得多。

## 常见问题

**Q：开了代理还是本地 IP 显示的是本机地址，是不是线路不干净？**
不是。这种情况一般出在客户端没把流量接上（进程没被捕获、规则没生效），属于技术层问题，和纯净度无关。先用检测页确认请求走的是不是线路出口，再去查黑名单与 ASN。

**Q：IP 检测纯净度多少分算干净？**
没有统一分数线。实务口径是五项交叉：黑名单零命中、ASN 归住宅、无代理标记、近 30 天无异常、同段邻居干净。前三项是硬门槛，第四五项决定能用多久。

**Q：为什么不同网站查同一个 IP，结论相反？**
因为各家数据库的覆盖范围、更新频率和权重规则都不同，有的按天更新，有的按周；电商和社媒的风控重点也不一样。以目标平台的实际表现做最终判据，第三方查询只作参考，并且至少交叉两家。

**Q：住宅 IP 就一定干净吗？**
不一定。住宅只说明 ASN 归属是家庭宽带运营商，还要看黑名单和历史行为。一条住宅段 IP 如果被大量账号用过，同样会带风险标记——归属是必要条件，不是充分条件。

**Q：查出来有风险标记，还能用吗？**
看标记类型。如果只是代理标记，换一条同档位的线路通常能解决；如果是黑名单命中或同段被牵连，建议直接换家或换段，继续用只会把风险带到你的账号上。

**Q：检测结果每次都不一样正常吗？**
轻微波动正常。大幅跳变（今天 0 分、明天 80 分）说明数据源本身不稳定，或该 IP 正在被动态标记——判断时看连续几天的趋势，不要用单次结果下结论。

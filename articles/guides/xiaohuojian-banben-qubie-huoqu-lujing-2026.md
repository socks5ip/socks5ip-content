# 装小火箭之前，先分清来源、平台与协议

一个付费图标装到桌面上看不出任何差别，三个月后却分成三种处境：一种照常更新到最新版，一种提示"无法更新"只能停在旧版，还有一种证书到期直接打不开。Shadowrocket 官方只出了一款 App，大家嘴里的"版本区别"实际是三件事——**获取来源、运行平台、协议能力**。其中只有协议能力算真正的版本差异；另外两层造成的麻烦更多，因为装完用起来一模一样，问题要过一段时间才暴露。长期用就认 App Store 正版，而另一半决定你连不连得上，在线路上：主站聚合的主流代理线路 **2.6~4.4 元/月起**，全部支持免费测试。

## 一、把「版本」拆成三层再谈

先破一个前提：Shadowrocket 没有"标准版 / 专业版 / 旗舰版"这种分档。名字里带小火箭的 App 一大堆，官方出品只有一款。用户搜"小火箭版本区别"时，想问的其实是下面三层里的某一层：

| 层 | 讲的是什么 | 日常会被说成 |
|---|---|---|
| 第一层 · 获取来源 | 这个 App 你是从哪弄到手的 | 正版 / 共享账号 / 签名包 / 越狱源 |
| 第二层 · 运行平台 | 装在哪台设备上 | iOS 版 / Mac 版 / 安卓上那个"小火箭" |
| 第三层 · 协议能力 | 这一版支持哪些代理类型与功能 | SOCKS5 / HTTP / Shadowsocks、订阅、分流规则 |

## 二、四条获取路径：能不能自己更新才是分水岭

国区 App Store 搜不到小火箭，需要用非中国大陆区（美区、港区等）的 Apple ID 登录才能搜到并购买。这一步与"版本"无关，却卡住了最多人。绕开之后有四条路：

| 路线 | 怎么装 | 能否更新 | 主要风险 | 适合谁 |
|---|---|---|---|---|
| App Store 正版 | 用非中国大陆区账号在 App Store 购买下载 | 可以，随时更新 | 需要自备账号与付费 | 长期使用、要稳定 |
| 共享账号下载 | 登录他人 Apple ID → 下载正版包 → 立刻退出 | 需再登同一账号才行 | 账号被改密/停用；切勿登录 iCloud | 只想先试一下功能 |
| 第三方签名包 | 从第三方站安装 IPA（企业签名 / 自签） | 不能，只能覆盖重装 | 证书被吊销即闪退；包来源不明 | 设备受限、临时测试 |
| 越狱源安装 | 越狱设备加源后安装 | 看源是否维护 | 新版 iOS 基本已不适用 | 老设备、越狱用户 |

把这张表浓缩成一句：**能自己更新，才算真正拥有一个版本。** 共享账号和签名包的问题不在"能不能装"，而在装完之后你失去了更新这条退路。

## 三、iOS、macOS 与安卓上那个同名 App

| 平台 | 有没有官方小火箭 | 说明 |
|---|---|---|
| iOS / iPadOS | 有，官方版本 | 功能最全，教程与节点导入方式都以这一版为准 |
| macOS | 有独立的 Mac 版 | 需单独购买；M 系列芯片的 Mac 也能直接装 iPhone 版兼容运行 |
| Android | 没有 | 按协议选客户端：NekoBox、Kitsunebi 等，配置逻辑与 iOS 版不同 |
| Windows | 没有 | 常用 SSTap、老鱼加速器等，走进程级或全局代理 |

安卓端特别容易踩坑：应用商店里叫"小火箭"或图标相似的一大把，开发商各不相同。判断标准只有一条——**看它添加节点时支持哪些协议、开发商是不是官方那个**。装错平台的版本，后面填代理 IP 的方式全不一样。

## 四、第三层才是真正的能力差：能不能吃下 SOCKS5 代理 IP

买代理 IP 的人尤其要确认这一条，因为协议选错的表现往往不是报错，而是"连上了但没网"。

| 你要做的事 | 这个版本要满足 | 装完怎么验 |
|---|---|---|
| 用 SOCKS5 代理 IP | 添加节点时可选 SOCKS5 类型 | 保存后连接，看状态栏是否出现代理连接标识 |
| 用 HTTP 代理 | 可选 HTTP 类型 | 同上，再打开网页确认出口 IP 已变 |
| 用 Shadowsocks 节点 | 可选 Shadowsocks 类型 | 同上，部分平台把它标为"游戏协议" |
| 导入订阅链接 | 有"订阅"入口 | 粘贴订阅地址后能拉出节点列表 |
| 按规则分流 | 支持全局路由 / 规则配置 | 全局路由设为"代理"，其余按需配置 |

这里有个真实高频坑：**部分代理平台在小火箭里必须选 Shadowsocks（也就是平台标注的"游戏协议"）才能通，选 SOCKS5 / HTTP 会表现为连接成功但没网。** 原因不在小火箭版本，而是这条线路在小火箭侧的协议口径对不上——站内的[小火箭配置 Socks5/HTTP 代理图文教程](https://socks5ip.com.cn/dailigongju/shadowrocketjiaocheng-2/)里专门标了这一点。

## 五、按用途对号入座

| 你的情况 | 建议选择 | 理由 |
|---|---|---|
| 长期自己用，要能一直更新 | App Store 正版 | 账号最干净，版本随时跟上 |
| 只是想先看看界面和功能 | 共享账号下载 | 零成本拿到正版包；下载完立刻退账号、别登 iCloud |
| 设备装不上或临时用一次 | 第三方签名包 | 能用就行，别当长期方案 |
| 跑项目、要长期稳定输出 | 正版 App + 独立代理 IP 线路 | 工具版本固定后，剩下的变量只有线路质量 |
| 老设备 / 已越狱 | 越狱源对应版本 | 新版 iOS 已不适用，能用即用 |

## 六、自测口径：版本装对了，先测线路再充值

小火箭本身只是一个"把 IP 填进去"的容器。同一台手机、同一版小火箭，换上不同来源的 IP，结果可以差到判若两件事：机房 IP 便宜但更容易被识别，住宅 IP 干净但单价更高。所以选完版本，下一步是先测线路。

| 要测什么 | 对应的检测 | 看哪些指标 |
|---|---|---|
| IP 是什么货色 | IP 质量检测 | 住宅还是机房、是否独享、归属地 |
| 这条线路能不能用 | 线路可用性检测 | SOCKS5 / HTTP 真实握手是否通过、延迟分级 |
| 跑得快不快 | 网络 / 宽带测速 | 下载、上传、延迟、丢包 |
| 适不适合我的业务 | 业务场景模拟检测 | 多场景适配评分与运营建议 |

主站聚合了 **20+ 家代理 IP 平台**（奔富、天行、沧海、鲸云、光子、光梭、糖果、无双、全球代理IP 等），主流线路区间 **2.6~4.4 元/月起**，全部支持免费测试——先测再买，是这套流程里最省钱的一步。价格核实于 2026-09-14，如有调整以平台后台实时显示为准。

## 常见问题

**Q：国区 App Store 搜不到小火箭怎么办？**
A：小火箭不在中国大陆区上架，需要用非中国大陆区（美区、港区等）的 Apple ID 登录 App Store 才能搜到并购买。自己注册一个账号是最稳的路子；只想先试试，也可以先用共享账号把正版包装上。

**Q：共享账号下载的小火箭能更新吗？**
A：能更新的前提是重新登录当初下载时用的那个账号。账号被改密或停用之后就更新不了，只能停在旧版。另外两条底线：下载完成立刻退出该账号，不要登录 iCloud。

**Q：小火箭是免费的吗？**
A：不是，它是 App Store 上的付费应用，标价以非中国大陆区商店实时显示为准。市面上所谓的"免费小火箭"，基本都是共享账号、签名包或越狱源三种形态，能用，但不保证长期可用与更新。

**Q：安卓手机上能装小火箭吗？**
A：不能，安卓没有小火箭。应用商店里同名的多为其他开发者的 App，功能与配置方式都不同。安卓端按协议选客户端更靠谱，比如 [NekoBox](https://socks5ip.com.cn/dailigongju/nekoboxshiyongjiaocheng/)、Kitsunebi。

**Q：小火箭里填了 SOCKS5 代理为什么没网？**
A：多数是协议口径没对上。添加节点时选的类型要和 IP 平台实际提供的协议一致；部分平台必须选 Shadowsocks（平台标注的"游戏协议"）才通，选 SOCKS5 / HTTP 就是连上但没网。建议先用 IP 质量检测确认线路本身可用，再回小火箭核对协议类型。

**Q：一句话该怎么选？**
A：长期自用 → App Store 正版；只想试 → 共享账号下载正版包；设备受限 → 签名包临时顶；跑项目 → 正版 App 配独立代理 IP 线路。版本只是容器，节点质量才是变量。

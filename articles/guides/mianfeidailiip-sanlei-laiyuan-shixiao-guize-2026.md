# 免费代理能用多久？三类来源的出口归属与失效信号

免费不等于能长期用。把手动换线的时间损耗折算进去，公开节点池往往比 2.24 元/月的付费档更贵——**真正决定一条免费线路能撑多久的，不是它免费，而是出口 IP 归谁。**

## 一句话结论

**免费源按出口归属只分三类，失效方式互不重叠。** 公开节点池把陌生人的出口借给你，地址随时可能被回收重分；平台官方试用额度把正式线路切一小块给注册人，额度内可排期；限速免费档长期在线，但共享出口、高峰排队。回答「能用多久」之前，先确定自己在用哪一类。

| 类型 | 出口归谁 | 失效方式 | 能否排进计划 |
|---|---|---|---|
| 公开节点池 | 陌生人（多人共用） | 地址被回收重分、线路被换中转 | 不能，随时可能断 |
| 平台官方试用额度 | 注册人（额度内独享） | 额度用尽或到期，线路本身不劣化 | 能，额度内完全可排期 |
| 限速免费档 | 平台（共享 + 限速） | 长期在线，但高峰排队、并发被压 | 能长期用，吞吐做不到稳定 |

把这张表读透，不少争论会自动消失：说「免费代理不能用」的人多半一直在用公开节点池，说「免费代理挺好用」的人多半只用到了官方试用额度——他们说的根本不是同一件事。

## 第一类：公开池失效前会留下三个痕迹

公开节点池不会发公告说要停，但失效前有可观测的前兆。抓这三个信号，比反复测速度有用。

| 前兆 | 看到的现象 | 背后的机制 |
|---|---|---|
| 出口变了 | 节点还能连，但出口地址与昨天记录不一致 | 同一入口被重新分配，出口换成另一台机器 |
| 延迟量级上移 | 连通正常，延迟却比之前高出一大截并稳定下来 | 线路被换成更远的转发，或中转换了机房 |
| 行为结果抖动 | 同样的操作，有时通过、有时触发二次验证 | 出口被多人共用，行为历史互相覆盖 |

前两条可以自己验证：连续记录出口归属，再换线重复同一个业务动作。只要结果抖动，这条线路就不该继续承接有连续性的任务。

## 第二类：试用额度为什么能排进计划表

平台发放试用是获客成本，所以给的通常是正式线路的额度切片——同一个后台、同一批节点，只是限量。**这意味着它的稳定性口径与付费档一致，测出来的结果可以直接当购买依据。** 下面是站内部分平台的真实试用口径。

| 平台 | 免费测试额度 | 月卡最低档 |
|---|---|---|
| 光梭IP | 5 条/天（不限切换次数） | 2.24 元/月起 |
| 奔富IP | 先测后买（不限切换次数） | 2.6 元/月起 |
| 烽迅IP | 先测后买（不限切换次数） | 2.6 元/月起 |
| 蛟龙IP | 2 条/天（注册即享） | 2.8 元/月起 |
| JiuIP | 30 次测试卡 | 3.4 元/月起 |
| 沧海IP | 10 条/天（另带 10 次测试卡） | 4 元/月起 |
| 光子IP | 10 条/天 | 4 元/月起 |
| 糖果IP | 5 条/天 | 5 元/月起 |

另有两个不宜当「免费源」规划的平台：鲸云IP 与 优享云IP 站内参数标注不支持自助免费测试，试用要走客服按业务开通或低价自购天卡。把它们算进免费池，计划就会落空。

## 同一个月的账：把两边对齐

比价最容易犯的错，是拿「0 元」去比「2.24 元」，却把时间成本记成 0。按常见操作节奏把两种方案放进同一个月对齐看：

| 对齐口径 | 公开节点池 | 官方试用额度 |
|---|---|---|
| 每月现金支出 | 0 元 | 0 元（额度内） |
| 前期投入 | 无 | 一次注册 + 实名，几分钟 |
| 断线后的处理 | 自己找替代节点，每次十几分钟（经验估算） | 额度内换线，秒级 |
| 出口是否独享 | 否 | 是 |
| 能跑多久 | 不可预期 | 额度用尽为止，可预期 |

换个角度算：2.24 元/月 摊到 30 天，每天不到一毛钱。**为了省这一毛钱，每月多花几次十几分钟去找节点，账其实已经反过来了**——「免费代理更贵」这句话说的是总成本，不是单价。

## 这四种用法继续用免费是理性的

| 用法 | 免费够不够 | 原因 |
|---|---|---|
| 只想确认某个网站在特定地区能不能打开 | 够，公开节点池即可 | 一次性动作，失败重试成本为零 |
| 验证协议与客户端能否跑通 | 够，优先用官方试用额度 | 避免把客户端配置问题误判成线路问题 |
| 低频查询，一天几次 | 够，限速免费档可用 | 对吞吐与延迟不敏感 |
| 挂机、多开、长期采集 | 不够 | 出口共享 + 随时失效，前面跑的数据作废 |
| 按窗口数稳定跑，每个窗口一个出口 | 不够 | 需要独享出口与够用的切换额度 |

## 常见问题

**Q：免费代理到底能不能用？**
A：能用，但要分类型。公开节点池适合一次性、断了无所谓的动作；官方试用额度能承担完整流程验证；限速免费档能长期挂低频任务。三类里没有一种适合长期承载有连续性的业务。

**Q：为什么昨天还能用的免费节点，今天就失效了？**
A：公开池的出口地址不归你，被回收重分或线路被换机房都会让原地址消失。它不会通知，只能靠自查出口归属和延迟量级提前发现。

**Q：平台的免费试用额度，算不算免费代理？**
A：机制上算，性质上不同。它用的是正式线路的额度切片，稳定性口径与付费档一致，测出来的结果可以直接用作购买判断。

**Q：怎么判断手上的线路是共享出口还是独享出口？**
A：记下出口归属，过一段时间再查一次；同时用同一套操作连续做几遍，看结果是否抖动。地址变了或结果不稳定，基本就是共享出口被反复重分。

**Q：如果只是挂机，免费和付费每月差多少？**
A：站内最低档 2.24 元/月，2.6 元/月 能拿到奔富IP、烽迅IP，折到每天不到一毛钱。公开节点池的隐性成本是每次断线后自己找替代的时间，按十几分钟一次估算，很快就不止这个数。

**Q：有没有不限速、不限量的免费代理？**
A：目前站内收录的平台里没有这种形态。免费要么限额度（试用）、要么限速限并发（免费档）、要么不保证持续性（公开池），三者必占其一。

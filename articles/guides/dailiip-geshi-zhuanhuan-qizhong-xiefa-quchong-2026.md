# 代理粘进软件报格式错误？七种写法与四个真因一次改完（2026）

为什么软件总说这行代理非法？四个真因里只有两个肉眼看得见，另两个藏在换行和多余列里。

**一句话结论：**问题几乎都出在四个地方——**分隔符不认、全角符号、换行丢了、多一列到期时间**。手工改这几类问题又慢又容易改错，正确做法是过一道格式转换——**粘进去，选好输出分隔符与字段顺序，复制回来**，一次同时把格式互转、去重清洗、批量提取做完，全部在浏览器本地算，账号密码不上传。

## 一、七种写法里，只有五种能直接读

各家后台导出的写法不一样，但归根到底只有两类：分隔符文本和代理链接。

| 写法 | 示例 | 常见来源 |
|---|---|---|
| 冒号四段 | `1.2.3.4:8080:user:pass` | 多数国内平台后台导出 |
| 竖线四段 | `1.2.3.4\|8080\|user\|pass` | API 提取接口返回 |
| URL 认证 | `socks5://user:pass@1.2.3.4:8080` | curl、代理软件配置 |
| 带备注 | `1.2.3.4:8080#浙江电信` | 手动整理的节点表 |
| 多一段到期时间 | `1.2.3.4:8080:user:pass:2026-12-31` | 部分平台导出含过期列 |
| SS 链接（SIP002） | `ss://YWVzLTI1Ni1nY206cGFzcw==@1.2.3.4:8388#香港` | 机场订阅 |
| VMess 链接 | `vmess://eyJ2IjoiMiIsInBzIjoi...` | v2rayN 分享链接（Base64 JSON） |

七种写法里只有前五种是"能直接读的四段"，后两种是链接，字段位置固定。认错类型的后果是"看着都是代理，程序一个都不认"。

## 二、四个真因：两个看得见，两个不报错

**① 分隔符不认。** 软件只吃冒号，你给的是竖线；或者反过来。看着都是四个字段，解析器只认自己那一种。

**② 全角符号。** 从微信、Word、某些后台复制时，冒号会变成全角「：」，逗号变成「，」。这种行肉眼看一模一样，程序一读就报服务器地址非法。

**③ 换行丢了。** 几十条代理连成一整行，是最常见的粘贴事故。转换工具按 `IP:端口` 的模式重新切开，恢复成一行一条。

**④ 多一列到期时间。** 后台导出常带过期时间，成了五段、六段。软件按四段解析，多出来那段就被当成密码的一部分，于是"密码明明抄对了却认证失败"。

四个真因里，前两个肉眼能看见，第三个和第四个最难发现——因为它们不报"格式错误"，而是报"认证失败"或"连接超时"，把排查方向引到账密和线路上去了。

## 三、转换面板上真正要设的是三项

转换不是只换分隔符，它有三个开关要一起设。

| 设置项 | 选项 | 什么时候用 |
|---|---|---|
| 输出分隔符 | 冒号／竖线／逗号／斜杠／空格／Tab | 给软件用冒号，给表格用 Tab，给脚本用竖线 |
| 字段顺序 | 服务器:端口:账号:密码／账号:密码@服务器:端口／只要服务器:端口 | 按目标软件的输入框顺序选 |
| 协议头 | 不加、带 socks5 头、带 socks5h 头、带 http 头、带 https 头、带 ss 头（共六种写法） | 需要链接形态时加 |

选了协议头之后"字段顺序"就不参与计算了——链接里的字段位置是固定的，硬套顺序会拼出无效链接。这一条最容易出错：既选协议头又选自定义顺序，结果拼出来的链接软件不认。

## 四、去重键选错，去完还是重复

去重看着简单，选错键的结果是"去完还是重复"。

| 去重依据 | 什么时候用 |
|---|---|
| 整行完全相同 | 确认两份导出完全一样时的重复行 |
| 服务器:端口 | 最常用。同一条线带不同到期时间或备注时，只有它能识别真重复 |
| 服务器:端口:账号 | 同一个 IP 上有多个账号且都要保留 |
| 只按服务器 | 只想知道有几个不同 IP，端口不管 |

高频坑在于同一台服务器被导出了两遍、备注不同：整行比不相等，按服务器:端口比才相等。反过来，如果同一 IP 上有两个账号都要用，按服务器:端口去重会把其中一个删掉——这时候必须用三段键。

## 五、端口、零宽字符、排序：三个容易忽略的开关

**补全默认端口。** 有些平台导出只给 IP 不给端口，工具可以按 1080 补。前提是你的软件确实走 1080，不然补了也连不上——真正的服务端端口写在凭证里，平台完全可能给你 9555 之类的高位端口。

**零宽字符。** 从网页复制经常混进看不见的 U+200B，会让一行"莫名非法"。工具解析前会先清掉这类字符。

**排序按数值不按字符。** 普通字符串排序会认为 `10.0.0.1` 小于 `2.0.0.1`，按号段分段检查时会看错顺序。工具里的"IP 从小到大"是按四段转数值比较的。

**保留 # 备注。** 备注常标城市或运营商，转换后保留能在客户端里认出是哪条线；加了协议头之后备注会跟到链接尾部。

## 六、自测口径：转换完还连不上怎么办

格式对只是第一关，后面还有两关，用两步就能分开。

1. **跑一次线路可用性检测。** 单条粘进去看"可用"列。打叉说明格式对了但线路不通，查账密与到期日。
2. **连上后跑一次 IP 质量检测。** 看当前 IP 是不是你要的地区。显示本地运营商说明代理没接管，回到客户端查端口与协议类型。

两步都过还是不顺，才轮到怀疑线路质量。顺序反了会把格式问题当成线路问题，白换几条线。

## 常见问题（FAQ）

### Q：转换要联网吗？代理账号密码会不会被传走？

不需要联网，全部在浏览器本地算。想自己验证，打开开发者工具的 Network 面板，粘一段代理再操作，能看到的请求里只有功能名和行数，没有你的代理内容。

### Q：socks5 链接能转成 IP:端口:账号:密码 吗？

能，反向也行。把协议头选成 `socks5://`，一份四段列表就能批量拼成链接，不用逐条手改。

### Q：为什么去重完看着还有重复？

大概率是按"整行"去重了。同一台服务器换了备注或到期时间，整行就不相等。改成按"服务器:端口"去重才能识别出来。

### Q：粘 20 行只识别出 8 行，剩下的去哪了？

两种可能：换行丢了连成一整行，或者混进了零宽字符。勾上"修复换行"、保留默认的"剔除识别失败的行"关掉，就能看到失败行原文，逐行修。

### Q：多出来的到期时间一定要删吗？

多数软件按四段解析，第五段会被当成密码的一部分，表现是认证失败。勾"去掉多余字段"即可。如果你确实需要保留到期日，用带备注的写法放最后一段。

### Q：格式转换完还是连不上，下一步查什么？

先跑线路可用性检测看握手成不成，再用 IP 质量检测看出口是不是你要的地区。两步都不行才怀疑线路；直接换线往往白花钱。

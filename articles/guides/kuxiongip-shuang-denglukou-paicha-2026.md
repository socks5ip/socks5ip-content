## 两个后台，两套账号，先认域名

酷熊对外有两个站点，各自带一套独立账号，这就是「登不上」里最常见的那一类。企业版叫「用户网络控制台」，面向按线路和窗口买国内 IP 的人；个人版是装到电脑或手机上的加速器。官网产品区把两者的分工写在标题上，其中企业版那句最关键——「需要单独注册」。

| 项目 | 企业版（用户网络控制台） | 个人版（酷熊加速器） |
|---|---|---|
| 登录入口 | user.kuxiongip.com/login | www.kuxiongip.com 右上角「登录」 |
| 面向什么 | 单窗口 IP、静态/动态 SK5 与 PPTP/L2TP 线路 | 客户端一键加速，桌面与手机都能用 |
| 账号体系 | 单独注册，与个人版不通用 | 单独注册，与企业版不通用 |
| 要不要装软件 | 不装也能用，直接拿服务器 / 端口 / 账号 / 密码 | 必须装客户端 |
| 起始档位 | 稳定 5M 静态住宅 SK5 20 元/月 | 包月 20 元起 |

同一个「酷熊」在浏览器里可以有两个已登录状态，互不干扰。目的是管线路、看订单、提 IP，走企业版；只是想让某台设备换个出口，走个人版。

2026-10-06 实测打开企业版登录页，整个表单就两项输入：账号和密码，外加一个「记住登录状态」的勾选。这个事实本身就能解释不少疑问——很多人习惯性找图形验证码或「短信验证码登录」按钮，找不到就以为页面坏了，其实是这一版登录页压根没有这两项。

|---|---|

| 账号栏 | 提示语「使用专业版平台注册的用户名」 |

| 第三方登录 / 图形验证码 | 登录时不出现（图形码只在注册页有） |

页面右侧还列了三条登录后能拿到的东西：线路状态与异常提醒实时同步、订单续费与售后进度集中管理、异地登录验证保护账号安全。这三条本身就是「登录进去要干什么」的答案。

## 账号栏要的是用户名，手机号只是联系方式

企业版注册页的字段规则写得很细：用户名必须是 6–16 位字母数字组合且首位为字母，密码至少 6 位并同时包含字母和数字。而手机号那一栏的原文是「请输入手机号（选填，用于上级联系您）」——注意是选填。手机号既然是选填，它就不可能承担账号的角色。

| 注册时填的 | 规则原文 | 登录时对应 |
|---|---|---|
| 用户名 | 6–16 位字母数字组合，首位为字母 | 登录框的「账号」栏 |
| 登录密码 | 至少 6 位，包含字母和数字 | 登录框的「密码」栏 |
| 确认密码 | 必填，需与上一栏一致 | 仅注册时校验 |
| 手机号 | 选填，标注「用于上级联系您」 | 不作账号用，只服务于短信验证 |
| 图形验证码 | 看不清可点击换一张 | 仅注册时校验 |

这里埋着一个后面会反复用到的前提：手机号可留空，就意味着「忘记密码」这条路对没留号的人是不通的。注册时顺手填上，成本几乎为零。

## 重置密码的三段流程，卡点在第一段

点登录页的「忘记密码？」出来的是一个三段式弹窗：先「手机短信验证」，再「修改密码」，最后在「忘记密码」标题下点「确认重置」。三步顺序不能颠倒，因为短信验证通过之前，后端不会把重置权限交出来。

| 步骤 | 弹窗标题 | 要准备什么 |
|---|---|---|
| 第一段 | 手机短信验证 | 注册时留的手机号 + 收到的短信码 |
| 第二段 | 修改密码 | 新密码，规则同注册（至少 6 位、含字母与数字） |
| 第三段 | 忘记密码 → 确认重置 | 点确认重置提交，回登录页用新密码登 |
| 没留手机号 | 第一段就走不下去 | 转右下角在线客服人工核验 |
| 收不到码 | 短信延迟或被运营商拦 | 等一分钟再取一次，别连续点重发 |

重置与注册的密码规则一样，「包含字母和数字」是硬校验，纯数字会被直接挡回来。

## 异地验证弹窗是安全机制，不是故障

登录页自己列出的三条卖点里有一条是「异地登录验证保护账号安全」。所以换网络、换设备、或者从陌生城市打开后台时被要求收一条短信，是设计好的行为，不是账号被处理了。

| 弹出的窗口 | 什么时候出现 | 该怎么处理 |
|---|---|---|
| 手机短信验证 | 换设备、换网络、异地登录 | 用注册手机号收码，通过后继续 |
| 实名认证 | 首次登录或尚未实名 | 按提示完成，不实名买不了线路 |
| 警告提示 | 账号出现异常或连续失败 | 先确认是不是自己在操作，再决定要不要改密 |

如果短时间内反复被要求验证，重点不是继续点「确定」，而是回头看一眼网络环境——同一条线路上频繁切换出口，会持续满足异地判定的条件。

## 登录成功不等于能下单

使用教程里对这一步的原文是：登录时按平台提示完成实名认证，平台仅对接官方实名验证系统。也就是说登录成功和能下单是两件事，中间隔着实名。后台里的栏目也印证了这一点：

| 后台区域 | 能做什么 |
|---|---|
| 线路运行状态与异常提醒 | 看到线路当前状态，异常会在这里提示 |
| 订单、续费与售后进度 | 集中管理，续费不需要重新下单 |
| 充值中心 | 按金币制充值，1 元 = 0.9 金币 |
| 产品购买 / 订单管理 | 选线路、下单、提取 IP 信息 |
| 实名认证状态 | 未完成时会在登录后提示，完成才能下单 |

充值时数量可以自定义，所以后台看到的余额单位是金币而不是元，换算的时候别把它当成打折。

## 控制台凭据与节点凭据别用串

后台里最容易搞混的一点：进后台用的「账号 + 密码」，和填进代理工具里的那份凭据不是一回事。前者是你注册时设的用户名和登录密码，后者是买完线路后从订单里提取出来的连接信息，两边通常完全不同。

| 你要做的事 | 用哪一套凭据 | 包含什么 |
|---|---|---|
| 进后台看订单 | 登录账号 + 登录密码 | 6–16 位用户名 + 自己设的密码 |
| 把 SK5 线路填进老鱼、SSTap | 提取出来的 SK5 信息 | 服务器地址、端口、账号、密码（四项） |
| 把线路填进爱快、ROS | 提取出来的 PPTP/L2TP 信息 | 服务器地址、用户名、密码（三项） |

所以「控制台能登，工具里却连不上」通常不是账号问题，而是把两份凭据用串了。反过来说，后台能登进去，恰恰说明登录这一层是通的。

## 六种现象对应的处理方向

| 现象 | 大概率原因 | 怎么处理 |
|---|---|---|
| 输完账号密码，页面回到原样、没有报错 | 登的是另一个站，账号不属于这个入口 | 先确认域名，企业版和个人版分开试 |
| 提示账号不存在 | 把手机号当成了用户名 | 改用注册时设的 6–16 位用户名 |
| 忘记密码弹窗卡在第一步 | 注册时手机号留空 | 走在线客服人工核验 |
| 登录成功但下不了单 | 实名认证未完成 | 按登录后提示完成实名 |
| 频繁要求短信验证 | 异地或换设备触发安全校验 | 属正常机制，验证通过即可 |
| 工具里连不上、后台却正常 | 节点凭据与登录凭据混用 | 回到订单管理重新提取连接信息 |

还有一种情况是用户名怎么试都不对：如果你的账号是通过带邀请参数的链接注册的，注册页会自动确认邀请关系并绑定，但用户名仍然是当时自己填的那个，不会变成邀请码。真记不起来，就用「忘记密码」按手机号把账号找回来。

## 常见问题

**Q：酷熊的登录入口到底是哪一个域名？**
看你买的是哪一类。企业版（用户网络控制台）在 user.kuxiongip.com/login，个人版加速器在 www.kuxiongip.com 右上角。官网在产品区把企业版标注为「需要单独注册」，两套账号不通用。

**Q：登录框里能不能填手机号？**
不能。账号栏要的是注册时设的 6–16 位用户名，提示语写的就是「使用专业版平台注册的用户名」；手机号在注册页是选填项，标注「用于上级联系您」，不承担账号角色。

**Q：为什么登录页找不到短信验证码登录？**
实测这一版登录页只有账号和密码两栏，没有第三方登录，也没有短信登录按钮。手机短信验证出现在改密码和忘记密码重置的弹窗里，不在登录本身。

**Q：注册时手机号没填，密码忘了怎么办？**
忘记密码的第一段是手机短信验证，没有手机号这段就过不去，只能转右下角的在线客服人工核验。所以注册时建议把手机号填上。

**Q：为什么总是要求我收短信验证？**
登录页把「异地登录验证保护账号安全」列为卖点之一，换设备、换网络、跨地区访问都会触发。这是设计好的校验，验证通过就能继续用。

**Q：后台能登进去，为什么代理工具连不上？**
多半是把两份凭据用串了。登录用「用户名 + 登录密码」，SK5 要的是提取出来的服务器地址、端口、账号、密码四项，PPTP/L2TP 要的是服务器地址、用户名、密码三项。回订单管理重新提取一次即可。

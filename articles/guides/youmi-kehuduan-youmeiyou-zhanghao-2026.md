# 客户端里没有账号这一层

装一个客户端就能跑起来，还是必须先在一家平台注册账号？答案取决于你卡在哪一步：客户端只管把线路绑到进程上，账号只在卖 IP 的那家平台后台存在。**有米加速器没有账号体系，界面里连登录框都没有**；真正需要账号密码的是代理平台后台，那边的住宅线路 **2.6 元/月起**，登录后才能提货。

## 一、客户端和平台后台，两套东西分工不同

| 对比项 | 有米加速器（客户端） | 你买的 IP 平台后台 |
|---|---|---|
| 有没有账号 | 没有，不弹登录框 | 有，注册之后才有 |
| 你要准备什么 | 服务器地址、端口、用户名、密码 4 个字段 | 手机号或邮箱 + 平台密码 |
| 它负责什么 | 把线路绑到游戏、模拟器或浏览器的进程上 | 提货、续费、调换线路 |
| 出问题先看哪 | 客户端版本、目标进程有没有被捕获 | 账号状态、套餐是否到期 |

有米自己不提供 IP 资源，只是一个把线路分派给指定进程的调度器。你从别处买来 SOCKS5 线路，把四个字段粘进去，它再按窗口分下去——所以它既没有云端账户，也不需要登录来完成「激活」。

## 二、客户端要的四个字段，从后台哪里拿

| 字段 | 从平台后台哪里拿 | 长什么样 |
|---|---|---|
| 服务器地址 | 提货后的 IP 列表 | 形如 `1.2.3.4`，部分平台给的是域名 |
| 端口 | 跟在同一条 IP 记录后面 | 纯数字，如 `1080` |
| 用户名 | 提货时随线路一起生成 | 字母数字串 |
| 密码 | 与用户名一一对应 | 字母数字串 |

导入格式必须是 `IP|端口|用户名|密码`，中间用竖线，不要用空格或逗号。这一行写错，客户端会一直报连接失败，看起来很像「登录没成功」。

## 三、三处「登录」入口，归属完全不同

| 入口 | 在哪 | 要不要账号 | 用来干什么 |
|---|---|---|---|
| 有米客户端本体 | 你的电脑上，一个 exe 文件 | **不要** | 导入线路、把线路绑到进程上 |
| 你买 IP 的平台后台 | 该平台自己的官网 | **要** | 提货、续费、换线路 |
| 本站聚合入口与工具中心 | socks5ip.com.cn | 不要 | 找客户端下载、看教程、横向比价 |

第三处常被误解。本站是渠道聚合，不是某一家的官网，这里没有「平台账号」可登；它的作用是把人送到对的地方——要买东西去价格中心，要学配置去代理工具中心。

## 四、四类「登不上」，只有一类是真的账号问题

| 现象 | 大概率原因 | 怎么处理 |
|---|---|---|
| 官网里翻遍找不到注册或登录按钮 | 把有米当成了要注册的网站 | 它是本地客户端，去代理工具中心下载即可 |
| 平台后台输了密码进不去 | 密码记错、注册没成功、或记错了是哪一家 | 用注册手机号或邮箱找回，先确认当初注册的是哪家 |
| 导入线路后连不上，以为是登录失败 | IP 已过期未提货、分隔符写错、单 IP 窗口数超了 | 回后台看线路状态，导入格式改回竖线分隔 |
| 换了电脑，之前的配置全没了 | 客户端不连云，配置只存在本地 | 重新导入一遍，把导入用的那段文本单独存一份 |

四类里只有第二类是真的「登不上」，其余三类都不是账号问题。按现象对号入座，能省掉反复重装客户端的功夫。

## 五、区分「连不上」和「登录失败」：看报错里有没有账号两个字

有米不验证账号，所以它的提示只会指向三类：进程没被捕获、线路无法连接、导入格式不对——**从来不会说「用户名或密码错误」**。出现后者的提示，说明当时操作的是平台后台，不是客户端。

| 顺序 | 查什么 | 判断标准 |
|---|---|---|
| 第 1 步 | 线路是否还在有效期 | 平台后台能看到状态正常、未过期 |
| 第 2 步 | 导入格式对不对 | 四个字段齐全、竖线分隔、没有多余空格 |
| 第 3 步 | 目标进程有没有被捕获 | 全局设置里能看到对应的游戏或模拟器进程 |
| 第 4 步 | 窗口数配得合不合理 | 可分配数值不小于你要绑定的窗口数 |

排查完四步再回到第 1 步测一次线路质量。线路本身延迟抖动大，客户端配置再正确也跑不出稳定效果——用 [IP 综合检测中心](https://socks5ip.com.cn/ip-check-center/) 免费测一遍归属地、延迟与丢包，确认没问题再投产。另外一条经验值：**同一个 IP 绑的窗口越多，这些窗口在目标平台看来越像同一批**，多开场景保持一窗口一 IP。

## 常见问题

**Q：有米加速器要注册账号才能用吗？**
不需要。它是一款装在 Windows 上的进程级代理工具，下载安装后把 SOCKS5 的服务器、端口、用户名、密码导进去就能用，软件本身没有账号体系，也没有登录入口。

**Q：有米的登录入口在哪？官网找不到注册按钮。**
本站的代理工具中心提供客户端下载和图文教程；如果你要找的是「买 IP 的那个账号」，入口在价格中心里各平台的官方注册链接，注册后登录的是那个平台的后台，跟有米客户端没有关系。

**Q：导入线路后提示连接失败，是不是登录没成功？**
客户端不存在登录环节。连接失败的常见原因是线路已过期或未提货、字段分隔符写错（必须用竖线）、单 IP 窗口数超过可分配数、目标进程没有被捕获。

**Q：重启电脑后需要重新登录一次吗？**
不需要。客户端不保存云端会话，重启后只要配置文件和导入的线路还在就照常可用。但如果你买的是会过期的套餐，重启前先确认线路仍在有效期。

**Q：一个 IP 可以同时绑几个模拟器窗口？**
在代理管理里右键线路选编辑，把「可分配」数值改大即可，绑 2 个窗口就填 2。不过同一个 IP 绑的窗口越多，它们在目标平台看来越像同一批，多开场景建议保持一窗口一 IP。

**Q：怎么判断导入的这条线路值不值得长期用？**
先看它是不是真实住宅 IP，再看延迟与丢包，最后跑一遍业务场景模拟。这几项在 [IP 综合检测中心](https://socks5ip.com.cn/ip-check-center/) 都能免费测，先测后买比用出问题再换线路省事。

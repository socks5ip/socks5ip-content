# 电脑直连 L2TP 报 691／720／789：三个码各指向哪一层

改参数还是换线？这个判断不该靠猜，**拨号窗口弹出来的那一串数字已经告诉你答案了**：它报的是哪一层，问题就在哪一层。把码看错，就会在错的地方反复折腾一晚上。

**691 是身份验证被拒，789 是安全协商没谈拢，720 是本机到服务器的隧道根本没建起来；先看码落在哪一层，再决定动哪个格子。**

## 一张表把错误码对到层

| 错误码 | 落在哪一层 | 第一件事查什么 |
|---|---|---|
| 691 | 身份验证层 | 账号密码逐字核对、线路是否到期、是否已达同时在线上限 |
| 789 | 安全协商层 | 预共享密钥那一栏是否与平台给的完全一致（含大小写与后缀） |
| 720 | 隧道建立层 | 服务器地址是否填成代理端口、本地宽带是否本身就不通 |
| 809 | 中间网络（NAT 穿透） | 路由器或公司网关是否拦了协商用的 UDP 端口，换手机热点试 |
| 868 | 名称解析层 | 填的是域名而本机 DNS 不解析，改填平台给的 IP |

这张表的价值在于**它把「试」变成「查」**：691 去翻账号，789 去翻密钥，720 去翻地址与网络，三类动作互不重叠，也就不会互相掩盖。

## 为什么重拨十次也没用

同一个码连续出现，说明卡点是稳定的，不是抖动。L2TP 拨号是分阶段推进的：先寻址、再协商安全参数、再验证身份、最后才分配地址。**每个阶段失败都会立刻回一个专属的码，重拨只是把同一个阶段再失败一次。**

真正会变的是时间窗——有些线路对同时在线的设备数有限制，早上能连、晚上报 691，那不是密码错了，是名额被自己另一台设备占了。这类「时段性失败」要看的是平台后台的在线设备列表，不是拨号窗口。

## 15 分钟定位顺序

按顺序走，每一步都有明确的「过」或「不过」，不做无用功：

1. **先换网络**（3 分钟）：用手机热点拨一次。热点能通、宽带不通，问题在你家路由器或运营商，不在参数。
2. **再换目标**（3 分钟）：同一台机器、同一套参数，换平台给的另一个服务器地址拨一次。换地址能通，说明原来那条地址对应的节点在维护。
3. **再验参数**（5 分钟）：把账号、密码、密钥三栏对着平台后台**逐字符**念一遍。最常见的是密钥末尾多了一个空格，或者账号被误填成了注册邮箱。
4. **最后看日志**（4 分钟）：Windows 事件查看器里「远程访问」相关的记录会写明协商停在哪一步，比错误码更细。

四步走完还没通，基本可以判定不是本地配置问题。

## 那两栏最容易填错的地方

**密钥这一栏区分大小写，且不接受首尾空格。** 从网页复制时很容易把换行一起带进来，肉眼看不出来，填入后必然报 789。粘贴完先在记事本里过一遍，再手工粘进对话框。

账号栏的坑在「后缀」。有些平台给的账号是纯数字，有些带一段后缀；两者不通用。**先把平台后台「连接信息」那一块整段复制下来，再一格一格对**，比凭记忆敲要快。

## 什么情况下别再调参，直接换线

出现下面任意一条，就不要再在本地改参数了：

- 同一套参数，**换一台设备、换一个网络**依然报同样的码；
- 平台后台显示线路**在线**，但拨号报 720 或 809；
- 昨天同样的配置能用，今天什么都没改就不通，且持续超过 30 分钟。

这三种都属于线路侧的问题。站内 24 家平台的 L2TP 线路 **2.6 元/条起**，多数提供免费测试额度——手边留一条备用的，代价比停一整晚小得多。

## 连上之后还要验的三件事

拨号成功不等于能用，三格验完才算通：

| 验收项 | 动作 | 通过标准 |
|---|---|---|
| 出口是否真的换了 | 拨号前后各开一次检测页 | 出口 IP 与归属地都变了 |
| 是否整机生效 | 另开一个不相关的程序访问同一站点 | 走的是新出口，不是本机 |
| 是否稳定 | 连续访问 5 分钟、换 3 个站点 | 不掉线、不出现间歇性超时 |

第三格最容易被跳过，而它恰恰是「能连上」和「能干活」的分界。

## 常见问题

**问：691 反复出现，密码肯定没错，还能是什么原因？**
多数是同时在线的设备数已满，或者这条线路已经到期。先去平台后台看在线设备列表和剩余天数，再回来重拨。

**问：789 是不是说明线路坏了？**
不是。789 报的是安全协商没谈拢，九成出在预共享密钥这一栏：大小写不一致、末尾带空格、或者平台换过密钥而本地没更新。

**问：手机热点能拨通、家里宽带拨不通，问题在哪？**
在本地网络这一段。常见是路由器或运营商拦了 L2TP 协商要用的 UDP 端口，也可能是宽带本身做了连接数限制。这种情形改参数没用，换网络或找运营商。

**问：能连上，但浏览器打不开网页，算连上了吗？**
不算。拨号只证明隧道通了，出口是否切换、是否整机生效都要单独验。用检测页看一次出口 IP 与归属地，最直接。

**问：一条 L2TP 线路能让几台设备同时用？**
取决于平台的套餐限制，不是协议本身的限制。站内 24 家平台的线路 2.6 元/条起，多设备场景建议按设备数买对应条数，避免互相挤占名额。

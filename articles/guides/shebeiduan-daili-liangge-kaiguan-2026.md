# 电视盒子、游戏主机、NAS 想单独走代理，先在系统里找这两个开关

打开电视盒子的无线设置，翻到「代理服务器」那一栏，把地址和端口填进去、保存——退出设置再打开内置的视频应用，它照样从本地宽带出去。**能不能让一台设备单独走代理，只看系统给不给你两个开关**：一个能填 HTTP 代理的「代理服务器」，一个整机生效的隧道配置。两个都没有，这台设备就只能在上游路由器上解决。

## 客户端装不上，事情才变麻烦

客户端是厂家为某一类系统专门做的程序，装得上就能用；装不上，就只剩系统自带的能力。而系统能给的代理能力其实只有两种，很多人卡住，是因为把它们当成了一回事。

| 对比项 | 代理服务器（HTTP / SOCKS5） | 整机隧道（L2TP 一类） |
|---|---|---|
| 管到哪些流量 | 只作用于「愿意走代理」的应用 | 整机全部流量，包括不认代理的应用 |
| 归属层 | 应用层代理 | 网络层隧道 |
| 典型设置位置 | 网络或无线设置的高级项里 | 系统「添加配置 / 添加网络」里 |
| 最常遇到的拦路虎 | 应用内部自己走直连，绕过系统设置 | 系统根本不提供这一项 |

举个常见的落差：一台安卓盒子的无线设置里能填代理，但它内置的视频应用不一定读这个设置；换一台老式电视棒，连代理这一栏都没有。所以「能不能挂」的答案永远在那台设备的设置菜单里，不在任何一篇攻略里。

## 三类设备，三种待遇

按系统给不给开关，屋里的设备可以粗分成三类，先归类再动手，比一台台试快得多。

| 设备类别 | 系统里的开关 | 典型成员 | 怎么办 |
|---|---|---|---|
| 两条路都有 | 代理服务器 + 整机隧道 | Windows、macOS、安卓手机、iPhone | 逐台自己配，最省事 |
| 只有代理服务器 | 能填 HTTP 代理 | 安卓系电视盒子、Android TV | 能配，但要看应用认不认 |
| 两个都没有 | — | 封闭系统的智能电视、部分游戏主机、打印机与物联设备 | 只能走上游路由器 |

第三类是最容易被误判的一类：不是「配置没写对」，而是它根本没有入口。硬在一台设备上折腾两小时，不如把这条线接进路由器，一次覆盖全屋。

## 三条接入路径，从最省事排到最费事

把「让这台设备走代理」拆开，能走的路只有三条。选哪条，取决于设备给不给你开关，以及你愿不愿意在网络上多花一笔钱。

| 路径 | 覆盖范围 | 需要什么 | 什么时候不合适 |
|---|---|---|---|
| 逐台填系统代理 | 只覆盖这一台 | 系统有「代理服务器」这一项 | 设备上的应用不读系统代理 |
| 逐台配整机隧道 | 整机流量，含不认代理的应用 | 系统自带隧道客户端 | 系统没有这一项 |
| 上游路由器统一接入 | 全屋所有设备 | 一台支持隧道接入的路由器或软路由 | 只为一台设备弄，成本不划算 |

第三条路是很多人的最终答案，因为覆盖面是「屋里的东西」而不是「某一台设备」。代价也摆在这里：多一台路由设备、多一段配置过程，而且整屋设备从此共用同一个出口。

## 协议先看设备认哪一个

SOCKS5 和 HTTP 属于应用层代理，要应用或系统主动去用；L2TP 属于整机隧道，系统设置里配好就整机生效。设备认不认，直接决定你要在哪一类平台里挑货。

站内跨平台比价表把 23 家的协议支持列得很清楚：**19 家同时支持 SK5 + HTTP + L2TP + PPTP 四种协议**；只给 SK5 + HTTP 的是**无忧IP、百兆王IP、优享云IP、皇冠IP** 这 4 家。也就是说，如果你打算在路由器层接隧道，就得从前 19 家里选，选之前先把这一栏看清楚。

## 买之前先量三件事

设备侧的活，最容易花冤枉钱的地方是「先买了线路才发现设备接不上」。所以顺序要倒过来：

1. **先确认开关**：拿设备进设置里翻一遍，找不到「代理服务器」也找不到隧道配置，就直接跳到路由器方案。
2. **再确认协议**：要走隧道就从前 19 家里挑，别挑完才发现只有 SK5 和 HTTP。
3. **最后再谈价格**：国内起步价区间是 **2.24 元到 20 元/月**，带 L2TP 的档位多落在 **10 元/月** 上下。月卡最低档只是入场门槛，不等于你的账单。

线路到手之后，先用站内的 IP 综合检测中心免费跑一遍出口归属与连通性，再用速度实测看延迟、抖动、丢包和上下行四项评级，确认能撑住整屋同时在线，再往路由器里写配置。

## 常见问题

**Q：电视盒子的无线设置里填了代理，为什么应用还是走本地网络？**
系统代理只对「愿意读这个设置」的应用生效。很多盒子自带或预装的视频应用内部自己建连接，会绕过系统代理，这种情况只能改用整机隧道，或者在它上游的路由器上做。

**Q：游戏主机能单独挂代理吗？**
看你那台主机系统里有没有隧道配置。有的话可以在网络设置里填服务器地址；没有的话，主流做法是在同一局域网的上游路由器上接入，让主机跟着路由器走，而不是单独给主机配。

**Q：路由器接入之后，全屋设备是不是同一个出口？**
是。路由器层接入的代价就是「一个出口给所有设备」，这对只是想让某台设备能上网的场景没问题；但如果多台设备需要互不相干的出口，就不能这样接，得回到逐台配置。

**Q：为什么有些平台的线路填进软路由就连不上？**
大概率是协议没对上。只提供 SK5 + HTTP 的平台，写不出隧道参数，路由器那一步会直接失败。要在路由器层接隧道，就从支持 L2TP 的 19 家里选。

**Q：这套方案一次要花多少钱？**
国内起步价区间是 2.24 元到 20 元/月，带 L2TP 的档位多在 10 元/月上下；如果本来就要一台支持隧道接入的路由器或软路由，那是另一笔硬件支出，和线路月费分开算。

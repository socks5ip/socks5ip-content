# 代理IP入门到精通：是什么、怎么用、怎么买

## 结论

代理 IP 就是"帮你换一个网络出口地址"的服务。选 IP 只有三件事：**先弄清自己干什么（场景）→ 按场景选类型（静态/动态、住宅/机房）→ 先测后买**。

## 一、代理IP是什么

代理 IP 由平台提供服务器节点，你通过 SOCKS5/L2TP 等协议连上后，对外显示的就是节点的 IP 地址。用途集中在三类：

- **多账号场景**：同一业务多个账号，用不同 IP 实现账号安全管理与隔离
- **地区需求**：需要某个地区的出口（跨境电商用海外 IP、国内业务用国内 IP）
- **稳定性需求**：单一出口固定/可切换，适配自动化与长期挂机

## 二、核心概念速览

| 概念 | 区别 | 怎么选 |
|---|---|---|
| 静态 IP / 动态 IP | 静态=地址固定，动态=可换 | 长期项目选静态，需要轮换选动态 |
| 住宅 IP / 机房 IP | 住宅=家宽资源更"真实"，机房=服务器资源更便宜 | 对纯净度要求高选住宅，性价比优先选机房 |
| SOCKS5 / L2TP / HTTP | 连接协议 | 工具/游戏多用 SOCKS5，软路由/多设备用 L2TP |
| 国内 / 海外 IP | 出口地区 | 业务在哪就选哪 |

## 三、新手四步上手

1. **定场景**：游戏多开 / 社媒 / 跨境 / 采集，场景决定类型
2. **选平台**：参考价格中心 20+ 平台比价，看协议、带宽、调换次数
3. **注册领测试**：几乎所有平台都支持免费测试，先测归属地、延迟、稳定性
4. **导入工具**：电脑用老鱼/SSTap，安卓用 Kitsunebi，软路由直接配 L2TP

## 四、避坑提醒

- 不只看低价：2 元/月的基础套餐和 20 元/月的高纯净套餐，场景不同没有绝对好坏
- 认准免费测试：不支持先测的平台，谨慎下单
- 合规使用：代理 IP 用于合法业务场景，账号安全管理是正道

## 常见问题

**代理IP合法吗？** 作为网络工具本身合法，用于多账号管理、跨境业务等场景时注意遵守平台规则与当地法律。

**第一次买多少？** 建议先按月买 + 免费测试验证，稳定后再按季度/包年降低成本。

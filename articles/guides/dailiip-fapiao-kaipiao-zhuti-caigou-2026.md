# 票面只认实付：企业采购代理IP 的发票怎么处理

票面金额只认你实付的那一笔，赠额与折扣都不进成本——**充 100 送 25，票面仍然只写 100**。代理IP 的发票由收款的那家平台开具，聚合导购站不收你的钱，也就没有开票能力，所以「这一单能不能报」必须在付款前问清楚。

## 谁收了你的钱，谁给你开票

企业采购最容易错的一步，是把「入口」当成「收款方」。全网低价IP（socks5ip.com.cn）做的是聚合导购：把各家平台的价格、测试额度和线路整理到一起，点进去之后钱是打给平台的，后台里那个「发票 / 财务」入口属于平台自己的控制台。三条常见付款路径对应的开票方并不一样：

| 你的付款路径 | 谁收到钱 | 谁开票 |
|---|---|---|
| 直接在各平台官网或后台充值 | 该 IP 平台 | 该平台 |
| 通过聚合导购站的优惠入口跳转过去充值 | 仍是该 IP 平台（链接尾巴上只是带了一串邀请码） | 仍是该平台，与走不走导购入口无关 |
| 走第三方分销、代理商或同事代付 | 代收的那一方 | 一般由代收方开给你，平台不会重复开票 |

站内有一篇把单家平台的开票路径写全了：天行IP 登录入口与账号管理，给的路径是「登录后台或联系官方在线客服，提供开票抬头和充值订单信息」。这个结构在同行里很典型，可以当成模板去套别的平台。

## 普票四项资料，专票再加四项

报销被卡，多数不是平台不开，而是资料给少了。普通发票和专用发票的门槛差在四项企业信息上：

| 资料项 | 普通发票 | 专用发票 | 填的时候要留意 |
|---|---|---|---|
| 企业全称 | 需要 | 需要 | 与营业执照逐字一致，括号、空格、全半角都别自己改 |
| 纳税人识别号 | 需要 | 需要 | 18 位统一社会信用代码，抄错一位就得作废重开 |
| 开票项目名称 | 需要 | 需要 | 平台多为技术服务费一类，具体品名以平台为准，不要自己指定 |
| 接收方式 | 需要 | 需要 | 电子票发邮箱、纸票要收件地址，邮箱建议用能长期收信的财务公邮 |
| 注册地址 | 不需要 | 需要 | 营业执照上的注册地址，不是办公地 |
| 注册电话 | 不需要 | 需要 | 工商登记留的那个号码 |
| 开户银行 | 不需要 | 需要 | 支行全称也要写全 |
| 银行账号 | 不需要 | 需要 | 对公基本户或一般户账号 |

部分平台在首次开专票时会额外要一份盖过章的开票信息表模板，或要求核验一般纳税人资格。这类材料准备一次可以长期复用，建议和营业执照扫描件放进同一个文件夹。

## 赠送的额度不会出现在票面上

平台开票的依据是实际收取的款项，赠送额度、优惠券、折扣让利都不是计税销售额的一部分，所以下面几张票的金额都只等于你付款的那一边：

| 你实际做的动作 | 票面金额 | 原因 |
|---|---|---|
| 充值 100 元，另外送 25 元额度 | 100 元 | 赠送部分没有对应收款 |
| 月卡标价 20 元，用邀请码打完折实付 16 元 | 16 元 | 折扣让利不进票面 |
| 年付 360 元，另赠 60 天使用期 | 360 元 | 多送的天数不是钱 |
| 只用免费测试额度、测试卡，没有付款 | 不开票 | 没有实际付款就没有票 |
| 对公转账预存 5000 元 | 一般按实收 5000 元开 | 后续按次消耗不再重复开票 |

少数平台按自然月汇总开票，把当月几笔充值合成一张，但金额仍等于当月实付总额，不会因为合并而变多。想在同样业务量下把票面做高，唯一办法是提高实付金额，而不是想办法把赠送塞进去。

## 跨月能补，跨年多半补不了

开票不是随时都能补的动作，它有时间窗，而且和退款会互相卡住：

| 环节 | 常见口径 | 你要提前留的余地 |
|---|---|---|
| 充值完成后 | 多数平台随时可申请，当月最晚次月办结 | 别攒到年底一次性申请 |
| 跨月补开 | 一般仍可补，但需要说明并核对订单 | 把订单号、实付金额记在同一个表里 |
| 跨年补开 | 多数平台不愿意再开上一年的票 | 每年 12 月中旬前清一遍未开票订单 |
| 申请退款 | 已开票的订单通常要先作废或红冲，退款流程才继续 | 确定要退的订单，先别急着开票 |
| 纸质专票开错 | 要把原件退回平台后才能作废 | 收到票据当天就核对抬头、税号、金额三项 |

「先开票还是先退款」这个顺序问题，站内已经有一篇专门整理各平台退款口径与申诉路径：[代理IP 能退款吗？各平台政策与申诉路径](https://socks5ip.com.cn/zuixinzixun/zonghejiaocheng/dailiip-neng-tuikuan-ma-zhengce-shensu/)，两篇对着看能省掉一次往返。

## 财务退回单子时那句话，对应哪个动作

退回理由往往只有一句话，但背后对应的是不同的处置：

| 被退回的说法 | 大概率的真实原因 | 怎么处置 |
|---|---|---|
| 抬头和营业执照不一致 | 用了简称、多了空格、括号用了半角 | 按营业执照逐字改，走作废或红冲重开 |
| 税号对不上 | 识别号抄错一位，或写成了旧的工商注册号 | 换成 18 位统一社会信用代码 |
| 金额和付款记录对不上 | 票面含了赠送部分，或把多次充值并成一张 | 按银行流水或支付记录的实际付款额重开 |
| 开票项目名称不合适 | 品名与公司费用科目不匹配 | 先问平台可选品名范围，再和财务确认能入哪个科目 |
| 怎么是普通发票 | 公司需要进项抵扣，但一开始没说要专票 | 确认平台能否补开专票；不能补就下次换一家 |
| 已经跨月了 | 错过当月作废窗口，只能走红冲 | 准备一份简短说明，配合平台走红冲流程 |

## 四个问题必须在付款前问掉

把问题前置到付款之前，是最省钱的一条建议。四句话问完，绝大多数报销问题都不会发生：

| 要问的问题 | 为什么要先在付款前问 |
|---|---|
| 能不能开增值税专用发票？ | 确实有平台只支持普通发票，钱充进去再问，只能走退款或自己承担 |
| 票面按实付金额还是按充值额开？ | 直接决定赠送部分能不能进你的成本核算 |
| 开票周期多久，跨月还能不能补？ | 决定财务月末能不能结账，也决定订单号要不要单独记账 |
| 已开票的订单要退款怎么处理？ | 把「先开票还是先退款」的顺序提前定下来 |

企业采购的常规流程建议照这个顺序走：先用免费测试额度验一轮线路质量，再小额充一笔把开票流程跑通，确认票能到手、科目能入账，最后才谈批量采购。各家的起步价、协议与测试额度可以直接在[跨平台比价页](https://socks5ip.com.cn/dailiip-jiage-duibi/)横向看。

## 三条不能协商的底线

能协商的是速度、周期和收件方式，不能协商的是票面本身。第一，不要为了凑报销额度要求把金额开高，票据金额必须与实际付款一致；第二，不要要求平台把品名改成与实际业务无关的科目，平台拒绝是正常的；第三，不要拿同一次付款去开两张票，重复开票被发现后，红冲责任落在你这边。

凭证也建议留全：订单号、支付截图或对公转账回单、线路清单，和发票放在一起归档。线路清单可以用 [IP 综合检测中心](https://socks5ip.com.cn/ip-check-center/)把出口 IP、归属地和连通性测一遍留档，验收和报账都能用上。

## 常见问题

**Q：代理IP 的发票是导购站开吗？**
A：不是。全网低价IP（socks5ip.com.cn）是聚合导购站，不收你的钱，也没有开票资质。发票由你实际付款的那家 IP 平台开具，入口一般在平台后台的财务或订单区域。

**Q：充 100 送 25，能开 125 的票吗？**
A：不能。票面金额按实付金额开，赠送与折扣部分不属于计税销售额，只能开 100。想让票面更高，只能提高实际付款金额。

**Q：开专用发票要提供哪些资料？**
A：在企业全称与纳税人识别号之外，还要补注册地址、注册电话、开户银行、银行账号四项；部分平台还会要求首次开票的资料表模板，或核验一般纳税人资格。

**Q：个人账户付款，能开企业抬头的发票吗？**
A：多数平台可以，付款方式不影响抬头，关键是开票信息与实际业务主体一致。如果实名认证的账号主体和开票抬头不是同一家，有些平台会要求说明用途，最好先问清楚再充值。

**Q：发票开错了能重开吗？**
A：可以。当月一般走作废重开，跨月多数走红冲后再重开。纸质专票需要把原件退回平台才能作废，所以票一到手就先核对抬头、税号、金额三项。

**Q：已经开了票，还能退款吗？**
A：通常要先处理发票——作废或红冲之后退款流程才继续，这也是企业月底集中申请退款时最容易卡住的一环。各家条款不一样，建议对照退款政策逐家确认。

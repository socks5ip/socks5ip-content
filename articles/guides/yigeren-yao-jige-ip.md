# 一个人做跨境/多开业务，到底要几个IP？

## 一句话结论

**单人业务按"核心账号数 + 批量任务并发"算，多数人 1-4 个出口就够**：1 个核心店铺 = 1 条目标国静态住宅；再加批量采集 = 1 条动态；游戏多开就按同时上线的号数补静态/独享。一上来买一堆 IP 的人，九成在给闲置付费。

## 计算公式

```
需要出口数 = 核心账号数（一账号一静态出口）
            + 批量任务并发组（采集/批量按组配动态）
            + 游戏多开同时在线档（重度场景另算）
```

**核心原则**：账号类业务"一账号一出口"不可省；采集类按并发"够用即可"；两条线分开算，别混买。

## 三种典型单人配置

**人设一：单店跨境卖家**
- 1 个店铺后台 → **1 条目标国静态住宅**（核心，预算重点）
- 选品/比价/素材采集 → 1 条动态机房即可
- 合计：**2 条线，约 15-50 元/月**

**人设二：矩阵运营（3-5 个社媒/店铺账号）**
- 3-5 个核心账号 → **3-5 条静态住宅**（账号各占一出口）
- 日常素材上传 → 共用 1 条大带宽动态
- 合计：**4-6 条线**（账号少的可先 2-3 条起步）

**人设三：游戏工作室（多开 10-20 窗口）**
- 主力号 2-3 个 → 静态独享 100M 档（如 8 元/月档×2-3）
- 其余小号 → 动态轮换补充
- 合计：**3-6 条线按并发买**，先小后大

## 三条红线

1. **核心账号绝不共用出口**——两条店铺线挤一个 IP，被关联的损失 > 省下的钱
2. **采集线和账号线分离**——采集出口被反爬标记不会连累账号
3. **先 1 条跑通再扩**——单人业务先最小配置验证流程，业务量确认了再按公式加

## 常见问题

**Q：可以 1 个 IP 带 2 个同平台账号吗？**
不推荐。同平台多账号共用出口是关联判定最直接的信号；不同平台（如店铺+广告账号）在出口层面风险低些，但仍建议分开。

**Q：动态线能不能临时当账号线用？**
低频、非核心操作勉强可以；长期运营账号别用动态轮换线——出口变化本身就是异常信号。

**Q：预算只够买几条，优先保谁？**
保核心账号的静态/住宅品质，批量任务用最便宜的动态顶着——顺序错了钱白花。

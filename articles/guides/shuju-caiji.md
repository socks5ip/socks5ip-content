# 数据采集用什么代理IP？并发、轮换与成本平衡

## 结论

数据采集选 IP 看三个数：**并发、轮换、成本**。量小用动态住宅，量大用动态机房或大带宽静态，关键是先小规模实测目标站点的容忍度。

## 三个关键点

| 点 | 说明 |
|---|---|
| 并发 | 目标站点允许多少并发，决定要多少 IP/带宽 |
| 轮换 | 目标站是否反爬，决定动态轮换频率 |
| 成本 | 采集量 × 单价，动态机房最便宜、住宅最贵 |

## 怎么选

- **小规模/低频采集**：动态住宅 IP，纯净度有保障，成本可接受
- **中大规模/高频**：动态机房 + 代理池轮换，性价比最高
- **长期稳定抓取**：静态大带宽，配合合理的抓取频率
- **反爬严格的站**：住宅 IP + 低频率 + 真实 UA，别硬刚

## 配套工具

- 代理线路可用性检测：批量验证代理池连通性
- 网络测速：确认带宽达标
- 价格中心：按预算筛选支持 API 提取的平台（如优众支持 API 批量提取）

## 常见问题

**采集会被封吗？** 合规采集 + 合理频率 + 纯净 IP 能大幅降低风险，但目标站规则要自己遵守。

**API 提取重要吗？** 自动化采集强烈建议支持 API 提取的平台，手动复制效率太低。

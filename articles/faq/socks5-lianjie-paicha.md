# Socks5连接失败排查10问

## 一句话结论

**Socks5 连不上 90% 出在四类原因：地址端口填错、认证信息错、本机防火墙/安全软件拦截、目标站点限制。** 按下面的排查顺序走一遍，多数 5 分钟能定位。

## 连接失败排查顺序

### 第一步：先确认"能不能连"

**Q1：提示"连接超时/无法连接到服务器"怎么办？**
先 ping 不通不代表代理不可用（很多节点禁 ping）。直接测 TCP 端口：用工具连接 `IP:端口`，能通说明线路通；不通检查 IP 是否输错、端口是否填对（常见 1080/8080/端口号记混）。

**Q2：提示"连接被拒绝(Connection refused)"？**
端口没开或填错，或该节点仅授权特定协议。核对套餐协议是否包含 SOCKS5，换平台提供的标准端口重试。

**Q3：提示"403/目标站点拒绝"？**
代理本身通，是**目标网站**拒绝了这个 IP 的访问（地区限制/风控/被标记）。换地区节点或换纯净度更高的线路。

### 第二步：检查认证与软件设置

**Q4：提示"认证失败/401"？**
账号密码填错、或把"提取码/邀请码"当密码填了。在平台后台复制"连接账号+连接密码"（不是登录密码），注意区分大小写。

**Q5：软件里协议类型选错？**
填 `IP:端口` 的地方要选 SOCKS5（不是 HTTP）。有些软件默认 HTTP，Socks5 填进去会报协议错误。

**Q6：提示"远程主机拒绝认证方式"？**
部分节点只支持用户名密码认证。软件里勾选"需要认证"并填入账号密码，别留空。

### 第三步：检查本机环境

**Q7：本机防火墙/安全软件拦截？**
Windows 防火墙、杀毒软件可能拦截代理客户端出站。把代理软件加入白名单，或临时关闭测试一次区分。

**Q8：系统代理设置冲突？**
如果系统全局代理和其他代理工具同时在跑，会互相覆盖。关掉其他代理（包括系统"设置-网络-代理"里的残留），只保留一个。

**Q9：浏览器能上但软件连不上？**
浏览器可能走了插件代理。给软件单独填代理时，确认填的是 IP:端口+协议+账号，三样齐全；有的软件还要求填 SOCKS5 的主机名与端口分开填。

### 第四步：确认线路本身

**Q10：换了软件还是连不上，是线路坏了吗？**
用平台提供的**测试工具/备用节点**验证：多给几个节点都试。如果全连不上，可能本机网络到节点段被限制（企业网/校园网常见），或节点故障需找客服换线。

## 排查清单速记

| 现象 | 优先检查 | 常见解法 |
|---|---|---|
| 连接超时 | IP/端口是否填对 | 核对后台信息，测 TCP 端口 |
| 连接被拒绝 | 协议是否含 Socks5 | 换标准端口，确认套餐协议 |
| 认证失败 | 账号密码是否复制错 | 用"连接账号/连接密码"，区分大小写 |
| 403/被拒 | 节点地区/纯净度 | 换地区，换高纯净线路 |
| 软件报协议错 | SOCKS5/HTTP 选错 | 明确选 SOCKS5 |
| 全节点连不上 | 本机网络到节点段 | 换网络测试，或联系客服 |

## 常见问题

**Q：排查完还连不上怎么办？**
把报错原文+节点信息发给平台客服（微信/工单），一般能远程定位。正规平台都有响应及时的客服，这也是买前就该验证的一项。

**Q：哪类工具对 Socks5 支持最稳？**
主流的代理客户端、游戏加速类软件和采集工具都原生支持 SOCKS5。相关工具可在[代理工具中心](https://socks5ip.com.cn/dailigongjuzhongxin/)查阅，先测后买。
